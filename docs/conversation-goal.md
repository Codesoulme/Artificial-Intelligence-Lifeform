# 中文交流持续迭代目标

授权：用户于2026-11-06要求持续迭代，直到能够正常聊天。阶段汇报和提交不视为整体完成；不以模板物品题的高分代替聊天能力。

先修复有限读取稳定性，同时准备有来源与许可的中文教材。学习材料可以包含现成模型生成的文本，但不下载或使用其预训练权重，不调用其他模型代答本地用户。训练材料不自动作为个体亲历。

正常聊天的本地最低交付标准预先定义为：独立新题覆盖问候、日常解释、简单建议、复述、指令跟随、信息不足时澄清、两至五轮对话中的指代和纠正。至少60个对话场景、300个用户轮次，合理比例为自由表达；每轮逐项评定相关性、可理解性、前后衔接、事实与未知表达，不以含关键词就算正确。基本有效轮次至少90%，各类不少于80%，中文编码合法及正常终止至少99%，严重机械重复和无关输出低于5%。这些是工程发布下限，不代表达到市售通用模型水平。

开发题可反复用于改进；最终题应在候选和标准冻结后另行构造，检查与训练语料近似重复，不供训练和选点。模型若失败，保留题目和失败输出；下一轮使用新的最终题。需保留完整对话原始生成，由人工逐条审查，自动指标只能辅助。自评与独立用户使用仍有差距，应如实说明。

交付还包括本机可启动的多轮入口、明确加载版本、原个体文件核对、延迟和内存实测、长输入截断的可见行为、冻结旧检查点与回滚。旧符号记忆需继续通过重启核验。使用文本上下文回答不称持久回忆；自然语言写入与跨重启回忆另立验证。

路线：P22d先测试同世界两种已知对象加未知对象与逆序的配对监督；P23准备真实中文覆盖、适合中文的紧凑编码与更长输入，采用与旧个体隔离、可追溯的研究语言路径。参数扩展须以本机吞吐与独立表现决定。避免把无限修补单一合成题作为学习中文的替代品。

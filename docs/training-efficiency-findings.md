# 训练效率检查（2026-11-08）

当前维持F既定配方。两项候选都只在临时副本测量，没有把更新写回训练状态。

每批16条时，单次处理4→16条的小网络满512位置短测速约0.492→0.463秒，只改善约6%；大结构4→8条约1.196→1.148秒，约4%。首更新有约3e-6至6e-6的张量差异，没有通过原先严格的2e-6级一致性判断，因此不把它当成位级透明恢复。损失接近不代表长期训练轨迹一致。

新增受监督位置投影：注意力与记忆读取仍处理完整输入，仅在有效标签处计算词表输出。单元测试和两种训练状态的GPU梯度检查通过，最大初始损失差不到1e-5。但同样每次处理4条时提速不普遍，全位置预训练反而更慢；同时增大处理条数的试验不能把收益独立归给投影方式。暂不用于正式训练，也不宣称已获得稳定提速。

本机有其他负载，检查时CPU利用率曾约76%；不同时间的绝对耗时不宜直接比较。接下来如继续评估，需在同负载下交错比较大批量dense与selected，并分别统计教学／预训练、显存及完整运行成本。当前应优先完成语言与容量对照，避免为微小工程收益频繁重置训练。

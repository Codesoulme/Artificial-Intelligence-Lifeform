# 开源语言骨干与孢子记忆：独立实验

本分支从 `research/language-ladder` 的 `6087e1c` 分叉。原随机初始化语言谱系的目标已暂停；现有个体、检查点和失败记录保留。本实验使用已有预训练权重，语言知识、偏好和指令行为来自所选基础模型，不能称为孢子从零学会中文，也不能将底座回答当作原个体记忆的证据。

## 基底与资源

首选 [Qwen2.5-0.5B-Instruct 固定修订](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct/tree/7ae557604adf67be50417f59c2c2f167def9a775)，模型卡声明 Apache-2.0；权重约 988 MB、配置 24 层、隐藏宽度 896。硬件是 6 GB GTX 1060 Max-Q，不支持依赖原生 BF16 的加速；读取时明确转换为 FP16。模型文件及临时依赖仅放在 `runs/`，不加入 Git。CUDA 上可用显存和实际性能须以运行时测量为准，不能从权重体积推断训练可行。

实验包单独安装在 `runs/open-base-deps`，不更改原项目 `.venv` 的已安装包；使用原虚拟环境的 PyTorch 2.5.1 CUDA，通过显式路径加载 Transformers 4.57.6 及配套包。基础模型、词表及个体按摘要校验；不运行远程模型代码。模型下载路径和底座版本会在运行记录中固定。

## 结构路线

1. **原始基线**：同一底座、同一提示和解码设置下记录中文生成、用时及显存。此时没有接入孢子记忆，生成文本不代表孢子本人的记忆或能力。
2. **层内读取**：在解码层的隐藏状态加入可训练的神经记忆残差读取，直接读取原个体的当前矩阵和历史页，而不把原始记忆拼成文本提示。新接口初始化为零影响，首先验证关闭或零初始化时与基线数值一致；非零接口应能读取不同状态并改变模型内部计算。这只证明数据流连通，不证明记忆语义对齐。
3. **有限适配**：单独保存接口权重，在独立副本上训练其读出，原个体和底座权重默认冻结。分别使用已记录、未记录、纠正和历史状态做保留与拒答对照，并比较屏蔽或替换记忆的结果；需要保留未参与训练的实体及问法，验证重启与不同调用入口。受控符号数据不是自然语言自由聊天的充分验收。
4. **逐步重构**：在对照结果支持时再研究写入、持续活动、睡眠及其他模块。替换底层骨干不是简单重排参数，形状或计算方式不匹配时需要训练、迁移或重新初始化；不能承诺完整替换后保留全部底座能力，也不能保证形成主观意识。

实验中不向已有个体写入、不覆盖或迁移历史文件；后续如进行写入实验，必须使用隔离副本并记录前后状态。模型接口需要关注 KV 缓存与记忆版本一致性，不能在复用旧缓存时静默切换记忆。

## 本机复现

以下命令在 `D:/SPORA` 运行。前提是保留本机的固定版本模型文件、原个体和 `runs/open-base-deps/`；这些大文件和本机包不随 Git 提交。

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_open_base_memory tests.test_open_base_synthetic_alignment
.\.venv\Scripts\python.exe -m scripts.open_base_synthetic_alignment --steps 400 --output runs/open-base-synthetic-new
```

训练命令要求输出目录不存在，不会覆盖此前的检查点。它训练的是人为设置的矩阵信号，不会向真实个体写入；参数只能用于该合成任务。原始基线和结构探针使用固定输出文件，已存在时会拒绝覆盖，需保留旧结果并修改输出位置后复现。

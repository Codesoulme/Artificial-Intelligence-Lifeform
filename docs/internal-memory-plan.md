## 当前实施单元

1. **P12 写入判定与来源表征**：从随机初始化训练小型判定网络，输入有限符号环境给出的来源类型、证据质量、旧判断及有效时刻，区分新增、纠正、加强依据、重复、待定。输入可信程度是环境提供的课程特征，不声称已经自行辨认真伪。假设与模拟通过明确保护规则禁止改写当前事实，所有收到的输入仍保留历史。历史来源和判定写入关联神经矩阵，与主记忆同事务保存。旧个体缺失的来源标记未知，禁止补造。
2. **P13 有预算的内部读取**：以实际历史矩阵训练小型低秩得分近似，先估计相关区域，再计算候选。以近似矩阵残差给出遗漏误差上界，不能满足门槛则全读。检验4/8/16个实际写满的段，记录延迟、额外张量、构建开销和回退。已有字节接口未学语义，本轮不能宣称语义寻址完成，也不以随机接口上的加速作为保证。
3. **变化触发的有限整理**：用新增信息、纠正次数、完整段与有限预算决定是否建议整理；实际转存复用P10已有蒸馏与行为门槛。触发不等于通过，失败保留原状态；不生成想象经历。

固定协议见[配置](../configs/p12-p13-plan.json)。每个判定类别至少95%，历史、当前值和来源读取分别验收；两类虚构来源禁止改写。路由输出与全读比较，每次读取误差上限1e-4；默认启用还需有真实成本收益。三随机种子、独立审计、重启/事务/扩容/睡眠兼容及旧文件校验均需记录。

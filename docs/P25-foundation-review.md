# P25：结构基础复查与有限修补

日期：2026-11-08。基线提交：1985f43。用户要求先检查并打牢基础，再开展后续能力。此次没有扩大中文训练、导入外部权重或替换默认聊天入口。

## 判断

当前最紧迫的问题是信息接口与模块整合，而非继续堆叠功能名称。现有个体能够保存多种神经模块，但“保存在同一份个体中”并不代表它们已通过共同表征协作。已有语言骨干使用因果注意力、RoPE、RMSNorm、SwiGLU与共享输入输出词表；这些组件本身并不构成语言学习障碍的证据。

核心有值得保留的基础：当前／历史分离、局部写入、纠正保护、来源与模拟边界、事务保存、原个体保护，以及独立任务中的循环规划。但不能据此宣称整体优于常规模型。

## 实际结构与限制

检查的是源码、原个体以及P23/P24实验；图索引缺少较新的conversation模块，对已知文件直接核实源码。

| 部分 | 现状 | 需要解决的基础问题 |
|---|---|---|
| 个体记忆 | 64个符号实体，16种已知值；当前正交地址、历史RLS；每段64次事件，最多16段 | 实体和值的开放语义尚未建立，不能无限增长；来源质量仍由环境声明 |
| 中文路径 | 约861.6万可训练参数，另有加宽至约3008万的研究候选；两处只读记忆接入 | 无中文写入闭环；旧读取会混淆当前与历史角色，未读取来源、不确定性与世界预测 |
| 清醒模块 | 244个学习参数，有限图上的循环规划；状态可保存 | 与中文、长期经历、旧时间模块之间没有共同工作表征；自定目标未建立 |
| 时间与世界预测 | 有真实时长记录、有限动力学预测 | P11和P24分别维护运行状态；整合时需统一事件与时钟契约，不能相加当成总体验时长 |
| 睡眠 | 历史段压缩、行为保持检查；清醒核心可暂停 | 尚无完整想象、跨模块回放、语言语义巩固 |

本次检查的prechinese-v3父个体已有72次符号观察，分配4段，其中2段尚未写入；核心及附件共1,052,725个参数。当前、历史与控制状态另行计费。原文件中的time_world、write_control、semantic_memory和skill_policy是存在的；P24新增awake_core，但语言路径没有因此自动使用它。

## 发现一：旧中文读取存在可证明的角色信息丢失

P23的`ConversationBridge.read_memory`对当前矩阵和所有历史段使用同一查询、同一评分与加权求和。令各段读数为vᵢ=Mᵢq，输出为Σsoftmax(q·vᵢ)vᵢ。它对矩阵排列不敏感，既没有当前／历史标签，也没有历史段序。

因此，当两个个体只在“当前与历史互换”上不同，而输入文本相同，该路径产生相同结果；下游层再大也无法仅从相同输入恢复被丢弃的角色。早期字节接口有page_key，新中文实现没有保留这一设计。这个结论限定在该读取通路，不能推断骨干完全不能学习文本中的时间关系。

已实现可显式选择的`memory_read='typed_v1'`：

- 当前读数与历史读数先拼接，再由学习投影接入语言层，保留两种角色。
- 历史路由加入可学习段位置键；它只是段序，不冒称已理解事件日期。
- 只纳入cursor覆盖的段，未写入的预留容量不参与归一化；零历史时历史通道为零。
- 封存段使用L(Rq)直接读取，不先重建LR及本次无需使用的精度矩阵。写入与未知判断所需的精度状态仍保留，没有删除。

对标准宽度256、记忆宽度90，候选增加48,960个参数，约为原语言路径的0.57%。没有增加个体经历，也没有改写原始矩阵。

版本兼容：未声明memory_read的旧检查点仍按legacy加载；不能只改配置文字把旧权重当成新结构。新版本的输出投影形状不同，必须建立有明确迁移与训练协议的新候选。加宽映射已支持新读法，前向保持经过验证；这不代表两个读法之间存在无损迁移。本轮没有发布新的中文训练权重，也未切换默认入口。

## 发现二：容量预留会影响旧读数

旧路径读取全部分配段，包括没有新增经历的初始矩阵。多预留几个空段就改变softmax分母与读数，造成“没有学习新东西，却改变了读取”的行为。结构见证中旧结果最大差异约0.01346；新候选为零。

这项修补只解决整段未写入的情形。已用段中哪些地址缺乏证据，当前通道哪些内容是未知，仍须由未来的证据读取与拒答机制处理，不能把整段掩码当作完整的事实校准。

## 发现三：持续写入与逐步生成之间缺少一致性边界

原逐步生成接受已有注意力中间状态，却没有绑定生成它的个体记忆与模型参数。当记忆写入、对象替换、扩容或权重更新后继续沿用，会混合不同版本的计算。

已加入`ConversationPast`，绑定模型、张量身份、正常PyTorch更新版本及事件游标；在前向开始和结束核验。发生变化时明确要求用完整前缀重新计算，而非继续使用旧状态。无变化时数值计算不变。普通全序列训练不产生这类状态。

限制：这是版本一致性检查，不是跨线程事务锁。未来统一运行器仍需采用单写入者或锁定快照；不得直接通过`.data`或其他绕过版本计数的方式修改张量。无版本计数的推理张量不允许用于该增量接口。时间计数、图规划等本来不参与语言读数的工作状态，不因此被宣称已接入。

## 实验与自审

- 结构见证：旧读法交换当前／历史，差异为0；新通路约0.04246，能够保留角色差异。新方法对预留空段保持严格不变。
- 下游可读性实验：三种种子，每种256对训练样本、另外256对未见样本。每对保持查询与内容集合相同，只交换角色；目标为当前值。相同130参数线性读出器训练200步，旧表示50%，新表示100%。总计1536条未见样本。它证明这个特定信息缺口可修复，不证明中文理解、任意历史检索或总体智能提升。该实验训练的是读出器，未训练中文骨干。
- 因子读取：float64输出与查询梯度对照通过，因子不接收写入梯度；float32短测最大误差低于7×10⁻⁸。90维、rank16、单线程CPU交错测速中，两种长度下直接读取约0.043/0.066毫秒，原展开路径约0.392/0.372毫秒。仅是局部运算测量，机器存在其他负载，不是整模型速度或功耗承诺。
- 真实P23f-small2000检查点对照基线源码：整段输出逐位相同，12步生成序列一致，原文件和个体张量不变；使用数值前缀做回归，不计作中文质量测试。
- 覆盖旧格式恢复、新格式恢复、角色与段序、空段、封存读取、梯度、冻结保护、加宽、分段生成、状态变化拒绝与前向中途修改。最终回归数量与日志摘要见[报告](../reports/P25-foundation-results.json)。
- 最终完整回归151项通过，43.636秒。状态中途变化保护加入后，另外重查真实旧语言检查点，输出及原文件仍保持一致。

## 下一步的结构优先级与验收门槛

| 顺序 | 优化内容 | 开展下一阶段前应得到的证据 |
|---|---|---|
| 1 | 语言—经历语义连接：分别学习实体、当前／历史意图、时间与来源查询；依据不足能输出未知 | 同一中文问题在写入、纠正、历史查询、重启后符合个体状态；对未见实体／措辞分开测试；遮蔽或替换对应记忆能因果改变答案 |
| 2 | 稳定地址与写入边界：保持地址空间版本，防止语言表示更新使旧经历无法定位 | 中文训练后旧读写地址行为不漂移；可信纠正有效，推测不覆盖事实；来源与低置信度按独立任务验证 |
| 3 | 共同工作状态：目标、观察、待解决问题、预测、来源与时间通过有类型的状态交互；统一时钟与单写入者 | 一个目标无新提示可推进，语言能准确说明状态；中断／唤醒／重启不串状态；仍区分显式记录与学习表征 |
| 4 | 按收益调算力：选择是否继续推演、读记忆或请求观察 | 与固定预算同任务比较完成率、遗漏、时延及真实CPU/GPU成本；平静期不以无效循环充当有用思考 |
| 5 | 语义巩固和增长：摘要语义与具体事件并存、学习稳定检索，再考虑更大容量 | 保留纠正历史、来源与未知边界；同容量／同预算对照证明收益；不能抹掉稀有事件来提高平均分 |

这些是下一阶段门槛，不是已经实现的能力。特别是第1项必须先做有限中文记忆任务，不能把带标签的数字接口直接命名为端到端理解。

现有实体数量与事件容量均有限。开放世界需要新的实体寻址、关系与组合表征；长期增长还需检索的成本控制。神经写入并不能独自保证个体一致性；需要在不同调用者、不同措辞和相互矛盾输入下测量持久经历及行为边界。

## 暂不采纳的结构改动

不因近期研究名称而全面替换语言骨干。P23f两组同为2000步、6,025,696个目标词元、相同批次轨迹；大组段耗时约2615秒，小组约943秒，机器负载和执行时段不同。这不是等算力实验。大组36轮贪心输出仍有9轮明显循环，抽样方式虽无明显循环，也有答非所问；尚未完成全面人工评分，不能声称更宽已解决中文交流。

目前也不加入大型专家混合、全模块每步更新、无边界自生成训练或大规模睡眠想象。它们会扩大训练与归因难度。应先验证信息没有丢失、状态能一致恢复、语言确实读到了自己的经历，再增加复杂度。

## 研究核对

本轮新增原始摘要核对：[End-To-End Memory Networks](https://arxiv.org/abs/1503.08895)、[Mamba](https://arxiv.org/abs/2312.00752)、[Titans](https://arxiv.org/abs/2501.00663)，网页散列与阅读范围记入报告。

Memory Networks支持研究可学习读取与多步访存，但其外部记忆不等同于本项目的参数／状态记忆；Mamba说明选择性递归值得做同预算对照，其论文的吞吐数据不能套用到本机；Titans支持短期注意力与神经长期记忆结合这一方向，却不证明我们现有接口已完成对齐。此次只读这些论文摘要，没有复现实验，也不将它们作为本轮改动的效果证据。

持续内部计算的研究延续[P24设计](P24-awake-design.md)和[原始综述](continuous-cognition-research.md)。本次修补的直接根据是可重复的结构反例与回归，不以论文声望替代验证。

# P19：短证据步骤与可训练循环层

本阶段回答一个有限问题：语言接口尚不能可靠问答时，加入可核验的短步骤或可训练上下文层，是否能改善按记录答题？结果见[P19报告](../reports/P19-report.md)，固定预算见[配置](../configs/p19-short-reasoning.json)。这不是完整的自主思考系统，也没有启用睡眠想象。

## 三组结构

| 组别 | 输入 | 监督目标 | 新增结构 |
|---|---|---|---|
| A `answer` | 三条有序移动记录与问题 | 最后位置 | 无 |
| B `trace` | 相同记录与问题 | 相关记录编号、最后编号、位置 | 无 |
| C `recurrent_trace` | 相同记录与问题 | 与B相同 | 一个共享因果注意力块，连续使用两次 |

共同继承P18语言接口和冻结的原个体。新增块在原骨干之后、语言适配层之前，宽128、四个注意力头；残差输出投影置零，其他参数随机初始化，起始变换为恒等。没有采用外部预训练权重。

三种子只改变抽样顺序以及C的新层初始化，全部共享一个已经训练的P18来源，因此不等于三个独立预训练底座。A/B目标字节数不同；B/C同时改变可训练容量及计算深度。虽然同种子的训练记录、问题模板、回放样本与更新次数相同，不能称为参数量或计算量匹配。

## 课程和边界

六种物品、四个地点、两件物品参与三条记录，其中一件出现两次，另一件出现一次；三个地点不重复。两类问题均衡。任务如：

```text
记录:1:杯到柜;2:球到架;3:杯到桌;问:杯现在哪?答:
A目标：桌。
B/C目标：据:1,3;后:3;答:桌。
```

答案由有限环境根据事件规则产生。评分器只在训练标签生成和审计中使用；神经网络推理只接收字节和原有神经状态。完整步骤和最终答案分开评分，答对但证据错必须记录为步骤失败。

物品枚举顺序为杯、球、书、笔、包、盒，按此顺序生成无序二元组合，再用组合序号模5分区。原配置的“sorted pair”措辞不够精确，实际并非按Unicode重新排序；代码和分区在训练前已经固定，报告披露此澄清。训练2592、开发864、测试864个任务。每个符号出现在训练中，物品组合跨区隔离；同一规则、格式和有限词表仍是明显的结构先验。

每组每种子1200步，批8。五步中四步训练任务，只对回答字节及结束符计算损失；第五步回放P18课程，半批重点材料、半批基础中文，整段计算预测损失。回放为有放回抽样，不继承P18的遍历覆盖保证。每300步审查48条开发样例和整个旧个体摘要，保存最终研究检查点。日志的`loss_last_batch`来自回放步骤，不能当成推理任务的损失。

## 验证

固定采用第1200步文件，另一个进程恢复后测试96条未见组合题；不按测试结果挑版本。测试包含换问法、改问另一件物品和倒转事件顺序。倒序时，重复出现的物品应该改变答案，只出现一次的物品应该维持答案，两类必须分别汇报。成对正确率要求原题和变化题同时正确，单纯输出变化不算成功。

同时评估固定的训练分区样例，区分拟合不足与泛化失败；检查旧重点课程、历史查询以及所有冻结张量。C另测同一权重只运行一遍和完全跳过新增块，这属于推理消融，不能替代独立训练对照。

能力门槛是三种子均达到95%答案与成对正确率，带步骤组还须达到95%完整证据正确率。UTF-8合法、格式像样或预测损失下降均不能替代门槛。完整结果保存全部原始输出，不仅展示成功例子。

这里的移动记录属于问题内的工作上下文，**没有把这些记录写成个体亲历**。本实验能检查学习到的处理规则，但不能证明语言已能访问原有经历，更不能证明文字步骤忠实反映神经网络内部运算。用户希望的持久身份与记忆仍由原个体保存，并另行验收。

## 复现与保存

在已具备本地P18权重和课程清单的环境中，从仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/train_short_reasoning.py --arm answer --seed 7 --start-training
.\.venv\Scripts\python.exe -X utf8 scripts/train_short_reasoning.py --arm trace --seed 7 --start-training
.\.venv\Scripts\python.exe -X utf8 scripts/train_short_reasoning.py --arm recurrent_trace --seed 7 --start-training
```

随后对11、23执行相同命令，完成全部九份后运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/audit_short_reasoning.py
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
```

训练目录为`runs/p19-{arm}-seed{seed}`；已有目录会被拒绝覆盖。当前有限研究入口保存优化器与随机状态，但尚未提供中断后续训命令。每300步原子替换同一研究检查点，未保留全部中间权重；开发测量保存在`training.json`。最终审计默认写入`runs/p19-final-audit`，也拒绝覆盖。

研究文件采用专用格式`spora-short-reasoning-v1`，普通聊天加载器拒绝误载。默认`chat.cmd`仍使用P18；本阶段没有自动晋升。源码仓库不携带权重和本地课程产物，只有克隆源码不能直接重现本次数值，须先按前序阶段重建对应来源并核对摘要。

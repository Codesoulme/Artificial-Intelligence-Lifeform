# P1 实施记录

2026-11-05。用户授权在 D 盘开始实践。工作目录为 `D:\SPORA`。

## 本轮边界

实现 SPORA T：4 层、宽 128、4 注意力头、前馈宽 512、符号词表 512。第 2、4 层接入 64 维两层快速神经记忆，每处包含两个秩 16 的慢速专家。精确枚举为 969,576 个参数。训练从无已学知识的初始化开始；偏置等常数按 v2.0 约定初始化，不下载或加载预训练模型。

首轮任务是跨事件随机符号关联，测试新生成的映射。每次查询只输入当前问题，禁止拼接过去事件。当前版本是符号实验模型，不是中文聊天系统。

## 明确的简化与待验证项

- 键和查询共享地址投影，地址从当前问题中的符号及可信来源产生，不依赖已经变化的快速记忆，防止写入坐标漂移。语义地址与独立键查询投影留作后续消融。
- 每个世界有独立的快速张量和动量；外循环跨世界学习读写机制。使用精确短展开求导。
- 全部初期事件由受控环境生成，写入门取可信事件的 1；未获准的来源取 0。惊奇门、世界模型、增长及群体机制不在此次声称范围内。
- 首轮不声称 P2 慢速巩固成功；重启测试区分保留快参数与清空快参数。
- 本次每个查询为三个符号词元；每个事件边界重置工作激活。虽然骨干含因果注意力，尚未验证长窗口语言或时序推理。初期分类只计算 16 个结果词元的共享嵌入输出，其他词元没有语言输出证据。
- 8 个事件后才查询，全部关联由快速神经网络参数传递；64 个键与 16 个结果属于基础训练已见词表，新颖性来自未见的随机组合，不等同理解新概念。
- 慢速专家参加基础训练，但没有生活经历的独立巩固过程；本次 A 类重置应丢失新事实，B 类保存才应恢复。
- 训练、开发及审计的随机种子区间分离。开发检查用于诊断；审计结果不用于选检查点。

## 必须通过的检查

1. 内循环的写入不改变主体权重；查询不写入任何参数。
2. 未来答案不在查询输入，互斥映射应产生不同预测。
3. 二阶梯度可用、参数有限、保存和恢复后的预测一致。
4. 新进程仅载入神经检查点及当前查询；经历记录和答案由外层评估持有。
5. 保存快参数有因果增益；删除该变化后比较结果；再学习新关联并测旧关联下降。
6. 包括无写入对照；本轮成功仅支持有限符号任务，不代表完整设计已证实。

## 环境

GTX 1060 Max-Q 6GB，16GB 主内存。独立 Python 3.11 环境，PyTorch 2.5.1 CUDA 12.1；已实际验证显卡前反向和二阶梯度计算。
PyTorch 官方安装来源：https://pytorch.org/get-started/previous-versions/

训练按有限步数运行，记录耗时和显存，不设置自动常驻任务。实验结果保存到 `runs/`，模型张量保存到 `checkpoints/`，两者默认不上传 Git。

## 一致性和使用约定

普通查询载入同一份 `checkpoints/individual.pt`，每次启动不加载对话记录。`learn` 明确开启写入，事务同时保存两处快速网络、动量和经历游标。`ask` 仅读取神经参数。文件锁保证本地单写者；异常退出留下的锁须先确认没有活跃写入，再手动清理。系统未提供远程多人服务。

基础检查点含元训练的优化器和随机数状态，可使用 `--resume` 继续；个体检查点不携带训练集、答案表或外部回放。跨进程评估只发送当前问题，模型加载后安装 Python 文件与网络访问审计钩子。该措施是实验隔离，不是操作系统级安全沙箱。

首轮采用 3 个独立随机起点、每个固定 1,000 步，并以最终版本审计；不从审计结果挑最佳版本。每个起点使用同一批新随机世界进行配对比较。世界间区间用于该起点的探索结论，不能把所有查询当成独立训练重复。

## 已发现的问题

seed 7 的独立容量探测显示，经历数量从 8 增到 64 后，最早 8 条准确率降到 63.28%；一次可信纠正的成功率只有 12.5%。这说明首版学会了有限关联写入，但没有可靠掌握冲突纠正或长期容量管理。该探测与主审计分开记录，不用于本轮调参或选择模型。下一轮应先用独立开发任务研究纠错课程和遗忘机制，再讨论语言扩展。

参数计数需区分：基础网络含 969,576 个学习参数（其中包括快速网络的初始化模板）；单个体另保存两处快速网络共 16,640 个当前参数与同样数量的动量数值。快参数直接参与神经前向，不是原文或符号查找表。

# 从历史保护到中文训练前接口

2026-11-05。实现方案和实测证据分开：本文件描述结构；最终实验数字由报告生成，不将开发集数字当发布结论。

后续补充：P14–P16加入有限属性归纳、反馈策略及完整的训练恢复和数据检查，最新结构与范围见[中文前实施说明](pre-chinese-implementation.md)。已有字节接口仍未学会中文，也未完成词语到事实地址、新慢层或动作模块的对齐。

## P5：历史写入的相关性保护

P4 更新为 M←M+β(v−Mq)qᵀ，旧地址与新地址相关时会改变旧读出。本轮保留同样的随机训练谱系定义，改用递归最小二乘对历史参数更新。令 P 初始为 I/λ，λ=0.01：

g=Pq/(1+qᵀPq)，M←M+(v−Mq)gᵀ，P←P−Pqgᵀ。

P 是递归优化器的逆相关矩阵，保存了地址几何信息，必须计入持久状态；它不保存事件文本或目标值。测试将顺序更新与批量岭回归闭式解比较，并检查正定性与恢复后的下一步一致性。有限精度与病态地址仍可使方法失败，不能称其普遍消除遗忘。

拒答不只依赖分类器最大概率。历史查询的 λqᵀPq 提供新颖度信号；学习阈值和缩放，将信号加入 unknown 类别。这是结构先验加可训练读出，不是环境提供“这个问题的答案是否存在”。错误键与时间也只输入同样的查询字段。

公平性：rls90 每层有当前矩阵、历史矩阵、逆相关矩阵，两处共 48,600 个活动标量；delta110 对照有当前和历史矩阵，共 48,400 个。逆相关状态虽不是目标值参数，仍完整计费。总网络参数、计算与梯度路径并非严格相等。

训练预算由 P4 的 380 步改为 600 步，最长训练序列由 32 改为 64；不能把跨阶段的全部成绩差异归因于写入算法。P5 内部对照匹配训练预算，但 RLS 同时增加新颖度拒答头，二者贡献没有单独消融，报告保留此限制。

旧时间格式为兼容仍保存同形状的零动量张量（这些写法不读取它们），因此完整个体文件还有这部分冗余存储及骨干/初始矩阵开销；活动标量数不是完整文件大小。增长格式去掉不用的动量，仅保留真实状态，报告同时列出模型、固定缓冲区与活动量。

## P5b：开发失败触发的第二轮

P5 在四实体反复变化时表现较好，扩展为 64 个不同实体时，开发检查暴露当前区错误与未知误判。这一失败保存在 runs/p5-varied-development.json，不合并到最初四实体得分中。

第二轮将有限的 64 个当前符号映射到随机生成的正交地址。不同键的线性写入投影相互正交；查询读出的能量用于一个可训练 unknown 判别。输入键仍然决定神经地址，值由经历写入矩阵；没有储存 key/value 数组。基向量为 2×64×90=11,520 个固定标量，另行计费。

这不是开放世界实体识别，也不是任意语义都能天然正交。它利用已知符号词表建立可验证基座；以后中文如何识别同一实体、如何对齐关系仍需学习并单独评估。训练混合四实体轨迹与不重复实体流，增加不可信值先到的样本。

## P6：同一个体的有成本扩展

当前矩阵在整段生命史中共享，每 64 个时刻追加一个神经历史区。绝对时间只决定区间和局部时间表示；区间中的内容仍由稠密矩阵计算。旧区间不再接受新观察，已存在张量不被覆盖。

扩展时只增加初始神经矩阵及优化器状态，证明和测试的性质是“旧查询函数不变”，不是无限容量或语义压缩。四段共 256 次经历，rls90 的活动状态从 48,600 增至 145,800 个标量；另加固定骨干与地址缓冲区。硬上限为 16 段/1,024 时刻，未经新验证不扩大此上限。

P5 已形成的个体可以直接复制其真实矩阵到增长格式，记录父文件摘要；不读取事件列表重建记忆。这只支持该结构的精确收养，不宣称 P1–P4 旧模型的跨结构迁移已经解决。原有文件继续保留，不能把新谱系称为旧谱系的无损成长。

## P7：尚未训练的中文能力接口

采用 UTF-8 字节词表（256 字节 + 起始/结束/填充三符号），避免先下载词表或继承预训练编码器。中文文本可以无损编码，只说明编码覆盖，不说明语言理解。

新增可训练字节嵌入、位置向量、记忆查询/读出投影、区间位置表示、小适配层及输出头；复用当前个体的因果骨干，并只读访问内部各个神经矩阵。区间表示让接口能感知历史顺序，尚未学会其中文意义。首阶段冻结已有个体的结构权重和经历状态，梯度通过冻结的计算传向新接口。冻结能保护既有符号查询，但可能限制语言学习能力；这一取舍必须在中文试验中测量。

本阶段仅使用随机字节张量检查未来信息隔离、损失和梯度、状态恢复、参数不被意外更新。保存的是未训练接口，中文训练 token 数为零。接口虽然能读取神经状态，尚未学会把中文“我昨天听到了什么”对齐到时刻和关系，因此不得声称能够用中文回忆。

## 中文训练启动前的下一阶段规格

- 首次训练仍是小规模试验，先测下一字节预测与保留的符号行为；不以聊天流畅当作身份连续性证据。
- 语料必须具备可核对的来源、许可和本地清单；先按文档划分训练/开发/封存测试，再去重，避免先切片再划分导致泄漏。本阶段不下载或训练中文语料。
- 初期不让文本自动写入经历区。下一轮先训练句子→实体/关系/可信来源/时间的对齐，只有可验证接口才能提交观察；未知实体不能静默归入已有符号。
- 第一批训练不覆盖候选父状态。每个版本保存摘要、训练 token 数、真实耗时、开发损失、独立测试及既有记忆保持结果。
- 只有在语言试验失败后才决定放开哪些旧权重；若放开，要新增保留约束、巩固与迁移审计，不能把冻结下的成绩外推到共同训练。
- 本轮完成时停在实际中文训练之前；用户审阅报告后再决定语料、规模与预算。

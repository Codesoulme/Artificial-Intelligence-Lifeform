# 从复制到条件选择的语言阶梯

本轮承接P19，目标是让语言接口学会从有限文本记录中按问题选择信息，同时保留已有神经记忆和旧中文预测能力。训练结果及失败修订见[P20开发记录](../reports/P20-development-notes.md)。

## 不变的个体边界

父个体仍为`checkpoints/individual-prechinese-v3.pt`，旧观察、历史段、来源、技能和计时状态不更新。研究接口作为该个体的新参数组件单独保存，并通过父文件摘要绑定。语言计算路径可以改变，原骨干仍用于旧符号能力。此阶段没有把文本中的物品移动写成真实亲历，也没有完成自然语言到原事实地址的语义连接。

P18接口是明确的训练来源，新增注意力层、卷积及重置的位置表都来自随机初始化；没有加载任何外部预训练模型。源模型的预测分布仅用于旧训练材料的保持约束，它不是新任务的答案教师。

## 课程与保持

1. 单条记录复制位置，检验整个有限物品／地点字表的拟合，不把这一阶段称为未见组合泛化。
2. 两件物品各出现一次，根据所问对象选择地点。
3. 两件物品共三条记录，其中一件重复出现，选择最后一次匹配的地点。

每步有16条任务样本和8条旧中文回放。后续阶段的前三个采样位置优先抽取旧阶段；成对模式还会补充相邻的另一问法，实际旧题数可能多于3。旧材料使用无放回遍历，重点与基础比例1:3。基础目标为回答损失＋0.5×旧材料损失＋0.5×P18预测分布差异；P20e起回答损失权重为4，P20f/g另有下述辅助损失。

每300步同时检查训练与开发题，含改问另一物品、倒转顺序的成对正确率。所有适用指标须达到95%，旧阶段也须保持95%，中文开发损失不超过P18的105%；连续两次通过后才升阶。各修订上限在相应配置中明确，结束后的研究目录拒绝覆盖。选择依据是开发集，最终审计读取完整未见物品组合分区；沿用P19的公开基准，不称全新秘密测验。

P20c发现48题抽样通过后，完整开发分区的单次出现目标倒序保持只有91.67%。P20d加严为抽样连续两次通过后，还要完成所有旧／当前阶段的完整开发分区验收，才能升级。最终报告也须披露这一开发选择过程，不能只保留胜出候选。

## 结构修订的含义

`original`共享冻结骨干。`cortex`使用新的可训练因果块处理字节，从两个明确位置只读原来的当前及历史神经矩阵。P20为两层；P20b增为四层；P20c在位置表示之前增加因果局部字节组合。后者有助于检验中文多字节表征是否成为匹配障碍，但其收益必须由对照证明。

新路径与冻结路径并非同参数、同计算量；从P18新建路径还包括位置表重置，不能把全部收益归因于某一层。深度对照中同种子也不等于新增模块每一个随机张量都相同。配置、来源、阶段进度、优化器、抽样状态、参数和失败结果都保存；当前研究入口没有自动断点继续命令。

P20d仅扩展任务物品种类至16，保持地点为4；训练分区114种物品对，双物品5472题、三记录32832题。开发和测试仍使用原六种物品的各3种隔离组合，分别有144／864题。单记录64题用于字表拟合。它仍是很窄的合成环境，扩大物品不等于获得一般语言泛化。

P20e进一步把同世界不同提问放入同批，并提高任务损失权重至4；未跑满预算便记录中止。P20f另加一个可训练的因果注意力读取层，训练时在问题末尾对正确地点字节位置提供辅助交叉熵监督。标签由有限环境生成，只进入训练损失；该层推理只处理神经表示，不解析记录、不接收答案位置或答案集合。报告分别测量位置选择和自主生成，明确增加了人工可核验的证据监督。

这一结构并非完整的思维链系统。原来对文字步骤的承诺仅在基础条件选择通过后再研究；当前仍输出简短地点答案，不把辅助位置监督描述成模型自主发现的思考过程。

P20g将证据注意力转成输入字节概率，再以可训练门与生成词表概率混合。训练额外监督答案前三个字节对应的原文位置，并监督这些位置复制、后续标点和结束符生成；证据及门损失权重各为1。推理只接收原始字节和原个体神经状态，不接收这些标签，也不调用题目解析器。这是明确的结构先验与教学监督，不能把结果归因于未经指导的自主思考。

P20g的种子7通过开发而种子11失败后，P20h增加局部匹配约束：证据查询使用32字节因果卷积，键使用9字节窗口，二者经归一化计算相似度，并加入强度可训练的单调近因偏置。这限制了键把整对物品一起编码的机会，但查询仍可能看见问题前的部分记录；它并非严格的对象不变性保证。网络不提取符号对象，也不接收人工标注的边界。窗口、距离方向和训练标签均是研究者提供的先验。旧上下文查询／键投影保留在文件中，此变体不使用它们计算证据得分；参数总数包含这些张量。

H的种子23未通过后，I版仅将查询窗口改为24字节，从P18重新建立各副本。缩短窗口旨在减少前一记录中物品名干扰，固定输入形式仍是明显限制；不把短窗口当作通用文本实体理解。最终评估必须分别覆盖两种训练问法，另报第三种未训练问法。

I种子7再次未通过后，J版保留结构，另在不含近因偏置的内容得分上增加权重1的匹配损失。该分布对所问对象的每一次出现给予相同目标概率；原有加入距离项后的监督仍要求选择最新记录。两种标签分别教内容关联与时间选择，没有在推理中加入符号匹配器。新增目标属于更强的人工监督，不能直接与早期仅回答监督的参数数量或训练步数作公平优越性比较。

`spora-language-ladder-v1`是专用研究格式，恢复时验证结构、参数名称／形状／有限性和个体摘要，普通试聊入口不会误载。检查点只包含语言参数；配套原个体才形成可运行的完整状态。保存优化器所需字节不能直接叫作纯模型参数大小。

## 本地运行

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/train_language_ladder.py --arm original --seed 7
.\.venv\Scripts\python.exe -X utf8 scripts/train_language_ladder.py --arm cortex --seed 7
.\.venv\Scripts\python.exe -X utf8 scripts/train_language_ladder.py --arm cortex --seed 7 --plan configs/p20b-language-depth.json --tag p20b
.\.venv\Scripts\python.exe -X utf8 scripts/train_language_ladder.py --arm cortex --seed 7 --plan configs/p20c-local-bytes.json --tag p20c
.\.venv\Scripts\python.exe -X utf8 scripts/train_language_ladder.py --arm cortex --seed 7 --plan configs/p20g-learned-copy.json --tag p20g
.\.venv\Scripts\python.exe -X utf8 scripts/train_language_ladder.py --arm cortex --seed 7 --plan configs/p20h-local-evidence.json --tag p20h
.\.venv\Scripts\python.exe -X utf8 scripts/train_language_ladder.py --arm cortex --seed 23 --plan configs/p20i-query-window.json --tag p20i
.\.venv\Scripts\python.exe -X utf8 scripts/train_language_ladder.py --arm cortex --seed 7 --plan configs/p20j-content-matching.json --tag p20j
```

先依据开发结果选定修订，再按相同配方执行种子11和23。最终审计入口支持`--plan`、`--tag`、`--output`指定对应谱系。运行这些命令需要前序本地权重和课程，源码仓库不携带训练产物。

验收通过只能说明有限文本中的条件选择，不意味着能自由聊天、忠实表述内部运算、拥有主观体验或完成睡眠想象。后续复杂度必须另立验收。

## 方法来源与贡献范围

复制与生成混合是已有方法家族，不是本项目发明。See、Liu、Manning的[Get To The Point: Summarization with Pointer-Generator Networks（ACL 2017）](https://aclanthology.org/P17-1099/)明确将源文本指向复制和词表生成结合。本轮于2026-11-06核对官方摘要：它支持采用这一机制的依据，但论文的词级摘要任务、覆盖机制和ROUGE结论不能移用作本项目成绩。本实现使用字节级因果复制、位置及门监督，并在H版加入局部卷积和近因先验；并非该论文完整复现，也不称为新的基础架构突破。有效性由本地保留的失败实验及多种子审计决定。

H版的距离线性惩罚也属于已有的近因偏置思路。[Train Short, Test Long: Attention with Linear Biases Enables Input Length Extrapolation](https://arxiv.org/abs/2108.12409)的官方摘要明确描述了对注意力得分施加与距离成比例的惩罚。本实现的可训练单一强度、局部匹配层和保留的位置嵌入与ALiBi不同；没有验证长输入外推，不能引用其论文成绩来宣称本模型具备该能力。

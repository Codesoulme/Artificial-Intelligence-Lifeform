# P11：真实时长与有限环境预测

2026-11-05。中文学习继续暂停。本阶段在原有个体的副本中加入从随机权重训练的小模块，验收范围是时间输入、简单动力学、持久状态与已有历史的兼容性。

## 时间和记忆各自保存什么

| 内容 | 保存位置 | 含义 |
| --- | --- | --- |
| 当前事实、历史经历 | 原有神经矩阵及封存因子 | 原有72次符号观察，读取不依赖事件表 |
| 环境变化规律、周期估计函数 | 新增4,932个神经参数 | 从合成转移训练得到的能力，不是保存512,000条经历 |
| 最近观察、动作、环境参数、预测、最近两个信号间隔 | 48字节浮点工作状态 | 明示的短期传感状态，不冒充长期参数记忆 |
| 在线累计时间、计数、存盘时刻、空白间隔估计 | 检查点元数据 | 显式计时机制，不是神经网络自行发现的时钟 |

符号时间仍是事件序号。新计时器使用 `time.perf_counter_ns()` 的单调高精度差值；不以消息次数或循环次数代替秒数。累计值随同个体保存，不保存可跨进程复用的绝对计时起点。电脑休眠期间的计时行为受操作系统计时器语义影响，数值不表示实际计算量或主观体验。

重启时重新建立单调时钟起点。UTC只估计“上次提交至现在”的空白间隔；它可能包含崩溃前未提交的运行时间，也可能受系统时钟调整影响。若UTC倒退，间隔标记未知；在线累计值不倒退。无论估计是否有效，重新启动都会使环境连续性和连续信号证据失效，必须接收新观察。不会补写离线经历。

## 学到的预测与结构先验

环境状态为位置、速度、温差，输入动作是推力和加热，阻尼与冷却系数由环境直接提供。本实验没有证明能自行推断未知物理参数。

神经向量场采用 `7 → 64 → 64 → 3`，两个隐藏层使用tanh；它学习状态随时间的变化率。训练读取有限间隔的转移样本，推理用显式RK4积分。积分算法是已知数值先验，环境方程只存在于实验脚本，不进入个体运行代码。动作与环境参数在预测窗口内假定保持不变；它们改变时，应带着新的实际状态调用 `observe_world`。

每个时刻的预测都从最近一次实际观察出发，用累计经过时长重新计算。因此相同总时长被拆成多少次调用，不会被误当成不同经历。本次有效窗口为0–2秒；起点位置±3、速度和温差±2、动作±1、环境系数0.15–0.8。超出窗口后返回需要观察，超出输入范围拒绝接收。输入范围属于明确课程约束，不能理解为通用的不确定性估计。

信号头采用 `2 → 16 → 1`，输出正周期。收到三次同源脉冲，得到两个实际间隔后，才尝试预测。课程周期0.2–2秒、观测抖动±2%；运行时检查支持范围与两次间隔的一致性。用预测周期减去已过时长、判断到期，是显式运算。到期只发出一次预计提示，不会自行增加观察计数。简单平均值在本次测试中更准确；保留此对照，不宣称网络优势。

目前没有端到端训练把这个模块与符号读写、语言或行动策略联合起来。小型动态工作状态已经持久化，但并非一个持续自主思考的循环网络。新能力模块随个体保存，外部上下文不负责提供答案。

## 事务、睡眠与边界

时间参数、传感张量、时钟元数据、已有记忆和游标同处SQLite事务。改变其中多项时，恢复只允许旧版或新版完整快照。保留旧版本写者检查；新增模块必须和运行状态一起序列化。普通学习、扩容、历史睡眠、便携保存及恢复均携带这份状态。

空闲更新不追加符号历史。工作张量固定12个float32，共48字节；只有预测变化时，浮点载荷通常是12字节，但每次事务仍有约15.7KB的清单以及SQLite日志和页面开销。小载荷不等于只有12字节磁盘写入。计时循环会占用计算资源，详见实测报告。

睡眠继续压缩已满的历史段，新增模块通过兼容测试。环境预测尚未成为睡眠时的想象、生成回放或策略优化；P3慢速专家也仍未合入。此阶段没有实现完整做梦系统。

## 本地使用

发布副本：`checkpoints/individual-time-candidate.sqlite` 与同名 `.pt`。前者是工作事务文件，后者是发布时的便携快照；继续运行后不会自动同步两者。原有个体未替换。

查询快照信息和原有事实：

```powershell
.\.venv\Scripts\python.exe -m spora.online_cli --individual checkpoints/individual-time-candidate.sqlite info
.\.venv\Scripts\python.exe -m spora.durable_cli --individual checkpoints/individual-time-candidate.sqlite ask 12
.\.venv\Scripts\python.exe -m spora.durable_cli --individual checkpoints/individual-time-candidate.sqlite ask 12 --time 0
```

后两项应分别为7和5。`info`只展示已存盘的状态，不暗示程序当前正在计时。

先备份为新的实验文件，再运行2.2秒演示；备份文件名必须未存在：

```powershell
.\.venv\Scripts\python.exe -m spora.durable_cli --individual checkpoints/individual-time-candidate.sqlite backup --output checkpoints/my-time-demo.sqlite
.\.venv\Scripts\python.exe -m spora.online_cli --individual checkpoints/my-time-demo.sqlite run --seconds 2.2 --tick-ms 50 --synthetic-pulse-period .3 --demo-world
```

演示使用真实电脑时间，在调度器实际执行时发送三次**合成脉冲**，并提供一个合成环境起点。没有接入真实传感器，也没有语言交互。预计第四次信号到期只产生提示；之后程序退出。若调度严重延迟，脉冲不补发，间隔不足以支持预测时返回未知。运行上限60秒，未安装后台常驻任务。

应用层可通过 `OnlineSession.observe_world` / `pulse` 提供新输入，并标明 `sensor` 或 `synthetic` 来源。来源标签是调用者声明，不是独立真实性认证。无参数的空闲运行只能积累时长，不能凭空获得环境知识。

## 研究依据与未复现部分

- [Latent ODE / ODE-RNN](https://arxiv.org/abs/1907.03907)：不规则间隔与连续动力学。本项目借鉴连续时间建模方向，使用完全可观察的状态，没有实现该文潜变量推断。
- [Neural CDE](https://arxiv.org/abs/2005.08926)：连续路径驱动动态状态的方向；本阶段没有实现CDE控制路径。
- [Time2Vec](https://arxiv.org/abs/1907.05321)：时间特征可学习。此处采用秒数与周期头，没有复制其正弦时间编码。
- [Liquid Time-constant Networks](https://arxiv.org/abs/2006.04439)及[Closed-form Continuous-time Neural Models](https://arxiv.org/abs/2106.13898)：时间尺度与效率的后续候选，当前未采用其完整单元。
- [Neural Hawkes Process](https://arxiv.org/abs/1612.09328)：时间事件的概率建模。本轮只处理近似周期信号，没有实现点过程概率、风险率或校准。
- [DreamerV3](https://arxiv.org/abs/2301.04104)：世界模型支持想象与行动学习。当前只有简单环境的监督转移预测，尚无潜在世界模型、价值函数、策略或想象训练。

下一步优先考虑不规则事件的概率预测、未知环境的适应，以及有误差门槛的短时想象与真实观察核对。扩展前应冻结新的课程和独立验收集；现有成绩不外推到开放世界或生命性。

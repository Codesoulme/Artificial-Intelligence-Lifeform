# P2 实验协议与实现范围

日期 2026-11-05。本轮按课程、写入策略、定向更新、保护对照、慢速巩固依次研究，默认个体不替换。

## 实验单位

基础参照为 P1 的三个独立随机谱系 7、11、23。MLP 候选从各自谱系继续学习，不能称为第二次完全随机起步。Delta 参考则从随机参数起步，基础训练预算另列，不把与 MLP 的不同起点混成严格架构优劣比较。

固定每个长度 40 个世界批次，4 个世界/批次，长度 8、16、32、64。每个世界末尾加入四个可信修正，每个之后附一个不可信冲突和一个复述。每 8 个事件截断快参数的梯度，数值及动量跨段保存；主体只在完整世界结束后更新，避免段间表示漂移。

第一次工程运行 `p2-mlp-seed7` 只在段末监督，没有即时修正损失。该运行保留为诊断，不纳入正式候选；后续 `p2-v1-*` 增加修正后即时损失，避免复述替代纠正。

## 语义边界

当前真值是最后一次可信修正后的值；先前事件与当前判断属于不同目标。第一批主要比较当前事实更新，不声称已经学会回忆每个历史版本。来源可信位由受控环境提供；屏蔽不可信写入是接口约束，不能报成学得的来源判断。

Delta 使用 90 维矩阵，每处 8,100 个快参数，两处共 16,200；MLP 共 16,640，差异约 2.6%。骨干规模、投影数量和计算成本并非完全相等。该参考只有归一化键的 delta 写入，未冒充完整 Gated DeltaNet 或其后续模型。

## 策略与选择

比较固定一步、固定两步、最多四步。自适应停止读取当前可信事件的输出概率，只用于优化这个已知监督目标，不能访问未来答案。候选阈值 0.5、0.8、0.95 仅在开发随机流选择。原始审计随机流 610000 及其长度偏移不参与选择。

审计同时报告即时纠正、无关事实、首尾事实、低可信覆盖和内部更新次数。额外回放与保护约束均计费。没有时间匹配对照时明确注明，不以多花计算的结果声称等计算优势。

巩固仅训练慢速专家 P，冻结主体与读写坐标，教师为带原始 F 的完整旧模型。训练回放只在优化阶段开放。F 重置后的 A 类恢复、保留 F 的 B 类恢复及无巩固对照必须分开测；不通过则保留原版。

## 追加验证（固定方案，不再根据结果选阈值）

随机流 620000：先写 64 个不同键，之后连续修订同一键 16 次，或交替修订四个键共 16 次。每次修订后立即测试，再插入一个不可信冲突和八个其他键的可信新值后重测；没有帮助目标答案的复述。开发集锁定的策略原样使用。每个训练种子测试 64 个世界，分别保留结果。

等事件参考：MLP 与 Delta 均从随机参数出发，以同一数据随机流执行 300 个预热批次和 160 个课程批次，每批 4 个世界，共 36,480 次事件呈现。只有 seed 7 补齐这一对照，不能充当三个公平训练重复。

算术成本：用 PyTorch 的运算计数工具采样每种固定张量形状的完整前后向及参数更新，乘训练步数。两种计数机制的覆盖范围分开保存；未统计的非线性、内存搬运与内核调度不能假装为零。因此只报告近似等已计数运算量，不报告严格相同实际硬件成本。并行运行的墙钟时间不用于公平速度排名。

时间语义约定：`current(k)` 的标签是截止时刻最近一条可信赋值；`event(k,t)` 的标签是该时刻实际收到的事件内容，不能被后来的纠正改写。后者需要额外的时间条件和历史表示；当前网络入口只接收键，尚无这项能力，不用外部查表冒充实现。

CLI 的一次 learn 在获得文件锁后完成所有内部步数，只原子保存一次，游标增加一次；默认策略保持一步，候选可显式使用 two 或 adaptive-max4。模型文件不保存经历文本。

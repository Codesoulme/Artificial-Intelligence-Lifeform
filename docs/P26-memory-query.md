# P26：有限中文查询自身神经记忆

2026-11-08。完成一个有明确范围的连接：原始中文问题 → 神经网络选择对象／查询类别／事件序号 → 个体既有神经矩阵读值或来源 → 固定格式呈现。问题中不附经历记录，不根据外部答案表回应。

## 实现与范围

新增81,358个参数，从随机权重训练。64维双层问句编码器学习当前、历史、来源和拒绝四种意图，并以六个数字槽学习对象与事件地址。字符位置标签只用于训练损失。模块作为chinese_query子模块与个体一同保存，权重之外不保存问题答案表。

当前仅支持对象编号0–63、事件序号0–1023，以及现有16种符号值。编号具有事先约定的意义；不支持任意姓名、开放实体、指代或自动理解新关系。十进制合成、地址边界、原神经记忆分发、中文响应格式均为显式程序。学到的是有限中文问句的访问地址，不是自由语言生成。P25的typed_v1仍是另一条候选路径；本轮没有把P23生成器重新训练成可靠的记忆叙述者。

数值指针一致性保护只检查网络选择：位置必须指向完整、连续、不重叠的数字串，且与数字头一致；空前导位必须为0。失败时拒绝，不替换成规则推断的正确地址。相关输出最小置信度低于0.90也不读取。这项保护不能保证任意措辞下的正确性。

读值使用已有当前／历史神经矩阵，来源使用已保存的关联来源矩阵。没有记录的来源返回未知；模拟经历可在历史中查到，但不覆盖当前事实。当前来源标签仍是调用方声明的类别，不表示模型认证了现实真假。

## 迭代与证据

A轮总体开发达标，却发现事件7可能被误读为77，且事件1偶尔被拒绝。前者通过指针一致性约束拦截；后者由0–1023均匀采样造成短序号占比很低。保留A的权重与结果，B重新从随机权重开始，将1／2／3／4位事件按组平衡，不降低拒答阈值。

B使用7／11／23三个种子，各2000步、batch64，共每种128,000条训练呈现。三个末次检查点全部通过开发门槛，随后冻结源码和权重才开启最终组合。

最终每种子5120次评测，总计15360次，使用同一套分组进行种子对照，不能当作15360个独立问题。各支持问题分组的正确接受率为99.09%–100%，其余支持问题被拒绝；本轮未接受错误地址。有限拒绝样本全部拒绝，这些句型与训练共享，不能推断开放域拒答已解决。对象编号和事件数字有独立留出，措辞只验证已知词汇组件的新组合。

独立复核进一步确认：最终负例的全文均已在训练负例出现，因此拒绝率只能作为保持检查，不是新拒答问法迁移。支持问题的全文与训练没有交集。报告中的parsed_correct在门控之后计数，与correctly_accepted重复，不能当成另一个未经门控的原始解析指标。

三个种子各84项实际记忆检查，共252项通过：

- 原个体当前值7、旧事件值5／9／3能分别通过中文问题读出。
- 对同一问句，改变副本中的可信当前事实，16种值均相应改变；历史仍保留。
- 查询新来源能读出direct；加入simulation后当前事实不变，历史和来源仍可查询。
- 擦除当前或对应历史记忆后返回未知；不存在的事件不制造答案。
- 六个留出对象编号的可信纠正可读；便携保存、事务保存与恢复保持结果。

这些检查中预期事实由独立评测器给定；运行时只使用提问、模型权重与个体状态。对照中的写入发生在副本；发布候选保留父个体原来的72次观察。原张量和父文件散列保持。

本机入口已用新进程检查：当前／历史输出7、5、9，旧来源未知，检查点散列不变。157项完整回归通过。完整数据、失败阶段与来源指纹见[实验报告](../reports/P26-results.json)，训练前门槛及开发修订见[协议](P26-protocol.md)。

独立子智能体另检查408项来源／模拟边界与59项数字校验，均通过；发现开发报告未强制绑定实际文件的问题，已补充权重与源码散列核对，三个真实候选核对通过，并增加失配拒绝测试。神经权重和最终问法结果不变，未重新打开最终题调参。

## 使用

在D:\SPORA双击memory_chat.cmd，可输入：

```text
对象12现在的值是多少？
对象12在事件0的值是多少？
对象12在事件1的值是多少？
对象12在事件0的来源是什么？
/quit
```

该入口只读取已有记忆，不将对话自动写入经历，也不启动清醒循环。默认加载runs/p26-memory-acceptance/individual-query.pt。可用`--individual`明确指定其他带该模块的便携文件或SQLite个体；`--details`显示解析与来源结果。原chat.cmd仍是此前的中文研究入口。

# P23f：同样训练量下比较两种容量

预先协议：以E4000作为共同训练起点，保留862万参数控制组；实验组使用已测试的保函数加宽映射到3008万参数。词表和原个体不变，复制输入对应的线性列加入相消微扰，允许后续学习分化。新组重置优化器，两组都这样处理，不让一方保留额外优化状态。

两组使用同一v4教材、同一短教学集、相同种子和批量16，学习率0.0001、热身100、20000步余弦日程，与E相同批次比例。每次只处理4条并按监督词元总量汇总梯度，完整16条后裁剪和更新一次。训练序列逐步累积SHA256，比较结束时须一致；有效目标数也须完全相同。

先各500步检查资源与稳定性，再各2000步比较旧开发NLL、教学训练NLL、36轮实际多轮输出、正常终止、乱码及重复。两种解码均保存，不增加重复惩罚或外部补答。尚未学过的新最终验收题保持封闭。预计较大组耗时增加，实际报告显存和时间。若更大模型更快拟合训练而开放问题不进步，不能宣布容量是答案。

限制：这是网络参数化／容量与相同优化配方的对照，不是相同计算成本对照，也不能排除不同宽度最适学习率不同。宽度变化会影响共享输出梯度尺度，初始前向一致不代表训练动力学相同。单种子开发筛选不能证明普遍优越。

继续准备的v5普通文本不进入这个对照，否则无法区分数据扩大与容量变化。后续若采用须明确新分支与审计；旧教材、个体、快照及失败输出保留。

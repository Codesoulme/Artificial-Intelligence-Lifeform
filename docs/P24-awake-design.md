# P24：个体内部持续工作与可调计算——第一版

2026-11-08，依据用户明确授权实施。目标是清醒时持续保持工作状态、接收外部信息并推进目标；放松与专注采用不同计算预算。当前交付为有限图环境下的可训练原型，不是已具备人类清醒体验或任意中文自发思考。

## 结构与保存边界

原个体TemporalSPORA新增可选子模块awake_core。模块中的transition和budget是从随机状态训练的神经参数，当前共244个；图、目标、规划值、位置、模式和计时等工作张量为注册buffer，共1304字节。两类张量都进入原有个体保存与SQLite事务。来源、现实时间和次数是显式工程记录，不能称为网络自行学出的时间知觉。

模型内部循环不是定时调用大语言模型生成句子。每次清醒更新实际执行神经状态转换，并在没有后续用户消息时逐步传播规划值。模型输出下一步建议，模拟环境仅检查边是否存在并执行该建议，没有为模型搜索路线。只有得到新环境反馈才更新已知位置。最新图是显式传感工作状态，不冒称长期权重记忆。

模型层保存状态与执行规划；运行器提供单调时钟、输入队列、唤醒和事务保存。任何计算机模型都需要运行器分配执行时间，这一外层不承担规划答案。新观察让旧方案立即失效；断线、休眠长间隔或新进程都要求重新观察，不补造离线思考。

## 计算与训练

当前有限任务为16节点、有向、完全可观察图中的路径规划。神经局部转换接收目标标志与邻居规划值，迭代形成到目标的折扣价值。训练监督采用折扣0.85的局部Bellman目标；最大邻居聚合和拓扑是明确的结构先验。该机制受Value Iteration Networks启发，不是CTM复现，也不是自主发现规划算法。

预算网络输入专注标志、是否有待完成规划、紧急标志，学习选择每次1／4／8步。类别训练来自显式预算策略，尚未通过强化学习发现最佳资源分配。放松周期0.25秒、专注周期0.05秒由运行策略规定；完成规划后通常回到1步。周期可在AwakeConfig中配置，睡眠暂停本核心。唤醒后需要新观察。

无目标时仍执行轻量神经转换，可能到达不再改变的固定点。这只能说明持续活动／状态维护，不能把每次调用称为有价值的新思想。系统目前不会自行发明生活目标，不从无意义自输出继续训练，也未将中文生成接到该工作回路。

三种随机种子7／11／23，每种3000次更新，无第三方参数。开发图每种200个；后续独立图每种500个；评价算法在测试脚本中计算最短距离，不进入模块或保存的个体。原型只覆盖有限图任务，不外推为现实世界规划。

## 现实时间与生命周期

分别记录清醒秒数、睡眠秒数、未观测间隔、实际tick数、神经步数和观察次数。没有输入仍可继续同一目标。超过2秒的调度空白按未知间隔处理，环境失效；这是一项明确的保守策略，不代表离线期间发生了神经计算。改变调用次数不会伪造更多现实秒数。

睡眠模式只完成规划暂停和状态隔离；已有历史巩固可独立使用原机制，完整睡眠想象仍未完成。清醒规划和睡眠学习是不同过程，不能将暂停说成做梦。

新命令被接受后保存状态；连续思考中默认每5秒保存，崩溃可能丢失上次提交后的工作推进，恢复保证完整快照而非每个瞬间零损失。实时神经活动不直接修改原有历史或当前事实，因此不会把预测路线写成亲历。

## 已有验证

- 三种子共1500个未见图，下一步最短路径／不可达判断通过率100%。这是有限数值任务成绩。
- 100次闭环导航，每次一个目标，后续只有环境执行反馈；全部到达目标，0次非法动作，路径长度均与独立最短路判定一致。
- 15边链条：保留循环值后能规划；每次抹掉这些值后无法完成，验证状态对结果有因果作用。
- 临时封路让旧建议立即失效，后续判定不可达。
- 真实时钟短测：放松2.01秒8步，进程CPU约0.0156秒；专注2.02秒54步，CPU约0.0313秒；睡眠0步。样本很短，计时存在平台分辨率，不是功耗测量或长期利用率承诺。
- before_commit等三处强制退出恢复为完整旧版或新版；原有张量保持，符号回答仍为7、5、9、3，原文件散列未变。
- 142项完整回归通过；随后新增2项时间／重启测试，awake专门7项通过。最终结果见报告，不能把两组数量重复相加。
- 最终命令行实测：一次目标输入后约3.24秒形成下一步建议，5.09秒内执行21次神经更新；重新启动保留目标10但要求新观察。连续执行sleep／status／wake验证睡眠期间步数不增，唤醒不采用陈旧建议。报告另存最终源码散列，区别于训练时版本。

## 研究依据与区别

CTM (2025) 为跨内部步骤的动态表示提供方向；其所读版本尚未验证语言建模。Clockwork／Skip RNN支持不同更新率和跳步；PonderNet支持按任务复杂度分配步数。CfC启发显式处理真实时间，但本版未采用其连续时间单元。

RWKV（https://arxiv.org/abs/2305.13048）展示可保持递归状态的语言网络，供后续语言连接参考。CogAgent（https://arxiv.org/abs/2312.08914）展示外部界面的视觉理解，与低成本清醒循环不是同一问题。Agent-Pro（https://arxiv.org/abs/2402.17574）研究经验反馈与策略反思；本文不导入其提示／教师路径。Value Iteration Networks（https://arxiv.org/abs/1602.02867）为可微神经规划提供直接参考，本实现采用有限图上的简化局部学习，不冒称提出了全新规划理论。

国内外相关方向的原文阅读记录保存在runs/continuous-cognition-research；详见[前期综述](continuous-cognition-research.md)。下一阶段需扩展部分可观察环境、学习事件重要性／计算价值，以及自然语言输入输出与持久记忆的语义连接。只有这些经过独立验证，才能把此原型称为更广泛的持续认知系统。

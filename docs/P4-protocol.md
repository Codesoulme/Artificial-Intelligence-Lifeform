# P4：当前判断与历史经历

2026-11-05，父版本 1955d01。原有三个个体和各阶段训练结果只读。

## 查询含义

- current(k)：最后一条可信赋值；从未收到可信值时回答 unknown。
- event(k,t)：第 t 次实际收到的关于 k 的内容，即使该内容不可信。后续更正不改变这段经历的标签。
- 错误的键与时刻组合、未发生的时间：unknown。历史查询不是询问当时世界真实值，也不是询问当时自身信念。

例：t0 收到可信 k=5，t1 收到可信 k=9，t2 收到不可信 k=3。当前应为 9；三个历史问题应分别为 5、9、3。记得听到过某句话不等于认可它。

## 参数实现及对照

沿用自定义因果骨干与归一化键 Delta 写入，但本轮两种结构都重新随机训练；没有把架构扩展冒充旧个体的无损成长。历史地址由键和时间的可训练表示联合生成，经历通过固定大小稠密神经矩阵参与前向计算。推理没有事件文本、数组或外部查找表。

split 每处分别拥有当前与历史矩阵，90 维，共 32,400 个快参数；shared 每处一个 127 维矩阵，共 32,258 个快参数。只近似匹配快参数量，骨干投影、专家和总运算量不同，另行计数。显式分区属于设计先验，不是模型自行发现的认知模块。

每次外部事件恰好推进一次时间游标。可信值更新当前区，所有实际观察均更新历史区；不可信内容不触发当前赋值。共享区可能产生间接干扰，需要行为测试，不能以门控规则声称无影响。

## 训练与验证

三个独立训练种子；固定预算 200 个短序列预热批次，以及 8、16、32 事件各 60 个批次，批量四。每八个事件截断快参数梯度，保留数值；完整世界结束后才更新主体。时间起点随机偏移，避免把固定序列位置当答案。所有标签仅由训练/评估程序持有。

输出类别为 16 个符号值与一个 unknown。有效历史、当前事实、错误键时刻组合、未来查询分别监督并报告，不能用大量 unknown 掩盖有效回忆失败。主审计 64 个新世界/种子/长度，不以审计结果重选超参数。

额外控制：完全不写入、只重置历史区、无历史写入、时间置乱；从新进程在空工作目录查询，模型加载后禁止文件/网络读取。查询仅接收键、模式和时间，绝不传答案。

重启逐项比较在相同 CPU 两线程配置下进行，避免不同线程归约顺序影响位级比较；跨设备的浮点位级相同不属于本次承诺。对照还包括只重置当前区，以检查另一方向的分离。

执行记录：首个审计进程在统一线程修补生效前已载入模块，原始四线程对两线程比较出现概率末位差异。该审计原样保留；另由 scripts/restart_p4.py 对六份原测评状态追加一致设置复核，保存 runs/p4-restart-standardized.json，不重做训练或修改主评估成绩。

本版时间范围 0–63，达到上限必须明确拒绝且保留旧文件，不静默循环覆盖。当前检查点独立于 P3 的巩固方案；本轮验证历史存储和修订分离，不同时声称完成历史压缩、扩容或无限事件记忆。

## 实际优化口径（主审计运行前补记）

每个模型固定 380 次外层更新，批量四，共 19,840 次事件呈现。AdamW，学习率 0.0003，权重衰减 0.01，梯度范数上限 1。损失是当前、有效历史、错误组合、有效未来四组交叉熵的等权均值，加 0.1 倍值编码辅助目标；各截断段再等权平均。当前组有四个已知键与四个未见键。未来时间超出词表时整行排除，不把最后一个真实事件误标成 unknown。两种结构的主体宽度均为 128；配置中的 90 与 127 是记忆地址维度。

一次事件有两个参数区写入尝试；不可信行的当前更新幅度为零，历史区照常记录。报告分别统计外部呈现、非零参数区更新及两个附着层的更新量，避免把一次观察重复计为两段经历。主模型权重、初始快参数、个体活动快参数须区分：经历在活动神经矩阵中保存，而不是每次在线改变全部骨干权重。

第二个及后续种子没有依据第一个种子的结果修改超参数；共享方案也保持同一预算。短序列中间成绩不能作为最终成绩，全部使用 32 事件课程完成后的检查点评估。三个种子使用相同审计世界，便于配对比较；因此汇总的 192 世界运行并非 192 个不同的环境样本。

## 额外诊断与预先承诺

主审计前增加三次观察的早期诊断：第一条不可信，随后两次可信且更正；同时测从未认可过的键是否 unknown、历史是否仍记得不可信内容。该分布不同于训练流前四条必可信的安排，作为分布外诊断单列，不拿来选择参数。

训练及主评估的错误键为原键加一，另以加 7、19、37 的组合和开始前的未观察时间测拒答，防止把特定负例形式的成绩当作普遍拒答能力。历史按四段分别统计，以辨别遗忘是否集中在早期。

64 事件属于超过最长训练流的容量压力，不计入预定发布门槛，但必须披露。未来查询在时间 63 后没有合法词表位置，64 事件测试的对应统计为 null 而非 100%。主门槛在每个长度分别要求当前、历史、错误组合拒答、未来拒答均不低于 95%；只允许固定 seed7 的 split 通过后导出候选，不能改选运气更好的种子。若失败，仅保存研究底座与测评用状态，不发布新的默认个体。

## 机制依据与证据边界

- Gated Delta Networks: Improving Mamba2 with Delta Rule，arXiv:2412.06464，原文 https://arxiv.org/abs/2412.06464 。本轮参考归一化键上的定向 Delta 更新；没有实现论文全部门控、并行算法或模型，也没有复用权重。
- Titans: Learning to Memorize at Test Time，arXiv:2501.00663，原文 https://arxiv.org/abs/2501.00663 。其可学习神经记忆提供相关机制依据，但不能据此推断本模型获得了该论文的长上下文能力。

对当前实现可直接推导：M' = M + β(v − Mq)qᵀ。另一旧查询 r 的读出变化为 β(v − Mq)(qᵀr)。归一化并不保证 q 与 r 正交；新旧地址相关时，历史仍会受扰。把当前与历史分区能消除两区之间的这种直接干扰，但不会自动消除同一个历史矩阵中的竞争。该公式只描述局部线性读出，不能代替完整网络的准确率实测。

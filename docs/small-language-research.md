# 小型语言候选的训练决策依据

查阅日期：2026-11-06。用于课程与测量设计，不把其他项目结论当作本候选的成绩。

- TinyStories（Eldan与Li，2023，https://arxiv.org/abs/2305.07759）使用受限词汇与合成短故事，展示千万参数以下网络可生成连贯英文故事。这支持研究教材难度和质量，但不证明同等规模能够完成开放中文聊天、多轮指令或持久经历理解。
- SmolLM2-135M-Instruct官方模型卡（https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct）披露基础训练约2万亿词元，并另做监督微调和偏好优化。这是一个已有公开配方的实际规模，不是本项目必须照搬的成本，也不能把我们几百万目标后的失败直接归因于结构无效。
- smol-smoltalk官方说明（https://huggingface.co/datasets/HuggingFaceTB/smol-smoltalk）使用更短的交流，并减少改写、概括等专门任务，不包括函数调用，以适应较小网络的容量。本项目借鉴“教材匹配规模”的研究思路，不导入它的预训练权重，也没有把英文样本直接当成中文监督。

本地判断：先收集连续学习曲线与同题开发输出，再区分训练不足、数据噪声、指令监督稀薄和容量瓶颈。当前C阶段约862万语言参数，只累计了少量百万级有效目标，不能从这点预算断言路线可行或不可行。若旧／新开发损失仍下降，先按固定配方积累训练；若损失接近平台但内容理解持续失败，再做课程质量与参数扩展的独立对照。最终仍需未用于训练或选点的新场景验收。

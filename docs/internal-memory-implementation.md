# 内部写入、来源与有限读取：实现说明

2026-11-05。实施按[计划](internal-memory-plan.md)推进。P12新增内部写入判定和来源表征；P13完成有误差保护的读取实验，因实测变慢而不默认启用。更高层语义巩固及技能学习按依赖顺序留在内部路线。

## 新增结构

`WriteControl`是从随机初始化训练的10→64→64→5网络，共5,189个参数。输入为四类来源编码、输入质量、当前事实是否已知、内容是否相同、先前依据质量、有效时间的新旧关系，以及是否有已记录依据。输出新增、纠正、加强依据、重复、待定五类。置信度不足时暂缓事实写入。

当前模型仍处理64个符号实体及16种值，来源与质量是环境显式提供的数值信号。网络学的是规定课程里的判定规则，不是从自然语言发现可信来源，也没有识别人类撒谎或开放世界真假的能力。相同符号值上的“加强依据”不能称为语义信息合并。课程教师是简单确定性规则，按定义可准确给出标签；本轮没有证明神经网络优于规则程序的正确性或成本。

两项保护属于确定性结构：推测、模拟不写入当前事实；与旧状态明显不一致的动作标签暂缓。即使未被相信，输入仍写入历史，并记录本次来源及最终判定。“重复”仅跳过当前通道，历史会继续消耗容量，满段后仍需显式扩容。

当前依据保存在3×90关联矩阵中，复用已有正交实体地址，编码存在性、质量和有效时间。其阈值和正交地址属于有限词表先验。相同低质量信息反复出现不会累加权威；系统尚未实现多个独立来源的证据合成。

每个历史段新增27×90关联矩阵，复用原历史地址与RLS更新：来源4维、判定5维、质量8位、有效事件时间10位。质量量化为最接近的1/255，时间范围0–1023，范围受现有16×64容量限制。只保存神经矩阵，不保存逐条符号或来源答案表。

读出数值位时会检查是否接近不确定区间；不可靠时返回未知。离散编码消除了本次有限试验中的连续回归偏差，不构成任意负荷下的无损保证。新增矩阵本身的容量、辅助状态和延迟均应计费。早于接入时刻的来源保持未知，不能凭现有事实反推当初的信息出处。

## 读取实验

`LearnedReadPlan`把已有神经矩阵的对称部分蒸馏为rank12因子，以较小的矩阵运算估计各段得分。每个已有区域独立学习低秩近似，属于对当前个体状态的数值近似；并非训练好了一个对未来任意新段均有效的语义选择器。

令评分矩阵为M、近似为LR，则对查询q，二次型误差不超过 `||sym(M)-LR||F × ||q||²`。结合注意力遗漏权重和记忆输出范数估计最终读取误差，要求不超过1e-4才能跳过其他区域。浮点实现保留裕量，未使用形式化区间算术；这仍只是一次读取的数值界，不能自动保证任意下游网络的最终分类不变。

不满足门槛会全读；随后的写入、扩容或历史转存会使已训练因子失效。因子可以持久保存，使用时依据实际矩阵重新计算残差界，不信任未经核对的旧误差统计。没有因子的个体即便请求实验模式也会回退到exact。

九个4/8/16实填段测试全部回退，额外计算导致变慢；人为拉开段得分的对照能跳过区域，但不代表自然查询已具备选择性。因此候选默认exact，不预装额外因子。保留`learned`模式用于后续研究。查询明确给出历史时刻时，原符号接口已有精确分段定位，不需要此近似。

## 有限整理

控制状态累计新增、纠正和加强依据的次数。累计达到门槛且存在已写满的活动段时，建议最多整理一段；转存仍经过P10蒸馏、行为一致性和空间收益检查，只有通过才提交，并清零本次累计计数。失败不发布。计数与门槛是公开调度规则，不冒称神经决策。

此流程仅在明确调用时执行，没有安装后台常驻任务。现阶段没有误差驱动的自适应睡眠策略、世界模型想象回放、语义抽象层或自主技能训练。完整做梦继续待办。

## 保存与使用

所有控制参数、来源矩阵、旧记忆、时间状态和游标在同一SQLite事务中保存。扩容、睡眠、便携保存均携带新增部分。旧的`learn --trusted`路径对这类个体明确拒绝，防止绕过来源判断；普通查询、备份和扩容仍可沿用durable_cli。

最终候选使用带`v2`的文件名：`checkpoints/individual-internal-v2-candidate.sqlite`和`.pt`。接入时保留父个体的72次观察，没有添加演示经历。实验演示单独保存在`runs/`。第一份不带v2的内部试验副本保留为未发布中间产物，连续来源编码只支持读取近似值，不作为最终交付。

先备份再演示，目标文件名必须尚未存在：

```powershell
.\.venv\Scripts\python.exe -m spora.durable_cli --individual checkpoints/individual-internal-v2-candidate.sqlite backup --output checkpoints/my-internal-demo.sqlite
.\.venv\Scripts\python.exe -m spora.internal_cli --individual checkpoints/my-internal-demo.sqlite learn 12 8 --source direct --quality 1
.\.venv\Scripts\python.exe -m spora.internal_cli --individual checkpoints/my-internal-demo.sqlite learn 12 2 --source simulation --quality 1
.\.venv\Scripts\python.exe -m spora.durable_cli --individual checkpoints/my-internal-demo.sqlite ask 12
.\.venv\Scripts\python.exe -m spora.internal_cli --individual checkpoints/my-internal-demo.sqlite source 12 --time 73
```

此演示明确声明一次直接来源输入和一次模拟内容；前者更改当前值为8，后者只进入历史。最后应读出simulation/defer；它是接收到的模拟信息，不是实际世界发生了该事实。来源标签由调用者提供，没有认证调用者是否如实标注。

`internal_cli info`显示累计计数与有限整理建议；`consolidate`最多尝试一段。`prepare-read`会付出训练成本并保存实验因子，默认exact读取仍然保留。Python字节接口显式指定`read_mode='learned'`才能尝试实验路径，训练阶段继续使用可微完整读取；中文没有启训。

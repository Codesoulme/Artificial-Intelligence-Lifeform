# P22：长问题读取与无证据回答

训练前固定：先在种子7进行1200步同课程对照，局部查询原结构与新增上下文残差查询分别从同一P21后代出发。新投影零初始化，初始函数与来源一致；两个模型参数数目不同，不称同容量比较。只有开发结果支持才扩展三种子。旧检查点、原个体和默认P18保持。

长问题采用4个前缀和4个句尾的组合：12训练、2开发、2最终，词汇组件共享，不代表任意中文理解。沿用已知的物品对划分，最终只是新问法组合。所有后缀足够长，使目标离回答起点超过24字节；对象仍是16种单字，地点仍是4种单字。未知目标从同一训练词表中抽取且不出现在记录里，不能靠某个特殊名字拒答。

每步16条任务：4条旧短问法、8条长问题有答案、4条长问题无答案；隔步将2条旧题改成短问题无答案。另回放8条旧中文，含用户指定价值观材料。已知答案使用位置和匹配监督；未知答案无证据位置标签，复制门全关闭，响应学习“未知。”。所有标签仅进损失，推理不接收解析器结果。

训练损失沿用4倍响应、1倍证据、1倍匹配、1倍复制门，以及各0.5倍旧中文和P18预测约束。未知回答有6个字节，标点结束符另计；不能对它套3字节复制标签。固定预算，最后检查点为候选，不挑最佳测试表现。

开发至少95%：有答案、无答案、同世界两者都对、切换对象成对、逆序成对；错误拒答率不超过5%。每300步检查，最后两次通过小开发，再检查完整开发和旧任务；旧中文开发NLL不超过P18的1.05倍。三个结构候选及工程保持全部通过后才打开最终组合；失败则保留而不降低门槛。旧P21已公开的测试只作为保持基准。

此阶段不扩大文字窗口，不支持变长实体，不执行亲历写入，不宣称睡眠想象或开放聊天。查询路径能使用完整已有窗口，不保证一定学会有效选取对象。语义与记忆的连接后续另立任务验证。

增加因果注意力选择目标，汇聚三字节局部特征，零初始化输出投影同时接入证据查询与复制门。训练时给出问句中目标最后字节的位置，在前三个响应预测位置施加权重1交叉熵；有答案和无答案都教目标提取。标注来自任务渲染器，只作为训练损失，生成时不解析问句或接受位置。这同时增加容量和监督，不能把收益单归因于架构；也不称已经自主发现思考过程。门槛与最终题封存规则保持。

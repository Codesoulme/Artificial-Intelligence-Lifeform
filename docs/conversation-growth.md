# 语言网络加宽候选：保留计算再学习

当前仅完成工程验证，未采用为默认入口，也未证明提高聊天水平。

依据：Chen等人的Net2Net（2015，https://arxiv.org/abs/1511.05641）研究通过保留函数的映射，将小网络转为更宽或更深的网络。本文实现需要另行处理旋转位置、多头分组、SwiGLU门控、RMS归一化和输入输出共享矩阵，不能直接用论文结论保证正确。原论文摘要和获取散列保存在runs/p23-growth-research。

本实现将宽度256扩至512，头数8扩至16且每头宽度不变，前馈中间宽度704扩至1408。每个特征复制两份，线性层输入权重对应减半；Q/K/V及门控／数值两组分别复制。输出与输入共用词表矩阵，所以最终归一化缩放也减半。原个体与词表均不变。可训练参数由8616194变为30077442。

直接复制会造成两个副本长期相同，因此在线性层输入列添加成对相消的小扰动；对完全相同的输入副本，数学上不改变前向计算，更新后可分开学习。浮点累加存在微小差异，不承诺位级一致。优化器需要在新分支明确重置，不能伪装成原结构续训。

在D6000训练状态的CPU验证中：6个自然语言前缀的24步生成完全相同；另测16、128、512位置的随机输入，最大输出分数差约4.82e-5，逐位置最大分数对应的词元一致。原个体与源快照保持。有限探针不覆盖所有输入，也不证明扩容能改善泛化。

单元测试检查非零记忆读取、整段与增量计算、保存格式重载、一轮更新后副本能分化，以及旧语言张量和原个体保持。还须在实际训练显卡上测吞吐／显存，并以独立的同数据训练对照评估容量收益。当前只保存了D6000的加宽诊断产物，没有开始它的训练。

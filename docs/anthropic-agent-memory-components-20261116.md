# Anthropic Agent Memory 研究对 SPORA 睡眠巩固的启示

来源：Anthropic，*The components of agent memory*，2026-11-06，
https://www.anthropic.com/research/components-of-agent-memory

## 研究中真正可借鉴的部分

文章把 agent memory 定义为跨会话保留的经验知识，并明确排除权重更新、单会话上下文学习和上下文压缩。它描述了一种分工：经历先快速进入日志或短期记忆，离线阶段再通过 replay 进行校验、提炼、合并和组织。文中把 dreaming 的作用归纳为四类：修正错误记忆、生成新的记忆笔记、构造更高层的 wiki 或链接表示，以及决定下一次会话应预先加载什么。

文章中的几个结果对 SPORA 有直接约束：

1. 记忆不是“保存得越多越好”。记录每个瞬时状态会产生过时内容，并显著增加整理和检索成本；稳定规则、计划和已验证策略比可从当前观察直接读出的状态更值得长期保存。
2. 记忆应当是对未来需求的预测。事实或规则只有在经过核验并标注来源后，才适合作为以后可以直接依赖的知识。
3. 错误记忆必须能回到原始轨迹复核。文章中的 dreaming 用会话记录作为证据，发现错误位置描述后重写记忆，而不是只在错误笔记上继续推理。
4. 高层表示要可维护。wiki、链接、重复合并和逐轮修剪可以降低长期检索成本，但当问题能由单个原始文档直接回答时，额外表示未必有收益。
5. 固定的“只记录失败”规则可能损害较强模型的记忆收益。保存策略应允许模型依据显著性、未来复用可能性和不确定性判断，同时接受外部验证和预算约束。

这些结果来自带持久文件目录的 agent 评测，不是对神经参数记忆、意识或人类式睡眠的证明。它们也不能直接证明 SPORA 的内部记忆读写有效；需要在本项目的个体、底座和独立保持集上重新验证。

## 转成 SPORA 的内部机制

### 1. 清醒阶段：事件与候选记忆分开

事件账本保存原始输入、模型输出、行动、结果、时间、来源、置信度、状态版本和纠正关系。清醒工作台只保留当前目标、未完成任务、最近观察和低频预测。模型可以产生“记忆候选”，但候选不等于已确认事实。

候选至少要带有：

- `evidence_ids`：可以回放的原始事件；
- `claim`：要长期保留的事实、规则或计划；
- `status`：`hypothesis`、`confirmed`、`superseded` 或 `rejected`；
- `salience`、`uncertainty`、`reuse_prediction`：睡眠调度所需的分数；
- `valid_time`、`observed_time` 和 `source`：区分事实发生时间、观察时间和来源。

当前已有事务存储、来源和时间字段，但还没有完成“候选必须回到证据核验”的统一闭环。

### 2. 睡眠阶段：验证优先于压缩

每次睡眠从候选队列选择有限预算的事件，不遍历全部历史。优先级由以下信号组合：新颖性、预测错误、冲突、不确定性、重复使用、用户明确纠正和长期未复核时间。对每个候选，巩固器应：

1. 回放原始事件和相关旧记忆；
2. 检查主张是否能由证据支持；
3. 搜索冲突和重复；
4. 生成压缩后的事实、规则或链接节点；
5. 保留证据、版本和反例；
6. 将无法确认的内容降级为假设或拒绝写入长期层。

这比直接训练一个低秩学生去拟合旧矩阵更强。矩阵压缩可以是后续存储优化，但不能替代错误校正和来源核验。

### 3. 高层记忆图与预加载

对通过核验的长期节点建立主题、实体、时间和因果链接。图索引只服务于定位和预加载，不能变成第二份无来源事实库。下次清醒启动时，根据当前目标和预测需求加载小型 dashboard、相关节点和必要的原始证据摘要；近期可变状态仍从工作台读取，不重复写入长期记忆。

### 4. 遗忘与版本化

瞬时状态、未验证猜测和过时计划应有衰减或过期时间；已验证规则、用户明确身份事实和关键纠正保留更高优先级。新版本不能静默删除旧证据，而应记录 `supersedes` 关系，允许审计和回滚。睡眠失败时只保存诊断，不发布候选。

## 实施顺序

1. 在现有事件账本上增加统一的 memory candidate schema 和证据引用。
2. 实现离线验证器：错误回放、冲突检测、重复合并和状态转换；先用合成事实和已有时间实验验收。
3. 增加有限预算的 replay scheduler 和预加载计划，测量整理时间、检索 token、旧事实保持和错误纠正率。
4. 再加入 wiki/主题链接表示，与“只做原始检索”的对照比较；只有跨文档问题明显受益时才保留。
5. 最后把通过验证的候选接入神经读取器，独立测试自然语言寻址、未知拒答、纠正、崩溃恢复和普通聊天无回归。

在神经 query-key 读取尚未通过身份区分和未知拒答之前，睡眠模块只能改进账本和候选记忆，不能把未经验证的内容写入 DeepSeek 底座或正式个体的可学习参数。

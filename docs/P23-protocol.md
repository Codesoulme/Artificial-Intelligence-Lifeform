# P23：广覆盖中文与独立语言候选

用户要求持续迭代至实际聊天。P22仍用于检验有限读取；不把继续刷物品题等同于语言成长。P23与此前权重隔离，保留原个体与全部旧语言文件；新路径自行实现并随机初始化，不导入预训练网络。

语言候选初版：宽256、8层、8头、前馈704、共享输入输出嵌入、自建8192词元字节回退BPE、旋转位置表示，512词元上下文。两个位置只读原当前／历史神经矩阵，冻结原个体。注意力、归一化和门控前馈属于已有常用组件，不宣称基础创新。词表改变不能直接继承旧字节输出头；这是同一持久个体的独立语言候选，不冒称P22所有语言知识已迁入。

首先进行小步吞吐、因果性、增量生成与完整生成一致性、随机状态保存恢复及原个体保护检查，再以固定批次渐增训练。所有评估保存原始输出，禁止用其他模型或答案表补齐生成。完成门槛另见[交流目标](conversation-goal.md)。

材料来源为gongjy/minimind_dataset的mini文本与对话文件，仅采用文本，不使用其模型或词表。仓库卡片声明CC-BY-NC-4.0并列出混合上游，当前用于本机非商业研究，保留出处和修改说明，不把教材原文公开推送。两文件按提供方元数据固定版本、字节数和SHA256后使用。镜像网络失败记录保留。

分词器只用训练分区的原文学习；开发／测试文档不参与词表学习。文档先规范化分组再划分，记录精确与近似重复处理范围。最终聊天题不以数据集验证损失替代。过滤工具调用、外部模型身份宣称与非空思考过程；不把公开文本中的人设写成个体事实。原三层价值观材料作为独立回放组继续学习。

首轮只是学习曲线与硬件可行性试验，不能用低损失或流畅片段声称正常聊天。更广语言路径也没有自动获得原符号记忆的语义使用能力，必须另做跨重启自然语言验证。

# P28：用完整短故事检验中文叙事基础

当前目标仍是有用的中文对话。P27的扩展任务文本没有带来稳定改善，P27b在检验混合词元更新；任何一次损失下降都不视为聊天验收。P28先回答更基础的问题：在词汇和情境较简单、故事首尾完整的材料上，这个本地语言路径能否学会连贯续写。

候选来源为 `Gabrui/multilingual_TinyStories` 的中文训练分区，固定版本 `7fb5f327b907318dd95877a366e288f1971b64c1`，首个训练分片。保留上游来源、声明许可 `CDLA-Sharing-1.0`、翻译信息、下载地址和散列；数据正文不推送到代码仓库。故事属于虚构阅读材料，不登记为个体亲历，也不把拟人情节当作事实知识。采用既存文本，不调用外部模型生成教材或回答。

上线条件分开记录：源文件校验、机械隔离、抽样质量三项均需完成。失败的百科候选继续保留且不得混入。新材料采用原8192词表，仅保留可在现有512位置范围内容纳的完整故事；不裁掉结尾、改写缺损片段或拼造事实。按故事分组并去重，对旧开发／测试材料及新留出分区排除有界词面重合。该检查不能证明语义隔离。源仓库测试分区不下载。

准备后的数据保留旧开发文件、旧对话和价值观回放文件原字节，替换预训练的训练流；新增故事开发／测试文件单独保存。固定抽取训练样本人工式评阅，说明抽样只代表一个分片和当前规则，不能当作全库正确性认证。开发文件仅用于评测，测试内容不得用于调参。

训练沿用已验证的混合词元更新器和原个体冻结机制，实验计划在数据及前阶段评审完成后填写精确父快照散列。首段以短故事为主要来源，保留部分已批准教学、小教材和用户指定价值内容回放；具体比例、步数及学习率以固定配置为准，不在运行中修改。阶段结束检查原状态、持久文件与旧记忆答案。

效果同时查看三类证据：新故事开发损失、既有中文续写原文、既有多轮聊天原文。不同数据流的绝对损失不能直接横比；同一流使用固定窗口、相同词表比较父快照与新快照。短故事进步不等于聊天进步；正式交付仍遵循 `conversation-goal.md` 的新场景多轮标准。若未改善，保留失败记录，再决定数据、学习率或容量的下一项对照。

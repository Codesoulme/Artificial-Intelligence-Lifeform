# P34：中文无指令预训练诊断

P27至P30的主要训练每次更新约8192个有效目标词元，通常把教学问答、普通混合文本、短故事和基础课程放在同一更新流中。P28的故事比例为89%，故事开发NLL从4.30降到2.41，但旧文本NLL升到4.01，聊天仍大量重复；P29将故事降到20%后旧文本NLL回到3.50附近，故事NLL仍降到2.87，聊天仍未通过。P30只使用42条审核问答，100步后对话NLL升到3.51，语义仍不稳定。

这些结果证明语言路径能更新并学习局部中文分布，但没有证明它已经完成基础语言建模。当前训练过早加入单轮指令监督，普通预训练文件又是很多无角色的题目与答案拼接；二者都不适合作为从零语言基础的唯一来源。每个阶段的有效词元量也远小于完整语料规模，不能从几百万目标词元推断模型已经充分学习中文。

P34从F-small2000父快照开始，训练流只包含普通预训练分支和完整短故事分支，目标比例80%／20%，不使用教学问答、核心价值focus回放或小教材。普通分支保持原有数据血缘，故事分支保留自己的开发集。首段500步只用于诊断，不晋升聊天候选。

## 判定

- 基础中文开发NLL稳定下降、故事NLL下降、开放续写重复减少：说明前置语言建模不足，继续增加清洁文本和词元预算，再接对话课程。
- NLL下降但续写仍乱码、循环或无语义：检查词表、位置编码、采样、容量和训练标签；不直接追加指令数据。
- 基础NLL几乎不动且语言层张量确实更新：优先检查优化目标、学习率、数据取样和梯度路径；仍不改善才做结构容量对照。
- 基础语言改善但聊天仍失败：进入多轮角色课程，保持基础回放，使用独立聊天评测决定晋级。

P34与P28/P29保持独立检查点，原个体和旧语言候选不替换。这个实验不能证明自然语言意识、内部经历或人工生命，只回答当前语言路径是否需要先完成更长的中文基础训练。

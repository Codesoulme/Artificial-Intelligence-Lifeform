# P32：清醒运行时、自愈基础与中文训练顺序

P31复核后，先加入不会改变语言权重的运行时基础，再继续中文训练。当前实现包括：

- `spora/event_ledger.py`：SQLite追加事件、幂等键、父哈希链、来源、置信度、时间和状态版本；支持完整回放与链校验。
- `spora/awake_session.py` / `spora/awake_cli.py`：清醒时间脉冲、观察、目标和模式切换可写入事件账本。事件只记录结构化元数据，图本体用摘要绑定，避免把账本变成答案表。
- `spora/dna_shadow.py`：独立EMA影子参数、完整摘要、原子保存、人工损坏检测和显式恢复。恢复不会自动发生，也不会覆盖活动模型。
- `spora/health_gate.py`：封存题目摘要、指标回归检查和候选晋级决定。候选集变化或指标退化时拒绝发布。

这四个模块已通过清醒、持久状态和事务测试，共16项相关测试通过。它们尚未自动接管生产语言训练，避免未经验证的自愈修改模型。

## 继续顺序

1. **运行时验收**：对事件重复、乱序、链损坏、崩溃前后、清醒会话恢复和DNA文件损坏做独立测试。
2. **健康晋级接入**：将P28/P29的固定评测结果绑定到候选快照；只有同一题集、同一解码器和旧能力保持同时通过，才可标记候选。
3. **人工对话课程**：P30机械筛选出的11,714条不能直接视为审核数据。先从角色明确的教师记录中人工审核至少256条，建立角色、意图、答案完整性、事实风险和重复风险标签。
4. **中文对照**：用P27b B500同一父快照，采用79%已验证回放与基础语言、20%审核对话、1%核心价值课程；普通散文为0%，故事保留独立分支。先100步，再决定是否500步。
5. **DNA影子实验**：在冻结语言候选上比较不修复、活动权重直接回滚、DNA影子恢复和重新训练四组，人工注入10%、50%、80%参数损坏。先验证恢复准确性、文件成本和身份保持，再考虑自动触发。
6. **Engram对照**：中文对话稳定后再加入小型静态N-gram查找模块，单独测词法损失、复制风险、内存占用和开放聊天，不把查找表写入个人经历。
7. **世界模型与睡眠想象**：最后接入事件账本中的预测、实际观察核对和受限回放。想象事件必须带假设来源，不能直接写成亲历事实。

## 晋级条件

运行时模块只能在恢复、幂等和完整性测试通过后进入默认入口。中文候选必须在独立多轮题上减少重复和无关回答，同时保持旧开发损失、UTF-8/EOS、原个体记忆和重启一致性。单独降低NLL、增加结束符或故事续写变好都不足以晋级。

# 架构收益：目标、已证实能力与未证实优势

2026-11-08。回应用户“区别在哪里已了解，但优势在哪里”的问题。结构不同不等于性能更好；项目目前没有证明整体优于同资源的现成模型。

| 研究目标 | 当前证据 | 不应宣称 |
|---|---|---|
| 新经历进入持久神经状态 | 有限符号环境中的写入、重启保持与参数回退检查 | 任意中文经历已可学习并跨重启准确表达 |
| 纠正当前事实并保留历史 | 有限来源、时间与纠正实验 | 已能判断开放世界真假或任意历史关系 |
| 增长时保护已学能力 | 记忆分段扩展、历史转存，以及语言加宽的有限前向保持检查 | 容量增长必然提高泛化，或可无限增长而成本不变 |
| 来源和想象边界 | 有限来源通道与写入策略 | 完整睡眠想象已完成，或模型拥有主观生命体验 |
| 效率 | 已做读取／存储／训练测量；某些候选更慢 | 已比常规模型更快、更省资源 |

常规模型也把大量知识存于权重；上下文变化不会改变其基础参数。项目重点是如何将运行期间新增的具体经历稳定并入个体，而不是首次实现模型内知识。微调、持续学习、外部存储及其他神经记忆系统也能实现相关功能，不能将它们描绘成完全没有记忆。

中文候选大量采用常见Transformer计算组件。真正待验证的研究收益在于持续写入、历史／来源保持、巩固与语言表达之间的整合。当前语言支路仅连接只读记忆，尚未完成语义对齐，符号实验的成功不能外推为日常交流中的记忆优势。

后续需要在可用语言基础上比较：同数据、同参数／算力预算的普通语言网络；带外部事实存储的系统；本项目的持久神经记忆路径。任务需包含新增经历、纠正、历史询问、重启保持及长期干扰，并同时记录准确性、更新代价、文件增长与回复延迟。个体一致性应按行为与状态连续性测量，不由模型自述或“生命”名称判定。

目前准确的定位是：已验证部分持续记忆机制、语言交流尚未通过的研究原型。保持创新目标，但以实验决定是否存在优势。

参数内记忆也不自动等于稳定人格或抗提示操纵；外部存储同样可以维持个体连续性。应验证不同调用者下经历和边界是否一致，并比较可靠性、纠错／删除能力及成本，而非单凭存放位置判优。

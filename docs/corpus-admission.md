# 训练语料准入策略

`spora.corpus_admission.validate_review` 是训练器之外的失败关闭校验。它要求审查记录明确批准试验、绑定实际文件摘要、覆盖计划步数、声明质量门禁通过，并记录独立审查和抽样计数。

字节语言训练入口还必须调用 `validate_language_training_approval`。批准记录必须同时绑定实际 manifest 摘要和父个体摘要，并通过 `--review` 显式传入；训练配置会保存 review 文件摘要，后续恢复不能更换这份谱系。只有 manifest 的来源、分区和近重复检查通过，不代表候选已获训练批准。

默认 major 比例上限为 0，危险内容数量上限为 0，要求独立审查。调用方可以为明确的探索性实验调整比例，但必须把参数写入新计划和报告；已有候选的 `candidate_not_trained` 状态不会因调用此模块自动改变。模块不读取正文、不计算摘要、不替代版权或隐私审查，也不修改训练入口。

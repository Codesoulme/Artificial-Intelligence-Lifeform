# 自定义网络如何借助成熟模型学中文

## 路线及影响

1. 文本／序列蒸馏：教师给出回答，学生使用自己的词表学习。结构无需相同，学生可从随机权重起步。现有GPT-4生成材料属于这一类最基本的监督信号，但当前材料质量、覆盖和多轮衔接不足，不能把“来自强教师”当作质量保证。
2. 概率分布蒸馏：除标准答案外，学习教师对候选输出的相对判断。通常的逐词元KL损失需要词表／位置对齐；本项目自建8192词元编码与教师不同，不能直接对相同数组下标比较概率。ULD提供跨词表的研究路线，仍须本机实现和验证。
3. 中间表示蒸馏：以可训练映射对齐部分表示或关系。可以保留不同层数／宽度，但层对应、维度变换、词元位置及记忆支路都需要设计，不保证小网络可容纳全部知识。
4. 选择性移植：搬入相容的词嵌入或语言层，再训练适配。架构可保留一部分，但被移植部分不再是从随机状态学到的。仅截取矩阵或强行降维没有保留知识的保证；词表、RMS缩放、旋转位置、头数／分组和共享输出均会影响兼容性。
5. 使用成熟语言模块加自定义记忆系统：最能直接继承已会聊天的能力，但属于混合系统，改变用户最初全部自定义随机起步的路线。此方案目前没有实施。

结构规定计算和学习方式，权重记录学习到的规律。继承权重不会神秘地把结构变成教师，但会带入其知识、行为倾向、表达习惯、偏差及部分能力边界。蒸馏也会传递这些特征，绝不是没有影响。

## 推荐的可比较试验

保留当前学生与个体，先选择一个通过来源／许可核验的教师。教师仅参与离线教学，交互时由本模型独立生成。准备不同于开发／最终题的日常解释、澄清、信息更新、指代与纠错教学；教材中的第三方故事不能成为本个体亲历。保持原重点价值观原文回放。

同一学生快照分为普通监督组和教师增强组，按有效目标量、实际训练时间、教师生成／推理成本分别报告。以新问法和真实历史的多轮回答决定收益。先做文本教学，再决定是否实现跨词表或表示蒸馏；不把这些尚未实现的算法当作当前能力。

如果尝试参数移植，必须另立明确混合初始化分支，保留当前随机起源谱系；移植前后比较旧记忆、语言表现、身份和虚构亲历倾向。冻结原个体只能保证原神经状态不变，不能证明自然语言已经能正确表达它。

## 证据与限度

- MiniLLM，https://arxiv.org/abs/2306.08543 ：研究生成式语言模型的教师分布蒸馏和反向KL目标；摘要中的学生规模120M–13B，不是本项目8.6M／30M中文候选的直接收益预测。
- ULD，https://arxiv.org/abs/2402.12030 ：针对不同结构与词表的输出分布蒸馏，基于最优传输。支持跨结构借助教师的可行性研究，不提供本项目的已验证配方。
- TinyBERT，https://arxiv.org/abs/1909.10351 ：表明Transformer表示蒸馏可有效压缩特定理解任务；BERT／GLUE结果不能直接外推为中文开放聊天。

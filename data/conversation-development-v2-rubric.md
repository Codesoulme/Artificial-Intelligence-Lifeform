# 中文多轮开发诊断 v2：人工判断要点

此文件仅用于开发比较，不是最终独立验收。逐轮阅读实际回答，检查是否理解问题、遵循约束、合理利用历史、避免无根据地断言；不能仅凭关键词或结束符打分。第二轮以后使用模型自己生成的历史，不同模型看到的历史可能不同，因此逐轮差异不能简单归因于某一处能力。

| 场景 | 最关键的检查点 |
| --- | --- |
| 早餐约束 | 建议不含鸡蛋；无面包后换可行方案；最后压缩自身方案。 |
| 先后顺序 | 初始上午邮局、后来菜市场；对调后先到菜市场。 |
| 两人借物 | 杂志由阿青借出；钢笔由阿青持有，还后回到小陈。 |
| 未知数量 | 未见抽屉应说明不知道；七张拿走两张为五张。 |
| 改约时间 | 最终周四晚上八点，影院门口。 |
| 风格与长度 | 有安慰、轻松、不新加建议，末轮不超过十个汉字。 |
| 条件计划 | 下雨按原计划看电影；合理确认朋友是否方便或一起看。 |
| 否定与原因 | 温水；未给出不喝咖啡的原因；改喝后为茶。 |

对超短回复、泛泛复述或拒答，应结合每轮问题判断；事实题的精确措辞可以不同。不能用本开发集成绩作为独立验收，也不能据此声称长期记忆已写入模型。

# 单层历史键值接入对照

日期：2026-11-27。根据[预先计划](spora-native-attention-oracle-plan-20261127.md)，比较关闭、重算当前注意力、旧研究核和直接附加人工给定的历史键值；底座与研究候选冻结。运行正常退出，输入权重和候选文件摘要前后一致；用时约 127 秒，CUDA 峰值分配约 3.37 GiB。

## 方法和结果

八个样本为两位人物、饮品和水果各两个值。同一问题只改变事实状态。历史状态由每条人工事实单独前向计算，取第 5 层、第 0 个 KV 头；重新计算该头对应的六个查询头注意力并拼入历史键值，其余注意力输出沿用原模型。旧核使用同一份事实键值并注入同一个头组。没有训练，也没有自动写入、查询或正式持久化。

| 条件 | 回答含完整目标 | 自然结束 | 换值后两次都含对应目标 |
| --- | ---: | ---: | ---: |
| 关闭 | 0/8 | 0/8 | 0/4 |
| 只重算当前注意力 | 0/8 | 0/8 | 0/4 |
| 旧研究核注入 | 5/8 | 8/8 | 1/4 |
| 直接加入历史键值 | 0/8 | 0/8 | 0/4 |

旧核唯一两值均出现的组为小林饮品；水果组均把香蕉答成苹果。直接加键值的八条都输出与关闭时相同的自我介绍并在 24 词元处截断。是否包含字符串只是筛查，不等于回答事实可靠。

第一个问题在未生成时，对比原路径与手工重算当前注意力：所有位置 logits 的最大绝对差为 0.041015625，最大值词元一致；八条自由生成中，重算与关闭逐词元相同。这为本轮条件提供有限校验，但不保证其他输入、实现或精度下相同。

## 判断

仅把这一层一个头组的原始历史键值拼回当前注意力，未能让本组回答读出事实；不支持直接以此方案替代旧研究核。旧核能在部分题目输出正确词，但也把不同值映射为同一回答，仍不可靠。

预计划称此为“上界参照”不严谨：单层、单头、固定位置与特定缩放并不代表多层完整历史缓存的上界。这里也没有复现 MoNe 的多层神经记忆、元训练投影、门控、分段学习或评测条件，结果不能用于评价该论文整体有效性。问题可能包括注入层、注意力权重、位置编码、早期层缺少事实及查询表示；现有实验不能确定原因。

后续先根据公开研究和已有结果设计跨层、位置及注入强度的受控诊断，并在相同题目上测注意力分配和输出变化；不要把结果直接归因于记忆压缩，也不要继续扩大旧标量门控预算。目标仍需可更新神经状态、自动选择、纠错、重启与真实对话验证。

逐条输出及输入摘要保存在本机 `runs/research/native-attention-oracle-20261127-v1/result.json`；代码入口为 `scripts/deepseek_native_attention_oracle_20261127.py`。实验使用人工事实、两种固定问法与少量人物，不能推断一般中文能力或个体记忆能力。

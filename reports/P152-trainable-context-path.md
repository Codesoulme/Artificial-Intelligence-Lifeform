# P152 可学习上下文路径

审查语言接口后发现，原 `LanguageBridge.contextualize()` 是恒等函数。字节嵌入进入冻结的随机骨干后，训练只剩输入嵌入、记忆读投影、逐位置适配器和输出头，缺少明确的可学习因果序列建模层。这会让中文连续学习过度依赖随机骨干的固定变换，不能把此前的低进展简单归因于数据量。

本轮新增可选的因果上下文层：

- 每层是从随机权重开始的多头因果注意力和前馈残差混合器；
- 输出投影和前馈下投影零初始化，初始行为保持残差恒等，降低对旧接口的破坏；
- 默认 `context_layers=0`，旧 v1 接口和历史检查点保持兼容；
- 新接口使用 `spora-byte-interface-v2`，显式记录上下文层数并在载入时严格匹配；
- 训练、评估和本地交流入口都会从接口元数据恢复层数，不能把 v2 参数错误载入旧结构。

本轮只完成结构和断点恢复路径验证，没有启动中文训练，也没有把随机字节或有限模板诊断当作中文能力。下一步应在权利清晰的原创候选上做同父个体、同预算的 v1/v2 对照，观察开发损失、UTF-8 完成度和独立多轮行为是否真正改善。

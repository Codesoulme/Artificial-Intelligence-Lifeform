# 两项待定草稿的跨轮确认

在固定 CrossWOZ 验证包的 242 个字面新值事件中，按领域和字段取 24 条，核对前后用户表达，并补读七个案例的中间轮次。部分字段变化来自更换查询对象、新开搜索或询问属性。以「改成」「换到」「还是」「重新」等常用措辞筛选，只有 3 个字段事件、2 个用户回合进入筛选结果。这两回合分别发起新的游览搜索和回到景点门票请求，缺少确定覆盖旧记录的独立标注。CrossWOZ 可帮助构造容易发生误写的场景，当前数据未用来训练或充当更正确认真值。 [前轮语料统计](spora-revision-value-roles-20261125.md) · [CrossWOZ](https://aclanthology.org/2020.tacl-1.19/)

## 对照

在六个已知场景中，每个案例设置两项已知字段和完整备选值。先列出两个待定草稿，再用一句话明确讨论其中一项，或说明两项的指向仍不清楚。最后一句确认对本组所有样本完全相同。交换草稿顺序后再测一遍。每个候选独立评分，当最高分或两者分差不足时保持原记录。在校准集优先减少误写，再最大化正确提交。

三个数据划分分别有 144、36 和 24 组事实，对应 864、216 和 144 个决策。训练、校准和留出的范围措辞不同。特征使用 DeepSeek 孢子冻结前 20 层，每组训练相同大小的循环分类头。第一组只读最后一句。第二组给特征提取器当前待核对的草稿和会话，分类时只取最后确认句的隐藏表示。第三组改为读取建立指向的句子，已知后续动作是确认。实验使用已知待选草稿并写入隔离会话状态，后续还需把经过实际提取的候选和自然指向接入同一路径。

第一轮两组在校准门槛下都没有放行。无门槛时，有完整前文的末句特征在 96 条明确指向题中有 59 条把正确草稿排在前面，校准集仅 71/144。只含最后一句的输入在同一组两个候选上分数相同。简单选择最后列出的草稿能答对 48/96，还会对全部 48 条指向不清的记录发起写入。首轮主要是诊断跨轮信息从哪里进入分类器。 [前轮更正事件实验](20261125-revision-events-stall-diagnosis.md) · [Event-DST](https://aclanthology.org/2026.conll-main.30/)

| 指标 | 只读确认句 | 读过全文后的确认句 | 直接读取指向句 |
| --- | ---: | ---: | ---: |
| 明确指向时，校准集正确草稿分数严格更高 | 0/144 | 71/144 | 91/144 |
| 明确指向时，留出集正确草稿分数严格更高 | 0/96 | 59/96 | 48/96 |
| 校准门槛下，明确指向的留出提交正确 | 0/96 | 0/96 | 0/96 |
| 校准门槛下，指向不清却提交 | 0/48 | 0/48 | 0/48 |

直接读指向句在校准集能正确提交 1 条，在留出集没有写入。当最高分候选缺乏明显差距时不提交。末句特征的最高候选分在新措辞下普遍低于固定阈值网格，另从校准集观测到的最高候选分逐个取阈值，并令所需分差高于剩余错误候选。用这套较细的边界重新计分，末句组在校准集有 3 条正确提交，留出仍为零。直接指向组在校准集仍只放行 1 条，留出却误选了 2 次明确指向另一草稿的记录。仅调整门槛无法得到可靠写入。

这些结果支持分别训练动作确认和引用绑定。当前头在训练时每个字段只有一种指向说法。后续应让相同字段对应多种措辞，并做整个字段描述及场景留出。在模型内部可分别编码草稿的主题及字段和当前发言，再比较其语义特征。匹配结果应能拒绝缺少目标的确认，并在两项顺序交换后保持一致。 [Description-Driven Task-Oriented Dialog Modeling](https://arxiv.org/abs/2201.08904)

前两组训练加评测约 229 秒，直接读取指向句约 206 秒。第三组独立重载用时约 204 秒，逐题复现分数、提交和状态回放。三次运行的受控持久记忆读回均为 32/32，与事件父实验逐条一致。15 项相关单元测试和草稿顺序、指向句偏移及拒写条件检查通过。逐题结果分别位于两个运行目录的 `result.json`。

## 复现

```powershell
$env:OMP_NUM_THREADS = '2'
$env:MKL_NUM_THREADS = '2'
$sporaSplit = 'runs/spora-recurrent-split_gated_block_delta-warm-v1'
$sporaArgs = @(
    'runs/spora-composition-late-gates-20-23-24-v1/candidate.pt',
    'runs/spora-revision-events-v1/result.json',
    'runs/spora-revision-reference-v1',
    "$sporaSplit/layer-19", "$sporaSplit/layer-22"
)
.\.venv\Scripts\python.exe -u -m scripts.train_spora_revision_reference @sporaArgs
```

读取指向句时将输出目录改为 `runs/spora-revision-reference-clause-v1` 并添加 `--scope-clause`。独立重载用相同运行参数并追加 `--verify`。

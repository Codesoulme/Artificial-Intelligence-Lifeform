# 从输入向量到输出空间的记忆桥试验

## 问题与方法

上轮直接取底座输出头对应词元的向量来编码，受控首词输出较高，但写入时依赖答案词元的输出头行，不体现从输入表示学习。本次改为用冻结底座**输入词向量**投影到 90 维，拟合一个线性映射，预测同一词元的冻结输出头行的 90 维投影。预测向量经反投影后添加到隐藏状态，由原输出头评分。映射使用 11,936 个词元类型拟合；另以 64 类型选择增益、128 个不重叠类型测试。材料来自本地中文维基百科训练分区，底座预训练是否见过相关词元未知。

写入时仍由程序提供词元编号及地址；这是利用预训练输入词向量的受控词元编码，不是自然经历理解。训练目标使用对应输出头行，因此不能宣称无需词元监督。增益候选为 0、10、30、100、300、1000，以校准正确数最高、平局取较小者选择。

## 结果

64 个校准词元在所有增益下均为 **0 个正确**，因此选择了 0。留出集直接输入、临时矩阵读回及空记忆均为 **0/128**。零增益意味着自动选择的条件实际没有给语言模型注入记忆，不能拿它评价非零干预的效果。

随后增加了事先用于旧输出对齐实验的固定增益 1000 作为诊断，在同一留出集上经矩阵读取的正确数仍为 **0/128**；64 对不同目标中，40 对首词不同，但没有一对两侧均正确。六个无关问题在零增益时首词未变，在固定 1000 强制注入时 **6/6** 首词发生变化。测试只比较首词，不证明整句质量。固定增益诊断是在看到零增益选择后补加，因此不能当作完全预先登记的独立评测。

留出向量映射结果与输出侧目标的平均余弦约 0.498；临时记忆矩阵读回输入投影的最小余弦约 0.99999988。这说明受控存取没有明显破坏向量方向，但本次线性映射没有达到正确输出。它不证明所有输入侧编码、非线性桥或自然语言结构都不可行。

两次分别约 174 秒和 150 秒，PyTorch 峰值约 3.52 GiB；源底座、候选和个体摘要前后核验。拟合及输入检查的两项测试通过。代码 `scripts/deepseek_input_to_output_memory_pilot_20261117.py`，结果 `runs/deepseek-spora-input-output-memory-pilot-v2-20261117.json`；候选未保存为可部署模型。初版结果另存于 `runs/deepseek-spora-input-output-memory-pilot-20261117.json`。

## 决策

不接入该映射，也不以向量相似或首词变化代替正确回答。下一步优先从已有连续记忆到完整回答的隐藏状态桥出发，研究多关系、多词元的换值训练，同时单独核验人物、关系和完整事实。既有多关系报告的部分 `stored_value_correct` 只检查目标值及同域竞争词，没有严格核对人物和关系；这些分数不能直接当成完整回答正确率。空记忆、无关问题和独立重载仍须单列。

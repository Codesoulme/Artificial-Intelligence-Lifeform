# P161 中文连续语料用途分流

对 P158 的 1,085,328 条训练记录进行了第二次流式扫描，只输出类别计数和每类固定样本。没有读取开发或封存测试分区，没有复制完整正文，也没有启动训练。

机械分流结果：

| 类别 | 记录数 | 占比 |
|---|---:|---:|
| 连续文本候选 | 361,394 | 33.296% |
| 指令/任务形态 | 358,277 | 33.031% |
| 混合待审 | 127,177 | 11.722% |
| 商业词/模板线索 | 78,243 | 7.210% |
| 知识风险词 | 60,176 | 5.545% |
| 风险或噪声 | 56,097 | 5.169% |
| 代码/标记 | 33,928 | 3.126% |
| 对话/角色形态 | 10,036 | 0.925% |

这里的“连续文本候选”只表示没有触发本轮形态规则、长度和汉字比例满足阈值；它没有通过事实、隐私、版权、来源、语义重复或人工质量审查。相反，其他类别也不等于全部拒绝，部分记录可能在专门的数据用途下有价值，但必须和连续预训练分开处理。

当前最合理的下一步是只对 361,394 条机械连续文本候选按来源、长度和 group 做分层盲审，再决定能否形成小规模训练子集。P161 本身不改变 `candidate_not_approved_for_training` 状态。

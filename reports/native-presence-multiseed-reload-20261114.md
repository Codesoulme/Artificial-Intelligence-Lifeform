# 原生记忆存在状态检查

## 方法

对同一个既有孢子个体的参数，分别建立三个空白隔离状态，使用三个固定随机种子。每条轨迹依次写入 16 个数字地址、尝试更正其中 8 个地址，再向另外 16 个地址写入 48 次干扰，共 72 次观察，状态扩展至两页。

每个阶段在全部 64 个数字地址上读取原生分类结果：最高分为未知类别则视为未知，其余类别视为已知。实验记录只在控制器实际接受当前写入时更新期望值，因此检查的是“已接受写入后的状态是否匹配”，不是独立判断观察是否真实。最后把隔离状态保存到临时目录，由新进程加载并重新读取全部地址，比较预测和完整状态摘要。

## 结果

三个种子的结果相同：

| 阶段 | 已接受地址数 | 未知误判为已知 | 已知误判为未知 | 已知值读取正确 |
| --- | ---: | ---: | ---: | ---: |
| 空状态 | 0 | 0 | 0 | 0/0 |
| 初次写入 | 16 | 0 | 0 | 16/16 |
| 更正后 | 16 | 0 | 0 | 16/16 |
| 干扰及分页后 | 32 | 0 | 0 | 32/32 |

三次新进程恢复的全部预测与状态摘要均一致。各轨迹使用相同模型参数，阶段之间和地址之间相互关联，不能将结果当成独立模型的统计可靠性。

## 对架构的意义

这个原生有限记忆的存在信号值得继续研究：在本批受控状态中，它同时区分了已接受地址和空地址，并保留了更正后的值。它目前不能直接修复最近低秩参数试验中的未知人物误答：那些试验没有连接该有限记忆，且自然语言到数字地址的解析可能选错人物；原生类别概率也没有经过置信度校准。

下一步需要在隔离实例中联测语言识别、地址选择、存在状态和最终回答，分别记录误接受、误拒绝及错误值，并覆盖相似姓名、未知关系和普通请求。不能把实验提供的数字地址当作模型已经完成自然路由。

## 限制

只有三个随机轨迹、一个已训练个体、64 个地址及有限值类别；没有自然语言、关系消歧、多用户、长时间负载或概率校准。重启检查不是断电恢复、并发写入或完整聊天评测。原个体摘要未变，实验检查点位于系统临时目录，结束后由临时目录管理器清理。

脚本 `scripts/spora_presence_multiseed_reload_audit.py`；逐地址结果位于 `runs/spora-presence-multiseed-reload-20261114.json`。

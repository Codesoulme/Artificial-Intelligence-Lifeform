# 同一答案跨记忆状态的对比试验

原有片段损失在每个记忆状态下比较不同答案的平均对数概率，因此既受记忆影响，也受不同答案原有概率差异影响。本试验加入隔离研究目标：同一个答案、同一强制前缀下，比较正确记忆与替换记忆；两边分别计算，再与原有完整答案、首词交叉熵和首词对比目标联合训练。它只要求正确状态相对提高答案概率，并不保证答案成为最高概率或能完整生成。

沿用多词元片段组的起点、种子、训练集、样本顺序、64 步、其他损失和生成设置，只替换片段目标；与先前未启用片段目标的对照一起比较。身份、事实与地址依然由实验指定，模型生成时没有提供事实文本。该研究入口通过在本进程替换损失函数来实施对照，未改正式模型；结果记录中的通用配置字段 `multitoken_counterfactual_weight` 不区分损失类型，必须与本入口及本报告一起理解。

三组训练前 70 条输出逐词元一致，训练后 70 条也逐词元一致；与训练前相比均有 3 条输出变化。按既有受控短句评分，留出人物与留出值的原值回答为 **0/12**，同一问题原值与换值两侧均正确为 **0/12**，训练人物严格正确 **2/36**；三组相同。每类两个留出值、一名留出人物、两种问法，题目并非独立样本；换值一侧可能为训练值。评分规则可能拒绝正确改写，不能替代开放语义判断。

运行约 369 秒，PyTorch GPU 峰值约 4.16 GiB；底座和来源保护检查通过。结果与隔离候选在 `runs/deepseek-spora-multitoken-state-contrast-64-20261117/`，脚本为 `scripts/deepseek_spora_multitoken_state_contrast_20261117.py`。11 项相关单元检查通过。保存候选尚未独立进程重载；其格式沿用既有框架，但配置没有单独标明本次损失，不能当成自描述训练记录。

这一结果没有支持所提出的目标在当前预算和条件下改善生成；不能据此排除其他权重、数据或结构。受控事实不证明自然记忆写入、身份寻址、未知拒答、跨会话保持或普通对话安全。下一步需要改进读写结构和训练数据，并优先进行反事实、无关记忆干扰以及独立重载评测，不将此候选部署。

# 文本级记忆重建阶段报告

## 方法

新增一个独立的小型自回归回答头，不调用 Qwen 对话生成器，也不注入 Qwen 输出 logits。它读取孢子连续矩阵中的语义槽，经过冻结的词向量语义桥，再逐词元重建完整中文事实句。训练目标是文本交叉熵，训练人物为小林、小周、小王，留出人物为小赵。

## 结果

- 训练人物完整句重建：54/54 exact。
- 留出人物事实内容：18/18 包含正确水果。
- 留出人物完整句：0/18 exact，因为姓名全部被生成成训练过的小林或小周。
- 留出人物示例：目标“小赵喜欢的水果是苹果”，输出“小林喜欢的水果是苹果”。

这说明连续记忆可以支持未见人物上的事实内容重建，但当前小型文本头没有学会从身份槽泛化出未见姓名。失败集中在实体表面化，水果事实本身没有失败。

## 判定

这是对记忆结构的重要正向证据：独立文本头能够从内部连续记忆重建完整中文事实，不依赖当前问句或 Qwen 的语言先验。但它还不是开放文本记忆，因为身份泛化失败，且数据仍是人工水果事实、数字地址和有限词表。候选未接入正式个体。

下一步应加入身份 token 的独立重建损失、实体组合留出和已知身份/未见事实交叉测试，区分“记忆内容可重建”和“实体绑定可泛化”。

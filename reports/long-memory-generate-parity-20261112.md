# 长输入下记忆生成的缓存对照（2026-11-12）

对当前整合模型，给两个已知数字键各写入旧值和新值；输入由重复的人工作文式填充及单个中文问题构成，长度均为 174 词元。使用程序指定的键、当前或历史事件地址及对应输出证据，在同一份不可变临时记忆上分别调用 `IntegratedOpenBase.generate`，比较开启与关闭缓存的贪心生成，最多 24 个新词元。

四组的缓存与非缓存输出词元完全一致，两个记忆读取位置在每种条件下均执行。两组严格回答预期值；一组当前值应为“豆浆”却答“水”，一组历史值为“果汁”却答“橙汁”。后者不满足严格匹配且加入了未验证的具体种类；不能仅凭它判断完全错误，但也不应当把更具体的描述当作已知事实。测试前直接数值记忆读取在四组均得到目标值，说明至少在错误样本中，直接记忆值正确仍不足以保证语言输出正确。

运行结果中的每组缓存与非缓存内容相同，但只有两个键、四个问题和一段重复填充；地址与时间由程序直接提供，未验证自然语言路由、写入或真实对话。缓存只在同一次生成中使用同一快照，没有跨记忆写入或跨会话复用；24 词元上限可能截断回答。模型原检查点及真实个体摘要未变。

脚本 `scripts/deepseek_spora_long_memory_generate_parity.py`，结果在本机 `runs/deepseek-spora-long-memory-generate-parity-20261112.json`；约 99 秒，峰值分配显存约 3.71 GB，使用研究流式加载器。后续应扩大事实、人物和表达，追查记忆值到语言输出的偏差，并验证写入后重新生成不会携带旧缓存。

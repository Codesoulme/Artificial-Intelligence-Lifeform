# TTT 写入目标的值向量约束

## 方法

从 `ttt-joint-writer-reader-20261116` 的同一初始化、随机种子、数据与 192 步预算出发，除原回答损失外，对训练事实值所在位置的写入目标加入余弦约束，使它接近冻结底座对应词元的输入向量，权重为 1。该目标只用于训练人物和训练饮品；测试人物和测试饮品不用于优化。事实值边界由程序指定，这是理想化写入实验。

这次使用 DeepSeek 原语言层内的 TTT 研究分支，不是第 6、12 层孢子替换候选；临时状态和低秩适配器也不属于正式个体。旧结果可作为同配置历史对照，但新目标带来额外计算，且未在本轮重跑旧组。

## 结果

| 条件 | 原联合训练 | 加值向量约束 |
| --- | ---: | ---: |
| 训练人物、训练饮品 | 4/16 | 4/16 |
| 留出人物、训练饮品 | 2/8 | 2/8 |
| 留出人物、未训练饮品 | 0/4 | 0/4 |
| 留出人物、新问法、训练饮品 | 2/8 | 2/8 |

两组 36 条生成逐词元一致，但训练出的写入器和读取器并非完全相同：与旧候选相比最大参数绝对差分别约 0.136 和 0.021。新增约束的训练采样损失从首步约 1.030 到末步约 0.962，首尾是不同样本，不能据此评估收敛程度。两条普通问题在关闭记忆时训练前后输出一致，仅是极有限的控制。

此方案没有展示未见值或实际输出的改善，不接入正式个体。严格短答可能漏判合理完整句，样本小且单种子；没有检验自然路由、持久化重载、事实更正或真实多轮聊天。底座文件摘要前后相同，训练约 139 秒，CUDA 峰值分配约 3.65 GiB。

代码为 `scripts/deepseek_spora_ttt_joint_writer_reader_pilot.py`，隔离结果和候选在 `runs/deepseek-spora-ttt-value-alignment-20261116/`。辅助损失测试检查值配对与梯度，不证明语言能力。

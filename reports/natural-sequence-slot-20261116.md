# 自然语言序列语义槽审计

本轮把槽从单向量扩展为有限长度的向量序列。自然语言写入器从事实值文本取得完整 token 序列，并追加 EOS 向量；读取头在缓存生成的每一步消费一个向量。状态文件保存序列、长度、占用标记、人物关系键、修订号和底座绑定摘要。

## 结果

初始写入并重载：

- “小林喜欢喝椰汁”：2 个值 token，生成 `椰汁 + EOS`，完整匹配
- “小梅喜欢喝柠檬水”：2 个值 token，生成 `柠檬水 + EOS`，完整匹配
- “小赵喜欢喝什么饮料”：没有路由

纠正并再次重载：

- 小林改为“矿泉水”：1 个值 token，生成 `矿泉水 + EOS`，完整匹配
- 小梅仍为“柠檬水”：完整匹配
- 小赵仍没有路由

初始已知事实 `2/2` 完整正确，纠正后已知事实 `2/2` 完整正确。结果文件为 `runs/deepseek-spora-natural-sequence-slot-audit-20261116.json`。

## 判断

序列槽解决了此前单向量读取只能保证首词、后续继续列举的问题，并保留了纠正、未知拒读和持久恢复能力。当前读取增益仍是容量原型，写入端直接使用值 token 向量，解析句式有限；它还没有自动学习写入、开放关系抽取、自然身份消歧或完整自由聊天能力。下一步应把序列写入器从 token 向量直存改成可训练的文本编码器，并加入多轮聊天与冲突事实评测。

# 逐项寻址与自动分段对照

同问句换档的配对训练没有让集合头正确减少读取。本轮把请求拆成若干片段，让每个片段独立在四条候选和「无匹配」之间选择，再合并选中的地址。候选文本只包含场景与字段名称。逐项匹配参考 Schema-Guided Dialogue，错场景与同名字段的干扰继续沿用删档对照。 [上一轮](spora-address-deletions-20261127.md) · [Schema-Guided Dialogue](https://arxiv.org/abs/1909.05855) · [StaleBench](https://arxiv.org/abs/2611.19752)

冻结双循环版的第 23 层特征，使用 60 条训练请求中的 120 个带标注片段，训练一个共享匹配头。无匹配选项的对数分数固定为零，和四个地址分数一起训练及解码。三种评测使用同一个头。标注组输入目标短语，标点组用仓库已有的分段器处理原问句，连词组把同样的目标短语用「还有」连起来再交给同一分段器。标点组的输入可包含额外文字，差异反映整个分段接口的影响。

| 指标 | 标注片段 | 自动按标点 | 「还有」连接后按标点 |
| --- | ---: | ---: | ---: |
| 普通留出整题选对 | 25/32 | 14/32 | 12/32 |
| 普通留出误选字段 | 2 | 11 | 8 |
| 原换档整题选对 | 5/12 | 5/12 | 3/12 |
| 新换档整题选对 | 5/12 | 2/12 | 3/12 |
| 原换档减少一项 | 4/12 | 4/12 | 0/12 |
| 新换档减少一项 | 4/12 | 0/12 | 0/12 |
| 原换档前后地址均正确 | 2/12 | 2/12 | 0/12 |
| 新换档前后地址均正确 | 2/12 | 0/12 | 0/12 |

原集合候选在同一批普通留出题中答对 19/32，在两套换档中均无完整正确的删档前后配对。逐项匹配在提供短语时更有效。普通题按标点切成 120 个片段，标注组只有 64 个，其中「关于某场景，询问字段」会被切开。新换档按标点恰好得到两个片段，整题仍只答对 2/12，说明片段边界和附加文字都会影响读出。标注组在三道新场景无匹配题里也全部误选，字段匹配和弃权仍需改进。

实验约 233 秒，独立按逐题输出复核整题计数，32 项相关回归通过。实验只评估地址选择。权重和逐题输出位于 `runs/spora-clause-addresses-v1`。后续可在同一问句中标注请求跨度和关联场景，训练分段器保留场景前缀并识别无标点的复合请求，同时加入新场景的无匹配样本检验弃权。

```powershell
$env:OMP_NUM_THREADS='2'
$env:MKL_NUM_THREADS='2'
$env:PYTHONUTF8='1'
$parent='runs/spora-composition-late-gates-20-23-24-v1/candidate.pt'

```

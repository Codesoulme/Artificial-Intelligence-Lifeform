# P207 跨来源故事预测诊断

使用先前对照过源码、网页和初步文本质量的 Storybooks Canada 中文故事，选取原审查标记为“通过”的 20 篇，共 30,578 UTF-8 字节。以 P203、P206 和 P205 两个分支的相同词表，对相同正文和固定 128 单位窗口逐单位计算下一单位损失，排除 EOS，再按原文 UTF-8 字节归一化。每篇的来源摘要、损失和评测输入摘要保存在 `runs/p207-storybooks-hybrid-evaluation-20261109.json`。

| 检查点 | 原文每 UTF-8 字节 bits |
| --- | ---: |
| P203，扩容前后代 | 4.26583 |
| P206，扩容后 100 步 | 4.12500 |
| P205，冻结语言块 | 4.19850 |
| P205，可训练语言块副本 | 4.19480 |

在这 20 篇中，P206 相比 P203 每篇的归一化损失均降低；P205 副本组相对冻结组有 16 篇降低、4 篇升高。后两组是相同数据、种子和更新数的配对实验，但参数量和计算量不同；P206 与 P205 使用的数据窗口、种子及结构也不构成严格配对。小样本与先前多次使用的材料不足以推断普遍收益，也不能证明架构优劣或聊天能力。

这组故事曾经过项目探索，不是最终验收。此前 [P95](P95-storybooks-overlap.md) 对 P28 训练池和部分旧来源做过有限全文及片段检查，没有发现 20 字符重合，但无法排除翻译、改写、其他祖先或语义重合。故事审查是模型初评，未逐篇核对译文、事实或完整权利链；不能将评测用途解释为训练准入。

混合词表可能对同一文本存在多种单位序列；这里仅计算确定性编码路径的负对数似然，不是对所有可能编码路径求和的精确字符串概率。固定窗口会重置上下文，EOS 未计入，因此数字主要用于同一词表和评估条件下的对照。它们不是输出质量、结束率或长期记忆对齐的证据；P206 的实际生成仍重复且不能回应用户，见 [P206](P206-expanded-story-diagnostic.md)。

原个体、四个检查点和词表评测前后摘要一致，内存中冻结个体状态不变；未读取最终测试正文或执行训练。`scripts.evaluate_storybooks_hybrid` 校验审查记录、故事文件及检查点绑定，并支持含可训练块副本的后代。

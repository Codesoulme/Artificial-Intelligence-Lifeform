# 时间判断分歧与持续学习研究（2026-11-12）

连续两轮时间头训练在一条旧题上将“后续”判为“过去”，简单回放蒸馏仍未消除这一回退。查阅研究后，考虑的方向包括：

- [A-GEM](https://arxiv.org/abs/1812.00420) 利用回放约束新任务更新，减少对既有任务的干扰；其研究涉及持续任务学习，并非本项目这种小型时间分类器的直接保证。当前 v3 只是训练样本上的软输出保持，并未实现 A-GEM 的梯度约束。
- [Selective Classification for Deep Neural Networks](https://arxiv.org/abs/1705.08500) 研究以覆盖率换取选择性预测风险，要求符合其校准与数据假设。两个模型赞同并不自动具有论文中的风险保证。
- [DGAR，ACL 2025](https://aclanthology.org/2025.acl-long.537/) 在时序知识图谱持续推理中研究历史上下文和新旧事实冲突，采用生成与自适应回放。其问题设置、数据和模型均不同于孢子的数值记忆，不能将其结果直接当作这里的验证。

在现有结果上事后计算一个**离线方案**：两个时间头输出同一类别时采用该类别，不一致时暂缓。并未将其接入模型。比较先前已查看的 86 条同题同标签旧开发样本，以及 36 条已查看的新句式：

| 样本 | 原版：错误读取 / 错误暂缓 | v3：错误读取 / 错误暂缓 | 一致才读取：错误读取 / 错误暂缓 |
| --- | ---: | ---: | ---: |
| 旧开发 86 条 | 1 / 0 | 1 / 1 | 0 / 2 |
| 新句式 36 条 | 3 / 3 | 0 / 0 | 0 / 3 |

错误读取包括选择与标签不符的具体时间类别；错误暂缓指标签要求时间类别但给出暂缓。两组分别只能说明这批题上观察到的取舍；一致也可能共同判错。样本小、模型相关且已经用于方案选择，无法估计真实风险或确认可用性。旧数据有一条标签发生变化，已排除。

复现脚本 `scripts/deepseek_spora_temporal_agreement_audit.py`，本机结果 `runs/deepseek-spora-temporal-agreement-audit-20261112.json`。后续需保留独立的时间方向、否定、未知和多时间事件数据，比较错误读取与暂缓的代价，并用真实完整流程验证；也可研究具有代表性的旧样本回放及约束梯度，而非直接依赖两个高度相关的头。

# 人物与关系分开判断的诊断

## 方法

上一轮整句三分类探针对不同问法泛化不足。本轮从冻结底座中提取两种隐藏表示：实验提供准确姓名位置并对该位置的词元取平均，训练人物分类头；整句末端向量训练关系分类头，区分饮品、城市、爱好及普通问题。训练问题与上一轮扩展探针相同，均由程序提供人物与关系标签。

实验还手工提供五名已知人物与三种关系的事实存在表。两个分类头的输出与该表组合，选择已有原样本候选、扩展样本候选或冻结底座；不把事实答案插入问题或输出。人物位置及存在表均不是模型自主获得，保存的名字和表只是隔离诊断数据，不能视为个体的自主参数记忆或身份凭证。

沿用上一轮 100 条开发问题和 23 条新句式问题的逐路径生成；若本次需选择此前未保存的底座回答，则重新生成。题目和候选在开发阶段已经查看，普通训练问题仍有 8 条与评估重叠。

## 结果

两个分类头的训练准确率均为 100%。部分严格短答结果如下：

| 检查 | 上轮整句探针 | 分开判断 |
| --- | ---: | ---: |
| 旧开发集：已知事实留出问法 | 11/14 | 14/14 |
| 旧开发集：未知人物与未知关系 | 41/56 | 56/56 |
| 新句式：已知事实 | 4/7 | 5/7 |
| 新句式：未知人物 | 8/12 | 7/12 |
| 新句式：已知人物未知关系 | 4/4 | 2/4 |
| 普通留出问题选择底座 | 8/8 | 8/8 |

短答改善不能掩盖内部识别错误：60 条陌生人物问题涉及 16 个名字，其中 31 条将陌生人错判为已知人物，涉及 9 个名字；31 条中有 28 条的最终回答仍恰好严格为“不知道”。因此只看回答会低估错误归属。多条问题共享姓名与句式，不能把 31/60 当作独立样本的真实错误率。

新句式中，关系分类对七条已知事实正确 4/7，对十二条陌生人物问题正确 7/12，对四条已知人物未知关系正确 1/4；部分路由结果偶然仍给出正确短答。普通问题的人物位置在实验中被直接标为不存在，并未验证自动姓名定位。

## 限制与判断

尽管部分开发题的最终回答提高，这个候选仍不可靠：人工提供准确姓名边界仍存在大量人物误认，关系分类在新句式下也不稳。手工存在表只反映当前七条标注事实，不能自行更新或处理同名、别名和时间；如果姓名被上游截断，该试验不会发现。不能把它接入正式记忆或用于真实身份判断。

实验仅为合成小样本和单一种子，问题和候选此前已用于开发；未测试自然经历、自主登记、完整多轮交流或长期更正。底座摘要在试验前后核对一致，两个候选摘要在开始时核对；实验未写入候选。运行约 124 秒，CUDA 峰值分配约 3.57 GB。

# DeepSeek 注意力键值与后续查询的隔离诊断

从冻结 DeepSeek-R1-Distill-Qwen-1.5B 的第 6 层（代码索引 5）提取旋转位置编码后的真实 query、key 和 value。4 段人工中文短文本各按词元位置一分为二，用前半段 key/value 拟合线性岭回归矩阵；用后半段 query 读取，并与它对前半段的实际 softmax 注意力输出比较。两个 KV 头分别评测，query 按底座的 grouped-query 对应关系分配。写入矩阵仅是一次受控线性求解，不是 Titan-Llama 的非线性梯度更新或孢子正式状态。

8 个文本与 KV 头组合中，原写入 key 到 value 的重建余弦均在 **0.9996 以上**；但后续 query 输出与历史注意力目标的均方误差约为 **0.127–0.159**。作为简单参照，直接使用历史 value 均值的误差约 **0.031–0.126**，在本次全部 8 个组合中都低于线性矩阵。余弦表现不完全同向：第二个 KV 头的矩阵余弦高于均值基线，因此不能简单概括为每项指标均较差。

这说明本例中的 key/value 写入重建与后续 query 检索是两个不同任务：重建接近 1 不足以证明能模拟真实注意力。线性矩阵没有学习输出归一化或上下文相关权重，而 softmax 本身是非线性的；对单一矩阵和岭系数的结果不能推广为所有神经记忆都无效。

后半 query 在运行完整原模型时生成，前面各层仍可看到历史；这里只比较该层的历史注意力向量，不是验证断开历史后的生成。分割位置是数值中点，可能位于事实或句子内部；四段人工样例、单层、单次运行，不代表自然对话、跨会话记忆或纠正能力。求解时暂存完整前缀并构建 Gram 矩阵，不能用于声称恒定空间或计算优势。没有接入或修改正式个体。

耗时约 85 秒，PyTorch GPU 峰值约 3.33 GiB；底座散列前后相同。代码 `scripts/deepseek_attention_kv_memory_probe_20261117.py`，逐项结果在本机 `runs/deepseek-attention-kv-memory-probe-20261117.json`。下一步应先检查归一化、非线性及多段连续更新能否改善未见 query，同时保留均值和真实注意力基线；再以隔离模型验证遮断历史后的输出和事实换值。

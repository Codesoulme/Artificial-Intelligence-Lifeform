# P33 多轮候选复核

v6 从 `conversation-data-v5/dialogue-train.jsonl` 产生 510 条机械筛选候选，固定种子 330108 抽取 128 条。独立复核重新计算抽样行号，确认其为源训练文件的一基物理行号；510 条候选与源行逐字节对应，记录的源文件摘要匹配。v7 在同一筛选基础上增加了源文件摘要核对，修正助手字符数的统计，未提高内容质量。

固定样本前 20 条逐条检查，其余仅作摘要筛查。典型缺陷包括：源第 4234 和 5721 行编造当天早餐；第 1863、2620 行虚构工作或学习经历；第 6327 行将假设技术效果表述为已获验证；第 3514 行对神经机制作过度确定的推断；若干记录只是重复讨论同一主题，后续回答没有利用前文具体信息。第 4033 行换车成本追问有可辨认的承接，但不能据此判定整批合格。

结论：v6 和内容相同的 v7 保持 `ready_for_training=false`，不接入训练。以上抽查不是整体缺陷率估计；固定开发集用于迭代，不能作为最终未见测试。下一步应评估来源与许可明确的新对话材料，建立按角色、真实来源、信息承接和纠正能力划分的训练/开发集，避免通过继续添加关键词声称消除所有问题。

# 在多轮对话中接续版次记忆并写成消息

显式成句命令已通过写入、重启及新旧值替换对照。独立的时间选择器在自然语料中仍会把日期查询当成正式安排，自动寻址在排除字段时也有漏读和误读。本轮增加一条可以从已有查阅接续的对话路径。参考 Hy-MultiTurn 里的指代与行动抑制、StateMemBench 里的生效状态，以及多轮指令逐步提供时的回复偏差。 [显式成句](spora-local-composition-20261126.md) · [自然时间实验](spora-natural-time-and-addresses-20261125.md) · [Hy-MultiTurn](https://arxiv.org/abs/2607.29196) · [StateMemBench](https://arxiv.org/abs/2608.19652) · [多轮对话研究](https://arxiv.org/abs/2505.06120)

用户按原有查阅流程选定同一人的两项记录。读出成功后，下一轮可用「按这两项写一句消息」引用这两个具体版次。记忆值从张量档案重新读取，成句模型的输入包含写作要求、字段名、人物和时间。上一轮短答和历史文本未用于这次生成。时间可在写作要求中明确给出，也可以在孢子询问后用独立的一句时间作答。出现多个候选时先追问。按规则识别明确指代和时间，生成由已有成句权重执行。

通过 Windows 正常入口运行两次。首次登记 8 个张量版本，18/18 通过。重启后 20/20 通过。重启之后先尝试复用未完成的请求，孢子要求重新查阅。再次查阅后，生成回答与首次一致。测试还覆盖同一次查阅包含两个人、两种可能时间、转题、取消以及清空对话。SQLite 文件摘要保持一致。

| 源记录 | 自然续写 |
| --- | --- |
| 当前地点、上一版用品 | 周五傍晚在杏叶廊见，请带上青布袋。 |
| 当前地点、当前用品 | 周五傍晚在杏叶廊见，请带上灰毛帽。 |
| 当前地点、首版书目 | 今晚七点请带上《河口雨声》。我们在南帆馆见面。 |

表中句子按原输出记录。第三条包含两句，未逐字满足「写一句」的格式要求。竹篮清洁普通问答还忽略了「一句话」并被截断。38 个流程检查主要验证分支判定、使用的记录编号和实际生成包含指定值，开放中文的质量仍需另测。本轮两次入口用时约 101 秒及 109 秒。原显式成句入口的 27 项检查及 53 项版次和命令单元测试通过。

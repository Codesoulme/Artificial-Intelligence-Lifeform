# 多实体、问法泛化与持续学习阶段报告

## 结果

上一轮直接把多实体状态和多种问法混入原训练，单实体从 17/18 降到 15/18，多实体只有 52/90。随后改为从已验证的更正候选继续训练，学习率降到 `2e-5`，并保留回放样本：

- 单实体当前事实：18/18。
- 单实体换记忆后的替换事实：18/18。
- 多实体共存：67/90。
- 重载后单实体原结果：18/18 逐词元复现。
- 重载扩展多实体：5/6；更正序列：6/6；新人物：8/12。

持续学习避免了直接混合训练造成的退化，但多实体仍有约三分之一失败。候选没有接入正式个体。

## 问法专项

上一版问法专项最初只评估了默认问句，脚本随后修正为让留出人物也覆盖新增问法。对同一候选进行语义重评分后：

- `请只说出...喜欢的水果名称`：18/18。
- `记录里...喜欢哪种水果`：17/18。
- `当前最喜欢的水果`：18/18。
- `请查阅记忆后告诉我...爱吃什么水果`：13/18。
- `关于...爱吃的水果`：16/18。
- `水果偏好是什么`：11/18。

评分器现在接受“爱吃的水果是……”和“水果偏好是……”等语义等价表达，同时拒绝水果列表、否定、冲突水果和非水果答案。原始生成没有改写，重评分记录在 `reports/question-focus-semantic-rescore-20261113.json`。

## 判定

持续学习是当前有效的迭代方式：它保留了更正记忆，并把多实体能力从 52/90 提升到 67/90。问法差异仍然是主要语言层问题，尤其“爱吃什么”会触发底座的食物先验；增加问句模板能改善一部分，但还没有形成稳定的查询意图表示。

当前最值得保留的候选是持续学习版本：

`runs/continuous-reader-multi-entity-question-finetune-pilot-20261112`

问法专项 v2 是同一训练候选的重新覆盖评估，不应重复计为独立模型：

`runs/continuous-reader-question-focus-pilot-256-v2-20261113`

下一轮应把记忆查询意图作为独立条件训练，区分“喜欢/爱吃/偏好/当前/历史”，并继续保留更正回放和多实体回放。

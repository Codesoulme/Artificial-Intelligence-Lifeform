# 连续文本编码的地址容量试验（2026-11-12）

在上轮隔离矩阵试验基础上，用固定种子从底座词表抽取 300 个可单独往返编码的中文词元，组成 65 个不重复的 1–3 词元序列；它们是随机组合，不保证是自然短语。分别用两组随机投影，测试写入 8、32、64 个正交数字地址，并在 64 项写满后覆盖第一个地址，再读取全部记录。两处孢子快速矩阵均参与，每项附带结束标记。

| 项目 | 每组投影的两处矩阵均完整恢复 |
| --- | ---: |
| 8 个已写地址 | 8/8 |
| 32 个已写地址 | 32/32 |
| 64 个已写地址 | 64/64 |
| 64 项中覆盖一项后 | 64/64 |

合计 336 个地址查询、672 次矩阵读取均逐词元包含结束标记地匹配。最小最近邻分数差在两种投影中分别约为 0.00175 和 0.00356，说明某些词元与其他词元的投影非常接近；尚未对噪声、不同精度或训练导致的表示漂移做鲁棒性测试，不能将当前精确率视为安全余量。

这属于理想化容量测量：地址来自现有 64 个正交基，当前矩阵从全零开始；同一底座词向量投影同时用于写入和全文表最近邻解码。8、32 项时仅抽查一个未写地址，其向量范数接近零，但这来自零初始化和正交地址，不能当作正式未知记忆检测。覆盖只测试每组一次，地址分配、自然语言写入、事实时间、持久化、其他数据分布及超过 64 个对象都未验证。

64 项、两处矩阵的批量全文表解码在两种投影下约 0.058–0.118 秒；它不含模型加载、建立码本、地址识别和语言生成，也非单用户端到端延迟。词表码本是额外的共享结构，约 12.8 MiB（151936×22 个 float32），两处 90×90 float32 当前矩阵合计约 63 KiB；这些数字未计底座、历史状态或运行时临时张量。实验峰值分配显存约 4.29 GiB，耗时约 122 秒，包括加载和校验。

脚本 `scripts/deepseek_spora_continuous_text_capacity.py`，完整样例、输出和耗时位于本机 `runs/deepseek-spora-continuous-text-capacity-20261112.json`。底层写入仍绕过正式写入控制，原底座、检查点和真实个体经摘要核验未变。下一步需引入非正交或相近地址、噪声、未知项判断、连续多次纠正，并验证能否被语言模型读取，而不是把固定码本解码当成自然记忆。

# 多轮追问的内部记忆读取

同一句追问接在不同主题之后时，经过多轮训练的路由在留出集上正确识别了 12/18 个字段，单轮训练的路由为 9/18。完整生成中，严格正确的回答从 2/22 增至 8/22。多轮训练同时增加了错误放行，候选继续留在研究分支。

实验使用真实聊天角色模板。每个样本含两个用户回合，中间插入固定的中性助手回复。前文提示关注的属性，没有给出事实值。每组省略追问复用完全相同的末轮问题，分别搭配饮品、职业、地点、时间、数量或其他属性。另设明确改问和普通话题切换。训练、校准、留出分别包含 44、14、22 条对话。焦点仍由实验指定为同一个对象地址，原值和更正值来自已有内部矩阵。

两组复用冻结 DeepSeek、相同的词元池化结构、句首适配器和矩阵输出方式。对照组加载单轮路由，多轮组用同一训练方法拟合角色标记后的对话。训练时标注应关注哪个用户回合，省略例标第一轮，明确切换例标最后一轮。评测只让模型看到对话。阈值分别在同组独立校准样本上选定。

| 指标 | 单轮训练路由 | 多轮训练路由 |
|---|---:|---:|
| 字段首选正确 | 13/22 | 14/22 |
| 省略追问首选正确 | 9/18 | 12/18 |
| 明确切换首选正确 | 4/4 | 2/4 |
| 有记录请求正确放行 | 5/11 | 8/11 |
| 错误放行 | 1/22 | 3/22 |
| 缺失属性明确说明 | 6/9 | 7/9 |
| 普通请求保留默认解码 | 2/2 | 1/2 |
| 完整回答严格正确 | 2/22 | 8/22 |
| 原值与更正均严格正确 | 1/11 | 4/11 |

多轮组四个严格配对包含三种饮品问法和一种地点问法。三个错误放行发生在两条时间追问和一条普通面试问题，均未进入事实词元注入。普通面试问题仍进入了带记忆适配器的生成路径，因此不能按普通路径保持计分。最高权重词元落在标注回合的比例从 6/22 增至 21/22，但仍出现字段错判。定位到正确回合与理解所问属性是两个现象。

另外只移除首轮与中间回复，复用相同末轮问题及多轮路由。三个省略问句各只产生一种字段首选，18 条均未获准读取。其中一个问句被判作其他属性，按当前策略会说明找不到记录，而不是请求澄清。这组对照只执行路由，未生成回答。

核对了 66 个完整生成组合、逐行结果、计划和检查点摘要。多轮路由在评测前从磁盘加载。实验约耗时 112.8 秒，PyTorch 峰值分配约 3.55 GiB，完整记录位于 `runs/deepseek-memory-dialogue-context/`。当前使用手写对话和固定承接回复，仍需验证更长历史、真实对话和跨轮对象切换。后续应优先检查模型何时可以继承上一轮属性，何时必须以当前问题为准，同时复测已正确选中记录却未表达事实的样本。

# 中文成品示范与版本记忆的组合对照

新编的六场三至五轮对话中，原版 DeepSeek 和孢子改造版的末答逐字相同，均未得到可直接使用的成品。本轮分别识别生成与内部值读出的瓶颈。对话示范使用同样的请求、指导语和先行示例问题，单独替换示例答案。内部记忆则按 StateMemBench 和 StaleBench 的思路区分有效值、已更正值和其他失败，同时逐条核对是否交付成品。 [上轮对话](spora-fresh-dialogue-20261125.md) · [AFVE-Bench](https://arxiv.org/abs/2611.10541) · [StateMemBench](https://arxiv.org/abs/2608.19652) · [StaleBench](https://arxiv.org/abs/2611.19752)

## 给定现行要求后，示范能否恢复成品

固定 DeepSeek 孢子的底座、检查点和个体张量，复用六条人工确认的现行要求。直接输入用于复现已有结果。另三组分别只有统一指导语、指导语加三条「好的，已收到」的对话、指导语加同样的三个问题和实际成品答复。示例中的人名、地点、事项与测试分开。示例答案组和确认组的词元数量不同，这个对照测的是选择哪种回答作为示范的整体作用。生成上限均为 224 词元，无历史被截去。 [示范格式的研究](https://arxiv.org/abs/2202.12837)

| 条件 | 可直接使用的末答 | 正常结束 |
| --- | ---: | ---: |
| 仅现行要求 | 0/6 | 6/6 |
| 加统一指导语 | 0/6 | 6/6 |
| 加通用确认示例 | 0/6 | 6/6 |
| 加成品示范 | 1/6 | 6/6 |

成品示范使小组分工答复正确写出「六点到南厅，阿宁登记来宾并准备备用笔，小齐发座位卡」。文件交接写到了 PDF 和明天下午，却额外要求收件人准时送达。取件答复擅自增加「7 点前」，并把到店的一方弄反。冷凝解释仍漏掉水来自空气。直接输入逐词复现此前六条基线。试验约 183 秒，CUDA 张量峰值 4.94 GiB。结论适用于这些固定输入及单次贪心生成。

## 两项内部值能否组成日常回答

另固定四条普通请求，要求给某人写取书、会面或携带物品的消息。为每人写两个字段，每字段写两版，获得 16 份低秩张量。使用独立 SQLite 档案，关闭写入连接后从磁盘重开。测试将明确的字段地址和所选版本提供给读出，重载后从张量恢复词元。四组共享同一个问题和空历史，分别选两项当前版、只换第一项、只换第二项和两项都换。输入没有事实值。另比较当前版降低混合权重、移除内部值、以及把正确字段明确写在问题里的文本对照。冻结 DeepSeek 语言底座，沿用已训练的双项读出头和双项结束控制，各组生成上限为 72 词元。这个实验跳过自然寻址，集中检验读出与生成。 [双项读出](spora-dual-version-reply-20261125.md) · [指针生成](https://doi.org/10.18653/v1/P17-1099)

| 条件 | 两个所选值均出现 | 两值各一次且自然结束 | 整条可直接发送 |
| --- | ---: | ---: | ---: |
| 双当前版 | 4/4 | 4/4 | 0/4 |
| 只换第一项 | 4/4 | 4/4 | 0/4 |
| 只换第二项 | 4/4 | 4/4 | 0/4 |
| 两项都换 | 4/4 | 4/4 | 0/4 |
| 双当前版，混合权重 0.50 | 4/4 | 4/4 | 0/4 |
| 无内部值 | 0/4 | 0/4 | 0/4 |
| 正确值置于可见问题 | 1/4 | 0/4 | 0/4 |

16 次状态组合均能跟随换值，未输出替代版本。所有含状态的回答都以「记下的是」一类短查阅开场，漏掉了会面时间、携带动作或面向收件人的措辞。降低权重后，四条当前版答复逐条不变。空状态有一题擅自填了公司门口和手机。可见文本对照的一题确实生成了一条可摘出来使用的微信，但整份回答还重复两个值并带引导语，其余三题未同时给出两个字段。所有 28 次均正常结束。这表明当前缺陷包含语言生成和记忆读出头的表达范围。档案大小 86,016 字节，写入和首轮评测约 129 秒，CUDA 张量峰值约 3.46 GiB。

下一轮将保留已验证的版本状态，调整解码器如何在成品句中使用内部值。具体对照同一套训练预算下的短查阅动作头与包含真实成品措辞的动作头，检查普通词元能否保持由语言解码驱动、两个选定字段能否在适当位置读出。开发数据和留出用不同人名、不同值、不同措辞，额外验证换值不影响另一项，关闭读取时普通生成可复现。只复述值或格式通过不能算成品成功。公开的 TransMem 可用作设计更正关系的参考，其做法采用文本检索，孢子本轮的因果测试用独立张量。 [TransMem](https://arxiv.org/abs/2611.10683)

独立进程在约 127 秒内逐词复现全部 28 条输出和选中槽位。数据库前后摘要一致，SQLite 完整性检查为 `ok`，重查有 16 条版本记录。49 项版本相关单元测试通过。逐题记录见 `runs/spora-reply-demonstrations-v1/result.json`、`runs/spora-memory-in-ordinary-replies-v1/result.json` 及 `replay.json`。

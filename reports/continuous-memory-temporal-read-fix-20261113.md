# 时间读取路由修复

## 发现

在更正后的隔离个体上，当前事实是“咖啡”，历史事件中曾记录“茶”。三个没有时间标记的当前问题中，前两问返回“咖啡”，第三问“偏爱的饮料是什么？”被时间分类器误判为 `past`，因此读取了历史值“茶”。记忆矩阵和更正数据本身没有错误。

## 修复

在运行时读取层增加显式时间证据约束：

- 只有出现“以前、过去、原来、之前、曾经”等历史词，才允许选择历史页。
- 只有出现“后来、之后、更新后、变更以后、后续”等词，才允许选择后续页。
- 没有时间标记时，若神经时间分类器误选历史或后续，回退到当前页。
- 历史和后续标记同时出现时拒答，避免猜测。

## 验证

- 时间约束单元测试：`4` 个新断言通过。
- 运行时聊天持久化回归：`14/14`。
- 时间路由回归：`2/2`。
- 隔离更正个体的三个当前问法全部返回“咖啡”。
- 之前的显式历史读取路径仍保留，约束只作用于缺少时间证据的误分类。

扩展到五问的第二次探针因显存资源竞争提前退出，没有把该次运行计为通过；已通过的三问结果来自独立成功的 v2 探针。

## 判定

这是读取路由错误的修复，不是记忆结构修改。它降低了当前事实被历史事件覆盖的风险，但时间表达仍需更广泛的中文评测。

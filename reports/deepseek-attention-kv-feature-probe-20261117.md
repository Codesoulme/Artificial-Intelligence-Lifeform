# 正值特征记忆与历史注意力对照

沿用上一轮 DeepSeek 第 6 层的四段人工文本、两个 KV 头和相同前后切分，在岭回归矩阵与历史 value 均值之外增加一个无训练对照。对 key 和 query 做 L2 归一化，再用 `ELU(2x)+1` 得到正特征；历史状态累计特征与 value 的外积和特征和，读取时以两者的 query 投影之比归一化。分批写入与直接正特征核计算等价的单元检查通过。

| 条件 | 查询历史注意力均方误差范围（8 个文本与头组合） |
| --- | ---: |
| 上轮线性岭回归矩阵 | 0.127–0.159 |
| 正值特征记忆 | 0.0312–0.1263 |
| 历史 value 均值 | 0.0312–0.1258 |

新方法在所有 8 个组合中比岭回归矩阵误差低，但与均值基线非常接近：均方误差绝对差最大约 0.00045；仅 2/8 个组合略低于均值，6/8 略高。这不能证明它有有用的查询选择性，更不是事实问答成绩。读取只针对历史注意力输出，没有测生成；不同向量余弦指标见逐项结果。参数 `2.0` 是一个预设研究值，不是经过独立验证的最佳配置。

每个 KV 头的状态在本次配置下为 128×128 矩阵和 128 维向量，即 16,512 个 float32 数值约 64.5 KiB，不包括模型、写入过程和多个层头；这是结构大小而非实测运行时总开销。每轮使用完整历史 key/value 构造状态；本实验也同时构造了岭回归对照，不能用整体峰值或速度来声称该机制的效率。

查询由原底座完整历史计算而来，仅测一个层位、四段短文本；没有自然写入、多主体、长时间保存、未知拒答或端到端生成。原底座散列前后相同，正式个体未参与。脚本 `scripts/deepseek_attention_kv_memory_probe_20261117.py`，研究模块 `spora/research_positive_feature_memory.py`，结果 `runs/deepseek-attention-kv-feature-probe-20261117.json`。运行约 87 秒，整体 PyTorch 峰值约 3.33 GiB；4 项状态与注意力参照测试通过。

下一步应测量注意力分布和特征核权重是否过于均匀，在开发集和独立留出集上比较更具选择性的特征或可学习映射；不能靠这一批题调参后宣布通用改善。候选仍不部署。

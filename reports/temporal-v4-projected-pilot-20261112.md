# 时间头梯度投影实验（2026-11-12）

基于 [A-GEM](https://arxiv.org/abs/1812.00420) 中的梯度约束思路，研究候选从原时间头初始化，每步计算新增样本的监督梯度和旧训练样本的监督梯度；若两者点积为负，则将新梯度投影到参考梯度的非负半空间，再用无权重衰减的 SGD 更新。采用完整批次，并非论文的在线任务流或完整复现。约束只对参考样本的一阶损失变化有效，不能保证有限步、旧测试或阈值结果不退化。

单元测试覆盖冲突梯度、多张量、无冲突、零参考与非有限输入。完成的 200 个训练步中有 199 步投影，记录到的投影后负点积（阈值 -1e-7）为 0。该数值检查不能替代模型表现评估。第一次运行的工具句柄失效且没有进程或结果文件，原因不明；重试成功并保存了本机日志。

对齐 86 条旧开发题中，原时间头和投影候选各正确 85 条，上一轮软输出保持候选为 84 条。投影候选恢复了“截至目前”这一当前问法，但仍将“后续记录”误判为过去；它也纠正了原版的一条否定句误判。题目是开发中已见的样本，并非独立验收。

此前的 36 条人工句式中，投影候选在当前、过去、后续三类与原版相同，分别为 9/9、6/9、9/9；暂缓类由原版 6/9 变为 7/9。上一轮候选在这组四类均为 9/9，但有上述旧题回退。该组仅检查时间头，与训练句式相近，也已经用于开发；它说明这次投影未保留上一轮观察到的全部新增覆盖，不证明对其他任务的表现。

实现 `spora/gradient_constraints.py`，测试 `tests/test_gradient_constraints.py`；实验及对照脚本为 `scripts/deepseek_spora_temporal_gate_v4_projected.py` 和 `scripts/deepseek_spora_temporal_v4_projected_holdout.py`。工件位于本机 `runs/deepseek-spora-temporal-gate-v4-projected-20261112/` 和 `runs/deepseek-spora-temporal-v4-projected-holdout-20261112.json`。训练器通用 `result.json` 的 loss trace 是为投影构造的代理值，不应当解释为普通交叉熵；投影统计见 `projection.json`。候选未进入默认运行路径，也未改变原个体。

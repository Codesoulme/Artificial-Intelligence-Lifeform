# TTT 写入目标与读取联合训练

## 方法

在值位置写入的隔离候选上，增加一个每层低秩 next-state target 修正器，并与原有低秩语言读取适配器共同训练。底座冻结，训练 192 步；临时状态保留梯度，以确认回答损失确实能回传到写入目标。这个实验没有改动正式个体或底座。

## 结果

| 条件 | 严格正确 | 基线严格正确 |
| --- | ---: | ---: |
| 训练人物、训练饮品 | 4/16 | 0/16 |
| 留出人物、训练饮品 | 2/8 | 0/8 |
| 留出人物、未训练饮品 | 0/4 | 0/4 |
| 留出人物、新问法、训练饮品 | 2/8 | 0/8 |

训练损失在前 80 步从约 `8.70` 降至 `0.71`，证明梯度可以从回答路径回到写入目标修正器；但最终生成泛化更差，且未见值仍完全失败。训练损失下降因此不能作为记忆形成的证据。

## 结论

当前 next-state fast weight 直接承载可学习写入修正时容易改变宿主语言分布。把写入目标和回答损失绑在一起，既没有产生值泛化，也没有保住已见事实的稳定读取。该候选不接入正式个体。

下一步转向专用语义记忆槽：让记忆状态在独立的低维通道中保存值语义，再通过受控读取层接入宿主语言层。必须先用同题换值、未见值和普通问题验证，再考虑替换当前 TTT 路线。

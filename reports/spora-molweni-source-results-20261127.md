# Molweni 多人对话数据核查

日期：2026-11-27。依照[核查计划](spora-molweni-source-plan-20261127.md)，读取 [Molweni 论文](https://aclanthology.org/2020.coling-main.238/)及[官方仓库固定提交](https://github.com/HIT-SCIR/Molweni/tree/2eb681d7e610ee3fda4ab3b4cc364554bd17ee67) 的训练集、说明和许可证。文件的 Git blob 与固定提交一致；训练集 SHA-256 为 `dc9c374d85e1174188e13ea5dafc15ab7551ad7f234203996a5eb4683edbb8ac`，与独立发布的 [tasksource 来源记录](https://huggingface.co/datasets/tasksource/molweni/blob/f2d24c023fa066b2972dcf827e648208350ad7f5/provenance.json)一致。官方开发集和测试集均未下载或读取。

## 核查结果

- 训练集有 8,771 段对话、77,374 条话语和 24,682 道问答题；其中 20,873 道标记为有答案，3,809 道为无答案。3,784 段对话同时有两类问题。每段对话包含 2–9 位标记发言人。
- 20,873 个正确答案位置和 3,809 个 `plausible_answers` 位置均可按数据给出的字符偏移精确切回原文；问题标识无重复。无答案题的 `answers` 为空，与 `is_impossible` 标记一致。字面位置检查不证明语义或标注正确。
- 论文说明可回答题的答案是对话中的文本片段，无答案题标注的是**看似合理的干扰答案**。因此 `plausible_answers` 可作为困难负例研究的辅助标签，不能当作正确答案或直接喂给推理系统。
- 按 `context` 的字节文本精确比较，训练集有 9 条重复上下文记录；后续划分训练与内部开发组时，至少应把相同上下文放在同一组，且继续检查相近或源对话重叠。篇章关系和发言人标注可研究证据定位，但答案跨度本身不一定覆盖完整推理依据。

官方仓库提供 Apache-2.0 许可，数据来源为 Ubuntu Chat Corpus；本次仅作本机研究，未将原始文本或问题提交。许可证和来源的下游适用范围需要随实际用途再核查。英文技术聊天与中文人物记忆的分布差距明显；有答案并不意味着支持事实更正、身份延续或持久化。

## 后续方案

可以先将训练集按完整上下文分组，构建小规模、预先固定的训练内开发对照，分别记录有答案误拒、无答案错误放行、发言人相关题表现和预测校准；再用官方未用开发集检验，最后保留测试集。主体相关分类需基于可复核标准，不能靠答案位置泄漏。候选如有进步，还须以中文独立对话、最终生成、事实更正和持久状态验证，才能判断是否值得融入孢子结构。

# 扩大写入器词元覆盖

## 方法

沿用输出头监督与训练样本竞争词方法，将训练目标从 256 个扩展到 4096 个稳定中文单词元；保留原来 64 个留出单字及两名留出人物。新增训练词必须能在两组人物的固定事实句中准确定位，原 256 个训练词和 64 个留出词保持不变。两个人物与每个训练词交叉，共 8192 条训练组合；从相同初始化训练 2048 步，较旧候选的 512 步和训练词数都增加，因此不是等算力或单变量对照。

训练不接收 64 个留出词作为目标或负词。它使用冻结 DeepSeek 原底座的第一层状态、程序给定的值边界及对应问题隐藏状态；预测向量经训练词平均范数归一化后注入冻结输出头。答案结束词元由实验提供，模型没有自行学会停止或决定读哪条记忆。

## 留出单字

在独立进程用完整词表检查前 64 个训练词和全部 64 个留出词；每词对应两名人物。旧候选与新候选在同一套问题上的结果如下：

| 检查 | 256 词旧候选 | 4096 词新候选 |
| --- | ---: | ---: |
| 训练人物、训练词首词 | 114/128 | 109/128 |
| 留出人物、训练词首词 | 114/128 | 106/128 |
| 训练人物、留出词首词 | 0/128 | 82/128 |
| 留出人物、留出词首词 | 0/128 | 69/128 |
| 留出人物、留出词完整生成 | 0/128 | 68/128 |

新候选首词排名与生成有一处差异，不能把数值前向与实际生成视为逐项等价。按不同留出词统计，28/64 个词在两个人物下均完整正确，12 个只在一人下正确，24 个两人均失败。每个词的两条问题相关，不能把 128 个组合当作独立事实。

## 饮品名称与替换层

另外使用八个以前项目中研究过的饮品名称、两名留出人物和两种问法，共 32 个组合；其中三个名称由多个词元组成。它们的目标词元没有作为本轮训练目标，但可能出现在底座预训练或本轮随机及竞争负词中，不能称为完全未见数据。程序仍指定人物、事实值边界、读取时机及结束词元。

| 检查 | 原语言层 | 替换第 6、12 层 |
| --- | ---: | ---: |
| 可学习写入器，完整生成 | 20/32 | 22/32 |
| 直接提供正确词向量的参考 | 32/32 | 32/32 |
| 同一人物与问法的换值两侧均正确 | 41/112 | 50/112 |

换值配对共享生成样本，不能视为独立试验；两种结构在 32 条中有 26 条输出逐词相同。样本较少，且直接向量与 EOS 的参考是人为提供的复制通路，不能由此断言替换结构更优、模型自主理解事实或已经形成参数记忆。两层候选只用于这轮推理，没有训练或修改。

## 限制与产物

单字分布由人工选择，语义未必符合饮品；八个饮品名称及部分问法在项目早期开发中出现过。没有自然观察、身份消歧、自动路由、独立个体持久化、更正、普通聊天保持或长期记忆验证。训练只有一个随机种子，候选暂不部署。原底座及来源候选文件的摘要前后相同。

第一次扩大训练在特征提取前因上下文分词边界不一致而退出，没有产生候选；添加边界筛选后完成。新训练约 190 秒、峰值约 3.56 GiB；完整重载约 157 秒；饮品测试原层及替换层分别约 80 秒和 82 秒。

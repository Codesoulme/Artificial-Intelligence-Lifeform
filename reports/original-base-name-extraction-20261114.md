# 原底座姓名抽取试验

## 目的与方法

检查保留原语言层的 DeepSeek-R1-Distill-Qwen-1.5B 在确定性解码、手动关闭思考段时，能否从句子中列出全部完整人名，作为评估其他定位方法的一条线索。固定一条提示，要求按原文顺序输出 JSON 数组；每题独立推理，不读取记忆，也不输入已登记姓名或地址。

24 条人工样本包括旧风险相关长名 4 条、其他中文名 4 条、英文及混合姓名 4 条、多人 4 条、无明确人名 4 条、别名 2 条、同名 2 条。这个集合是开发探针，不是独立人群基准；部分姓名或问法沿用了此前检查过的反例。别名和同名题只检查出现的不同姓名字符串，不评分是否为同一人，也不能验证身份消歧。

## 结果

直接要求无额外文字的 JSON，24 条只有 1 条准确。对已保存的原回答另做分析，允许完整的 JSON 代码围栏后，15 条可解析、13 条输出的所有字符串均出现在原句、4 条与标注的完整列表一致。

| 样本类别 | 题数 | 容许围栏后完整匹配 |
| --- | ---: | ---: |
| 相似长名 | 4 | 0 |
| 其他中文名 | 4 | 2 |
| 英文或混合姓名 | 4 | 0 |
| 多人 | 4 | 0 |
| 无明确人名 | 4 | 1 |
| 别名文本 | 2 | 0 |
| 同名文本 | 2 | 1 |

可解析但不准确的输出包括：“小林舟”被写成“小林”；“阿明晨”被写成“阿明”；“Mary Jane”被写成“Mary”；多人问句有遗漏。无人物句子“我喜欢喝茶。”输出了原文没有的“李明”。其他失败包括照抄原句和未按数组输出。原文包含该字符串仅证明它是子串，并不证明人名边界完整。

## 判断

本次提示和解码方式下，原底座生成抽取无法作为可靠的独立姓名校验器，也不能因为底座与定位头一致便假定判断正确。“小林舟”的共同截短与先前片段试验一致；不过这次没有把生成结果与定位器同时接到完整读取链，因此不能据此量化联合错误率或实际泄露。单一提示、人工样本和关闭思考段都限制结论；它不代表底座在其他提示、训练或解码条件下的能力上限。

后续应将身份确认、待澄清与真实读取前的拒绝分开验证，并使用不参与调参、姓名和问法均分离的评测。明确的交互确认可降低某些误认风险，但不能替代身份认证；同名、别名及对话中的指代仍需单独处理。

脚本：`scripts/deepseek_spora_name_extraction_probe.py`、`scripts/deepseek_spora_name_extraction_analysis.py`。原始输出及逐条分析分别位于本机 `runs/deepseek-spora-name-extraction-probe-20261114.json` 和 `runs/deepseek-spora-name-extraction-analysis-20261114.json`。推理及前后权重核验约 88 秒，显存分配峰值约 3408 MiB。底座权重核验一致；试验没有加载或修改个体状态、检查点或记忆。

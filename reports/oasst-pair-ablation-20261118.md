# 问题与历史表示的配对交互对照

## 结论

逐维乘积和绝对差值未带来可用的上下文依赖识别。与同参数量的线性配对对照相比，交互组识别了更多缺少历史的请求，却明显增加对独立请求的误触发；三条件全正确均为 1/10，低于上一轮单独使用 last 表示的 2/10。此结果不支持将配对交互晋级或接入正式记忆。

本轮只是冻结底座表示上的分类诊断；没有词元级可训练注意力、持久神经状态写入、实际检索或回答生成。不能由此认定所有问题—证据交互方案均无效。

## 受控设计

沿用[上一轮](oasst-context-crossfit-20261118.md)完全相同的 23 个对话树、69 条输入与五折来源隔离。训练/校准/测试的完整行号清单经逐项相等检查，包括错配历史来源的剔除。每折每种模式运行三个随机种子 4171/4172/4173，每个头 800 步 AdamW、学习率 0.02、权重衰减 0.001；门槛仅由当折校准标签选择。

每条输入取两个冻结、L2 归一化的 1536 维表示：q 是同一追问没有前文时的 last 表示，c 是该输入（无历史、正确历史或错配历史）的 last 表示。q 的对应根据对话、消息与变体核对，不依赖记录位置，且不借用正确历史或任何未来答案。

- 线性配对：`[q, c, (q+c)/sqrt(2), (q-c)/sqrt(2)] / 2`；后两个块不增加线性可表达的函数种类，但保持相同输入维数。
- 交互配对：`[q, c, sqrt(d)*(q*c), abs(q-c)] / 2`，d=1536；乘积的尺度为预设常数，未根据标签调整。

两组每个分类头都有 6145 个参数，初始化及优化步数匹配；特征变换的算术操作、有效自由度、正则化几何并不相同，因此并非完全等计算或等有效容量。数据已被多轮观察，本实验是开发消融，不是新盲测。每折训练仅 21–31 条、校准 6–12 条；不能推断一般表现。

## 五折留出结果

以下数值在三个随机种子下均相同：

| 指标 | 线性配对 | 交互配对 |
|---|---:|---:|
| 无前文时识别到需要前文的追问 | 5/10 | 8/10 |
| 无前文时误要求独立请求补充历史 | 7/13 | 11/13 |
| 原前文已有仍要求更多信息 | 5/23 | 9/23 |
| 错配前文时识别必要历史仍缺失 | 3/10 | 4/10 |
| 错配前文让独立请求误触发 | 5/13 | 6/13 |
| 依赖项三条件全正确 | 1/10 | 1/10 |

全部训练折 AUC 都为 1。线性配对留出折 AUC 约 0.409–0.841，交互配对约 0.594–0.719；这表明排序和最终决策的变化并非一致，不能只挑某个指标。当前数据量、折划分、阈值不稳定和表征泛化均可能参与结果，无法孤立归因。

## 验证及成本

训练只使用 CPU 和前轮保存的表示，约 57 秒，共 30 个头。独立进程重建配对特征并重新加载全部候选；训练、校准、测试的保存分数最大差为 0，门槛及留出预测一致。基础表示及输入摘要、实验相关源文件运行前后一致，未修改正式个体。

3 项新增单元测试验证问题来源配对、参数维数一致及对照线性性质、交互性质与空差值处理。它们验证实现而非真实语言能力。

## 后续约束

这些结果不支持继续在同一 23 树上叠加少量参数并据此宣称突破。后续应把此集合固定为开发回归，准备更多按主题和来源分组、定义一致的标注样本，再检验词元级关系表示、上下文指代和证据充分性。对新机制需要同时衡量遗漏必要历史和错误要求无关历史，不得用始终读取或始终拒绝掩盖失败。

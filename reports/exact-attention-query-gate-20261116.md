# 精确记忆注意力的查询位置门控

在已有“底座注意力投影初始化 + 精确词表记忆桥”分支上增加一个可训练的查询位置门。门以当前隐藏状态为输入，逐 token 乘到记忆注意力残差上；原始记忆注意力的键、值投影和标量强度仍按高学习率研究配置训练。模型、人物、关系和值设置沿用多关系宽覆盖诊断。

## 结果

| 集合 | 训练前 | 训练后 |
| --- | ---: | ---: |
| 训练人物 | 3/24 | 23/24 |
| 留出人物、已监督值 | 3/24 | 22/24 |
| 留出人物、未监督值 | 1/8 | 0/8 |
| 留出人物、替代问法 | 0/8 | 0/8 |

独立重载的 6 条复现检查通过。训练后提升来自受监督值的拟合；实验配置记录 `visits.old=288`、`visits.new=0`，也就是说 288 步全部访问旧值回放，没有访问新的训练值。因而不能将 `23/24` 和 `22/24` 解释为可泛化的内部记忆能力。此次没有独立普通聊天集或无关记忆污染评测。

## 判断

查询门让模型更容易在已见格式和已见值上把精确记忆送入语言输出，但没有改善未见值、问法迁移或自然关系路由。精确词表桥和程序提供的实体／地址仍是实验控制，事实并未因这轮训练进入底座参数。候选不接入正式个体。

代码入口 `scripts/deepseek_exact_attention_query_gate_pilot.py`；本地结果在 `runs/deepseek-spora-exact-attention-query-gate-20261116/`。原注意力模块的 8 项单测和选择性读取相关 23 项测试通过；正式底座、个体和源检查点未修改。下一轮若继续，应先修正值访问调度并加入新值、新问法、普通问题和无关记忆对照，保持同算力冻结组。

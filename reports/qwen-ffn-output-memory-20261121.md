# 将孢子记忆读出迁入前馈网络

以 `DeepSeek-R1-Distill-Qwen-1.5B` 的全层兼容检查点为基准。在第 5 层，把读取当前及历史矩阵得到的隐藏状态增量加到前馈网络的输出。常规门控前馈使用原隐藏状态，外层的旧读出关闭。读取地址和时间页由评测提供。对照含 8 道问题，每题也在替换值后的状态下运行一次。

| 条件 | 受控记忆 | 正确换值 |
|---|---:|---:|
| 原读出 | 7/8 | 6/8 |
| 15% 改走前馈输入 | 6/8 | 6/8 |
| 50% 或 100% 改走前馈输入 | 0/8 | 0/8 |
| 原读出减半 | 1/8 | 1/8 |
| 原读出完整，加一半前馈输入读出 | 5/8 | 2/8 |
| 全部改走前馈输出 | 7/8 | 6/8 |

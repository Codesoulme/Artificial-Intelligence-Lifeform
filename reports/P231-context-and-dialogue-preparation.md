# P231：章节上下文与多轮候选

`scripts/build_p231_wikipedia_context.py` 从 P230 保留片段回查固定百科分片，按页面核验正文摘要和字符位置，以 `scripts/prepare_p231_wikipedia_context.py` 合并相邻保留段落；被隔离的行会切断片段。真实页面标题及可识别的相邻章节名加入模型可见文本，并分别统计正文与标题词元。完整字段按 Parquet 行组读取，实际解码了 195,791 行，其中可能包括未选择页面；仅输出候选页面。原页面修订、事实、权利和其他来源的隔离仍未全部核实。

构建得到 3,239 页、9,079 段，正文 2,222,389 个 BPE 词元；附加标题按独立编码计 112,411，模型可见文本总计 2,334,800。这些是候选词元，不是已通过审核的新增知识，页面标题可能反复出现。排除 P230 两轮各 40 个已抽查页面后，固定种子每页抽一段、共 40 段；两位模型各审 20 段，12 clean、22 minor、5 major、1 uncertain，其中 13 段被认为标题有助于理解。没有双人交叉复核或外部事实核实，样本不能证明整池质量，也不能和 P230 的不同样本比例直接比较。

`scripts/audit_p231_wikipedia_ancestors.py` 对 P230 筛选后的 9,092 段，与 P28 的 100,000 条故事及 v5 的 1,085,328 条旧训练记录做规范化全文包含检查：分别有 0 和 2 段命中。该检查不包含片段重叠、语义改写及其他历史来源，命中也不证明模型当时实际抽到。原始查重结果在 `runs/p231-wikipedia-ancestor-overlap-v1-20261109.json`；章节候选在 `runs/p231-wikipedia-context-20261109/`。抽查及训练计划应将相应命中页面排除或单列，不能将全文未命中表述为与祖先完全独立。

`scripts/prepare_p231_dialogue_candidates.py` 将 P104 候选结合 P117-v2 族划分，四个候选组的 77 条源记录保守隔离；完整对话超过 512 词元时排除而非截断。余下 366 段、309 族，共 112,790 个助手监督位置；这是按候选编码计数，不代表质量合格或独立新数据。按族抽 40 段，由两位模型各审 20 段，判定 clean 2、minor 18、major 20；102 个助手轮次分别为有用 67、无用 32、不确定 3。缺陷包括虚构现实经历、事实和任务约束错误；这是单次模型判断，不是人工或事实核验，也不应直接外推全部候选。样本可能已有局部审阅历史。原文、掩码、源行和结果只留在 `runs/p231-dialogue-candidates/` 与 `runs/p231-dialogue-review-*.json`；该池没有直接用于训练。

`scripts/prepare_p231_wikipedia_pilot.py` 基于固定摘要构建受限诊断候选，整页排除三轮共 120 个抽查页面及祖先审计命中的两个页面；实际输入中排除 116 页。每页最多选一个完整片段，要求正文不少于 64 个 BPE 词元、含标题文本不超过 510 个 BPE 词元，并进行规范化全文及前缀去重。结果共 3,020 页、622,836 个模型词元，清单和候选位于 `runs/p231-wikipedia-pilot-candidate-20261109/`。这不是质量认证：模型抽查发现的问题、历史来源近似重合、事实及权利核查仍是限制，目前尚未训练。

用 `scripts/p115_encode_stories.py` 编码后，3,020 条全部通过词元往返校验，无拒绝记录；加起止符后共 628,876 个词元及 625,856 个文档内下一词元目标，输出位于 `runs/p231-wikipedia-pilot-encoded-20261109/`。构建与编码分别使用 tokenizers 0.23.1 和 0.22.1；编码阶段对实际输入重新检查往返，计量按编码阶段清单为准。数量不代表质量或相对于历史训练的新增覆盖。

构建子任务探索时曾对整个 `runs` 目录下的 JSON 文件做宽范围文本搜索，因此不能确认没有打开开发集或最终测试相关文件；这些文件没有作为候选构建输入。最终测试的严格保密状态应视为不确定，不能以其结果单独宣称独立泛化；正式验收需另设未曝光的独立评测并保持隔离。本轮未修改个体或历史检查点。相关输入和输出摘要保存在各本地清单，代码提供单元测试。

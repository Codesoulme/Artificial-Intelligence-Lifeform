# 多方对话指代语料来源检查计划

2026-11-27。上一轮人工背景模板没有稳定解决漏读。先核查 [MMC 官方仓库](https://github.com/boyuanzheng010/mmc/tree/a7007d1d4556a3f4347a3d7b686f71d66bd1e2d9) 固定版本及[论文](https://doi.org/10.1162/tacl_a_00581)所述中文投射标注；只取得 corrected 的训练和开发文件，不读取测试文件、不训练模型。远端逐项与 Git tree 中的 blob 摘要核对，文件仅放本地研究目录。

只统计 JSON 行、文档标识、句段、说话人、指代簇、范围合法性与训练／开发精确文本重合；核对 span 与子词映射的维度关系，不假定其是原始中文字位置。报告源文件与许可声明的可见范围。仓库根部未见总数据许可证，`experiments/LICENSE` 不能自动视为字幕数据许可；在用途和权利不明时仅开展本地来源和结构检查，不将语料提交、训练或公开逐条文本。中文通过跨语言投射，不能视为已人工逐条核验的金标。即使数据可用，指代任务也不直接标注应否访问个体记忆。

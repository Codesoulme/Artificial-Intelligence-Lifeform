# 同一批中文要求一次给全与分轮给出的对照

上轮实际聊天入口的 64 和 128 词元档结果相同。路由修复后，模型得到原有对话仍会复述已取消的要求。本轮直接调用孢子当前入口所用的生成骨干，和原版 DeepSeek-R1-Distill-Qwen-1.5B 各跑一遍同样的中文任务。采用《LLMs Get Lost In Multi-Turn Conversation》和规范上下文蒸馏论文的成对思路，逐轮记录要求与答复。 [上轮实机结果](spora-chat-mixed-budget-20261125.md) · [多轮失误研究](https://arxiv.org/abs/2505.06120) · [规范上下文蒸馏](https://arxiv.org/abs/2605.30251)

## 方法

12 个手写开发任务各三轮，覆盖安排更正、文本约束、条件更新和只输出指定字段。每道题的最后一轮比较四种输入。

- **分轮原样**保留模型自己的答复，一轮一轮继续，按实际输出构造下一次输入。
- **一次给全**将同样的用户原话按原顺序放在同一条消息中，包括被更正的旧要求。
- **分轮确认**保留对话角色和用户原话，统一把中间两条答复换成「收到。」。
- **整理后的现行要求**用人工整理的短提示表达最终生效的内容，去掉已取消的旧要求。它衡量模型拿到清楚任务时的上限。

另用四道题测试依赖助理提供的专名。实际文本或「收到。」二选一地放在被引用的助理轮次。按词是否齐全、过时值是否出现、长度、首尾格式及指定短答评分。停止生成单列统计。逐字检查只覆盖可以程序化核验的部分，流畅性和真实交流还需逐题或独立评测。

两模型使用 48 词元解码上限和不超过 256 词元的位置范围。固定贪心解码和原生中文模板。孢子直接调用实际聊天入口加载的解码器，使用独立路径加载初始个体。这个实验隔离生成能力，实际入口的记忆和范围判断在单元回归中另行检查。

## 结果

| 最终输入条件 | 孢子 | 原版 DeepSeek |
| --- | ---: | ---: |
| 分轮原样 | 0/12 | 0/12 |
| 用户原话一次给全 | 0/12 | 2/12 |
| 分轮用统一确认词代替旧答复 | 0/12 | 1/12 |
| 人工整理现行要求 | 4/12 | 5/12 |

孢子分轮逐步通过 7/12、1/12、0/12，原版为 8/12、4/12、0/12。两组的最终轮均保留两轮历史。旧要求和新要求同时可见时，移除助理答复只恢复了原版一题。出错包括使用已经换掉的地点、改了日期却丢失保留事项、复述整段要求以及用通用套话回答。孢子在人工整理的周末展馆任务里给出了「周日上午十点在湖边展馆」，同题分轮时遗漏了展馆。两模型的原样最终回复有 10/12 和 11/12 条正常结束，失败大量发生在有剩余生成预算时。

四条依赖助理原有答复的题，严格短答通过数分别为 0/4 和 1/4。孢子有三条提到了所需专名，但未按要求只输出该名称。两模型改用确认词后严格通过数均为零。历史中的助理信息需要按任务保留，当前结果支持先学会判断用户哪项要求已经被更正。

## 两次生成的对照

让孢子先读三轮用户原话，用最多 64 词元写出合并后的现行要求，然后单独作答，答复上限仍为 48 词元。12 条中有 8 条整理结果正常结束，最终答对 0 条。「周末展馆」被整理成原来的周六九点，丢掉两次更改。「午餐留言」留下已被梨替代的苹果。当前把整理交给同一个未经专项训练的模型，会把失误提前到第一步。

已把 12 条失败对话整理成开发样本。每条保留实际历史、错误回复和手写的正确答复。若有备用输出通过逐字检查，也一并保存。有些通过词面要求的输出仍会复述长度限制，或混淆水汽与液态水滴。备用答复作为审阅材料，后续训练目标采用经复核的参考。开发任务留作收集失败轨迹，新候选另用不同场景验收。

下一步学习从用户发言更新工作状态。为每条要求保留来源轮次，区分仍生效、被替换和明确取消，然后根据当前状态作答。旧词是否被带回答复、保留条件是否丢失、回复能否直接使用分别评分。StateMemBench 将现值、已过时值和其他错误拆开计分。AFVE-Bench 进一步检查模型采用新要求后是否仍提到应舍弃的旧内容，两者都可用来设计训练后对照。 [StateMemBench](https://arxiv.org/abs/2608.19652) · [AFVE-Bench](https://arxiv.org/abs/2611.10541)

## 复现

```powershell
$env:OMP_NUM_THREADS = '2'
$env:MKL_NUM_THREADS = '2'
$output = 'runs/spora-dialogue-evidence-v1'
.\.venv\Scripts\python.exe -u -m scripts.audit_spora_dialogue_evidence $output --model spora
.\.venv\Scripts\python.exe -u -m scripts.audit_spora_dialogue_evidence $output --model base
.\.venv\Scripts\python.exe -u -m scripts.audit_spora_dialogue_evidence $output --prepare-review
.\.venv\Scripts\python.exe -u -m scripts.audit_spora_dialogue_evidence $output --self-resolve
```

孢子、原版和两次生成的对照分别用时约 287、215 和 147 秒。前两项 CUDA 张量峰值分别约 3.56 和 3.34 GiB。逐项核对了 96 条成对结果及两组的 12 个手写参考。与记忆范围、读出和聊天相关的 19 项单元测试通过。逐题日志为 `spora.json`、`base.json` 和 `self-resolved.json`，开发样本为 `recovery-review.json`。本轮只做生成对照和样本准备。

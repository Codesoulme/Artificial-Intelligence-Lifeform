# 替换层长序列位置适配

## 问题与方法

现有第 6、12 层孢子替换块只训练过 0 至 127 的绝对位置；底座正常推理可能超过该范围。此前将新增位置设零并在少量短前缀上训练，没有得到可靠长序列能力。本轮从冻结的 DeepSeek-R1-Distill-Qwen-1.5B 生成四条正常推理前缀：两条训练、两条留出，来自此前逐条筛查过的不同对话来源。每条最多生成 384 个新词元，实际四条均达到上限，不能当成完整回答。

两层替换块的位置表从 128 扩到 512；保留原有 128 个向量，只训练新增位置。训练在 160、224、288、352 四种前缀长度上，匹配底座对下一个词元的完整概率分布，共 48 步；没有启用孢子记忆，也没有训练底座或替换块的其他参数。以相同教师轨迹测量训练和留出问题，96 位置作为短序列对照。

## 结果

| 检查 | 训练前 | 训练后 |
| --- | ---: | ---: |
| 训练问题，8 个长前缀平均 KL | 0.14176 | 0.01139 |
| 留出问题，8 个长前缀平均 KL | 0.27427 | 0.28774 |
| 留出问题，教师最高概率词元一致 | 6/8 | 5/8 |
| 留出问题，教师采样词元平均负对数概率 | 1.05946 | 1.07670 |

训练位置上的分布拟合明显改善，留出问题未改善，不能证明更长推理能力提高。每种长度只有两条留出序列；KL、最高概率词元和采样词元概率均不是最终回答正确率。

两层原有 0 至 127 位置的张量摘要保持一致；四条轨迹在位置 96 的记录指标训练前后相同。只使用到长度 352 的前缀，因此新位置 128 至 351 收到更新，352 至 511 仍为零；不能宣称整个 512 位置范围已训练。

将位置增量保存在隔离文件后，新进程重新加载底座、两个来源块及增量，重新计算 20 个教师强制前缀：记录的 KL 和采样词元损失最大差值均为 0，最高概率一致标记 20/20 相同。这只复核所记录指标，不证明完整概率分布、自由生成或优化器续训完全一致。

## 限制与判断

四条问题及其来源已用于项目开发，筛查通过不代表数据完全可靠；该导出并未批准通用训练。轨迹采用底座自身采样，可能不正确或不完整；每条训练和留出序列的多个位置彼此相关。未验证真实长对话、最终答案、正常思考结束率、活动记忆、人物寻址或自主记忆更新。当前尾部候选不接入正式个体。

底座和来源块摘要在运行前后核对一致；训练和评估约 295 秒，CUDA 峰值分配约 4.45 GB，新进程恢复另行运行。教师轨迹词元仅保存在本机隔离目录，不提交仓库。代码与检查为 `scripts/deepseek_spora_reasoning_position_distill.py`、`tests/test_reasoning_position_distill.py`；逐项指标、轨迹摘要、位置增量及恢复结果位于 `runs/deepseek-spora-reasoning-position-distill-20261116/`。

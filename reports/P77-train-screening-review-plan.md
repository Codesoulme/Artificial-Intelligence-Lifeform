# P77：训练侧首段分层与独立抽查方案

## 范围与状态

这是对第三版的 8,150 条训练侧首段做的**机械分层**，结果均未获训练或质量批准。数据来自固定中文维基媒体单分片，非全站代表样本；不生成训练二进制，不启动训练。脚本只读取第一、三版的训练正文以及五份既有审查样本，不读取开发或测试正文。第三版上游曾用开发提示做包含过滤，本次不重新读取或利用该正文。来源和上游未通过记录见 [P77](P77-wikipedia-intro-gate.md) 与 [P71–P72](P71-P72-wikimedia-wikipedia-triage.md)。

新材料位于 `runs/wikimedia-intro-screening-p77-v2/`，含两层 JSONL、待审样本及带摘要的清单。每条保留页面编号、地址、标题、正文、规则标记及已审组标记。脚本是 `scripts/stratify_intro_train.py`；运行 `python scripts/stratify_intro_train.py` 可在同一输入及脚本下复现，输出目录存在时会拒绝覆盖。首次试运行的 `runs/wikimedia-intro-screening-p77/` 保留作记录；它只用第三版建立相近组，不作为本方案样本。

## 机械筛选结果，不代表人工判断

| 疑似承接开头 | 201 | 开头为限定的代词、介词或谓语等 |
| 疑似列表残留 | 2,033 | 特定引导、编号、符号或密集顿号 |
| 疑似个人敏感信息 | 64 | 收入、住址、性暴力、未成年人等保守词组 |

规则可同时触发，因此各项不能相加。标题锚定只是一种明确可复现的主体代理：别名、简称、合理的省略和地名开头可能被隔离；完整标题出现也不证明句子有主语。顿号可出现在流畅枚举中；残缺列表也可能没有这些标志。敏感词会隔离财政收入等正常表述，也会漏掉委婉说法、无关键词的人名与私事组合。事实、科学或健康误导、严重语义问题及更新时效均不由这些规则解决。此前版本过宽的数学、医疗等规则已使候选发生选择偏差，这次不能估计原分片中被上游剔除的优质内容。

## 待执行的抽样与记录

五份历史样本分别是 P71、P72 和首段三轮，共 240 条样本记录，可能重复页面。先按页面编号排除；再用规范化字符五元组集合、Jaccard 不低于 0.8 构图，沿第一版训练侧段落传递闭包，排除与历史样本相连的第三版条目。对 P71/P72 的整页样本只用首个空行前的正文来建立文本关联。按此办法排除第三版的 166 条；同主题改写、阈值以下相似文本、正文以外的关系以及上游未入选页面仍可能遗漏。第一版训练与开发无跨组是 P77 原有核对的结果，本次没有读取开发正文重新验证。若发现其他已经审查的页面或组，必须补全排除清单并重新固定种子及样本后再审查，不能把现样本称为独立。

剩余保留层 4,622 条、隔离层 3,362 条。固定种子 `p77-train-screen-review-20261108-v1`，每层按 `SHA-256(seed + NUL + page_id + NUL + group)` 排序，各取前 40 条，完整正文和来源保存在 `review-sample.json`。这是各层等概率哈希排序抽样的操作约定；样本按条而非主题组抽取，组内相关性会降低有效样本量。现阶段**仅已生成样本，尚未阅读或打分**，不能报告余漏率、误删率或通过率。

独立审查员应先固定评价表和规则版本，完整阅读每条，逐项记录：主体与上下文是否完整、正文是否连贯、列表或标记残留、明显事实或科学错误、可识别个人的敏感内容、来源是否能定位，以及不确定原因。必要时按页面版本核查，但不得将未核实事实标为已核实。保留层分别统计严重缺陷和敏感内容的漏检；隔离层记录每个触发原因是否有实质问题、是否仍有其他严重缺陷，以及可恢复正文数，形成误删估计。允许多标签、保留原始判断和分歧；涉及个人信息仅在受控本地记录，不在公开报告复述。隔离层是混合层，其抽样不能直接给出单条规则的精确误删率；需按各规则触发量及有效样本数单独描述，必要时另行固定种子补抽。

每层各 40 条只能提供粗略信号：即使某类问题观察到 0 条，独立同分布近似下单侧 95% 上限仍约 7.2%，组相关和来源偏差会使推断更弱。两层抽样比例不同，整体估计必须按 4,622 与 3,362 加权；不得直接合并 80 条计算总体比例。结果只覆盖排除历史样本后的训练侧子集，不能外推到全部维基、开发集或所有历史组。先完成独立逐条审查与必要复核，再由项目制定适用用途和验收设计；不得沿用旧轮门槛追认，或在查看样本后调参并把同一批当作独立验证。

## 授权、隔离和未完成事项

页面地址和数据卡声明不足以证明逐页使用权。还需核对每条对应版本、贡献者署名、许可兼容性、共享相同方式义务及第三方内容；维基百科上的个人信息亦非因此自动适合训练。旧源池的全文包含记录见 P77，本方案没有重新核验语义近重复、旧模型实际抽样或其他语料重叠，也没有完成逐页事实、授权或人工盲审。所有输出均为待审研究材料，不能用于训练或称为高质量语料。

## 验证

四个针对规则、误删示例、组排除和固定排序的合成测试通过；本机系统 Python 与项目虚拟环境均未安装 pytest，使用 Python `runpy` 逐个执行相同测试函数。另核对输出文件摘要、80 条样本分层数量和精确摘要不重复，并在临时目录重新运行、逐字节核对全部输出。测试不构成人工质量审查。

## 新样本的模型检查

四个模型实例各完整检查 20 条；逐条结果的页面编号、组和正文 SHA-256 与样本一致。保留层 40 条中，严重缺陷标为“是”4 条、“否”30 条、“不确定”6 条；隔离层 40 条中分别为 3、33、4。四个审阅者均未标出明确个人隐私问题，但仅凭短段和一次模型检查不能排除隐含风险。审阅者未核查过滤规则及实际处理依据，因此误删一律标为不确定，不能计算误删率或宣称过滤准确。两层抽样比例不同，且按页面而非独立主题组抽取；结果不能直接外推整个来源。

一次审阅把隔离层其中 20 条全部判为乱码，经检查原始 UTF-8 没有替换字符，问题来自终端输出编码。使用明确的 UTF-8 输出重新检查后，该组严重缺陷判为“是”1 条、“否”15 条、“不确定”4 条；原误判文件保留在本地，统计采用重审结果。事实未做外部核验，四组审查不是人类盲审；当前筛选未取得内容、权利及独立性方面足够证据，仍不批准训练。

# 空状态残差学习率对照

从与[均衡监督试点](kernel-null-balanced-20261117.md)相同的候选出发，使用相同种子、训练顺序、192 步与人工数据；只把显式空状态残差的 AdamW 学习率从 0.0001 提至 0.003，记忆核及输出变换的学习率仍为 0.0001。空状态步骤和有记忆步骤交替，仍由实验人工标记，不涉及自动判断。由于两次分别运行且只用单种子，结果是小规模开发对照。

| 检查 | 原学习率 | 空状态学习率提高 |
| --- | ---: | ---: |
| 前 12 个空状态步骤平均损失 | 7.84 | 7.36 |
| 后 12 个空状态步骤平均损失 | 7.70 | 3.27 |
| 六个训练问题精确生成“我不知道。” | 0/6 | 0/6 |
| 六个训练问题给出具体事实猜测 | 2/6 | 3/6 |
| 留出人物三个空状态问题给出具体事实 | 0/3 | 0/3 |
| 留出人物三类关系换值，两次都精确匹配 | 1/3 | 1/3 |

损失是强制给定目标句时的逐词元平均值；前后各 12 步问题组合不完全相同，不能当作严格配对收敛曲线。提高学习率明显降低这一训练指标，但自由回答没有精确输出训练目标，且训练问题中仍有具体猜测。留出人物的饮品回答表示缺少信息，运动与职业回答表示尚未学会回答；这些不是对自然对话拒答能力的充分验证。

两道普通问题中，算术输出与无注入时一致；红灯问题在显式空状态下输出发生变化，且达到生成长度上限，不应视为正确或保持不变。两题不足以推断普通能力风险。错误关系状态仍由实验强制注入，不能代表自动路由表现；本轮未训练错误关系拒答，也未评估身份、自然写入、持久个体或重启恢复。

结论是提高空状态残差学习率可以更快降低目标句损失，但**尚不能可靠控制自由回答，也可能改变普通输出**。下一步需要同时衡量训练目标、拒答语义和普通对话退化，探索不同作用位置或门控，并用更多独立样本检验；不能将显式手工空状态当作自主记忆缺失识别。

脚本 `scripts/deepseek_kernel_null_lr30_20261117.py`，候选和逐步记录留本机 `runs/deepseek-kernel-null-lr30-20261117/`。底座及起始候选摘要前后核验，正式个体未参与；约 301 秒。5 项已有残差与成对损失检查通过，未覆盖真实模型训练全链路；脚本依赖部分本机未跟踪研究文件，单独检出仓库尚不能完整复现。

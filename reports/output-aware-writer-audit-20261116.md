# 写入向量与完整词表对照

## 范数诊断

沿用此前两名留出人物与八个单字值，第 1 层写入器的预测向量平均范数约 22.84，目标输入词向量平均约 1.12。将预测向量缩放到 256 个训练词向量的平均范数约 1.08，不使用测试值的真实范数；原始和缩放后均为首词及完整输出 0/16。目标词在完整词表中的中位排名分别为 179 和 4061.5；直接提供目标输入词向量的参考路径为 10/16。

底座输入嵌入与输出头未绑定，因此输入向量相似度及 320 词限定候选排名，不能代表完整语言头选择。程序仍然给出值位置、人物地址和结束词元；这不是自主记忆或自然语言能力测试。

## 输出头训练

冻结 DeepSeek 原底座，使用浅层状态及恒等初始化的线性写入器，在人工单字事实上训练 512 步。损失使用对应问题末端隐藏状态加上按训练词平均范数缩放的写入向量，经冻结输出头预测目标。初始训练词表包含 256 个训练词及 4096 个随机负词；64 个留出词既不参与目标，也不作为负词。两组相同种子、事实及步数；第二组每 64 步只根据训练批次的完整词表高分结果添加竞争词，结束时共有 4553 个输出类别。

新进程加载候选，在完整词表上检查每组前八个词、两个人物的首词排名：

| 条件 | 固定抽样负词 | 加入训练竞争词 |
| --- | ---: | ---: |
| 训练人物、训练词 | 0/16 | 14/16 |
| 留出人物、训练词 | 0/16 | 14/16 |
| 训练人物、留出词 | 0/16 | 0/16 |
| 留出人物、留出词 | 0/16 | 0/16 |

固定抽样组的 64 条检查中有 62 条选中了同一竞争词；训练词中位排名约为 2.5，而不是完全没有得分。竞争词组改善了这批已训练词的完整词表结果，但没有让未见词产生正确首词。对留出人物和留出词做实际贪心生成，两组均为 0/16，程序注入 EOS，停止行为也不是模型自行习得。

## 限制与记录

比较只有一个训练种子、单一固定句式与八个抽查词；每个词被两个人物重复使用，不能视为独立事实。抽查词和诊断此前已用于开发，不能当作密封验收。高分竞争词是在观察固定抽样失败后决定加入，算力和训练类别数有所增加，因此结果支持这一具体修正的开发判断，不证明其他训练设计无效。没有测试多词事实、自主选址、持续写入、孢子替换层、真实个体或自由聊天；候选不部署。

第一次竞争词训练在完成生成后因输出路径变量被生成张量覆盖而保存失败，已修正脚本并重跑；只有第二次结果计入表格。所有实验均核对底座文件摘要。范数诊断约 95 秒，固定抽样训练及重载约 111 秒和 94 秒，竞争词训练及重载约 97 秒和 83 秒；CUDA 峰值分配最高约 3.43 GiB。

# 多词元记忆路径的受控消融

## 方法

在同一隔离起点、同一问题和两种人工指定的记忆状态下，分别计算两个候选事实在**各自正确前缀**下的平均词元对数概率。对两组已有受控样本分别临时关闭：原生读取器、读取记忆的低秩适配器、晚层直接残差、最终隐藏状态残差；另比较全部路径关闭与完全不传入记忆。消融只替换本进程中的前向方法，退出后恢复，不修改权重、不执行优化器更新。

表中 A、B 分别为原值、换值；`A差`是记忆为 A 时 A 分数减 B 分数，`B差`是记忆为 B 时 B 分数减 A 分数。两者都大于 0 才表示在这两个候选中均偏向当前记忆值；这仍不是完整词表的自由生成正确率。两个候选长度可能不同，使用的是各自片段的**平均**对数概率。

| 原值 / 换值 | 路径 | A差 | B差 |
| --- | --- | ---: | ---: |
| 打羽毛球 / 踢足球 | 完整路径 | -1.104 | 0.892 |
| 同上 | 关闭原生读取 | -0.936 | 0.723 |
| 同上 | 关闭低秩适配器 | -1.456 | 1.351 |
| 同上 | 关闭晚层直接残差 | -1.266 | 1.069 |
| 同上 | 关闭最终残差 | -1.103 | 0.888 |
| 气泡水 / 葡萄汁 | 完整路径 | -1.468 | 2.082 |
| 同上 | 关闭原生读取 | -1.627 | 1.904 |
| 同上 | 关闭低秩适配器 | -1.318 | 1.870 |
| 同上 | 关闭晚层直接残差 | -1.544 | 2.044 |
| 同上 | 关闭最终残差 | -1.476 | 2.063 |

两组完整路径在两种状态下都更偏向 B；被检查的四种条件中，目标值第一个词元均不是完整词表最高分。关闭全部路径后，两种状态的对应分数完全相同，并与不传入记忆一致；实验程序检查该一致性。各单路径消融会改变部分分数，说明在这两个条件下路径有影响；路径之间可能存在交互，不能把逐个关闭的差异相加，或据此排名其一般贡献。

## 判断与边界

第二组中，完整路径的记忆切换让两种候选的相对分数发生变化，但仍不足以让 A 状态优先 A。第一组的相对变化方向也不同。这为“记忆影响了分数但没有可靠读对”提供了更细的诊断；仅两个受控样本，不能据此断言某条路径普遍有害、应永久关闭或是唯一瓶颈。

所有候选分数均为教师强制前缀下的诊断，**不是模型自行生成答案的结果**。任务给定身份、地址、事实、候选及目标片段，尚无自然写入、自动寻址、独立多轮对话、长期保持或普通对话质量评估。分数比较也不构成模型有主观记忆的证明。

入口 `scripts/deepseek_spora_multitoken_path_ablation_20261117.py`；单样本及完整路径参数分别在 `runs/deepseek-spora-multitoken-path-ablation-72381-20261117/diagnostic.json` 与 `runs/deepseek-spora-multitoken-path-ablation-72382-20261117/diagnostic.json`。两次分别约 184 秒、182 秒，PyTorch GPU 峰值约 4.02 GiB；源底座、起点检查点和原个体经前后摘要核验。消融恢复与既有梯度、桥接测试共 23 项通过。

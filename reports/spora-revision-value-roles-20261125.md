# 交换原值与备选值的写入器对照

上一轮给定正确字段时，孢子在 24 条提议里只提取对了 3 条，8 条原样选中旧值。本轮从该字段编号方案起步，构造 144 组同字段值对。每组交换原值和备选值的身份，并让备选值分别出现在前半句和后半句，组成 576 条原话。两组继续训练 5 轮，采样顺序一致。第一组监督完整字符跨度。第二组再要求完整新值的分数超过完整旧值及缺首字或末字的候选。两组沿用冻结的 DeepSeek 孢子特征和已知场景的三字段清单。 [上一轮提取对照](spora-described-revision-span-20261125.md) · [Contrast Sets](https://arxiv.org/abs/2004.02709)

新留出集由 24 组事实组成，每组四句，使用未参与续训的措辞和值，覆盖两个值的身份及出现顺序。另复测 24 条已确认和 24 条提议原话。自动选字段仍取跨度相对空操作的最大分差。整个候选对照评估的是应提取的备选值，提交许可另用已经保存的事件结果回放。

| 留出指标 | 起始写入器 | 交换样本续训 | 续训并增加排序损失 |
| --- | ---: | ---: | ---: |
| 新措辞，给定正确字段时选到完整新值 | 28/96 | 37/96 | 36/96 |
| 新措辞，给定正确字段时误选完整旧值 | 24/96 | 12/96 | 12/96 |
| 新措辞，给定正确字段时只截取了新值的一部分 | 11/96 | 17/96 | 17/96 |
| 新措辞，同一词序下交换身份后两句全对 | 4/48 | 10/48 | 9/48 |
| 新措辞，两个词序的四句全对 | 0/24 | 1/24 | 1/24 |
| 新措辞，自动找对字段和完整新值 | 27/96 | 34/96 | 34/96 |
| 原提议，自动找对字段和完整新值 | 3/24 | 5/24 | 4/24 |
| 已确认更正，自动找对字段和完整新值 | 13/24 | 10/24 | 10/24 |

交换样本减少了整段旧值错误，但截断更多。额外排序损失在本次设置下未改善留出结果。两种续训均只复习了提议类原话，已确认样本的退步需要用混合回放复核。

## 写入回放

从正确会话初值开始，将三组抽取的字段和跨度分别接回同一批 144 条事件记录。两种提交决定逐条沿用原评测输出。起始写入器在结构化决定下精确提交 6/48，续训两组均为 3/48。该决定在三组均误放行 12/96，实际改动应保留记录的次数依次为 10、10 和 9。起始组共有 92/144 条最终记录完全正确，续训两组分别为 89/144 和 90/144。

额外离线诊断使用旧事件头对首轮的预测，动态选择提议组或起始写入器，结构化精确提交为 5/48。给出正确的首轮意图作为上限，结果为 6/48。写入回放支持继续改进字段绑定、跨度边界和回合相关性，当前候选留在研究分支。 [事件写入对照](20261125-revision-events-stall-diagnosis.md)

下一次在相同步数下加入已确认原话，检验能否保住两类表达的提取能力。提交侧需显式学习后续确认指向的具体事务和字段。CoNLL 2026 的 Event-DST 用对话事件协调多个字段，可参考其事件约束与文本精度分路做法，实际中文写入需另测。 [Event-DST](https://aclanthology.org/2026.conll-main.30/)

本轮训练加评测约 156 秒，独立重载约 95 秒，逐题复现了候选跨度、评分和状态回放。受控持久读取 32/32，与父实验逐条一致，个体摘要一致。15 项相关单元测试和新旧值区间索引检查通过。详细结果位于 `runs/spora-revision-value-roles-v1/result.json`。

## 等步数混合回放

另从同一字段编号权重起步，每组保留两个提议句，覆盖两个值的角色和两种位置，再加入两条同字段已确认更新。混合组共 288 条提议和 288 条已确认原话。与纯提议组一样，每轮遍历 1,728 个字段监督项，共 180 次更新，学习率和样本加权不变。对照使用同一留出集和同一组提交结果。

| 指标 | 起始写入器 | 仅提议续训 | 混合回放 |
| --- | ---: | ---: | ---: |
| 新措辞，自动找对字段和完整新值 | 27/96 | 34/96 | 34/96 |
| 新措辞，给定正确字段时误选完整旧值 | 24/96 | 12/96 | 14/96 |
| 新措辞，给定正确字段时只截取新值一部分 | 11/96 | 17/96 | 12/96 |
| 原提议，自动找对字段和完整新值 | 3/24 | 5/24 | 4/24 |
| 已确认更正，自动找对字段和完整新值 | 13/24 | 10/24 | 11/24 |
| 结构化提交后，字段及完整值均正确 | 6/48 | 3/48 | 4/48 |
| 结构化提交后，应保留记录被实际改动 | 10/96 | 10/96 | 10/96 |

混合组降低了续训后的截断率，并恢复一条已确认更正，最终状态完全正确为 90/144，起始组为 92/144。结构化提交决定仍误放行 12/96。当前候选达不到晋级条件。

混合组训练和评测用时约 146 秒，独立重载用时约 95 秒。重载复现所有候选、分数和状态回放，32 条受控持久记忆读回与父实验逐条一致。15 项相关单元测试通过。数据检查确认每组保留的两个备选句覆盖两个值和两种出现位置。

为判断自编句式能否代表自然改口，核对了固定 CrossWOZ 验证包中的用户 `Inform` 标注。在 500 段对话中，同一领域和字段的用户标注先后出现不同值 259 次。其中 242 个字段事件对应的当前句含唯一新值，覆盖 207 个回合和 145 段对话。没有一条同时逐字含有两个互不包含的完整新旧值。并列追加、推荐条件变化和主题切换也可能产生不同标注值，后续需核验哪些确实替换了旧记录。这批记录适合优先审核跨轮变化案例，不能直接作为提交真值。 [CrossWOZ 论文](https://aclanthology.org/2020.tacl-1.19/) · [固定验证集](https://github.com/thu-coai/CrossWOZ/blob/df82c9fdff91b9b130f2d6b89110d3870ba6260e/data/crosswoz/val.json.zip)

统计只用用户回合，每个领域字段保留上一个单值 `Inform` 标注。跳过单字、空值和通用无偏好值。字面定位限当前句 4 至 120 字。不使用系统生成结果推定写入许可。验证包的 SHA-256 为 `b2b717990f6f0a1c98daaf5dc465e61d42f7de69c0d31e88e674275b1f34c94c`。

## 复现

```powershell
$env:OMP_NUM_THREADS = '2'
$env:MKL_NUM_THREADS = '2'
$sporaSplit = 'runs/spora-recurrent-split_gated_block_delta-warm-v1'
$sporaArgs = @(
    'runs/spora-composition-late-gates-20-23-24-v1/candidate.pt',
    'runs/spora-described-revision-span-v1',
    'runs/spora-revision-events-v1',
    'runs/spora-revision-value-roles-v1',
    "$sporaSplit/layer-19", "$sporaSplit/layer-22"
)
.\.venv\Scripts\python.exe -u -m scripts.train_spora_revision_value_roles @sporaArgs
.\.venv\Scripts\python.exe -u -m scripts.train_spora_revision_value_roles @sporaArgs --verify
```

混合回放将输出目录改为 `runs/spora-revision-roles-mixed-v1`，两条命令均添加 `--mixed`。

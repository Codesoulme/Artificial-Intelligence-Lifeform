## 范围与结果

- 先取得 [robots.txt](https://kids.frontiersin.org/robots.txt)：HTTP 200；`User-agent: *` 下没有 `Disallow` 或 `Crawl-delay`，另有只针对 Googlebot-Image 的图片规则。本次未请求图片。robots 规则只是抓取边界，不能替代授权或使用条款判断。
- 取得[中文目录](https://kids.frontiersin.org/zh/articles)首页和站点脚本，观察到 `#filter` 的 `data-page="0"`、`data-url` 及滚动加载脚本：下一批以 `page=1` 请求，并带浏览器 AJAX 请求头。普通页面请求带此参数仍返回首页；加 `X-Requested-With: XMLHttpRequest` 后返回另一批 12 个不同条目。只检查两批，不能推算站点总量；保存的目录页面和站点脚本为原始证据。
- 根据两批目录标题和摘要人工选择 14 篇，优先地学、气候、教育、经济与技术；排除已在 P89 阅读的三篇及明显医疗主题。主题筛选是近似判断，不能保证没有健康相关表述。没有继续遍历目录。
- 实际获取 14 篇文章 HTML，均返回 200；一篇先单独检查结构，其余 13 篇由脚本顺序获取。脚本每次请求前至少等待 5 秒；遇到非 200、限流、超时或其他网络错误立即停止，不自动重试，不跟随重定向。该低频设置不能保证未来不会遇到访问限制。13 次脚本请求开始时间为 14:06:59–14:08:31 UTC；第一篇的时间只能从保存的 HTTP `Date` 头近似确定。
- 各文章页面均找到单个与开放获取声明相连的 CC BY 4.0 许可链接。14 篇通过机器结构检查并生成完整正文**候选**；这不是人工确认的完整性或质量结果。初版把一个正常小标题误当作结束标记而拒绝一篇；改为精确匹配并加入离线检查后重新处理了全部快照。
- 三个模型实例对照快照逐篇审查后，12 篇标为存疑、2 篇建议排除；主要问题为指向已移除图示或文献的语句、译者信息不明确，以及个别科学或数量表述可能有误。各条 DOI 与清单一致，但评审文件写的是内容摘要而非候选文件哈希，因此不能据此证明审阅时的候选文件字节与当前一致。这是模型检查，不是专家或事实核验；样本为人工选择，不能推算站点总体质量，也不批准训练。

## 交付与复现

本次运行目录是 `D:/SPORA/runs/research/p90-frontiers-zh-20261108/`：

- `manifest.json`：逐篇 URL、文章 DOI、页面署名、访问时间、原始快照 SHA-256、许可链接、正文统计、处理决定及不确定性。译者未能从安全署名区确认，译者许可链接为空，表示**尚未核实**，不代表没有译者或许可。许可与作者的关联仅据各篇页面声明，尚未单独核验翻译授权。
- `raw/`：文章原始 HTML 和响应头；目录、robots、站点脚本等发现证据保存在运行目录。原始页面可能含人物简介、未成年人信息和联系方式，只保留在本机，不能作为清洗后的正文分发。
- `candidates/`：仅供本地人工审查的正文候选，不包含脚本有意保留的图注、参考文献、作者简介或少年审稿人区块。候选可能保留指向图片、文献的正文语句；语义完整性、资料残留仍须逐篇对照审核。不要把这些文件作为训练集。
- `explore.py`：固定选择清单、robots 检查、限频获取、结构化提取与拒绝条件。`requests.json` 记录脚本请求时间和状态。所有条目与路径保存在 `runs/`，该目录受仓库忽略规则保护，不会出现在普通 Git 状态中。

在项目目录中，使用安装了 BeautifulSoup 4 的系统 Python 和 Windows `curl.exe`：

```powershell
python runs/research/p90-frontiers-zh-20261108/explore.py selfcheck
python runs/research/p90-frontiers-zh-20261108/explore.py process
```

以上命令只读取本地快照；前者检查非 BY 许可拒绝、未知结构拒绝、结束边界及行内空格，后者重建清单和候选。`acquire` 子命令使用保存的 robots、两批目录及固定清单，只获取缺失的文章；如需未来再次联网，应先重新获取并检查 robots 和当前目录，确认页面结构仍相同。脚本限制固定清单最多 20 篇、排除 P89 三篇，且仅在目录中实际出现时获取。发现阶段的分页参数、脚本和服务器响应已保存在本次运行目录；目录结果会随时间变化，不能保证未来重现相同集合。

校验时重新计算了全部 14 个快照的 SHA-256，核对候选与处理状态的一致性，并对候选做了邮箱模式扫描。脚本还拒绝缺失、歧义或非 BY 4.0 的文章许可，拒绝异常短正文、未知顶层元素、缺少已知结束边界和检测到的正文联系方式。这些规则无法证明没有所有个人资料、遗漏、格式损伤或第三方材料；拒绝不等于文章没有价值。

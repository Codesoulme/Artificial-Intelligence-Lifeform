# 共享状态的写入器与读取器联合训练

使用冻结的 DeepSeek-R1-Distill-Qwen-1.5B，训练第 6、12 层的低秩写入目标修正器与读取适配器。每步将四个人物的事实依次写入同一临时 fast-weight 状态，对四个问题计算回答损失；每四步追加一次人物纠正。事实边界与事件顺序由程序提供，不是自主学习。候选与底座分离，未安装到正式个体。

首轮使用固定人物与值的对应关系；评测代码的索引错误导致第一次 256 步在保存前终止。修复后以相同种子重新训练，并在评测前保存参数。第二轮改为每步随机重排对应关系，同样训练 256 步。两轮都只使用四名训练人物、四种饮品和一条关系；留出人物与评测问法均是已使用过的开发材料。

| 生成精确匹配 | 固定绑定课程 | 随机绑定课程 |
| --- | ---: | ---: |
| 训练人物、原始分配 | 4/4 | 0/4 |
| 留出人物 | 2/4 | 1/4 |
| 训练人物、全部换值 | 0/4 | 2/4 |
| 追加纠正后，四人总计 | 3/4 | 1/4 |
| 未知人物非空回答 | 2/2 | 2/2 |

固定绑定课程的纠正总分 `3/4` 是三个未修改的人答对，纠正对象依旧答旧值，不能称纠正成功。随机绑定课程的纠正对象答对，但其余三人都错；该组换值与纠正组合可能已经在随机训练中出现，不属于独立测试。两名未知人物都输出饮品，无未知拒答训练或验收。

两轮使用不同训练分布，不能从这两个小样本估计统计意义上的收益。普通问题仅在记忆关闭条件下检查两条生成一致；没有测试开启记忆后的普通对话退化。训练损失下降不等于记忆成功。第一轮约 245 秒，第二轮约 232 秒，峰值各约 3.92 GB；底座摘要保持一致。

本次代码 `scripts/deepseek_spora_ttt_shared_joint_pilot.py` 为随机绑定版本；第一轮结果记录在 `runs/deepseek-spora-ttt-shared-joint-20261116/`，第二轮在 `runs/deepseek-spora-ttt-shared-joint-random-bindings-20261116/`。训练轨迹与候选均保留本机，未声称重启后行为等价或崩溃恢复。

下一步不应晋级任一候选。需要跨人物、跨值、缺失事实与相互冲突的对照课程，预先固定独立人物、独立问法和值组合；比较记忆开关、同题换值、纠正目标及非目标保持，并重新评估读写表示是否足以区分事实。

# 中文阅读理解数据与定位开发检查

使用 CMRC 2018 官方仓库 [固定版本](https://github.com/ymcui/cmrc2018/tree/c0eb1b6ba219847457e6af3180da722bbeb656af)的 `squad-style-data/cmrc2018_dev.json`。仓库 [LICENCE](https://github.com/ymcui/cmrc2018/blob/c0eb1b6ba219847457e6af3180da722bbeb656af/LICENCE) 标示 CC BY-SA 4.0；数据论文为 Cui 等人的 [A Span-Extraction Dataset for Chinese Machine Reading Comprehension](https://aclanthology.org/D19-1600/)（EMNLP-IJCNLP 2019）。数据留本机，没有把原文复制进仓库。许可证标示不自动解决每个下游用途的全部权利问题，后续若分发衍生数据需处理署名与相同方式共享等条件。

下载文件以官方 Git blob 摘要和大小校验，并计算 SHA-256。开发文件含 848 个段落、3219 个问题、9657 条答案标注；其中 200 条答案的字符位置不能直接对应原文，3043 个问题的全部答案位置匹配。含“谁／哪位／何人”的问题有 246 条，答案位置均匹配；其答案不一定是自然人。这批问题均附答案，不能用于评估无证据拒答。

按问题标识摘要排序，筛选长度不超过 500 字、单一位置及答案、答案为 2–8 字且在段落只出现一次的条目，每段最多一题：67 条符合筛选，选取 32 个不同段落。开始尝试的 250 字上限没有选出题目，保留该零结果后调整为 500；因此这是开发检查，不能称预先密封的独立测试。全部目标均可由当前词元边界与长度上限表示。

输入为**完整原段落加原问题**，只检查定位片段与数据集答案字符串是否相同：观察头选出 32 条、匹配 1 条；事实查询头选出 10 条、匹配 0 条。每题只有一个筛选后的答案文本和位置，未做语义同义判分、其他答案复核、身份识别或生成。数据集可能已出现在底座预训练中。上述数字反映该有限样本下的长文本定位弱点，不代表模型整体中文阅读成绩，也不能说明持久记忆能力。

原始文件、匿名选择清单及结果位于本机 `runs/`；脚本分别为 `scripts/audit_cmrc2018_dev_20261117.py`、`scripts/cmrc_who_development_selection_20261117.py` 和 `scripts/deepseek_cmrc_who_probe_20261117.py`。没有执行数据训练或记忆写入，模型与文件摘要前后核验；3 项筛选和数据检查通过。模型检查脚本依赖部分本机未跟踪研究文件，仓库单独检出尚不能完整复现。

下一步应先核对长段落的可用位置与任务输入差异，再开展按文章及答案实体隔离的短语定位训练，并保留未见自然语料、无答案及改写对照；不能将简单的答案位置标签视为真实身份或自主记忆授权。

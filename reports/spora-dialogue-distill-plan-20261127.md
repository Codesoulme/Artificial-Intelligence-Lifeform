# 自编较长对话的记忆写入试验

日期：2026-11-27。上轮对完整对话进行两槽和简单分块读取均不可靠，且位置与槽数量混杂。先不继续扩大模板训练次数，尝试让写入器接触含干扰轮次的自编对话，观察是否能迁移。

研究依据：[In-context Autoencoder](https://arxiv.org/abs/2307.06945) 研究把上下文压进可训练的连续状态；[Compressed Context Memory](https://arxiv.org/abs/2312.03414) 研究在线交互中的压缩上下文；[Latent Context Compilation](https://arxiv.org/abs/2602.21221) 使用长上下文行为监督紧凑记忆。本轮只借鉴同底座明文行为蒸馏，并非复现论文；首位置分布一致也不能证明证据完整保留。

从扩大错关系覆盖的候选开始，底座冻结；将既有自行编写的 48 条事实各嵌入固定的多轮干扰对话，以完整答案和结束符监督正确事实及换值，均匀抽取错误关系监督拒答；另以同一个底座看到完整对话时的问题末位置 logits 作为教师，用 KL 约束压缩状态回答首词的分布。保留普通问题的分布约束。固定种子、64 步，记录损失、来源摘要与成本；不使用 PerLTQA 训练。

先记录训练前后合成对话、短事实和已审阅的来源事实表现；再单独重载候选，以固定的八条 PerLTQA 开发对话与此前一致的提示进行关闭、压缩、其他状态和明文参照。自然语言子串只是筛查，须结合输出；教师分布可能包含错误，短样本和模板不构成独立评测。数据的封存组不参与，涉及非商业材料仅用于本地研究，不随仓库推送。实验候选不接入正式个体。

运行记录：首版在预先构建所有对话状态时进程退出，未进入训练，也没有 Python 异常文件；原因尚未确认，不应断言是内存不足。第二次改为限量缓存、按需编码，使用独立目录；这一实现调整不改变训练目标和样本。

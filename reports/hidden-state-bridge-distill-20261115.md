# 隐藏状态桥接蒸馏试验

## 目的

验证一个连续记忆向量能否通过宿主语言模型已有的隐藏状态空间进入自由生成。学生只接收问题和内部记忆快照；训练时教师额外看到同一事实的自然语言前缀，并把答案位置的最终隐藏状态作为蒸馏目标。教师不会进入运行时，也没有把答案词表查找结果直接写入输出。

## 实验设置

- 入口：`scripts/deepseek_spora_hidden_bridge_distill.py`
- 基础框架：晚层直接残差候选，记忆读取器位于原生第 5、17 层读取位置，语言适配位于第 18、20 层，并保留最终隐藏残差。
- 记忆：5 槽完整事实 + 身份，固定 codec 只用于研究性受控写入和读取。
- 训练：3 个训练人物、18 个水果值、6 种问法、320 步；只训练读取器和记忆适配器，底座冻结。
- 优化目标：原有完整答案交叉熵和反事实损失，加权隐藏状态余弦蒸馏，隐藏状态权重为 1.0。
- 起点：`runs/continuous-reader-final-hidden-residual-pilot-20261113/candidate.pt`
- 结果：`runs/deepseek-spora-hidden-bridge-distill-20261115/result.json`

## 结果

训练前后同一进程中的严格评测如下：

| 评测 | 训练前 | 训练后 |
| --- | ---: | ---: |
| 留出人物，原记忆值 | 98/108 | 100/108 |
| 留出人物，替换记忆值 | 98/108 | 100/108 |
| 两侧同时正确的反事实配对 | 91/108 | 93/108 |
| 训练人物记忆值 | 12/12 | 12/12 |

独立进程重载审计：

- 已记录的 18 个值逐词生成复现：18/18。
- 新人物：9/12。
- 新问法：4/8。
- 六条事实共存：6/6。
- 一条事实更正后：6/6。
- 关闭记忆的 8 条控制没有被判为事实正确，普通关闭记忆生成与重载前一致。

训练耗时约 1173 秒，峰值 CUDA 分配为 4,664,065,024 字节。底座、正式个体和正式检查点均通过前后保护校验；候选仍只保存在隔离 `runs/` 目录，没有接入默认运行时。

## 判断

隐藏状态蒸馏方向有可测但有限的增益，说明连续记忆到宿主隐藏状态的桥接可以继续优化；它没有解决新人物、新问法的完整泛化，也没有证明自然语言路由或开放事实生成。因此本候选不接入正式个体，不能称为正常聊天能力突破。

下一轮应扩大事实关系和多词元值的独立留出集，并把教师隐藏状态目标从单一最终层扩展为答案前若干层的局部轨迹，同时保持无记忆普通问题和严格反事实配对作为门槛。

# Qwen 主干内部记忆意图门

日期：2026-11-21

## 目的

Qwen2.5-0.5B-Instruct 的中文聊天能力明显优于当前 DeepSeek 分支，但记忆读取器如果对所有问题强制开启，会改变普通回答。本轮把一个小型意图头接入 `memory_hooks` 内部：调用方提供不可变记忆状态，Qwen 第一个记忆层根据当前问题隐藏状态决定是否读取；决定在一次生成中保持不变。

语言模型、记忆矩阵、孢子个体和数值记忆适配器均冻结，只训练二分类门控头。训练集包含 12 条普通问题和 32 条受控记忆问题，共 44 条。

## 结果

| 项目 | 结果 |
|---|---:|
| 门控训练准确率 | 44/44 |
| 普通多轮留出问题 | 24 条 |
| 普通留出启用记忆 | 0/24 |
| 普通留出回答保持不变 | 24/24 |
| 普通表面词探针启用记忆 | 0/4 |
| 未见对象记忆问法启用记忆 | 8/8 |
| 未见对象记忆数值回答正确 | 8/8 |

最终候选使用第 5 层隐藏状态训练门，并在第 5 层 hook 中执行，避免训练表示和运行表示错位。自动门版本和外部预判版本得到相同结果，普通问题的回答逐词元保持 `24/24`。第 3 版曾把最后一层表示用于训练、却在第 5 层执行，导致记忆问题全部退化为拒答；该版本作为负向对照保留，说明门控表示必须与注入位置一致。

## 结论

这轮验证了一个可用的结构原则：孢子记忆可以作为语言骨干内部的条件旁路，而不是每次生成都强制注入。它改善了记忆接入的边界，保留了 Qwen 的普通中文能力。

当前仍有三个限制：

- 门控训练样本很小，记忆问题仍来自有限数字地址模板；
- 数值读取器使用受控对象和有限词表，不是开放语义记忆；
- 候选没有接入正式检查点，也没有改变正式个体。

下一步应扩大自然中文记忆问法、加入历史时间页和未知事实负例，再把门控与语义寻址联合评测。

# 明确问题交互的匹配训练对照

原交互头将全部有效词元平均后与候选位置互动；长段落可能稀释问题信息。新增研究模块 `spora/research_question_conditioned_span.py`，对问题位置单独汇聚，再与每个候选位置形成附加交互分数。问题范围由实验输入格式明确提供，不是模型自己找出问题；附加投影零初始化，在两条开发输入上与原头输出逐元素相同。

两头从同一[旧候选](fact-paraphrase-train-20261117.md)出发，使用[同一自然阅读试点](cmrc-reading-train-pilot-20261117.md)的 63 条可表示训练例、32 条人工正负重放、相同次序、优化设置及各 400 步；底座特征共用，正式个体未参与。新头参数与每步运算更多，比较匹配步数但不是匹配参数量或 FLOP。

| 训练后检查 | 原头 | 问题交互头 |
| --- | ---: | ---: |
| 自然训练例精确位置 | 14/63 | 47/63 |
| 自然开发例精确位置 | 5/32 | 3/32 |
| 自然开发例错选 | 26/32 | 29/32 |
| 自然开发例暂缓 | 1/32 | 0/32 |
| 人工同类已知精确 | 16/16 | 14/16 |
| 人工同类无证据误选 | 0/8 | 0/8 |
| 人工同名误选 | 0/8 | 0/8 |

新增结构更容易拟合训练材料，但在已查看开发材料上更差，人工同类题也出现两次错选。小样本、单随机种子和人工问题范围不能证明结构本身无效；目前没有证据支持接入正式模型。自然数据没有无答案标签，人工负例不能证明自然拒答安全。

数据为 CMRC 2018 官方固定训练和开发分区，许可证及出处见[数据报告](cmrc-who-development-audit-20261117.md)。排除完全相同文章标题和所选开发答案字符串，但别名、相似文本及预训练重叠无法排除。开发组已多次用于设计，不是密封测试；答案可能并非人物，且仅测全文输入下的精确位置，不涉及模型内记忆、身份认证或生成。

脚本 `scripts/deepseek_cmrc_question_head_comparison_20261117.py`；两个隔离头、完整计数及摘要留在本机 `runs/deepseek-cmrc-question-head-comparison-20261117/`。原模型与输入摘要前后核验；约 303 秒、GPU 峰值约 3.57 GiB。5 项结构、问题掩码与重放检查通过。实验脚本仍依赖部分本机未跟踪研究文件，仓库单独检出尚不能完整复现；新增结构模块本身可独立导入。

下一步优先扩充相互隔离的自然训练材料并准备真实无答案对照，逐项审阅错选；使用严格未见的评估数据比较输入顺序和结构，不能针对已查看的 32 题反复调参后宣称泛化。

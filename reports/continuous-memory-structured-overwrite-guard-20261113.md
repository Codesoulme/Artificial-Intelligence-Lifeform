# 结构化记录覆盖保护

结构化状态目前每个数值地址仅保存一条记录，未表示事实关系，也没有该记录的历史版本。此前同一地址的新 packet 可能直接覆盖旧 packet；新颖度或查询相似度不能判断这是纠错还是另一条事实。

现在显式研究接口在已有记录时先恢复身份：身份 token 不一致则延期；事实 token 不同时，默认延期，只有调用方传入 `replace_existing=True` 才继续经过原写入门。这个标志表达调用者意图，并不验证事实真实性或关系一致性；codec 身份恢复也不是身份认证。重复事实仍由原门处理。

测试包括不同身份和未授权不同事实均不改变记录，相关 CPU 回归 44 项通过。真实 DeepSeek 隔离个体上，首次写入、重复、无关内容和显式更正分别得到写入、延期、延期、写入；独立进程重载后当前事实一致。原始结果在 `runs/deepseek-spora-structured-write-gate-audit-v3-20261113/`。

下一步需要设计可持久化的多关系记录和历史语义；本次保护没有实现多事实共存，也没有验证开放问答。

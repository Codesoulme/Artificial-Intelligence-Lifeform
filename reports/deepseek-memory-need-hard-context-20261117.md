# 记忆需求路由：主体、属性及否定对照（2026-11-17）

## 设置

不再训练，加载上一轮成对训练头和其固定阈值。在 8 个新手写问题上，每个问题分别配四种句子：直接回答的事实、同主体不同属性、不同主体的对应属性、对某具体值的否定。前三种均是单句陈述；否定句仅排除某个值，不能说明正确值，所以后三种均标为仍需要其他信息。逐条人工编写，未声称来自真实对话；无冲突事实或更多上下文。

## 结果

| 给定的信息 | 预期 | 判断正确 |
|---|---|---:|
| 直接回答 | 不需要额外经历 | 8/8 |
| 同主体不同属性 | 仍需其他信息 | 2/8 |
| 其他主体相同属性 | 仍需其他信息 | 0/8 |
| 否定一个候选值 | 仍需其他信息 | 0/8 |
| 四种情形均正确 | — | 0/8 |

例如，对于“阿琪喜欢什么花？”，提供“阿波喜欢茉莉花”或“阿琪不喜欢茉莉花”都不能确定答案；当前头仍把这些输入视为无需额外经历。这个小实验明确否定了将当前方案接入自动路由的依据，但不能从 8 组单次结果推断总体错误率，也不能判定错误究竟源于训练资料、池化、分类结构还是基础模型。前面挑选的阈值由小校准集决定；未对这组测试调阈值。

真实中文多轮材料仍需审查：`runs/oasst1-chinese-candidate-v5/manifest.json` 明确标记 `ready_for_training: false`，并说明候选存在同树分支和与公开验证内容重叠；数据卡的 Apache-2.0 是声明而非已完成法律核验。不能直接把它当独立训练或验收集。后续应建立有来源与分组信息、经人工检查的真实对话样本，标注主体、关系、否定、证据来源和时间；对照提取证据的架构，评估事实匹配与拒答，避免只优化单个二分类分数。

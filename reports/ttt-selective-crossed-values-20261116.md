# TTT 值位置写入交叉实验

## 方法

在与整句写入相同的底座、人物、饮品、问法和训练预算下，只把程序已知的饮品 token 位置写入 fast weight，并在同一分布上重新训练读取适配器。人物和值仍由实验控制，因此这是写入目标诊断，不是自主写入方案。

## 结果

| 条件 | 严格正确 | 基线严格正确 |
| --- | ---: | ---: |
| 训练人物、训练饮品 | 12/16 | 0/16 |
| 留出人物、训练饮品 | 6/8 | 0/8 |
| 留出人物、未训练饮品 | 0/4 | 0/4 |
| 留出人物、新问法、训练饮品 | 2/8 | 0/8 |

相比整句写入候选，已见值略有改善，但未见值仍为 `0/4`，同一问题在切换值时也没有达到两侧都正确的要求。训练人物没有一个做到四种饮品全部正确。

## 结论

单纯把写入位置缩窄，不能让当前 TTT 路线获得开放值泛化。它说明整句上下文确实会干扰值信号，但“只写值位置”只是理想化干预，不能替代可学习的值编码器。下一轮需要联合训练写入目标和读取层，或引入专用的语义记忆槽，再用未见值和重载测试筛选候选。

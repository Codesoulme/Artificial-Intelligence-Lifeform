# 文本级词表残差试验

## 方法

在最终隐藏状态注入之外，再增加一个研究候选：由孢子语义记忆直接产生词表残差，并与 Qwen 原始 `lm_head` 输出相加。语义向量与冻结底座词嵌入计算相似度，同时保留一个低秩可训练词表残差。目标是测试错误是否来自最终词表映射。

- 综合问法：98/108。

- 当前问法：18/18。

- 关于爱吃水果：16/18。
- 查阅记忆后问爱吃什么水果：15/18。
- 水果偏好：14/18。
- 训练样本：12/12。

词表残差没有产生可验证提升；峰值显存约 5.21 GiB，已经接近 GTX 1060 6GB 上限。候选没有接入正式个体。

## 判定

当前瓶颈不是简单的注入位置或词表输出映射。继续堆叠输出适配层收益有限，下一步应实现文本级记忆重建/回答头训练：让连续记忆在没有当前问法答案模板的情况下重建事实文本，并测试跨问法、跨实体和更正序列。

# 语言层与反事实记忆的同轮对照

## 设计与结果

同一个隔离模型实例比较两种配置：保留原始 DeepSeek 第 6、12 层，或使用孢子替换层；其他读取器相同。分别为两个人物写入咖啡或水，对每人使用两种问法。同一问题在不同状态下各生成一次，另外记录关闭读取时的回答。地址和值由程序指定，生成只使用记忆读取器，不使用答案词表输出适配器。

| 指标 | 原始语言层 | 两层替换 |
| --- | ---: | ---: |
| 记忆题严格短答 | 6/8 | 6/8 |
| 换值两侧均严格正确 | 2/4 | 2/4 |
| 普通问题强制注入无关记忆后输出改变 | 3/4 | 3/4 |

两种结构对第一种问法均能随记忆从咖啡切换到水；第二种问法中，咖啡可答对，而水未得到严格正确回答。原始层两次输出数字 `6`；替换层则输出未记录人物等内容。固定数字地址并不能证明自然语言实体路由成功。

普通算术题在原始层关闭记忆时答 4，强制注入无关咖啡状态后答 3；两层替换关闭记忆时答 6，注入后答 5。这是人为强制读取的干预，不是自然路由实际误读率。普通题的其他原文与词元均保存在结果文件中。

## 判断与限制

这组有限事实表明保留原始层时，现有读取器仍能在一部分明确地址的题上影响回答；同时误注入可能影响非记忆任务。两组记忆分数一样，并不能据此证明结构等价或选出最佳结构。题目、人物和数值均来自已反复研究的开发设置；严格短答可能拒绝正确完整句，生成最多 64 词元。没有自然写入、真实身份识别、开放关系、真正多轮、长期恢复或独立验收。

底座、来源检查点、源个体与受控状态摘要前后不变。入口 `scripts/deepseek_spora_paired_language_memory_20261116.py`，逐条结果 `runs/deepseek-spora-paired-language-memory-20261116.json`。下一步应在未用于训练和选择的事实、问法上扩大配对对照，并研究如何让无关请求可靠关闭读取，同时保护中文能力。

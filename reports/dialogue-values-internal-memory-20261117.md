# 用自然对话事实做内部记忆受控对照

## 设置

从已审阅的 8 段 DuLeMon 开发对话中选出 3 个能容纳于现有记忆包的事实值，分别关于运动、饮品、职业。来源及证据边界见 [对话数据说明](dulemon-evidence-context-development-20261117.md)；这三条来自不同会话，并非某个真实人物的三项资料。为进行受控诊断，实验人为将每条值**分别**写入虚构人物“小赵”的同一个数字地址，三次使用独立临时空状态。

程序在两处孢子快速记忆矩阵写入后，均按指定地址取回并用同一 codec 校验身份词元、事实词元和结束符。查询使用人为改写的“小赵……”问题，**没有把原始对话或事实值放入提示**。每个问题分别测试关闭记忆、空记忆、写入三个值，比较同一问题下的目标记忆和其他关系记忆。该实验证明不了模型能自主提取事实、识别说话者或可靠完成自然写入；输出头是既有高强度研究候选，未部署。

## 观察

- 三条目标写入条件的回答均未逐字包含所写事实：运动输出“跳绳”，饮品输出“红葡萄酒”，职业输出“教育工作”。其中“教育工作”可能与“大学老师”语义相关，但不够具体，不能简单判为完全无关或严格正确。
- 三条空记忆的输出与关闭记忆逐词元一致；关闭记忆时职业问题仍会生成多个猜测，其中含“教师”，说明没有可靠拒答。
- 写入与问题无关的饮品值时，职业问题输出“教师”；这一现象提醒我们，即使出现相关词，也不能据此认为它读到了正确事实。其他关系值使三条问题的输出均发生变化，但变化不等于正确。

9 个有值记忆条件的输出均不同于关闭记忆；另外 3 个空记忆条件未变化。运行时原结果的 `forced_memory_conditions` 将空记忆也计入，显示总数 12、变化 9；后续统计函数已区分空记忆，**原始结果未被改写**。模型回答最多 32 词元，部分截断；本次没有自动化语义准确率或独立人工盲评。

事实样本此前已用于开发，原始对话及主体关系被简化成受控值，不是完整自然对话测试；模型预训练是否包含字词未知。词元回读依赖同一 codec，只证明此条件下底层可复原，不证明身份绑定、语义读取、长时间保存或纠正能力。空状态、源检查点、底座和正式个体状态均在运行前后做摘要检查；未改变正式个体。

耗时约 173 秒，PyTorch GPU 峰值约 3.48 GiB。代码 `scripts/deepseek_spora_dialogue_values_memory_pilot_20261117.py`；结果 `runs/deepseek-spora-dialogue-values-memory-pilot-20261117.json`。相关检查 11 项通过。下一步需改进内部表示到回答的对齐，并用多个身份、已知/未知、反事实和时间版本分别评测；不能把字面匹配或回答变化当作可靠记忆。

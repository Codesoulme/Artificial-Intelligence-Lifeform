# 人工姓名边界下的底座词向量参照

沿用 [人物选择实验](deepseek-identity-selector-oracle-span-20261117.md) 已保存的训练和开发候选组合；不运行语言模型，也不训练选择器。由实验人工提供问题和记录中的准确姓名边界，取 DeepSeek 输入嵌入中姓名词元的平均向量，以余弦相似度选候选；拒读阈值只使用训练组 48 条未知案例，按此前方法限制最多 2 条误选。该阈值不是上线标准。

| 测试 | 结果 |
| --- | ---: |
| 训练组已知姓名正确选择 | 48/48 |
| 训练组未知姓名错选 | 2/48 |
| 开发组已知姓名正确选择 | 24/24 |
| 开发组未知姓名错选 | 0/24 |
| 近名开发案例错选 | 4/8 |

必须注意，这里的 72 个问题姓名表示，其 tokenizer 词元序列**全部与对应记录姓名相同**。因此已知匹配主要是相同输入嵌入的匹配，不是上下文、人物或事实的理解；这些姓名和问法均在先前实验中被查看。近名中“小林子”两次均被错选到某个记录，“阿宁宁”两次亦被错选；不能因普通未知组为零就忽略这种边界。

这个方法无法只凭同一姓名区分两个不同人物，也不处理别名、指代、多人物句子或姓名被错误截断。人工姓名边界和候选对象本身已经提供关键答案；没有测试自动抽取、记忆读写、实际回答或未知拒答。它只能作为研究中区分表示与上下文影响的参照，不能接到正式个体当身份认证。

数据和候选集合来自已检查过的人工开发例，阈值也在训练案例上选取，缺少独立校准和自然对话测试，结果不支持估计现实错误率。代码 `scripts/audit_identity_embedding_similarity_20261117.py`，数值在本机 `runs/identity-embedding-similarity-20261117.json`；底座及来源文件散列前后相同。约 52 秒，3 项既有阈值和边界辅助测试通过；正式个体未修改。下一步需检验自动人物片段定位、身份语境及冲突时的拒绝，并分开评估同名与近名，不能把词元相等视作个人身份。

# Qwen 查询地址索引持久化接口

日期：2026-11-21

## 变更

将可选的 `RecordedAddressIndex` 接入集成检查点元数据：

- 保存时写入地址索引并纳入检查点完整性摘要；
- 加载时校验格式、地址范围和个体 `key_count`；
- 在线写入被接受后登记对应地址；
- 重载运行时恢复索引；
- 带索引的新候选拒绝未登记的显式地址；
- 没有索引的旧检查点保持兼容，不改变原有调用行为。

索引只记录“哪些地址存在记录”，不保存事实值。事实仍由孢子矩阵和历史页读取。

## 验证

- `integrated_checkpoint.py` 与路由模块通过 Python 编译检查；
- `RecordedAddressIndex` 的构造、payload 序列化、重载和增量登记 smoke 通过；
- 未运行完整集成测试套件；
- 没有覆盖正式个体或正式检查点。

## 限制

当前还没有把自然中文问题自动接入 `IntegratedSPORARuntime.generate`，姓名、别名、同名和多主体查询仍需独立路由器。正式检查点也没有自动生成地址索引，因为旧个体缺少可安全回填的完整事件地址账本。

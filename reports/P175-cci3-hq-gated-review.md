# P175 CCI3-HQ 访问与使用条件核查

本轮只读取 Hugging Face 公开 API 元数据和固定仓库状态，没有申请 gated 访问、没有下载数据、没有读取最终评测正文，也没有训练。

## 已确认事实

- 数据集：`BAAI/CCI3-HQ`。
- Hugging Face 固定提交摘要：`d6f3aa30cebfef497e822ff968ed68a18bf90b8f`。
- 最近更新时间：2024-11-11。
- 元数据标记：中文文本生成、JSON、约 10M–100M 记录规模档、`gated=auto`。
- 公共元数据声明字段为 `id`、`text`、`score`，只有 `train` split，并声明数据文件为 `data/part_*`。
- gated 提示要求同意不得使用数据进行会伤害人体受试者的实验，并要求填写 `Company/Organization` 和 `Country`。
- 未携带访问授权请求 README 时返回 HTTP 401，因此当前无法核查数据卡完整正文、许可证、分片摘要和具体使用条件。

## 决策

CCI3-HQ 仍是研究上的质量对照线索：论文报告了 0.5B 模型和大规模中文语料实验，对“随机权重学习连续中文”的可行性有参考价值。但这不能替代本项目的准入证据。当前缺少数据级许可证、底层网页来源和权利链、隐私处理细节、去重范围、分片级摘要以及与本机训练材料的隔离结果。

当前状态保持 `gated_source_unresolved_not_training`。本轮不申请访问、不绕过门禁、不下载数据。若后续获得明确授权，应先保存申请条款和固定分片摘要，再只做有限训练侧抽样与独立质量/权利审查。

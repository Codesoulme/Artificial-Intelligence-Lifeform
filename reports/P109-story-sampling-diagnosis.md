# P109：故事抽样的长度偏差

当前 `DocumentStream` 先在整个故事池的预测位置上等概率选一个位置，再选择其所属文档；当文档不长于窗口时却监督完整文档。因此长度为 L 的短文被抽中的概率与 L 成正比，而一次抽中又呈现 L 个目标，故其目标呈现总量的期望与 L² 成正比。各个位置的期望呈现频率也随所属文档长度增加。这是训练分布特征，尚未证明它导致聊天失败。

独立重新读取 P28 训练流后确认：100,000 篇、19,138,513 个文档内目标，最短 48、最长 511 个目标；当前窗口为 512，所有故事均被完整监督。按目标数排序的最长 10% 文档包含全部池中 16.26% 的目标，但按照旧采样机制预计获得约 25.71% 的故事目标呈现。P107 真实覆盖记录中，同一最长十分位获得的目标呈现占比在 80:20 和 50:50 两组分别为 25.87%、25.31%；平分边界长度时按文档索引排序打破并列。统计只反映本次运行，不代表共同祖先的覆盖。

另一方面，P107 的旧预训练流直接切片拼接文档，注意力和部分监督跨越人为文档边界；故事流则分别按文档处理。这会改变训练条件，不能把前一轮结果仅归因于数据比例。可选的四元组惩罚只在受监督目标中寻找先前出现的序列，不检测只出现在未监督上下文中的序列；但用户要求复述时复制本来可能合理，不能据此自动惩罚。P107 没有启用该惩罚。

下一步保留旧采样为对照，另实现按文档均匀采样、完整监督短文的模式；当所有文档均可容纳在窗口时，它使各文档内目标的期望曝光相同。旧、新采样在上下文长度、所见文档和计算开销上仍可能不同；须比较实际目标数、覆盖、耗时以及开发表现，不能假设修正一定提升聊天。长文档需要另行设计，不能未经验证地套用这一结论。

`scripts/audit_story_length_bias.py` 可按固定语料和覆盖检查点复算上述统计；结果在 `runs/p109-story-length-audit.json`。新增独立的 `spora/uniform_document_stream.py` 和 `scripts/train_p109_coverage.py`，保留旧入口；均匀版本遇到超窗口文档时拒绝，而非截断。14 项采样及覆盖相关测试通过。以 P107 的 50:50 设置和相同种子运行新入口的旧模式 50 步，批次摘要、监督计数、所有语言张量及覆盖记录均与 P107 的第 50 步一致；这验证了所比较的路径在该次运行上的一致性，不证明所有输入均如此。

## 200 步对照

以共同 P34 父模型、50:50 来源配比和同一计划预算比较 P107 旧采样与新均匀采样；新入口的旧模式此前已逐张量复现 P107 第 50 步，因此复用其完整 200 步结果。两臂各用种子 391109，抽样机制不同导致批次不同，不是逐条匹配；数据质量和祖先接触的限制仍适用。

| 指标 | 旧采样 | 均匀采样 |
| --- | ---: | ---: |
| 全部目标呈现 | 1,757,102 | 1,752,455 |
| 故事目标呈现 / 本次不同位置 | 877,689 / 857,685 | 875,602 / 857,245 |
| 不同故事文档 | 4,137 | 4,456 |
| 最长十分之一的故事目标曝光占比 | 25.31% | 16.51% |
| 旧文本开发 NLL | 3.4281 | 3.4266 |
| 对话开发 NLL | 3.3267 | 3.3241 |
| 故事开发窗口 NLL | 2.6820 | 2.6795 |
| 24 轮开发结束 / 明显循环 | 19 / 5 | 14 / 5 |

长度曝光明显更接近语料本身的 16.26%，但三个损失差异很小，且均匀组在这组开发题上结束较少。对两组 48 轮回答隐藏分支身份、打乱对话后由两个模型实例逐轮审阅：旧采样 3 轮有用、21 轮无用；均匀采样 1 轮有用、23 轮无用。已逐一核对匿名标识、场景与轮次；其中 4 个场景的两个分支由不同实例评阅，且后续轮次依赖各自模型先前回答。这是模型盲评而非人审，也不是独立验收。仅有一个种子、一次短训练和已反复使用的开发材料，不能将差异解释为普遍效果或聊天能力突破。两个运行的目标数仍相差 4,647；长度分布及批次变化导致实际计算也不完全一致。

均匀组训练及监测记录约 233 秒、峰值分配显存约 856 MB；重点文本呈现 309 个目标。结束时原个体张量精确保持，合成探针为 `[7,5,9,3]`；故事不同位置数仅是本次统计，不证明相对祖先是新内容。检查点、完整覆盖统计、长度对照和开发输出仅留在 runs。独立最终聊天验收尚未进行。

均匀采样解决了本轮测得的长度曝光偏差，但没有显示多轮回答改善；不应把这一修正当作中文能力的解决方案。继续优先改善材料及训练目标，并保留两种采样供后续配对实验。

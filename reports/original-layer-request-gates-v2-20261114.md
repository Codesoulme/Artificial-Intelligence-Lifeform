# 请求门扩充与联合校准

基于第一版的错误，第二版在训练侧增加推荐、多人和正常读取表达，并新增 15 条人工挑战题。已有错误题已被查看和用于确定训练方向，只能作为开发对照；新增题虽然不参与本轮训练，也可能与项目历史表达相似，不能当作独立验收。

第二版在新增题中通过 4 条正常查询中的 3 条，拒绝 3 条多人、3 条推荐以及各一条否定、属性、写入、假设和普通问题。此前误接的推荐请求及两个旧多人挑战也被拒绝。但将第二版与上轮保存的姓名选址结果离线组合后，16 条已登记查询的正确地址从第一版的 5 条降至 3 条；结果不是实时读取或回答。

排查发现，单人门的原阈值取校准集中最高的非单人分数；这条最高分来自普通学习请求，而另一读取门在同一校准集中已拒绝它。于是本轮离线试验联合校准：先固定读取门阈值，再只用能够通过读取门的非单人校准样本约束单人门。小校准集有四条符合条件的多人样本，候选阈值从约 0.970 降至 -4.376；该选择发生在检查开发结果之后，没有安装到模型。

| 离线组合结果 | 原阈值 | 联合阈值 |
| --- | ---: | ---: |
| 16 条旧已登记问题正确地址 | 3 | 6 |
| 2 条旧多人问题错误放行 | 0 | 1 |
| 3 条新增多人问题两门均放行 | 0 | 3 |
| 4 条新增正常查询两门均通过 | 3 | 4 |
| 3 条新增推荐请求两门均放行 | 0 | 0 |

联合阈值保留了这几条校准多人题的拒绝，却明显放行了未用于阈值计算的多人表达；单人和多人分数仍有重叠。因而不能为了增加召回而启用它。第一版和第二版都没有通过足够的独立验证，不能作为正式请求判断或访问控制。

姓名映射、内容写入和指纹登记仍由程序提供。新增挑战仅测门控，没有完成对应的真实姓名路由、记忆或答案；本次也未覆盖历史时间、未知值、同名或长对话。应扩大不同来源的多人和推荐表达，重新划分未参与选择的数据，并在同一真实路径中同时测召回、误读取和答案。底座、原个体和现有候选未改动。

# 从孢子快权重读回完整词元

上一轮验证了同一个读出接口对问法很敏感。提供正确的存储地址时，固定短问法严格答对 20/32，自然问法答对 1/32。本轮固定这些已保存的快权重，直接恢复写入目标，检验回答环节为何难以取回原词。 [自然问法对照](spora-isolated-name-routes-20261125.md)

## 读取旧状态的隐藏表征

旧状态将每次写入保存为一对低秩因子。用本次更新方向的尺度系数恢复残差，再加上前面因子在本次键上的预测，从而恢复原来的隐藏层目标。用 208 个独立的登记事件核对恢复向量与第 6、12 层原始目标在浮点容差内相等。随后用这些事件训练一层岭回归，将恢复的向量映射到 DeepSeek 冻结的输入词嵌入空间。推断扫描完整词表，没有提供待选饮品列表。训练使用 8 个姓名、26 个饮品名。已保存评测的四种饮品词元不在该读出头的训练目标中。

| 评测 | 完整值 | 逐词元 |
| --- | ---: | ---: |
| 32 份已有隔离状态 | 0/32 | 0/32 |
| 固定人物问题对应关系并交换状态，按换入状态计分 | 0/32 | 0/32 |
| 新姓名与多词元饮品登记 | 2/8 | 9/17 |
| 在这些状态后追加一条更正 | 2/8 | 9/17 |

在空状态时没有输出词元。旧状态恢复的隐藏表示是确定的，但小规模监督无法把它转换为准确的未见词元。多词元测试中的饮品全称没有参加训练，部分组成词元在训练中出现。直接读出阶段由评测提供状态地址和事件词元数，未调用姓名识别或语言生成。训练和评测约 126 秒。首次重载时 Windows 记录了虚拟内存不足，进程在 CUDA 驱动中退出。改为只加载捕获目标所需的前段和紧随其后的一层、跳过全词表输出后，重载用时约 95 秒，原结果逐项一致。12 项相关单元测试通过，包含重复键写入的目标恢复检查。

## 另一种写入目标

保留按人物隔离和同样的逐次残差公式，把写入目标换成原词的 128 维归一化输入词嵌入子向量。第 6 层写入键也降到 128 维。用固定种子选择维度，读出时据同一组维度建立全词表向量空间。状态保存两组低秩因子和各次写入的词元数量。模型权重冻结，记录名由试验提供。读取时不提供事件原话、原词或每条记录的答案候选。

| 受控读回 | 完整值 |
| --- | ---: |
| 当前值 | 36/36 |
| 已更正的当前值 | 12/12 |
| 更正前的历史值 | 12/12 |
| 当前和历史合计的多词元值 | 8/8 |

36 人共写入 48 个事件、57 个词元。状态文件 78,334 字节，其中数值因子 58,368 字节。全词表投影约占 74.2 MiB，读取需要扫描 151,936 个词元。最小首选分差约 0.284。写入和评测约 106 秒，独立重载约 97 秒，均包含底座加载和文件摘要校验。重载按保存的因子和事件长度恢复，逐词元和分差与原进程一致。

此对照重新编码同批经历，无法直接替代已有快权重。它面向精确保留实际记录的词元，接入深层语义、自动边界识别和自然语言回答仍需另测。对逐字复现这一任务，词元序列本身也是低成本对照。向量方案的额外开销及其语义用途需要单独验证。

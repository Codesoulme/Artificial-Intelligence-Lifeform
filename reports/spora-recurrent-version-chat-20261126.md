# 循环注意力版的本机记忆复述与成句

此前准确复述和成句在原版 DeepSeek 骨干上验证，循环版单独从原生注意力读完整中文名称仍不稳定。本轮把已验证的词汇快权重、短答和成句头放在同一个包含第 19、22 层循环注意力的模型里，经正常 Windows 聊天入口检验。*Hidden APIs* 提醒，同一份内部记忆能否服务其他操作，应在后续任务变化时单测。混合 xLSTM 的蒸馏研究也用多个任务验证替换后的模型能力。 [原版成句回放](spora-dialogue-composition-cli-20261126.md) · [原生持久值训练](spora-persistent-value-reader-20261126.md) · [Hidden APIs](https://arxiv.org/abs/2607.27617) · [混合 xLSTM 蒸馏](https://proceedings.mlr.press/v306/hauzenberger26a.html)

## 实现

Windows 聊天入口可选载入已绑定的父检查点及两层循环权重。版次判定、记忆名称的短答、成句和普通答复均由这份模型运行。版次判定的多条语句逐条处理，符合循环层单序列的接口。输入位置上限设为 2048 词元，越界时提示用户清空对话或缩短输入。档案绑定继续检验原底座、分词器和词汇写入器。读取时从持久张量复原名称，成句由原有字段复制和语言生成共同完成。这条入口使用用户明确登记和选定的记忆。

首次端到端回放发现，旧写入器安装了一个用于试验的 TTT 包装，只接受原始前馈层的 `down_proj`；孢子融合前馈层把同一投影放在 `down`。写入器实际只需要观察投影输入。修复后直接定位原始或融合前馈层里的线性投影，在前向时捕获对应输入。CPU 回归针对外层包装内的融合块复现失败，修正后两条路径得到相同的低秩张量，同时保留两边原投影。

首次成功写入后，循环版的查阅短答还把正确书名标成了「用品」。短答头以槽的位置区分记录。新入口核对模型复制出的每段词元等于选中记录的名称，再用该记录的字段显示标签。含不同人物时在标签上保留姓名。模型继续生成成品消息，成句时传递字段和档案的读出值。

## 回放

首次进程登记八份张量，18/18 项通过。独立重启后 20/20 项通过。十次查阅均完整读回指定名称，并匹配记录字段。五次成句均包含指定两个名称及一次确认的时间，重启后相同版次的成句逐字一致。档案保留八份记录，重启前后摘要相同，SQLite 完整性检查通过。两次分别约 55、59 秒，含加载。54 项版次测试和 10 项循环注意力测试通过。

给定同一地点，旧用品生成「周五傍晚在杏叶廊见，请带上青布袋。」，当前用品生成「周五傍晚在杏叶廊见，请带上灰毛帽。」。书目与地点的例子生成「今晚七点在南帆馆见，请带上《河口雨声》。」。每个生成请求都只提供任务及必要的元信息，名称来自读取的张量。普通聊天的竹篮题答成了「先盖盖子，再把竹篮擦干。」，这项回放只检查转题后的会话状态，开放对话质量仍有限。

另将原注意力版的旧档案用 SQLite 备份到隔离目录，再由循环版打开。旧值和当前值均可复述和成句，旧档案和备份在测试前后各自的文件摘要一致。连续输入两条高分词密度消息时，第二条触发位置上限提示。清空对话后又能读回同一组旧记录。

默认入口重新跑过同一批 38 项，逐条输出与原注意力版的存档一致。循环版回放位于 `runs/spora-recurrent-version-chat-v3/result.json`，旧档案和位置上限核验位于 `runs/spora-recurrent-legacy-profile-v2/result.json`。默认入口回归位于 `runs/spora-version-chat-default-regression-v1/result.json`。

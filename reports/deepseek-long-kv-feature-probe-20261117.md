# 较长中文语料中的随机特征读取

本轮从本机既有清洗中文维基语料的训练文件开头顺序取两段各 1,040 个词元；文档之间以结束词元分隔，片段可能跨越文档。冻结 DeepSeek 原底座，提取第 6 层两个 KV 头的旋转位置编码后表示。固定使用每段最后 16 个位置的 query，分别只选其前方最近的 128、512、1,024 个 key/value 作为历史；每种长度测三个预设投影种子，并与相同历史的精确 softmax 向量及历史 value 均值比较。每段、头、种子和长度的 query 共享，因此不能视为独立测试样本。

| 历史长度 | 随机特征均方误差低于均值的组合 | 随机特征 / 均值：12 个组合的平均误差 |
| ---: | ---: | ---: |
| 128 | 0/12 | 0.1080 / 0.0349 |
| 512 | 0/12 | 0.0728 / 0.0247 |
| 1,024 | 0/12 | 0.0598 / 0.0415 |

这与上轮八段人工短文本的多数条件不同。当前数据表明新方法在此两段较长语料中未超过均值，不支持其已稳定适用于真实中文；也不能用两段文本推断所有自然语料。不同长度的 key/value 是后缀窗口，均摊结果跨两个头、两段、三个种子，不能当作整体统计显著性或上下文长度的因果结论。

采用绑定投影、底座标识、层位与头号的研究包装器，以 128 个 key 为一块合并。512 和 1,024 长度下，分块读取与整段计算最大绝对差分别约 **8.23×10⁻⁶**、**7.33×10⁻⁶**；128 条只有一块。这检查数值合并，不证明持续在线运行、持久化或抗遗忘。

本次 query 是完整原模型前向得到的，前面各层可见历史；精确注意力也只作为该层向量参照。没有遮断历史、生成回答、主体识别、多事实写入或评测长期保存，因此不能用作事实记忆成绩。语料本身曾供项目实验使用，底座可能见过相同内容。文件内容未提交，语料和底座散列前后相同。

脚本 `scripts/deepseek_long_kv_feature_probe_20261117.py`，逐项数值 `runs/deepseek-long-kv-feature-probe-20261117.json`。运行约 98 秒，PyTorch GPU 峰值约 3.53 GiB；9 项相关单元测试通过。采样范围有限，结果支持暂停把当前固定随机特征当成可靠读取器；下一步应先研究 query/key 分布与核近似误差，并在冻结的独立自然样本上对照其他方案，再进入遮断历史的端到端实验。

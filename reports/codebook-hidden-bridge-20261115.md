# Codebook 检索桥接对照

本轮把连续 codec 解码器改为“线性解码 + codebook 最近邻 embedding 残差”，用词表中的精确最近邻作为记忆内容检索上限对照。它不是开放记忆方案，只用于判断 embedding 几何误差是否是主要瓶颈。

入口：`scripts/deepseek_spora_codebook_hidden_bridge_distill.py`。

| 指标 | 训练前 | 训练后 |
| --- | ---: | ---: |
| 留出人物记忆 | 63/120 | 78/120 |
| 留出人物换值 | 52/108 | 66/108 |
| 严格反事实配对 | 0/108 | 48/108 |

codebook 重建损失约为 `0.2059`，但自由生成仍显著低于线性最佳桥的 `93/108` 配对正确。运行约 2212 秒，峰值 CUDA 分配为 6,354,921,984 字节，已不适合 GTX 1060 Max-Q 的 6 GB 显存环境。

## 判断

即使提供词表最近邻 embedding，语言桥接仍不能稳定使用当前记忆值。因此主要瓶颈不是单纯的 token embedding 重建误差，且该控制引入过高内存成本，不接入正式结构。后续应改造记忆到语言隐藏状态的联合表示或训练目标，并避免把词表查找当作模型自身的开放记忆能力。

评测仍使用受控地址、固定水果关系和有限问法，没有证明自然语言路由、自然写入或开放聊天。

# 学习型编码与随机编码的首词对照

固定问题、人工地址和同一 9 维事实槽下，将随机投影替换为训练词元向量的中心化主成分方向。拟合仅使用 2,048 个训练词元，不使用 256 个留出词元；其余保持冻结底座和原有首词桥训练框架：4,000 步、每批 16 个词元。主成分矩阵和训练均值保存在研究候选中，额外占用 15,360 个 float32 数值；对照的随机矩阵可由种子重建。输出仍由冻结 DeepSeek 完整词表输出层决定，生成路径没有使用词表码本的解码结果。

| 检查 | 随机投影旧结果 | 学习投影本次 |
| --- | ---: | ---: |
| 训练子集首词 | 108/128 | 121/128 |
| 留出词元直接编码 | 3/128 | 3/128 |
| 留出词元经临时孢子矩阵 | 3/128 | 3/128 |
| 临时矩阵通过同一编解码器还原 | 128/128 | 128/128 |
| 64 组换值两侧均正确 | 0/64 | 0/64 |

两组记录的底座、原个体检查点、语料、提示词散列、随机种子、样本量和训练预算一致；旧结果没有记录词元划分散列，因此不能仅凭结果文件证明两次划分逐项相同。新结果保存了划分散列；既有分割过程依赖相同种子和语料，但历史运行时完整代码状态无法由结果文件独立复原。主成分拟合改变编码与中心化，不能归因于某个单一数学操作。128 个底层还原使用与写入相同的完整词表码本，只是存储完整性检查，不是语言模型成功回忆。

本次训练约 289 秒，PyTorch 峰值约 3.46 GiB。保存候选中的投影和均值形状与有限性已检查，但尚未做新进程完整推理重载。15 项既有分割与结构记忆测试通过，未单独证明新编码的全流程；本试验未修改正式个体。入口 `scripts/deepseek_chunk_first_token_pca_20261117.py`，结果及候选在 `runs/deepseek-spora-chunk-first-token-pca-4000-20261117/`。

该固定首词实验不覆盖连续多词生成、自然问答、主体识别、真实写入或聊天保持。当前结果支持“新编码可拟合训练样本但没有提高留出首词总数”这一有限观察，不支持部署或断言所有学习型编码失败。应继续研究面向输出头的表示和更充分的独立事实评测，而非仅根据训练集分数选择结构。

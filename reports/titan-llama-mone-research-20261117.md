# 神经记忆接入预训练模型：研究核查

查阅原文：[Titan-Llama，2026-10-13 预印本](https://arxiv.org/abs/2610.19210v1)；[MoNe，2026-08-18 预印本](https://arxiv.org/abs/2608.17616v1)。以下是对论文方法及限制的核查，不是本机复现或对长期个体记忆的验证。

Titan-Llama 冻结 Llama-3.2-1B-Instruct，把前四层改为分段局部注意力，并为各 KV 头增加三层神经记忆。分段后的历史 key/value 用重建损失更新快权重；读取时按 query 生成逐通道门，与近期注意力结果混合。外层再以语言模型下一词元目标训练新增模块。论文称直接蒸馏历史注意力输出在其实验中难扩展且无效，最后改用语言建模损失；这不能直接否定孢子中其他蒸馏方式。

关键对照是其附录 C：主实验后续层仍可直接看到完整历史；当后续层也限制为局部窗口、记忆成为跨段唯一通路时，QuALITY 从无记忆 26.8 提升至 35.2、LongHealth 从 15.8 提升至 32.3，但仍低于完整注意力的 43.34 与 54.25。作者同时报告这一条件下 RULER 多类精确检索仍不可靠。论文训练用约十亿 FineWeb 词元、后续监督微调，GPU 时间测量使用 A100；本机 6GB 显存不能直接套用其训练与速度结果。

MoNe 在冻结 Qwen2.5-0.5B 上附加分层神经记忆，分段更新快权重、通过查询产生记忆键和值；训练了 LoRA 和更新相关参数，并不只是无训练插入。论文的核心结果主要来自 RULER 合成检索和聚合，作者明确将自然长文、多文档及真实对话列为后续工作；其报告的资源数字和长上下文表现不能直接迁移到本项目。即使查询成本不随已处理上下文长度增长，也不意味着记忆容量无限、能无损保留所有事实或天然具有个体持久性。

## 对孢子的实际决策

1. 不继续把一份事实压缩成极窄随机词元码并只加大生成残差。已有独立事实对照、多词元桥与最近主成分实验均未显示可靠泛化。
2. 可以研究以底座自身每层 key/value 为写入目标，并用训练后的门在注意力位置读快权重；同时保留无记忆及完整注意力参照。它是待测架构，不是照搬论文获得的结果。孢子此前的另一种 TTT 路线在多主体写入中出现覆盖与未知人物误答，不能将两种不同机制混同。
3. 用固定同一问题和不同事实、多个身份、相同与相近 key、纠正、空状态和无关问题做检查；比较完整历史、分段无记忆、仅记忆、分段加记忆四种条件。须关闭其他能看到历史的路径，记录事实是否泄漏进问题；只要还有直接历史通道，不能把正确归因于神经记忆。
4. 记录记忆状态增量、显存、写入/读取耗时和重载后结果；训练、开发及留出数据按主体、事实和对话分组隔离。先做小规模可复现的容量与干扰实验，再决定是否投入更大语言建模训练。长期保持和用户纠正仍需独立验收。

本轮增加 `spora/research_partitioned_attention.py`，实现历史与近期注意力分区的精确数学参照，含空历史处理；测试核对输出与反向梯度和直接掩码注意力一致，并拒绝重叠或全空分区。该参照不是可训练的记忆层，没有接入正式个体。7 项相关测试通过。论文 HTML 仅保存在本机 `runs/` 供核查。

# 更正序列记忆训练阶段报告

## 训练变化

此前语言读出训练只看单次写入状态，最后却用“旧事实→新事实”的连续记忆测试，因此更正失败可能只是训练分布缺失。本轮在训练集中加入同一人物同一地址的两次写入：先写旧水果，再写新水果；目标回答只监督最后一次事实。

结构保持为 5 槽完整事实、两处孢子读出、第 20 层晚残差注入、冻结 DeepSeek 底座。训练仍是研究隔离候选，直接数字地址和人工事实写入，没有接入正式个体。

## 结果

完全留出人物“小赵”的 18 条事实：

- 自身记忆回答正确：17/18。
- 换成相邻错误记忆后，回答替换后的事实：17/18。
- 原先只训练单次写入的晚残差候选：自身 15/18；更正序列没有被训练。
- 训练身份单次记忆：11/12。
- 关闭读取的普通路径保持底座输出；候选峰值约 4.21 GiB。

这证明模型已经能在受控条件下学习“最后一次写入覆盖旧事实”，且答案会随当前记忆切换。剩余错误是小赵的葡萄/樱桃组合，说明绑定仍有局部不稳定。

## 矩阵层证据

在不经过语言层的专项审计中，苹果→香蕉、香蕉→苹果、重复更正等序列在两个记忆读出点都解码为最后一次事实；旧目标余弦约 0.79，新目标余弦为 1.00。六个不同人物同时写入时，两处读出均为 6/6 正确，无地址串扰。

## 重载验证

候选在独立进程中重载后，18 条原始留出输出逐词元复现 18/18，证明结果不依赖训练进程中的临时参数。重载扩展测试：新人物严格断言 5/12，新问法 4/8，多实体共存 3/6，更正序列扩展 3/6。扩展结果说明自然路由、问法泛化和多实体语言读出仍未解决。

## 判定

“连续记忆矩阵能够保存更正”以及“语言层能够在训练过更正序列后使用最后事实”已经得到受控证据。这是当前阶段的实质突破，但不能称作开放长期记忆、自然中文聊天或完整人工智能生命体。候选未接入正式个体。

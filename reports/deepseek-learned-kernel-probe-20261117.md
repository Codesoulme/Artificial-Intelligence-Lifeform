# 可学习查询与键映射的注意力向量实验

## 设计

冻结 DeepSeek-R1-Distill-Qwen-1.5B，取第 6 层第一个 KV 头及其六个 query 头，分别以可训练线性层和 `softplus` 变换 query 与 key，用正特征聚合 key/value，再按 query 读取。目标是拟合底座真实历史 softmax 注意力的输出向量；这与训练模型回答事实不同。每例使用 256 个历史词元、其后 16 个位置的 query。输入的 query、key 使用旋转位置编码，但底座前面各层仍可直接访问历史。

从本机清洗中文维基训练文件顺序构造 4 个连续片段，开发文件构造 2 个片段，每个片段 272 个词元；可能跨文档边界。只训练新增映射，512 步、单样本顺序循环，冻结底座；优化的是按目标向量能量归一化的均方误差。训练仅用一个随机种子，两个开发片段已用于观察，不是最终独立验收。

## 观察

| 数据 | 初始平均误差 | 训练后平均误差 | 历史 value 均值基线 |
| --- | ---: | ---: | ---: |
| 训练 4 片段 | 0.0201 | 0.00091 | 0.0202 |
| 开发 2 片段 | 0.0263 | 0.00599 | 0.0265 |

随后单独启动进程，重载候选，在另一语料分区顺序取得的 4 个片段上评测：四个误差分别约 **0.00714、0.00349、0.00689、0.00564**，对应均值基线约 **0.01846、0.01423、0.02931、0.02023**，4/4 低于基线。这验证了该保存候选可在新进程对这四条产生测量结果，但没有对同一输入逐词比较保存前后的输出。四段彼此相邻，不能当作四个独立实验。

按完整词元序列散列排除了三组之间完全相同的片段，未排除共享句子、跨片段重复或语义重合；预训练底座也可能见过这些材料。语料未经事实审核。开发和测试结果都仅是一层、一个 KV 头、256 个历史词元、16 个查询位置；未与前述随机特征同条件同进程匹配比较，也没有多个训练种子或不同长度验证。

## 边界和后续

结果表明可学习映射在这批受控语料上更能拟合历史注意力向量，尚未证明断开历史后模型能回答，更不是个体神经记忆已经形成。目标向量来自完整历史；前面各层有历史通道。未测试模型内连续更新、多实体干扰、事实换值、未知拒答、持久化、普通聊天或效率。研究候选仍隔离保存，未改正式个体，底座及语料散列核验通过。

训练约 90 秒，独立测试约 86 秒；6 项相关单元检查通过，其中新增检查验证聚合公式与显式特征权重一致及梯度有限。候选不含优化器状态，不能精确中途续训。训练入口 `scripts/deepseek_learned_kernel_probe_20261117.py`，独立测试 `scripts/deepseek_learned_kernel_test_20261117.py`；本机候选及逐项结果位于 `runs/deepseek-learned-kernel-probe-20261117/` 和 `runs/deepseek-learned-kernel-test-20261117.json`。

下一步需要在预先冻结的多主题、多长度文本上做多种子、不同层头及分块状态对照；接着在实际模型中限制所有历史通路，以事实替换、未知拒答和无关问题评估生成，确认收益来自记忆而非直接上下文。只有这些检查成立，才考虑用于正式个体。

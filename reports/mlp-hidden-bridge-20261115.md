# MLP 连续记忆桥接试验

本轮将固定 codec 后的逐槽线性 embedding 解码器替换为两层 GELU MLP，并保留最佳绝对隐藏状态蒸馏适配器。为避免桥接器权重形状冲突，复用已有读取器和语言适配器，但重新训练 MLP 解码器 600 步。

入口：`scripts/deepseek_spora_mlp_hidden_bridge_distill.py`。

| 指标 | 训练前 | 训练后 |
| --- | ---: | ---: |
| 留出人物记忆 | 19/120 | 30/120 |
| 留出人物换值 | 18/108 | 28/108 |
| 严格反事实配对 | 0/108 | 9/108 |

连续码 embedding 重建损失在 600 步约为 `0.4589`，但语言桥接仍显著低于线性最佳版本的 `93/108` 配对正确。运行约 1166 秒，峰值 CUDA 分配为 4,669,416,960 字节。

## 判断

更低的 embedding 重建误差没有带来更好的自由生成，说明宿主语言层需要的不是逐槽 embedding 相似度本身；当前线性桥可能已经隐式保留了适配器训练时的坐标几何。MLP 方案不接入，后续应直接优化“记忆条件下的隐藏状态/答案分布”目标，或重新联合训练 codec 与语言适配器，而不是只提高 embedding 解码器容量。

评测仍使用受控地址、固定水果关系和有限问法，没有证明自然语言路由、自然写入或开放聊天。

# 连续词语编码写入神经矩阵：隔离概念试验（2026-11-12）

现有正式 `TemporalSPORA.write_temporal` 要求有限范围的整数值，最终输出也使用固定类别，因此此前饮品实验并未实现开放词语记忆。此次只做隔离可行性验证：使用 DeepSeek 底座的固定词嵌入和固定随机投影，将每个词元编码成连续向量，再将最多三个词元及结束标记分成四段，写入孢子原有的 90 维快速记忆矩阵。读取时对底座完整词表的投影向量做最近邻匹配，重建词元序列。

八个预先编写的短词语，包括两词元的“可乐”和三词元的“青玉铃”，分两轮写入，每轮四个互相正交的数字地址；每轮再将其中一个地址的内容覆盖，并重新读取四项。四组各有四次查询、每次读取两个记忆位置：每组均为 4/4 两位置都完整恢复词元与结束标记，共 32/32 次位置读取正确。这包含覆盖后的新值及其他三个地址的保留，但只有八个手写样例，不能推断大规模容量或可靠性。

这不是已经实现的开放式聊天记忆：试验直接调用底层矩阵写入，绕过正式写入控制、历史、持久化和自然语言路由；解码使用由底座词嵌入和随机投影构成的共享词表码本，对全部词表执行最近邻搜索，不能说事实完全由矩阵独立解码，也未测试语言模型能否根据这些向量自然回答。每个值最多三个词元，未测试未知值、同义表达、冲突事实、较大规模或长期干扰。

此结果表明，原有矩阵在这些受控条件下可以承载并恢复短词元序列，不必事先为每个词语分配饮品类别编号；是否能发展成可靠、可扩展的内部记忆还需研究。下一步应测试更多未见短语、相似词元、地址容量及错误检测，并比较计算成本，再研究如何在不依赖外部答案文本的情况下训练语言生成读取这些向量。

脚本 `scripts/deepseek_spora_continuous_text_memory_probe.py`，完整向量解码结果位于本机 `runs/deepseek-spora-continuous-text-memory-probe-20261112.json`。峰值分配显存约 4.27 GiB；试验矩阵独立创建，原底座、检查点与个体经摘要核验未变。

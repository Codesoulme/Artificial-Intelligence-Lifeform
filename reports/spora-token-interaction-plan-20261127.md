# 问题多词元交互对照

日期：2026-11-27。已有选择头将问题压为最后一个向量，人物变化时选中位置变化有限。参考 [ColBERT](https://arxiv.org/abs/2004.12832) 和 [ColBERTv2](https://arxiv.org/abs/2112.01488) 的多向量检索思路；本实验按对话词元对问题位置做最大匹配，并非复现论文。

冻结底座，保持投影参数、初始化、48 段自编训练对话、随机种子、576 步与学习率一致；对话词元与问题所有词元的投影作内积，取问题维度最大值作为该对话词元分数；无证据分数继续使用最后一个问题向量。保留问题模板中的特殊词元，不人为提供人名或答案位置。此改变同时引入更高的计算量，且最大值受问题长度及无关词元影响；模型是因果编码器，每个问题位置的状态只含其前文。

先在先前固定多人开发题对比同一预算的单向量候选，再复查单事实素材；此前均已查看，不是独立验收。报告误拒、误放行、目标位置覆盖和另一人位置，另记录耗时、显存及输入摘要。输出留本地，不连接正式个体；即使小样本改善，也需再测新对话、自然资料及自由生成。

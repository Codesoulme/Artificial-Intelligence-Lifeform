# 孢子本地入口的待确认事实

本地交流入口增加了 `/拟记事 姓名 关系 事实`、`/确认记事` 和 `/撤回记事`。拟记阶段先验算编码，把通过验算的事实向量及目标关系的当前修订号放入会话工作状态。每个会话最多保存一条待确认事实。撤回或离开会话后，该提议失效。确认将同一个向量交给现有的持久化事务。如果从提议到确认期间目标关系已经改动，提醒用户重新提出修改。其他关系的更新可以继续。

使用独立实验库启动本地 DeepSeek 孢子。登记许乔的集合点「北门」，以及零食「桂花糖」。提议改成「银杏亭」时，查询仍返回北门，撤回后也返回北门。再次提议并确认后，当前值为银杏亭，按首次记录的版本查询为北门，另一字段仍返回桂花糖。随后提出改为车站并退出。独立进程重开后无待确认记录，当前和历史查询结果一致。

新一轮先提议去车站，再通过既有 `/记事` 指令直接改为南门。过期提议在确认时被清除，当前值仍是南门，历史版本仍返回银杏亭。事务测试覆盖了目标此前不存在、目标更新过和邻近字段保留。36 项相关测试通过。写入意图的学习模块仍在离线实验证明阶段，本轮的状态转换由用户明确输入的命令触发。[多轮写入意图实验](spora-clause-intent-20261124.md)

本地验证使用 `runs/spora-pending-structured-cli-v1/individual.sqlite`。复测可指定另一份空白数据库。

```powershell
.\.venv\Scripts\python.exe -X utf8 -m scripts.spora_named_memory_chat --database runs/spora-pending-manual/individual.sqlite
```

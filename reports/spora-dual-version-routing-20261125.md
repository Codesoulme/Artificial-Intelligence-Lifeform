# 由孢子选择两项记忆的地址和版本

上一轮给定地址和版次后，双字段读出在 48 次交换中都能输出正确值。本轮冻结该读出头，移除实验提供的地址和顺序，从中文问句选择要查的字段。日期时间轴负责确定一条具体记录。两种学习方案覆盖当前、首版和上一版。 [双字段读出对照](spora-dual-version-reply-20261125.md)

TransMem 将变更关联到具体的事实，StaleBench 将目标记录是否有效和最后答复是否被旧值污染分别计分。MemConflict 还测试相似但不适用的事实，LongMemEval 把无法回忆时的弃权作为独立能力。本轮将这些思路用到孢子的内部张量，分别检查人物、字段、版次、是否真的读取以及回答。 [TransMem](https://arxiv.org/abs/2611.10683) · [StaleBench](https://arxiv.org/abs/2611.19752) · [MemConflict](https://arxiv.org/abs/2605.20926) · [LongMemEval](https://arxiv.org/abs/2410.10813)

## 方法

从项目的已验证快权重复制 24 份张量到新建的隔离版本库，再写入三份新张量。一个人物现在有三版饮品，可以区分首版、上一版和现值。同名近似测试另登记只差一字的人物。新进程启动时从保存库读取张量。库中地址和生效时间可以独立查询，值仍经神经张量恢复。

从问句匹配已登记的人名及显式字段词，按出现顺序生成候选。未登记的显式姓名清除承接范围。两个小头使用同一冻结 DeepSeek 前 12 层、相同训练题和更新数，对每个候选判断跳过、当前、首版或上一版。整句组标记候选后使用完整问句，分句组只看候选邻近的分句。各组在独立校准题上选置信度阈值。确定要读的记录都存在时，从 SQLite 读取选中的张量，然后由原读出模块生成。若有已请求的记录找不到，整组发出澄清并避免读取部分记录。

留出 24 道中文短问，包含同一人物的两个字段、跨人物同字段、一字近名、只查其中一项、缺字段、缺版次、未知人名和引用或改写等无读取需求。输入从空对话开始，不含任何记录值。使用相同的精确词面计分判定目标顺序、值是否完整、是否自然结束。其他中文对话质量另行验证。

## 学习式寻址结果

| 指标 | 整句 | 分句 |
| --- | ---: | ---: |
| 查询计划全对 | 5/24 | 9/24 |
| 应完整回答的题通过 | 0/15 | 3/15 |
| 双字段答复完整通过 | 0/11 | 0/11 |
| 部分记录缺失或未知时仍发生读取 | 0/4 | 1/4 |
| 普通、引用或拒读题读取记忆 | 0/5 | 0/5 |

两个小头各训练 144 个字段候选，分别用 16 个候选校准，均更新 160 步。整句组校准阈值为 0.97，分句组为 0.80。分句组通过的三条是单字段。整句组唯一一次实际读取把「现行前一份」选成了现值。分句组在一条缺字段测试中遗漏了第二项，并读出了第一项的旧版。其他多字段失败大多是第二项被归为跳过。首次运行约 138 秒，CUDA 张量峰值约 3.46 GiB。

独立进程重开含 27 份内部张量的库并重载两个查询头，约 130 秒，逐词复现原生成和选址结果。读库前后，原始 DeepSeek、双字段读出头、写入配置和已封存张量摘要一致。

## 显式版次对照

在同一持久库和冻结读出下，切换为逐分句解析明确版次。全句用来区分查阅、改写和引用，时间轴从每项范围内选择明确的当前、序号、相对版本或日期。请求存在但解析不全时保留未决项，避免把缺一项的查询当成单项查询。第一版显式解析也曾把「现行前一份」当成现值。修订后先识别与当前版相关的相对表达，含未能解析的相对时间则要求澄清。规则改动后用追加编写的例子测已识别和未识别两种范围。显式范围约束参考结构化解码中先验证请求是否合法的做法。 [PICARD](https://arxiv.org/abs/2109.05093)

| 最终显式解析指标 | 原留出题 | 新编范围题 |
| --- | ---: | ---: |
| 查询计划全对 | 19/24 | 20/20 |
| 应完整回答的题词面通过 | 10/15 | 10/10 |
| 双字段答复词面通过 | 7/11 | 8/8 |
| 缺失或不明确条件要求澄清 | 4/4 | 6/6 |
| 普通、引用或拒读题读取记忆 | 0/5 | 0/4 |

最终方案在新进程复测约 43 秒，两个题组均未读错记录或输出其他已存值。查询「闻韶宁的饮品现行前一份，以及闻绍宁的饮品当前登记」输出「薄荷红茶，杏仁奶茶。」同一人物的首版仍是「麦芽酸奶」。新题还验证了按日期定位一个字段，同时按序号定位另一个字段。原留出题中仍有五道应答题触发澄清，包括「第一笔登了什么」和「从前刚登记时」。新编范围题贴近显式解析的支持边界。单字段答复「旧邮局，」通过词面计分，但标点仍不完整。33 项版本相关单元测试通过。

下一步保留时间轴核验。在独立中文对话中，只让学习模块提取查阅范围和真实请求的字段，再由时间轴检查每项能否成立。验收包括省略姓名、同字段跨人物、上轮已过期的请求、明确排除的字段，以及仍需追问的版次。沿用冻结读出做对照，避免把寻址改动和语言生成变化混在同一分数里。

# 普通问题中无关记忆的路径消融

## 目的与设置

此前在 [高强度连续注意力实验](continuous-attention-gain10-20261117.md) 中，6 条普通问题强制读取 3 条无关虚构记忆的 18 个条件均改变了生成；其中一条红灯回答出现错误建议。原实验强制开启的是整条记忆通路，不能把现象归因于新注意力分支。本轮对同一隔离候选重新加载并复现这些条件，再分别关闭指定路径。地址和记忆仍由实验提供，不是自动路由。

## 新分支消融

6 条问题、3 条无关记忆共 **18 个条件**：全路径输出逐项复现此前记录；仅关闭新增连续注意力分支后，**18/18 生成词元序列不变**。红灯错误句也逐词不变。该结果不证明该分支对分数没有作用，只说明在这批贪心输出和 32 词元上未观察到生成差异；路径可能相互作用，也不能推广到其他输入。

## 其余路径消融

从上述问题中选取计算、鼓励、红灯三条，各配三条无关记忆，共 **9 个条件**；逐一关闭原生读取器、低秩适配器、直接残差、最终残差，再比较关闭全部路径。与全路径相比：

| 关闭的路径 | 生成序列发生变化 |
| --- | ---: |
| 原生读取器 | 8/9 |
| 低秩适配器 | 9/9 |
| 直接残差 | 3/9 |
| 最终残差 | 1/9 |
| 全部记忆路径 | 9/9 |

全部路径关闭后的结果逐词等于不传入记忆，实验过程对每个条件强制检查。对产生“红灯继续亮……继续前行”的条件，单独关闭原生读取器或低秩适配器虽然改变了句子，但生成内容仍含“可以继续前行”；关闭直接或最终残差时句子没有变化。全部路径关闭的输出在 32 词元上限处截断，不能据此宣称其完整答案正确。

逐个关闭会改变模型的后续上下文，路径之间还可能相互作用。**输出变化不是错误率，也不能证明某一个路径独立造成错误。** 结果只能说明在这些受控条件下，原生读取器和低秩路径对输出变化有可观察的影响，优先排查错误读取意图和主体归属仍有必要。

## 验证和边界

两次分别约 229、285 秒，PyTorch GPU 峰值约 3.50 GiB。程序核验候选、底座、原个体和临时记忆状态前后摘要；未修改正式个体。重载和统计等 11 项测试通过。结果分别为 `runs/deepseek-spora-gain10-ordinary-path-ablation-20261117.json` 和 `runs/deepseek-spora-gain10-ordinary-full-paths-20261117.json`；源码在对应 `scripts/deepseek_spora_gain10_ordinary_*_20261117.py` 及 `scripts/deepseek_spora_continuous_attention_gain10_ordinary_20261117.py`。

样本少、问题和记忆均由研究者编写，不衡量真实世界误触发概率或正常对话质量。所有情况均为人为指定地址并强制读取，模型没有自动判断相关性；底座训练来源与预训练重叠未知，候选未部署。

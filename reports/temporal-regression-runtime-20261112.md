# 时间方向回退的完整路径对照（2026-11-12）

以三个已知姓名分别建立临时记忆：先写入“咖啡”，再写入“水”。在同一个完整模型加载中，仅切换原时间头与 v3 实验头，比较四种人工问法；其他模块及默认输出设置相同。

| 问法 | 原时间头 | 实验时间头 |
| --- | --- | --- |
| “以前喜欢哪种饮料？” | 3/3 路由并回答旧值 | 3/3 路由并回答旧值 |
| “后续记录中……偏好是什么？” | 3/3 选择第 1 条并回答“水” | 3/3 错选第 0 条并回答“咖啡” |
| “截至目前……” | 3/3 在意图判断处拒答 | 3/3 在意图判断处拒答 |
| “告诉我……曾经喝的饮品。” | 3/3 在意图判断处拒答 | 3/3 在意图判断处拒答 |

由此确认此前观察到的时间方向回退在此受控路径中会产生旧值回答，而不仅是分类分数变化。后两种问法的拒答发生在时间路由之前，不能据此说更换时间头已经解决端到端覆盖。问题、姓名和有限值均为此前开发中见过的人工样本，样本量小，不代表真实对话或一般时间推理。

完整脚本 `scripts/deepseek_spora_temporal_regression_runtime.py`，本机输出 `runs/deepseek-spora-temporal-regression-runtime-20261112.json`。运行时仅临时切换时间头，状态摘要与原始检查点摘要均核对不变；采用研究用流式加载器。v3 不启用，后续应针对实际多事件、延迟事实、独立问法与错误时间读取风险做评估，并审慎研究分歧暂缓。

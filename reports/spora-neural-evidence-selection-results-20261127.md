# 问题条件证据选择试验结果

日期：2026-11-27。按[计划](spora-neural-evidence-selection-plan-20261127.md)，冻结 DeepSeek 底座，训练约 **19.8 万参数**的选择头：输入是对话词元的最后一层隐藏向量与问题向量，输出词元分数和一个无证据分数。答案位置只用于训练监督和事后计分，选择时没有传入位置或答案文字。实验未与现有写入器串联，也没有自由生成。

训练集为两个人物、32 段自编单事实对话，每段配一个正确问题和一个错误关系问题；留出集是另一人物与八个训练中未用过的关系值，每段同样配正负问题。人物和值隔离，关系和对话模板仍相同，不能视为自然对话泛化。训练 384 步，目标为分配概率给答案词元或无证据类别；前两个词元为固定预算，多于两个的参考值无法被完整覆盖。

| 指标 | 训练组 | 新人物与新值留出组 |
| --- | ---: | ---: |
| 有答案题：前两位至少覆盖一个目标词元 | 32/32 | 8/8 |
| 有答案题：前两位覆盖全部目标词元，未考虑拒答 | 28/32 | 6/8 |
| 有答案题：未被判无证据且前两位覆盖全部目标词元 | 28/32 | 3/8 |
| 有答案题误判无证据 | 0/32 | 3/8 |
| 错关系题判为无证据 | 32/32 | 7/8 |

留出组 8 个目标中有 2 个长度为 3 词元，因此受固定两词元预算限制，完整覆盖上限为 6/8。目标长度为 1、2、3 词元的题分别有 4、2、2 条。另一个问题是：同一段对话的正反问题，留出组 **4/8** 的前两位词元集合相同；错关系题即使最终判为无证据，前两位仍有 **7/8** 至少碰到该对话的事实值。这提示排序可能偏向显眼事实，不能仅凭“命中”断言选择器可靠地理解问题。

总耗时约 51 秒，CUDA 峰值约 3.33 GiB，底座权重摘要前后一致。选择头参数、训练轨迹及逐条结果保留在本机 `runs/research/query-evidence-probe-20261127-v1/`，未修改正式个体。

## 判断

内部向量包含可学习的词元线索，但当前无证据判定在新人物上有明显误拒，并有错误关系被放行；单事实对话也不能测试多个相似事实的绑定。**不能接入正式模型**。下一步应优先加入同一对话中的多个竞争事实、相同值／不同人物和无相关证据，严格隔离人物、取值与对话模板；再研究选择头与写入器联合读取及普通聊天影响。开发指标不证明模型已经具备自主长期记忆。

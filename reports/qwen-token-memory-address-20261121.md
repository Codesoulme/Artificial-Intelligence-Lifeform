# Qwen token 级自然中文记忆寻址诊断

日期：2026-11-21

## 目的

上一轮使用最终层的最后 token 与平均池化训练地址头。训练问法达到 `48/48`，但自然中文留出问法只有 `29/36` 地址正确。为判断问题是否来自整体池化丢失对象编号，本轮保留 Qwen、孢子个体、记忆矩阵、意图门和数字读取器不变，增加带相对位置特征的 token 注意力池化头。

## 方法

- 对每条问题保留最终层的完整 token 隐藏序列；
- 使用 token 隐藏状态和归一化相对位置计算注意力分数；
- 用注意力池化、最后有效 token 和 masked mean 的拼接预测十位与个位；
- 原最终层整体头和 token 头在同一批 48 条训练问法上训练，并在 36 条未见自然问法上比较；
- 地址头只作为实验候选，未写入正式个体、模型权重或运行入口。

## 结果

| 指标 | 最终层整体头 | token 注意力头 |
|---|---:|---:|
| 训练地址正确 | 48/48 | 48/48 |
| 留出地址正确 | 29/36 | 30/36 |
| 记忆门开启 | 36/36 | 36/36 |
| 留出最终数值正确 | 27/36 | 28/36 |

运行时间约 `37.1 s`，峰值显存约 `1.00 GiB`。候选产物位于 `runs/qwen-natural-memory-token-address-v1-20261121/`。

## 诊断

提升只有一个样本，不能证明 token 级池化解决了自然寻址。错误样本中注意力最高位置均为索引 `3`，对应 Qwen 对话模板中的固定系统内容 token `You`，而不是对象编号。模型学到了模板位置相关的捷径，存在明显模板过拟合。

因此当前瓶颈不是简单的“最后 token 还是完整序列”问题，而是缺少可泛化的实体跨度识别、数字绑定和查询类型判断。继续扩大同一类合成模板，或直接把这个头接入正式运行，都会把模板捷径固化。

## 判定

本轮不通过正式接入门槛。候选头和权重只保留用于复现，不修改正式检查点。

下一轮应使用人工审阅的多句式、不同 chat-template 边界、不同对象名称和非数字事实，训练并单独评估：

1. 查询意图；
2. 实体或对象跨度；
3. 地址绑定；
4. 未知事实与纠正后事实的拒答边界。

每项都必须在人物、问法和事实三重留出集上通过，才考虑接入运行时。

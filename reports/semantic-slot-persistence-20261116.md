# 语义槽持久化审计

在增益桥候选基础上新增了版本化槽库。槽库保存固定宽度向量、占用掩码、修订号、底座摘要和桥接摘要，使用临时文件、`fsync` 和原子替换写入；加载时校验完整性和两项绑定，避免把别的底座或桥接接到当前个体。

本轮把 6 种受控饮品的值向量写入槽库，重新加载后通过独立读取路径评测两个留出人物：

| 条件 | 首词命中 |
| --- | ---: |
| 已见值 | 8/8 |
| 未见值 | 4/4 |
| 总计 | 12/12 |

测试还确认普通请求不使用槽，底座权重摘要没有变化。实现和审计结果分别在 `spora/semantic_slot_state.py`、`scripts/deepseek_spora_semantic_slot_persistence_audit.py` 和 `runs/deepseek-spora-semantic-slot-persistence-audit-20261116.json`。

当前仍不能称为完整持久记忆：槽内容由实验直接提供值向量，没有自然语言事实解析、人物寻址、多事实共存、纠错、未知事实拒答或睡眠巩固；评测只看首个回答词。下一阶段应在不改变语言桥的前提下加入隔离的自然写入器和多槽路由，并继续通过重载和普通问题消融。

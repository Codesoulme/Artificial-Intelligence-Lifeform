# 原语言层输出反事实对照

针对完整路径中三条选对地址但未正确回答的问题，以及一条此前答对的问题，每条在同一人物地址分别写入两个不同饮品，共八个条件。程序直接指定地址，比较不读取记忆、仅使用孢子读取器、读取器加旧 v2 输出适配器，以及读取器保留正确状态但故意传入另一值作为输出证据。v2 原本在替换层结构上训练，本轮用在原语言层属于跨结构试验。

| 配置 | 严格短答正确 | 回答包含目标值 | 正常结束 |
| --- | ---: | ---: | ---: |
| 不读取记忆 | 0/8 | 0/8 | 6/8 |
| 只用读取器 | 4/8 | 4/8 | 8/8 |
| 读取器加 v2，证据匹配 | 7/8 | 8/8 | 8/8 |
| 读取器加 v2，故意错配证据 | 7/8 | 7/8 | 8/8 |

匹配证据时，三条原先失败的特定问法都开始包含目标饮品；但目标为果汁的一条回答是“果汁和碳酸饮料的偏好”，附加饮品没有受控事实依据，因此不能算严格正确。严格短答未必覆盖所有正确改写，逐条结果需要结合原文查看。

错配对照中，八条有七条仍严格说出真实状态的值，一条果汁回答变成含“水”的表述。说明这一批里读取器对生成有明显影响，但错误证据仍可能改变回答；不能把错配结果视为实际路由曾经错配，也不能据七条未变推断系统能检测证据冲突。未读取记忆的两组回答各自不随试验写入的值变化。

数据只有四条已检查过的问法、四个人物与有限饮品，地址和写入由程序提供；没有测试意图判断、未知人物、历史更正、多轮或持久化。该结果支持进一步研究适配器如何在原层结构使用，不足以替换默认配置。正式个体、候选及底座摘要均未改变。

脚本：`scripts/deepseek_spora_original_layer_output_counterfactual.py`；逐条输出：`runs/deepseek-spora-original-layer-output-counterfactual-20261114.json`。

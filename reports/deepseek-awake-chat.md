# DeepSeek 聊天进程的在线状态

聊天入口可通过 `--awake-state` 加载训练过的 P24 模块。模块作为孢子个体的 CPU 子模块运行，在等待输入时按已有模式频率更新。它保存运行张量和计数，状态文件绑定模型来源与记忆文件路径。在线状态每五秒及退出时原子保存。

```powershell
cd D:/SPORA
.venv/Scripts/python.exe scripts/deepseek_continuous_memory_chat.py --awake-state 'runs/awake-chat.pt'
```

输入 `/status` 查看状态，`/relax` 放松，`/focus` 专注，`/sleep` 暂停在线模块的更新，`/wake` 恢复。此入口沿用本地的 P24 seed 7 检查点及 DeepSeek 聊天产物。

真实聊天进程的两个约 1.1 秒无输入窗口中，放松模式推进 5 次神经更新，专注模式推进 18 次。睡眠窗口推进 0 次，并累计约 1.1 秒睡眠时间。唤醒后，聊天进程从 SQLite 记忆读出了“香橙冰茶”。退出前最后一次状态查询显示 27 次更新，新进程首次状态查询显示 29 次。重新加载期间累计约 43.8 秒的离线间隔，未补算神经更新。两次进程的外部观察计数均为 0。已有在线模块及时间测试共 18 项通过。

当前在线循环和语言生成由同一线程推进。测试中的一次约 3 秒生成超过了已有的两秒更新间隔上限，被记入间隔。重启沿用 P24 的失效规则，累计时间和计数会保留，依赖连续观察的工作向量会重置。在线模块在这轮仍执行有限图任务训练得到的递推，聊天上下文暂未接入该模块，睡眠模式尚未执行记忆巩固。

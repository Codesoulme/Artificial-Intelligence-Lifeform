# 共享记忆配对训练与研究参考

## 动机与研究

上一轮四组逐层消融均未在同题换值前后把两个目标首词都排到第一。近期研究中，[CAMR: Compatibility-Aware Memory Replay](https://arxiv.org/abs/2610.36734) 研究根据新旧样本兼容性选择回放及监督；[Routed Continual Learning](https://arxiv.org/abs/2610.38796) 研究把任务分区并选择合适的经验保存机制。以上判断基于论文摘要与论文自述，分别涉及参数微调和基于代理的记忆路由，不证明它们能直接改善本项目的神经快权重。它们提示应显式比较新旧事实及其相互干扰，而不是以单独记住某个固定配对作为验收。

## 方法

在既有共享状态联合训练中，每一步随机选一个人物，复制同一事件序列，只改变该人物的最后一次写入值，保持其余事件不变。对同一个问题的两个状态，额外优化两个首词 logit 间隔：原状态应偏向原值，改变后的状态应偏向新值。配对项权重 1，训练 128 步；原来的四人生成损失、写入目标和读取适配器联合训练保留。两次前向均保留梯度。目标事实边界与人名由程序提供，没有训练未知拒答。

单元测试验证最后写入被替换、其他事件不变，以及恰当切换比分数完全不变具有更低配对损失。两个候选状态的修改可能与其他人物值重复，这刻意保留为共享状态干扰情形。

## 结果

| 项目 | 精确回答 |
| --- | ---: |
| 训练人物与固定值 | 1/4 |
| 留出人物 | 1/4 |
| 训练人物全部换值 | 1/4 |
| 一次纠正后四人 | 1/4 |
| 未知人物有非空回答 | 2/2 |

这四组生成均统一回答“咖啡”。新进程加载候选后，单独改变小林的一个值，问题不变，前后都回答“咖啡”，目标配对 `0/1`；其余三人的输出虽不变，也都回答“咖啡”。两条普通问题在开启和关闭记忆时生成词元不同；不能从两条例子断言一般语言能力退化。

训练约 231 秒，峰值显存约 4.26 GB；同题换值进程约 130 秒。底座和候选摘要核对通过。候选单独保存，fast state 在新进程重建，没有测试跨进程状态持久化或崩溃恢复。

训练只用四个人物、四种饮品、两种问题；留出与反事实均是曾用于开发的小样本，不是封存测试。128 步与先前 256 步候选的分布、步数和随机序列不同，不能当成严格的因果消融；首词间隔训练也不保证完整文本忠实。该候选未通过，不能进入正式个体。下一轮应考虑读取器的表示坍缩和多状态写入间干扰，在独立匹配对照下联合评估，不仅增加训练步数。

# 连续文本记忆的地址与矩阵扰动（2026-11-12）

复用上轮 64 个随机中文词元序列和两个投影种子：先以正交数字地址将所有值写入两处隔离矩阵，再只在读取时施加可控扰动。表中数字是 64 项中两处位置都完整恢复目标词元和结束标记的数量，两个数字对应两组投影。

| 读取条件 | 两组投影 |
| --- | --- |
| 无扰动 | 64、64 |
| 随机地址扰动，强度 0.01 / 0.03 / 0.1 | 各为 64、64 |
| 随机地址扰动，强度 0.3 | 61、62 |
| 混入相邻地址 10% / 25% / 50% | 64、64 / 62、61 / 0、0 |
| 矩阵高斯扰动，标准差为矩阵均方根的 1% / 10% | 64、64 / 63、64 |

随机地址扰动是将单位随机方向按指定比例加到正确单位地址后重新归一化；强度 0.1 和 0.3 时，平均余弦相似度约为 0.995 和 0.958。相邻地址实验先将正确地址和另一正交地址按表中比例混合再归一化；混合 50% 时两个地址权重相等，读出大都不是完整目标。该操作模拟读取地址混淆，**写入时的地址仍是正交的**，不能解释成已测试非正交写入。矩阵噪声按整块矩阵的均方根缩放，不等同于实际量化误差。

结果表明该批数据对较小人工扰动有一定容忍，但地址混淆或较大偏差会导致错误；程序没有未知与低置信度拒答，错误可能成为看似有效的其他词元。由于只使用上轮同一批 64 个序列、两个投影及固定扰动方向，结果不是生产错误率，也没有测试自然人物路由、长记忆、长期写入、保存恢复或语言回答。

完整设置和错误样例位于本机 `runs/deepseek-spora-continuous-text-robustness-20261112.json`，脚本 `scripts/deepseek_spora_continuous_text_robustness.py`。峰值分配显存约 4.32 GiB；底座、原检查点及个体经摘要核验未变。下一步需以真实路由器的地址误差分布测试，并设计可靠的未知与冲突检测；无法仅凭这组人工扰动确定阈值。

# 随机特征状态绑定和长序列合成检查

新增研究包装器 `spora/research_bound_feature_memory.py`，将状态与投影 float32 内容摘要、调用方提供的底座摘要、层号和 KV 头号绑定。读取或合并时发现不同投影、底座标识、层位或头号即拒绝；还检查状态形状、有限值及设备。构造时复制投影，外部修改原张量不会改变包装器使用的投影。这里的底座摘要是调用方提供的标识，包装器不自行加载或核对底座文件；身份字段也不是对状态内容的防篡改认证，不能替代完整性校验或事务存储。

采用 CPU 上随机高斯 key/value/query，固定 512 个随机特征，按 128 条一块累计；分别在 1,024、4,096、16,384 条历史下对照单次整段构造、内存中的序列化恢复，以及精确 softmax 历史输出。一个随机种子结果：

| 历史长度 | 分块与整段读取最大绝对差 | 序列化前后差异 | 随机特征 / 历史均值的输出均方误差 |
| ---: | ---: | ---: | ---: |
| 1,024 | 4.77×10⁻⁷ | 0 | 0.21669 / 0.00168 |
| 4,096 | 4.77×10⁻⁷ | 0 | 0.12016 / 0.00038 |
| 16,384 | 5.36×10⁻⁷ | 0 | 0.05792 / 0.000095 |

这次分块计算保持数值一致，但随机特征近似在这些高斯数据上远差于均值基线。它与先前少量 DeepSeek 激活上的结果不同，表明当前设置的表现依赖输入分布；不能用合成实验推断真实长对话同样变差，也不能宣称它稳定有效。另检查了错误投影拒绝；匹配的相同形状投影、不同层、头和底座标识的拒绝均有单元测试。

测试共 11 项通过；一次合成运行约 0.56 秒。原始结果 `runs/bound-feature-long-synthetic-20261117.json`，脚本 `scripts/audit_bound_feature_long_synthetic_20261117.py`。本轮没有真实模型推理，序列化只使用内存缓冲区，不代表磁盘断电恢复、并发一致性或真实个体状态。此候选未部署。

下一步需要在更长的真实底座激活和多随机种子下测近似稳定性，并区分模型本身的查询与记忆绑定能力；在切断历史通道后评估真实回答和反事实替换，才能判断这个结构是否有助于目标。

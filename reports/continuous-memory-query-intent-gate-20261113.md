# 查询意图门控试验

## 目的

上一轮持续学习候选在默认问法上达到 18/18，但“爱吃什么水果”和“水果偏好”仍有错误。此轮在第 20 层记忆残差上增加 `query_gate`：门控从当前问题最后隐藏状态计算，决定记忆残差强度；无记忆路径保持原输出。实验从持续学习候选开始，低学习率训练 256 步，并保留问法回放。

## 结果

语义重评分结果：

- 默认喜欢问法：18/18。
- 当前最喜欢问法：18/18。
- 记录问法：17/18。
- 关于爱吃水果：16/18。
- 查阅记忆后问爱吃什么水果：13/18。
- 水果偏好问法：11/18。
- 合计：93/108。

无意图门控的持续学习候选在同一切片上也是 93/108。门控没有带来可验证提升，但单实体训练样本仍为 12/12，空记忆和关闭读取保护路径保持不变。候选峰值约 4.11 GiB，底座和正式个体没有修改。

## 判定

简单地按问题隐藏状态调节记忆残差不足以解决问法泛化。错误主要表现为：模型能输出水果事实，但会在“偏好/爱吃”改写中选择另一个水果，或仍受底座的非水果先验影响。下一步应建立显式、可监督的查询意图表示，并把当前/历史/更正状态作为独立训练维度；不能继续只增加门控参数或步数。

# 时间候选与意图候选的真实路径对照（2026-11-12）

使用三个已知人物、每人按顺序写入旧值咖啡和当前值水，编写当前、变更之前、最后一次更新后三种问法；逐一比较默认时间头和 v5 时间候选，按实际地址、时间类别及严格短答案计分。受控写入为数值事实，开启事件索引和来源信息，未模拟自然语言写入。

默认意图头下，当前和更新后问法两种时间头均为 3/3 正确路由且严格答对；“更换喜好之前”问法两种时间头均识别为过去，但三个人物都在读取意图判断被拒绝，0/3 到达正确答案。再临时替换为 v6 意图候选，完整复跑同样九题；各组结果完全相同，过去问法仍在意图判断处停止。时间头的分类虽在该组为过去，不意味着事件选择和输出已经成功。

这只是三个共享句式、三个已知人物的九个受控样例；比较两套时间头时使用相同意图头，比较两次实验时其他权重和输入保持相同。虽然问法新写，但模板与已有训练及研究可能相近，不能视为独立语料或证明泛化。此次没有覆盖否定、多人物、未知姓名与无记忆问题，不应为解决单个问法直接降低门槛。

脚本 `scripts/deepseek_spora_temporal_v5_varied_runtime.py` 和 `scripts/deepseek_spora_temporal_v5_varied_intent_v6.py`；逐项结果分别位于本机 `runs/deepseek-spora-temporal-v5-varied-runtime-20261112.json` 和 `runs/deepseek-spora-temporal-v5-varied-intent-v6-20261112.json`。候选仅在临时实例中使用，原检查点及临时状态经摘要核验未变。

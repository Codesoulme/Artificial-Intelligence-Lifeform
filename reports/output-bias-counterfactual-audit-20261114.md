# 输出偏置与记忆改值对照

使用同一个 DeepSeek/SPORA 实例、直接指定数字地址，对五条人工问题各写入两种先后值。比较保留神经读取器但不使用输出适配器、当前检查点内置适配器，以及既有 v2 候选；记录首词偏置、生成答案、底座和检查点摘要。前三条沿用上一轮问题，后两条使用两个此前在适配器实验中使用过的人物和新写句式，不能视为独立测试。所有事实是受控数值写入。

| 配置 | 内部读取最高分正确 | 严格短答案正确 |
| --- | ---: | ---: |
| 不使用输出适配器 | 10/10 | 8/10 |
| 当前内置适配器 | 10/10 | 3/10 |
| 既有 v2 候选 | 10/10 | 9/10 |

严格短答案可能低估正确的完整回答，但本轮 v2 唯一不匹配的回答为“果汁和碳酸饮料”，其中碳酸饮料没有由受控事实提供，不应算作正确。无适配器的两条错误为错误描述果汁和拒答。当前适配器在酸奶、果汁、豆浆等条件上多次回答“水”。

首词偏置提供了直接线索：当记忆值为果汁时，当前适配器对“水”的偏置约 +8.17，对“果汁”约 -3.41；v2 分别约 +4.66 和 +7.90。酸奶与豆浆也出现类似方向。偏置只是与语言模型原始分数相加，不能单独决定最终输出；不同词的分词也可能不同。以这些数值解释现象比仅比较答案更具体，但不能推断所有问题或值的效果。

结果支持继续研究 v2，而非立即设为默认：这批样本小、复用了开发题，八个有限值均可能参与过训练；未涉及自然语言路由、未知记忆、历史事件、长期保存或自由聊天。反事实值在同一地址先后受控写入，测试运行约 145 秒，显存分配峰值约 3,529 MiB。受保护文件和原个体状态校验一致，未更改默认路径。

下一步需设计与已见题、人物及模板隔离的对照，覆盖未登记人物、错关系、历史时间和多值更正，逐条区分事实正确、附加错误事实、拒答与短答案匹配。应特别核查 v2 对非目标饮品的正偏置及仅首词干预造成的后续内容失真。

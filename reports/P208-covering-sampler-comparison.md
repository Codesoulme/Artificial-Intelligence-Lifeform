# P208 窗口覆盖采样对照

从同一个 P206 检查点出发，对相同 4,096 篇训练故事及模型结构比较两种采样：随机有放回抽窗口，或每轮随机排列后遍历窗口。各组重置 AdamW 和采样状态，种子 2713001、批次 4、长度 128、200 步；目标数随窗口长度而略有差异。两组均继承 P206 的旧语言权重，不是两个独立随机初始化模型，采样内容也不同。

| 指标 | 随机采样 | 覆盖式采样 |
| --- | ---: | ---: |
| 目标呈现 | 80,790 | 81,407 |
| 不同窗口 / 800 次抽样 | 765 | 800 |
| 不同故事 | 715 | 752 |
| 不同窗口监督位置 | 77,243 | 81,407 |
| 起始故事开发 NLL | 4.67624 | 4.67624 |
| 结束故事开发 NLL | 4.48634 | 4.47134 |
| 20 篇 Storybooks 原文每 UTF-8 字节 bits | 4.04707 | 4.08931 |
| 本机训练循环秒数 | 43.48 | 48.05 |

覆盖式在本阶段消除重复窗口，并多覆盖 37 篇故事；两组各有 363 和 371 篇不在上一份 2,048 篇候选中，不能排除更早来源或语义重复。采样器状态和目标计数与检查点核对一致；不同窗口监督位置包含 EOS，不是不同知识。训练计时含周期性开发评测、日志和保存，不包含前置数据校验；显存峰值未记录。

Storybooks 对照沿用 [P207](P207-storybooks-cross-source-evaluation.md) 的 20 篇探索材料及限制：覆盖组相较随机组有 4 篇损失降低、16 篇升高。它们已被审阅和用于开发，不能充当最终验收。固定训练步数造成目标数和实际样本不同；两组只有一个种子，不能归因于覆盖方式本身，也无法证明覆盖越高泛化越好。

四条旧提示的贪心输出两组均未在 48 单位内结束且仍重复故事模板；相邻相同单位分别合计 85 和 130。每条提示另采样两个固定种子，随机组 8/8 合法、2/8 结束，覆盖组 6/8 合法、0/8 结束；均不能作为有效聊天结论。完整结果保存在 `runs/p208-{random,covering}-generation-20261109.json`、`runs/p208-{random,covering}-coverage-20261109.json` 和 `runs/p208-storybooks-evaluation-20261109.json`。

父个体和冻结状态训练前后未变，P206 源检查点保持 `fa614d31174bdb606033ea20a7c9e017b2f3ccaa2017cb1762576b84bdd4b0de`。随机与覆盖组检查点分别为 `86800039aefce3ef742c603d35f296c439d3f845a723d312d9c9d06b1cb78d80` 和 `703e96b6223ca5ee1de0a3740cb6dc34e17e8d52c7af0c3c92e8e44f743a44ee`。未读取最终测试正文。覆盖式可用于减少重复，但当前证据不支持更换默认采样方式或宣称能力突破；更自然、多样的材料和独立多轮评估仍是主要缺口。

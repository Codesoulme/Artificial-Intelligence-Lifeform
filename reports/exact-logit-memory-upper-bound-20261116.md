# 精确词表 logits 残差上限诊断

为区分“连续记忆到语言输出的桥接”与“底座生成上下文”两个问题，构造了一个研究上限：原生有限记忆读取后，用完整底座词表码本把槽位直接恢复为冻结词向量，并将该词向量与 lm-head 输出 logits 相加。实体地址、写入值和关系问题由测试程序提供；不训练、不接入默认运行时。

使用两个受控人物、四种饮品、相同问题，共 8 条生成：

| 配置 | 包含目标值 | 严格短答 |
| --- | ---: | ---: |
| 原始输出 | 6/8 | 6/8 |
| 精确词表 logits 残差 | 6/8 | 6/8 |

两种配置的两条错误都把“豆浆”回答为数字 `4`，直接添加精确词表向量没有改变结果。该诊断只说明在这组有限题上，错误不只是连续向量到词表 head 的最后映射；它仍可能来自问题上下文、注入位置、原生记忆表示或底座生成先验。它不是可部署方案，因为使用了完整词表最近邻、显式地址和人工状态。

此前脚本第一次运行因把水果值索引传给只支持 8 个有限饮品符号的原生接口而安全退出，未产生结果；第二次已修正为合法值并完成。入口 `scripts/deepseek_spora_exact_logit_memory_upper_bound.py`，结果在 `runs/deepseek-spora-exact-logit-memory-upper-bound-20261116/`。正式底座、个体和检查点未修改。

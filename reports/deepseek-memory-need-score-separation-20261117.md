# 记忆需求评分分离分析（2026-11-17）

## 为什么重新分析

先前报告按很高的固定阈值统计出多类干扰题几乎全部误判。进一步检查连续分数后，需要修正一种可能的误解：这些结果**不证明两个头完全无法区分证据**。本分析复用已观察的 8 组开发题，每组有一个足够回答的事实、三个不足事实；取分数越高越倾向需要更多经历。只分析保存的输出，不重新训练。

| 指标 | 仅简单成对训练 | 加入难反例训练 |
|---|---:|---:|
| 同一问题中，正确事实分数严格低于三个干扰事实 | 8/8 | 7/8 |
| 所有 24 条不足事实与 8 条正确事实跨题两两排序的 AUC | 0.818 | 0.8125 |
| 按本批数据事后穷举阈值的最少总错数 | 7/32 | 5/32 |
| 存在一个阈值使本批全部正确 | 否 | 否 |

本题内部的分数有排序信号，但不同问题的分布重叠。例如上轮模型中，部分正确证据分数很高，而其他问题的错误证据得分较低。固定阈值在不同题之间难以兼顾；之前的 0/8 属于当时预设阈值下的分类结果，并非排序能力为零。

AUC 是这小批开发样本的成对排序统计，类别不均且同题数据相关；不能代表真实总体。穷举得到的最少错误仅用于诊断，是事后利用测试标签的乐观值，**不能拿其阈值用于部署或称作独立成绩**。即使同题排序正确，实际场景也未必提供一个已知正确答案供成对比较；还需要校准、证据候选生成以及“所有候选都不对”的处理。输出不能证明证据真实、人物匹配或者持久记忆能力。

## 下一步

在严格分组的独立数据中比较绝对评分与多候选相对排序，并加入无正确候选、冲突、改口和多个相似主体；校准集与最终评估集分离，报告拒绝率与错误率。前次没有保存每条校准分数，因此本分析不能重新选择经校准的阈值，也未运行或修改模型。

分析脚本 `scripts/audit_memory_need_score_separation_20261117.py` 从本地两份实验结果重算曲线；2 项单元测试覆盖完美排序和相同分数。原始结果及模型文件均未更改。

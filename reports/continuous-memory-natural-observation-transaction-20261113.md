# 自然语言观察到内部记忆闭环

## 实验范围

在隔离的 DeepSeek/SPORA 工作个体上，使用真实替换特征、实体地址、极性和事实片段模型，将自然语言陈述转换为 `ObservationCandidate`，经过校准写入门后保存到临时 working checkpoint。正式个体、正式 checkpoint 和底座权重没有修改。

## 结果

四条陈述按顺序处理：

- `小梅偏爱的饮料是茶。`：解析到地址 `16`，肯定陈述，事实值“茶”，动作 `new`。
- `小梅不喜欢喝茶。`：解析到同一地址，但识别为否定，动作 `defer`。
- `小梅偏爱的饮料是热巧克力。`：实体和肯定极性通过，但值不在有限记忆词表，动作 `defer`。
- `小梅偏爱的饮料是咖啡。`：同一地址、肯定极性和已知事实通过，动作 `correct`。

写入后：

- 状态游标为 `4`，其中只有两条肯定事实实际写入。
- 当前事实值为词元索引 `1`，即“咖啡”。
- 关闭写入进程后，独立进程重载得到相同游标、相同当前值和相同 working checkpoint SHA-256。
- `same_current_value: true`。

## 判定

这是第一次在本项目中验证“自然语言陈述 -> 实体/事实/极性解析 -> 安全门 -> 内部记忆新增/延期/更正 -> 独立重载”的完整链路。它证明现有 DeepSeek 底座和孢子持久记忆结构可以承载自然语言写入流程。

仍需注意：实验只有四条人工陈述，事实词表有限，校准模型来自受控开发数据，当前写入入口仍是研究运行时，不是默认聊天入口。开放中文表达、多人关系、来源可信度、时间事实和未知实体拒答还需要更大规模的独立评测。

# 未训练词向量读取探针

## 方法

上一轮有限分类探针的参考数据包含全部测试饮品，因此无法验证新词泛化。本轮使用整句写入及既有适配器，提取固定问题最后位置两层原始读取向量，以四个人物和 12 种饮品的带标签数据拟合岭回归，目标是底座中对应首词元的归一化词嵌入。测试用两名未参与拟合的人物与另外四种饮品。

测试时不提供答案所在位置，不用其他测试样本计算人物均值。完整词表比较将预测向量与全部词嵌入比较；限定候选比较包含所有 16 个饮品的正确首词元，包括留出值，因此是理想化对照。三个正则强度均为开发诊断，没有在独立验证集选择参数。

## 结果

| 指标 | 已训练值 | 未训练值 |
| --- | ---: | ---: |
| 全词表第一，最好设置 | 14/24 | 0/8 |
| 全词表前十，最好设置 | 23/24 | 0/8 |
| 16 个已知候选内第一，最好设置 | 21/24 | 0/8 |

三个正则强度下，未训练值均为 0/8。第一组设置中，“奶茶”“椰汁”“橙汁”“矿泉水”的目标首词元全词表排名从 37,102 到 141,704；椰汁、橙汁有多个词元，本实验只测首词元，并未生成完整回答。

结果说明这个小规模线性映射没有把已训练值上的信号推广到新值，也解释了为什么先前“六类均有标签”的分类结果不能证明开放词汇读取。它并不能证明原始状态没有包含新词：其他映射、特征、训练样本或训练方式可能得到不同结果。

## 限制与下一步

仅有六个人物、固定事实句式及固定问题。多个测试词已在项目较早的探索中出现，本次只保证没有参与当前岭回归拟合，不是密封测试。原始读取经过前一记忆层及适配器影响；没有测试自然观察、多事实共存、写入纠正或持久恢复。底座和候选权重摘要未改变，峰值 CUDA 分配约 3.90 GB。

下一轮应扩大训练词汇和句式，并比较可学习非线性映射与不同层的词表示；验证必须留出新词、新人物和问题，评估完整生成与同题换值。不能将限定候选答案当成自主语言能力。

# 问题多词元交互对照结果

日期：2026-11-27。根据[计划](spora-token-interaction-plan-20261127.md)，从同一单事实选择头初始化，固定自编 48 段多人训练数据、种子、576 步、优化器和参数量，将每个对话词元与问题全部词元的最大匹配作为分数；底座冻结。无证据分数仍使用问题最后一个状态。该实现受 [ColBERT](https://arxiv.org/abs/2004.12832) 启发，不是其复现。

先前多人开发题的同题结果：

| 条件 | 原单向量 | 多词元交互 |
| --- | ---: | ---: |
| 不同值题：未拒答且前两位置覆盖目标 | 4/16 | 5/16 |
| 不同值题：误拒 | 5/16 | 6/16 |
| 不同值题：未拒答且选到另一人对应位置 | 9/16 | 6/16 |
| 共享值题：未拒答且完整覆盖目标位置 | 8/16 | 7/16 |
| 缺失关系判为无证据 | 8/8 | 8/8 |
| 缺失人物判为无证据 | 2/8 | 3/8 |

目标超过两词元时不可能被前两位置全部覆盖；另一个人位置被选中不直接等于最终答错，尚未验证完整生成。单事实留出人物的有答案题误拒由 1/8 变为 2/8，未拒答且完整覆盖由 5/8 变为 4/8；无答案题判无证据均为 8/8。多人和单事实题此前均参与开发，不是独立评估。该轮没有开展新模板评估，因此不能判断跨模板泛化。

多词元训练约 59 秒、多人检查约 44 秒、单事实检查约 55 秒，CUDA 峰值均约 3.33 GiB；与旧训练约 89 秒的总耗时受运行状态等因素影响，不是性能基准。训练及多人检查对底座、父候选或新候选摘要做前后比较；单事实检查在加载前校验候选摘要，但未在结束后再计算该候选摘要。

单事实检查第一次因脚本内旧类覆盖新类而发生矩阵维度错误；没有有效结果，错误日志保留本机。修正导入后在新目录重跑得到表内结果。来源对话、逐条输出和候选位于本机 `runs/research/selector-token-interaction-*`，没有修改正式个体。

## 判断

多词元交互在部分指标略有变化，但缺失人物仍只识别 3/8，同时出现更多单事实误拒；样本太少，不能认为结构可靠或存在可推广的改善。下一步需使用事先隔离的人物和新对话模板、增加不同位置的竞争事实，并考虑明确的主体与关系配对学习和可回答性校准；完成选择后还需检验写入器和完整生成。本候选不接入正式个体。

# 浅层与末层写入表示对照

## 方法

冻结 DeepSeek 原底座，在人工事实句中由程序指定值的位置，分别提取第 1 层输出与末层归一化输出。对每种表示训练一个相同大小的线性写入器，目标是恢复底座对应的词向量。词表从既有稳定单字词元池按固定种子划分为 256 个训练值和 64 个留出值；两名训练人物、两名留出人物，每种人物和值组合都单独统计。每组训练 512 步。

先用两个随机初始化种子比较层位置，再比较恒等初始化。恒等初始化下两个种子的起点相同，训练顺序和优化也完全相同，不能当成两个独立重复。候选排名仅在包含全部 320 个训练及留出词的理想化集合内计算，正确答案已在候选集合中，不能视为全词表识别或实际回答。

## 留出人物与留出值

| 写入器 | 平均余弦 | 限定候选首位 |
| --- | ---: | ---: |
| 随机初始化，第 1 层，种子一 / 二 | 0.254 / 0.253 | 18 / 128，17 / 128 |
| 随机初始化，末层，种子一 / 二 | 0.099 / 0.109 | 2 / 128，2 / 128 |
| 恒等初始化，第 1 层 | 0.269 | 74 / 128 |
| 恒等初始化，末层 | 0.129 | 53 / 128 |

恒等初始化前，第 1 层的限定候选首位为 20/128，末层为 71/128；训练后分别为 74/128 和 53/128。这些数字共享 64 个值和两个人物，不是 128 个互相独立的事实。固定句式、已用过的词池以及不同层的数值分布均限制结论；结果不能断定浅层在其他任务中一定更好。

## 实际生成

在独立进程加载恒等初始化候选，固定选取前 8 个留出单字和两名留出人物，使用相同的人工事实句和问题；程序直接给定事实边界、人物与读取位置，并通过已有序列桥注入写入向量和结束词元。完整输出严格匹配：第 1 层 0/16、末层 0/16、直接提供正确词向量的参考上限 10/16。

因此，受限候选排名有改善，但本组生成未显示可用记忆读取。直接参考路径本身也不稳定；序列桥是人为注入，并非自主检索或参数记忆。问题中的“饮品”与随机单字不一定语义相容，该实验只检查词元传递，不能评价真实事实理解。

## 边界与产物

仅比较冻结原底座，没有启用孢子替换层或真实个体，也没有自然事实解析、多词值、纠正、长期保存和开放对话。两组表示实验分别约 98 秒、CUDA 峰值分配约 3.33 GiB；生成检查约 91 秒、峰值约 3.34 GiB。底座摘要在各实验前后保持一致。

代码：`scripts/deepseek_spora_writer_layer_control.py`、`scripts/deepseek_spora_writer_layer_generation.py`。结果及隔离写入器分别位于 `runs/deepseek-spora-writer-layer-control-20261116/`、`runs/deepseek-spora-writer-identity-control-20261116/` 和 `runs/deepseek-spora-writer-layer-generation-20261116.json`。下一步应针对完整词表及真实多词事实改善读取通路，并以反事实换值和未见问法评估；当前候选不部署。

# 记忆反事实残差与词元分数诊断

沿用 [隔离生成实验](deepseek-learned-kernel-isolated-generation-20261117.md) 的同一人物、问题和“豆浆／咖啡”两份状态，重复自由生成，并另在模型输入后人为添加不包含目标值的相同回答前缀“小林最喜欢的饮品是”。这一诊断只观察紧随前缀的首词元 logits，不是自由生成或概率校准，也没有计算梯度；词元边界经 tokenizer 检查。

| 条件 | 豆浆首词元 logit / 排名 | 咖啡首词元 logit / 排名 |
| --- | ---: | ---: |
| 关闭记忆 | 4.965 / 217 | 13.500 / 1 |
| 豆浆状态 | 5.070 / 176 | 13.578 / 1 |
| 咖啡状态 | 4.992 / 184 | 13.484 / 1 |

指定相同前缀后，豆浆状态相对于咖啡状态让豆浆首词元 logit 上升约 0.078，咖啡首词元上升约 0.094；两个目标的差距仍都约 8.5，咖啡仍排第一。分数差不能直接解释为概率或最终答案的因果归因。关闭记忆的自由输出是一段被截断的自我介绍；添加人工前缀后的首词排序与它并非同一个生成状态。

在这个强制前缀的最后位置，两次注入向量范数约 4.157、4.109，余弦约 **0.9873**，差向量范数约 0.662；该位置的局部注意力对应部分范数约 5.833。说明注入并非完全相同，但在此单例方向高度相似；不能单凭余弦推断差异是否具有语义意义，也不能证明模型的全部记忆信息被压缩或损失。

自由生成仍是两种状态都回答咖啡，参考组提供原文时两者分别答对。两份状态摘要不同、记忆条件使用相同问题词元，事实阶段的 KV 缓存不传给问题前向。一个人物、一对短句、一个层头、直接加法及固定强制前缀，不支持推广到多实体、多关系或其他架构；没有更新或安装候选，底座和候选文件摘要核对通过。

脚本 `scripts/deepseek_learned_kernel_isolated_generation_20261117.py`，逐项结果 `runs/deepseek-learned-kernel-isolated-logit-diagnostic-20261117.json`；约 88 秒，PyTorch 峰值约 3.33 GiB。6 项基础测试通过，未覆盖该真实模型钩子。下一步应构造多身份、多值的训练与独立留出对照，直接训练记忆换值后的答案区分，同时测未知和无关问题；不能只增加注入强度或根据一个词的 logit 声称读懂。

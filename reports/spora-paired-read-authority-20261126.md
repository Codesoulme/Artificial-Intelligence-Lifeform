# 用成对请求训练记忆读取

上轮自然负例能抑制部分无档案请求，仍会选错要读取的人或字段。这轮让训练例共享姓名和事项，改变要求中实际读取、排除或恢复的部分。参考否定检索研究对不同否定范围的区分，以及 *Lost with a Map* 对状态结构、实际值和最终动作的分开评估。 [自然负例对照](spora-natural-read-evidence-20261126.md) · [否定检索研究](https://aclanthology.org/2025.findings-emnlp.839/) · [Lost with a Map](https://arxiv.org/abs/2609.33883)

## 设计

冻结 DeepSeek 前 12 层，为每个「姓名、字段」候选提取输入末位置的特征。训练对包括同一字段改为另一个人物、同一个人改查另一字段、以及先搁置再恢复其中一项。共 264 对，每字段 66 对。两组使用同样的成对数据、初始化、采样顺序和二分类损失，第二组额外约束同对的读取分数高于排除分数。阈值固定为零。训练含指明某个候选不用读取的反例，缺少整句属于泛聊、润色或外部信息查询的反例。

八对新题用于候选排序及同对双判；人物不在训练集，措辞也独立编写。另沿用 18 道旧题复测实际查阅。只检查问句中出现的已登记姓名，为每个人的已登记字段独立打分。模型最多读出两个当前记录。实际读出沿用同一份版本快权重和本地生成模型。旧题中的多人问法沿用先前的弃权标准，以便比较，仍有应用范围的限制。

## 结果

| 指标 | 二分类 | 二分类加成对排序 |
| --- | ---: | ---: |
| 新题确认分数高于排除分数 | 5/8 | 5/8 |
| 新题确认与排除都判断正确 | 0/8 | 1/8 |
| 旧题选全并成功生成正确值 | 3/11 | 2/11 |
| 旧题无需读取仍实际读出 | 5/7 | 6/7 |
| 旧题多读字段数 | 16 | 18 |
| 旧题漏读字段数 | 2 | 2 |

排序损失通过的唯一配对是许昀芝和黎书然的饮品请求，两边分数分别约 0.023 和 −0.065。两组都把「把原句说得更礼貌」当成读用品与见面地点，也都在「那杯先不查了」时读了书目。模型在很多留出题给不相关候选正分。增加排序损失没有减少多读，且读错时会实际打开被选档案。

上轮的自然负例对外部查询表现更好，但它使用不同训练集和候选范围。两组结果一起说明需要分别检验整句是否授权读取，以及哪个姓名、字段取得了授权。下一轮考虑将动作许可作为第一层决策，只有明确允许时才进入候选选择。沿用自然负例和成对数据作为各自的监督，再以同样样本比较单模型与两步模型。只有误触发和漏读同时改善，才考虑进入本机入口。 [任务状态进入执行的不同方式](https://arxiv.org/abs/2609.25686)

训练和评估约 59 秒。独立 CPU 检查核对 264 对训练数量、字段均衡、模型和档案摘要，并从逐题记录复算评测计数。54 项版次单元测试通过。权重和原始预测在 `runs/spora-paired-read-authority-v1/`。新题有八对，尚无跨种子或长对话验证。

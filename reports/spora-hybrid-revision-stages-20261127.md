# 长对话更正的选值与成句对照

上一轮发现，同样长度下，远距离更正和双字段回答都容易丢失新值。这轮将五种场景的两套取值分别放在近处和远处，每种模型得到 20 个问答组合。固定融合父检查点，对照在该检查点上安装第 19、22 层恢复权重后的版本。每个组合分别直接填写两个字段、在只差更新值的两份候选中选一份，以及在提问中给出已核对的两个值再填写。直接填写和给值后填写采用同一格式。选项交换顺序后，将两次分数差对齐平均。 [Lost with a Map](https://arxiv.org/abs/2609.33883) · [更正距离对照](spora-hybrid-revision-distance-20261127.md)

| 指标 | 完整注意力父检查点 | 第 19、22 层循环版 |
| --- | ---: | ---: |
| 直接答复含两个正确值且无旧值 | 4/20 | 4/20 |
| 直接答复的两个字段和值均按格式填写 | 1/20 | 0/20 |
| 交换选项顺序后，平均分选中新值 | 2/20 | 2/20 |
| 两种选项顺序均选中新值 | 0/20 | 1/20 |
| 给定正确值后，答复含两个值且无旧值 | 19/20 | 14/20 |
| 给定正确值后，两个字段和值均按格式填写 | 5/20 | 3/20 |

给出正确值提高了内容完整性，循环版仍有六条漏掉至少一个值。严格评分还要求字段名与值对应，且每行只有一个字段。两组都出现了仅输出值、用顿号合并两个值或省略字段名的答复。80 条生成均正常结束。

父检查点在 40 次选项前向中只有 3 次偏向 A，循环版有 8 次。将分数按选项交换对齐后，两组仍都只判对 2/20。这个结果衡量指定提示下的首词分数。A/B 的位置偏好和提示形式会影响结果，因此不能用它单独证明隐藏表示里是否还有新值。给定值的条件把正确事实放入最后一轮输入，属于诊断对照。该轮沿用小样本和原有档案，未重新评测开放聊天。

下一轮可使用原文值的完整词元似然，配合同一场景中交换新旧值的对照，检查首字母偏好是否掩盖了新值识别。答案组织可用相同的两个已核对字段单测，分别计内容、对应关系和格式。

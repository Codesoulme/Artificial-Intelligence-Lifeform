# 人物定位批次敏感性隔离计划

2026-11-27。[Transformers 补齐文档](https://huggingface.co/docs/transformers/main/en/pad_truncation)说明 `padding=True` 按批中最长序列补齐；[PyTorch 数值精度说明](https://docs.pytorch.org/docs/stable/notes/numerical_accuracy.html)指出浮点运算次序和实现可能影响数值。文档并不能确定本项目原因。

冻结现有双头、原底座与适配器，固定此前使用的 8 个人物及两个既有句式。对每句分别计算：单条、与自身复制配对、与预先固定的更长无关句配对；分别使用左、右补齐。比较目标实际 token 数与批次 token 宽度、有效字符位置隐藏向量、最高姓名、定位 margin、意图概率和两条既有门槛下的选址。长句与输入在同批且目标排第一；重复项为观察重排和批计算是否带来差异。不得利用结果重新选门槛，不访问真实个体、不训练、不生成。检查冻结文件摘要。左、右补齐只作为特征路径对照，不代表聊天生成已采用新设置。若单条与长配对变化，补齐长度、批形状、低精度算子等仍可能共同变化，不能单凭这一实验归因。

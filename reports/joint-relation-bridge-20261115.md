# 联合 Bridge 关系迁移试验

本轮从联合 codec continuation 候选出发，把事实值拆成三个关系域：饮品、颜色、活动。每个域四个训练值、两个留出值；身份、codec 和记忆地址机制保持一致，留出值只在评测出现。

入口：`scripts/deepseek_spora_joint_relation_bridge_pilot.py`。

关系答案使用 tokenizer offset mapping 提取上下文中的值 token，memory storage token 与答案监督 token 分开处理。关系域评分要求目标值出现且同域其他值不同时出现。

## 结果

对原始生成重新按关系规则评分，训练前后没有形成可用提升：

| 关系 | 训练后 memory 正确 | 训练后 swapped 正确 |
| --- | ---: | ---: |
| 饮品 | 3 | 0 |
| 颜色 | 0 | 0 |
| 活动 | 1 | 0 |

许多输出仍然回到水果先验、泛化回答或列举式回答。训练过程中总损失长期高于水果关系基线，说明现有联合桥对新关系语义没有自动迁移。

## 判断

当前联合 codec 的 `99/108` 提升仍局限在原水果关系，不能据此声称已经获得开放关系记忆。关系迁移候选不接入；下一步需要把关系类型作为独立的结构化记忆 lane 或加入关系条件的联合训练目标，而不是只替换答案词面。

本轮未修改正式个体、底座或正式检查点。

# 训练对话要求的保留、设置和取消

前一轮让孢子自行整理三轮要求再答，12 道题均失败。本轮把问题拆成两个可独立检验的能力。模型先判断现行要求应该如何更新，再根据更新结果作答。StateMemBench 对现值和过期值分别评分，AFVE-Bench 检查已经废弃的内容是否再次出现在答复中。 [前一轮对照](spora-dialogue-evidence-20261125.md) · [StateMemBench](https://arxiv.org/abs/2608.19652) · [AFVE-Bench](https://arxiv.org/abs/2611.10541)

## 训练

在上轮 12 条开发对话的 36 个用户轮次上标注操作，另编写 192 条带对照的更新样本。它们覆盖维持原要求、用新值覆盖、显式取消以及只引用原词。每条输入包含当前用户发言和进轮前已登记的条件。标签分别是保留、设置与取消。设置包括给空字段首次填值和替换旧值，值必须是当前用户发言里的连续片段。

冻结实际孢子入口加载的 DeepSeek 骨干，复用已有工作状态抽取器与前十二层字符对齐特征，训练独立的操作头和起止位置。候选目前覆盖 16 类临时要求，包括日期、地点、备品、格式及禁止词。它不提交长期记忆。训练使用标注的上一轮状态，独立评测另按预测结果逐轮累积，观察是否传递早期错误。

## 验收方法

六条三轮留出对话使用新的人名、地点和表达，部分日历及格式词汇与开发集相同。分别统计更新是否完整、保留项还在不在、取消是否生效，以及最终状态全部正确的场景数。再给出正确的上一轮状态跑一次，区分当前轮理解失误和累积误差。

答复比较使用相同解码器。第一组按实际三轮对话生成，第二组根据学得的状态生成，第三组输入标注的正确最终状态。两种状态输入都提供从首轮任务确定的任务类型，并采用相同文字格式。自动通过数只衡量明确的词、格式及长度要求。

## 结果

| 留出集指标 | 自己累积上一轮状态 | 给定正确上一轮状态 |
| --- | ---: | ---: |
| 更新完全正确 | 2/18 | 2/18 |
| 设置的字段和值均正确 | 11/36 | 10/36 |
| 明确取消被执行 | 0/3 | 0/3 |
| 保留未改动的有效值 | 7/21 | 20/21 |
| 最终状态完全正确 | 0/6 | 1/6 |

给出正确的上一轮状态，能大幅恢复需要原样保留的值，输入当前轮话语时的错误仍然存在。按预测历史运行时，36 个应设置值中只有 16 个在正确字段上提出设置，另有 5 个虽复制到正确词面却放在别的字段。候车任务把「松石桥」及后来的「纸鸢亭」都写到了主要事项，漏掉了时刻，也没有执行「雨衣免了」。给定正确上一轮状态仍漏掉全部取消，不能用早期错误解释这些漏判。

三种最终作答均为 0/6。给出正确状态的候车题回复包含纸鸢亭，却丢了日期。生成测试另将原题的最终要求人工改写成自然中文，作为参考。其中「早上」和截止前等修饰语超出字段表当前的表示，所以结果同时受输入表述和字段覆盖影响。

自然指令答对 1/6，即「周日早上七点到纸鸢亭」。其他五题仍未通过。状态模块的训练损失从约 3.036 降到 0.00019，独立场景里的迁移有限。下一轮优先设法找对字段。将字段语义写成模型可读的描述，分别测试新值定位、与已有条件建立联系和取消动作，再检验三者组合。描述驱动的对话状态研究表明，字段含义有助于迁移到不同任务。StateTree 的任务构造提供了多轮状态链的可验证对照。 [D3ST](https://arxiv.org/abs/2201.08904) · [StateTree](https://arxiv.org/abs/2609.38809)

## 复现

```powershell
$env:OMP_NUM_THREADS = '2'
$env:MKL_NUM_THREADS = '2'
$inputData = 'runs/spora-dialogue-evidence-v1'
$output = 'runs/spora-dialogue-revisions-v1'
.\.venv\Scripts\python.exe -u -m scripts.train_spora_dialogue_revisions $inputData $output
.\.venv\Scripts\python.exe -u -m scripts.train_spora_dialogue_revisions $inputData $output --verify
```

32 个训练周期共 320 次更新，首次运行约 170 秒，CUDA 张量峰值约 3.56 GiB。独立重载约 161 秒，18 条状态变化、六条场景的最终结果和生成词元均一致。30 项相关单元测试通过。`head.pt` 约 2.03 MB，逐轮证据位于 `result.json` 和 `reload.json`。附加生成对照保存在 `oracle-format.json`。本轮候选保存在研究目录。

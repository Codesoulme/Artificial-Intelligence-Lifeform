# 未知人物训练覆盖对照

## 方法

从多关系实验的同一更正候选及优化器状态出发，分别继续训练 84 步。两组使用完全相同的七条事实、事实回放顺序、损失系数及八条普通问题首词分布约束。原样本组使用原有七个人物与关系组合的未知标签；扩展组将其中 42 步的未知样本替换为七个额外人物与三种关系的 21 个组合。每条当前事实的两种训练问法各出现六次。

每组检查 100 条问题：28 条已知事实训练及留出问法、8 条已知人物未知关系留出问法、48 条未知人物问题和 16 条普通问题。未知人物中，八人已在上一轮审计中观察过；另外四人于本轮训练前选定，均不参与本轮未知样本训练。每名未知人物有两条饮品问题及各一条城市、爱好问题。所有事实与未知标签均由程序提供。

## 结果

| 检查 | 原样本组 | 扩展组 |
| --- | ---: | ---: |
| 三条旧事实训练问法 | 6/6 | 6/6 |
| 三条旧事实留出问法 | 6/6 | 3/6 |
| 四条新增事实训练问法 | 8/8 | 8/8 |
| 四条新增事实留出问法 | 8/8 | 8/8 |
| 上一轮审计的未知人物严格答不知道 | 31/32 | 32/32 |
| 本轮另选四名未知人物严格答不知道 | 14/16 | 16/16 |
| 已知人物未知关系严格答不知道 | 8/8 | 8/8 |
| 普通问题与起点输出逐词一致 | 7/16 | 7/16 |

原样本组对三个未知问题直接答出已知人物的值，其中两个问题来自本轮另选四人；扩展组全部严格答不知道，但将三条已知饮品事实的留出问法错误拒答。两组各有 7 条普通回答与起点逐词一致，但两组之间仅 6/16 逐词一致。输出改变不必然代表质量下降，逐词一致也不保证正确。

主实验约 244 秒，CUDA 峰值分配约 3.61 GB；底座与来源候选摘要前后未变。两个研究候选各自保存了适配器与优化器，但本轮未在新进程重新核对其输出。

## 判断与限制

本批对照显示，增加未知人物覆盖可减少观察到的错误赋值，但同时造成已知事实误拒答；不能将某一组作为可靠的解决方案。两组的未知样本组成和顺序均不同，且只有一个种子，无法判断其他覆盖策略或损失权重是否能改善权衡。

问题、人物、关系与事实均为小规模合成开发材料，此前出现过的名字及问法不是独立验收；本轮另选四个名字也不能保证未出现在底座预训练或项目更早实验中。严格短答可能把其他合理拒答计作错误，实际本轮未达标的未知问题均直接给出具体值。没有测试自动观察、真实身份识别、长时间记忆或完整多轮聊天。

代码和设计检查分别为 `scripts/deepseek_spora_unknown_diversity_audit.py`、`tests/test_unknown_diversity_design.py`；逐条输出、损失、训练样本顺序与候选摘要位于 `runs/deepseek-spora-unknown-diversity-20261116/`。

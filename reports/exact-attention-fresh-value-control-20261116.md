# 精确记忆注意力：新值调度与查询门冻结对照

上一轮实验把全部训练值标作旧回放，导致 `new=0`。本轮修正为前 3 个值作为旧回放、后 3 个值作为新值；两组都训练 288 步，旧值访问 144 次、新值访问 144 次。查询门组启用每 token 查询门；冻结组使用相同精确记忆注意力、投影学习率、数据、步数和种子，但不启用查询门。

| 结果 | 查询门 | 冻结门对照 |
| --- | ---: | ---: |
| 训练人物 | 23/24 | 24/24 |
| 留出人物、已见值 | 22/24 | 23/24 |
| 留出人物、未见值 | 0/8 | 0/8 |
| 留出人物、替代问法 | 0/8 | 0/8 |
| 独立重载逐词复现 | 6/6 | 6/6 |

查询门没有带来收益，训练和留出人物还略低于冻结组；两组未见值和替代问法都失败。精确词表桥仍由程序提供，人物、关系、地址和事实边界不是模型自主学习得到的。两组没有普通聊天污染、自然写入或开放状态验收，因此不能选择任一候选部署。

这轮确认了上一轮的主要问题不是“所有训练步都在旧值回放”这一单一配置错误；修正值调度后，开放值泛化仍为零。下一步应改变事实表示或训练目标，尤其要让未见词和值在不依赖精确词表查找的条件下进入可读状态，而不是继续调小门控或增加同类步数。

代码入口：`scripts/deepseek_spora_exact_attention_query_gate_fresh_values_pilot.py`、`scripts/deepseek_spora_exact_attention_frozen_fresh_values_pilot.py`。本地结果分别位于 `runs/deepseek-spora-exact-attention-query-gate-fresh-values-20261116/` 与 `runs/deepseek-spora-exact-attention-frozen-fresh-values-20261116/`。正式底座、个体和检查点未修改。

# 可学习记忆映射的长度与分块审计

独立进程重载上一轮候选，在测试分区跳过前 1,088 个词元后顺序取四段，每段 1,040 个词元。固定最后 16 个位置的 query，分别对其前方最近的 128、256、512、1,024 个 key/value 计算第 6 层第一个 KV 头的历史注意力；同条件比较可学习映射、512 维随机特征（一个种子）和历史 value 均值。候选训练只见过 256 长度。各长度、头和 query 共享片段，四段又彼此相邻；完整片段散列不同不排除句子或主题重叠。

| 历史长度 | 可学习 / 随机 / 均值：四段平均均方误差 | 可学习优于均值 |
| ---: | ---: | ---: |
| 128 | 0.01673 / 0.05155 / 0.01764 | 3/4 |
| 256 | 0.01660 / 0.04465 / 0.01890 | 4/4 |
| 512 | 0.01783 / 0.04305 / 0.02015 | 4/4 |
| 1,024 | 0.01510 / 0.02732 / 0.01901 | 4/4 |

本批可学习映射在 16/16 条低于同条件随机方案，在 15/16 条低于均值，但相对均值的平均优势明显小于上一批测试。随机基线使用更宽的 512 维、单一种子，不能归因于某个架构因素。表中数值是注意力向量误差，不是问答准确率；不同长度对应不同历史窗口，不能把差异解读为因长度增加导致的变化。

将学习型特征按 128 词元一块求和，再使用相同 query 读取；四个长度中分块与整段输出最大绝对差分别为 0、1.79×10⁻⁷、1.79×10⁻⁷、1.20×10⁻⁷。这是同进程累加的数学检查，非正式个体持久化或崩溃恢复。新增单元检查验证分块与显式核一致；相关 6 项测试通过。

原模型前面各层仍能看见完整历史；没有测试截断所有历史后的生成、自然写入、多个实体、反事实纠正或未知拒答。一个模型层、一个头、一个训练种子，不支持推广到其他层头。两个基线没有独立多随机种子；底座预训练内容、部分文本重叠及真实对话表现仍未知。候选、语料和底座散列前后核对，正式个体未修改。

运行约 91 秒、PyTorch GPU 峰值约 3.53 GiB。脚本 `scripts/deepseek_learned_kernel_length_audit_20261117.py`，本机逐项结果 `runs/deepseek-learned-kernel-length-audit-20261117.json`。下一步优先做模型内隔离干预：限制历史通路，在相同问题下切换事实记忆并比较实际生成，同时保留无记忆和完整上下文参考；单层向量误差无法证明该干预有效。

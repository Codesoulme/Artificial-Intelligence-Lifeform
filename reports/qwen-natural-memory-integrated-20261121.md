# Qwen 孢子自然中文记忆端到端候选

日期：2026-11-21

## 目的

把用户跨度约束的地址头、自然问法答案读取器和内部记忆意图门串成一条完整路径，检查单项实验的结果能否在同一次查询中成立。

## 组成

- Qwen2.5-0.5B-Instruct 主干冻结；
- 用户消息跨度约束的地址头；
- 只在自然问法上训练的两层 `OpenBaseMemory` 答案读取器；
- v9 内部记忆意图门；
- 孢子当前矩阵的受控数字状态。

地址头从问题预测对象，答案读取器再从当前矩阵生成数字。门控决定是否读取记忆。没有把记忆文本拼进提示词，也没有修改正式个体。

## 结果

在两个留出对象、三种自然问法上：

| 指标 | 结果 |
|---|---:|
| 地址正确 | 11/12 |
| 记忆门开启 | 12/12 |
| 独立分支答案正确 | 22/24 |
| 两个分支均正确 | 11/12 |
| 两个分支均自然结束 | 12/12 |

完整结果位于 `runs/qwen-natural-memory-integrated-v1-20261121/result.json`。

## 失败分析

唯一地址错误是“你记得编号 11 保存的数值吗？”被预测为对象 `1`，造成两个分支均读取错误。该问题暴露了多位编号的语义绑定仍不稳定；不是意图门问题，也不是生成未结束问题。

## 判定

本轮证明“自然中文问题 -> 内部地址 -> 神经矩阵 -> Qwen 输出”在有限数字任务上可以串通，达到研究候选标准，但没有达到正式接入标准。当前仍有以下边界：

- 地址和答案训练使用相关的合成数字任务；
- 没有姓名、偏好、来源、时间、未知事实和纠正历史；
- 未测试普通问题完全不受记忆残差影响；
- 未测试自然写入、崩溃恢复、重载和多轮对话。

下一轮优先增加多位编号、不同实体名称、未登记对象和查询拒答样本，按对象、问法和事实三重隔离。候选不能覆盖正式检查点。

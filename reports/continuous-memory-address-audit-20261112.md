# 连续记忆矩阵与地址误读检查

在隔离状态中，使用现有孢子当前记忆的两个写入位置、16 个正交数字地址以及 16 条短词元序列，分别测试零矩阵和模型初始矩阵。写入通过现有 `write_temporal`，读取结果使用共享词表码本最近邻恢复；随后纠正第一条，并检查其余记录。

- 两种初始化下，16 条记录在两处读取位置均完整恢复：各 32/32；纠正后原地址及其他记录也均为各 32/32。这是人工指定地址和单轮有限数据，不是自然语言读写或自由生成。
- 对 16 个未写入地址、两个位置共 32 次读取：使用模型初始矩阵时，向量范数约 0.169–0.223；首槽最近邻分数约 0.639–0.845。空地址也会给出候选，不能把最近邻结果当作存在记忆的证据。
- 零初始化的未写入地址，范数显示小于 0.000001，但浮点残留并不一定严格等于零，因此现有码本的“严格零”停止条件仍可能解出词元。这里的首槽分数约 0.640–0.926；该分数对极小向量高度不稳定，不能视作置信度。
- 将前两个已写地址按 5% 或 20% 混合后，两处仍恢复第一条；等比例混合时两处均未完整恢复第一条，即使首槽最高相似度约 0.947。这是人工混合地址，不能假称真实路由器会产生该地址，但说明高相似度和较大读出范数都不足以证明读对对象。
- 已写向量与目标的最大 L2 误差约 0.20；纠正后约 0.21，部分来自写入率和旧内容残留。本次没有直接测量长期写入、真实冲突或历史页。

结果不支持直接用单一范数或相似度阈值判定记忆存在。后续需要独立的存在性证据、地址归属与冲突检测，并对未见人物、同名和相近问法独立评测；任何阈值必须用分离的数据校准。真实个体、底座和检查点未修改，摘要核验一致；完整数据见 `runs/continuous-memory-address-audit-20261112.json`。

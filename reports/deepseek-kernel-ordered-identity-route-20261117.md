# 有序姓名词元与分离状态的隔离对照

沿用 [平均姓名向量的隔离链路](deepseek-kernel-oracle-identity-route-20261117.md) 的两份人工事实、同一候选和四个问题；由实验提供准确姓名边界，改为逐位置比较底座词元嵌入，长度不同则不匹配，相同长度取最低位置余弦。阈值约 0.2366，来自此前已查看的人工训练负例；最高分并列时明确暂缓。姓名信息并非由模型自动定位。

| 对象 | 选择 | 生成或实验动作 |
| --- | --- | --- |
| 小赵 | 小赵状态 | 输出咖啡 |
| 小林 | 小林状态 | 输出牛奶 |
| 小钱 | 无匹配 | 程序暂缓生成 |
| 小林子 | 无匹配 | 程序暂缓生成 |

另构造两份完全相同的“小赵”姓名向量，得分并列，程序暂缓；这个诊断并未给出两条不同的同名人物事实，因此不是同名消歧成功。此前平均向量在相同“小林子”例子中错读小林状态并输出牛奶；这次较长姓名的词元数量不同，因此被规则排除。这是有用的对照，但样例已经查看并用于设计规则，不能证明现实中近名安全。

已知姓名在记录和问题中具有相同词元，这主要是相同表示匹配。不同分词、别名、笔误、缺失或错误截断的边界可能导致误拒或误认；相同姓名的不同人需要额外上下文与证据。程序暂缓不调用生成，不等于模型学会说“不知道”。没有自然对话的自动寻址、多主体持续写入、正式记忆保存、未知事实问答或普通聊天验收；研究状态从人工事实临时计算，未部署到个体。

单独进程重载候选，先前八条留出生成再次逐词元一致；底座与候选摘要前后核验。运行约 101 秒，PyTorch GPU 峰值约 3.33 GiB。6 项单元检查覆盖顺序、长度、并列及阈值和人工边界；没有覆盖真实自然主体定位或真实注入钩子。

入口 `scripts/deepseek_kernel_ordered_identity_route_20261117.py`，选择器 `spora/research_ordered_identity.py`，逐项结果 `runs/deepseek-kernel-ordered-identity-route-20261117.json`。下一步应在未参与设计的自然语句上联合评测边界、同名和别名，并区分可回答、需要澄清和未知；当前人工规则不能作为正式安全保障。

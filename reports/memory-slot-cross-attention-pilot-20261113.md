# 语言层读取记忆槽的注意力实验

## 结构和训练

在第 24 层输出投影处增加研究性残差：按指定地址读取两处孢子矩阵，对前四个记忆槽分别用完整词表投影码本取得底座词向量；当前生成位置的隐藏向量对这些槽计算注意力，再将结果映射回语言层。空槽不参与注意力；没有记忆或读取关闭时保持原输出。检索值只作为网络内部向量，模块不直接指定回答 token，也不把事实文字拼进用户问题。

它仍依赖底座完整词表与共享码本，不等于事实已写进语言底座参数；最近邻是离散选择，梯度不穿过这一步。查询位置、身份及事实写入由实验程序指定。新层零初始化以保持起始行为，训练后输出投影权重范数由零变为约 1.76，说明参数确实更新。

从与上一轮无教师对照相同的候选、数据、种子开始，训练 1024 步；两组步数相同，但新组多出注意力计算和可训练参数，并非计算量完全匹配。训练前 100 条输出逐词元一致。

## 与同步数对照比较

| 留出人物的固定开发题 | 新注意力层 | 原读取结构 |
| --- | ---: | ---: |
| 单人状态，所选旧事实 | 6/6 | 6/6 |
| 单人状态，之前四种监督事实 | 3/4 | 3/4 |
| 单人状态，本轮新增监督事实，抽查四种 | 3/4 | 3/4 |
| 单人状态，未参加本轮监督的事实 | 0/6 | 0/6 |
| 多人状态，所选旧事实 | 6/6 | 6/6 |
| 多人状态，之前/本轮新增监督事实 | 各 3/4 | 各 3/4 |
| 多人状态，未参加本轮监督的事实 | 0/6 | 0/6 |

两组训练后 100 条生成有 94 条逐词元相同；被监督新增事实的反事实配对均为 2/4 两边正确。六种留出事实在单人及多人条件下仍全部答错。输出参数非零并不意味着新层形成了有效记忆读取。

## 新进程重载与消融

重载后，6 条旧值输出逐词元复现；两名测试人物各自在四种监督事实中答对 3 种，两种额外留出事实均答错。读取前已用共享码本核对受控记忆词元。对这 30 条重载检查，在同一候选上临时关闭新层再生成，**30/30 的输出逐词元相同**；之后恢复开关。该结果说明本批生成未显示新层贡献，不代表其隐藏状态完全相同或其他输入上绝无影响。

## 局限与判定

只有一个随机种子、人工水果事实、固定名字和数字地址；留出事实与问法已参与本项目开发，预训练重合未知。未测可靠身份路由、真实用户状态、开放关系、长周期记忆或正常聊天。空槽阈值也是实验设置，未经开放场景校准。该候选不部署，也不能声称完成孢子结构改造。

代码 `scripts/deepseek_spora_cross_attention_memory_pilot.py` 和 `scripts/deepseek_spora_cross_attention_ablation.py`；结果在 `runs/continuous-reader-cross-attention-pilot-20261113/`、`runs/deepseek-spora-cross-attention-ablation-20261113/`。相关测试覆盖零初始化、空记忆、关闭开关、梯度及研究权重恢复；源底座、源个体及既有候选未改。

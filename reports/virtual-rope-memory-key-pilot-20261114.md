# 记忆键虚拟旋转位置编码试验

## 方法

在精确词表记忆桥和高学习率记忆注意力分支上，为记忆键加入底座 Qwen2 `rotary_emb` 产生的固定虚拟槽位置。原自注意力和记忆分支的查询/值路径保持不变；记忆槽仍由程序指定，事实文字不进入问题。由于 6GB 显存限制，本次使用 SGD，避免 AdamW 优化器状态导致峰值溢出；学习率、数据和其余结构沿用组合候选。

第一次 AdamW 运行在第一次优化器更新时触发 CUDA out-of-memory，没有产生有效训练结果；该失败目录单独保留，未被计入结果。修正后的 SGD 版本完成 288 步。

## 结果

虚拟旋转位置版本训练前后 64 条原评测输出逐词元相同，严格正确数也没有变化：训练人物 3/24、留出人物 3/24、本轮留出值分别 1/8 和 0/8。独立进程加载第 288 步后 **64/64 条逐词元复现**；来源候选、底座和正式个体摘要未变。

因此，在本次低显存 SGD 诊断中，加入虚拟旋转位置没有显示可观察收益。由于优化器、学习率与此前 AdamW 版本不同，不能把它当作完全匹配的算法否定；同时第一次 AdamW 版本没有有效结果。实验没有部署。

## 限制

单一种子、指定地址、人工事实和有限评测；没有自动路由、多实体、自然写入、长期恢复或开放聊天。虚拟槽位置取固定的前若干位置，只是一个位置先验。相关原型测试 14 项通过；测试结果及最终恢复在 `runs/deepseek-spora-rope-exact-attention-pilot-v3-20261114/` 和 `runs/deepseek-spora-rope-exact-attention-reload-20261114/`。

# P174 WanJuan 1.0 协议与获取入口核查

本轮只核查公开仓库、固定提交、许可文本和 OpenDataLab 获取入口，没有下载 WanJuan 正文、没有申请账号、没有训练，也没有读取最终评测正文。

## 固定证据

- 仓库：`opendatalab/WanJuan1.0`。
- 核查提交：`17269a7dadc59568091134d41af1c8a18cd390f8`，提交时间为 2023-10-20。
- README blob：`f32d6a165af8c7aaf6669acc113ed1b8760c96d1`。
- License blob：`4ea99c213c5c0c005ae4e80df8e52169d06896ec`。
- README 声明整体采用 CC BY 4.0，并要求署名、许可链接和修改说明。
- README 同时明确提醒：部分子集可能受其他协议约束，使用具体子集前必须查看相关协议或元数据。

## 获取限制

README 的下载链接转到 OpenDataLab 门户，而不是公开的稳定文件目录。门户页面脚本显示：

- 下载流程需要登录、填写身份和下载用途；用途选项包括模型训练；
- DSDL 数据下载流程要求确认许可证，部分数据需要申请并等待审批后通过邮件获得下载链接；
- 页面声明平台数据仅用于学术交流，禁止商业使用，并明确平台不保证用户拥有使用数据所需的全部许可，隐私、肖像权和其他权利仍需自行承担；
- 门户前端没有在未登录页面暴露 WanJuan 的子集文件清单或可直接取样的公开 API。

## 决策

WanJuan 的总许可声明足以作为来源调查线索，但不能作为本项目直接摄取整库的批准。当前缺少：

1. 可固定获取的具体文本子集和文件摘要；
2. 网页、百科、书籍、专利、教材、试题各子集的独立协议与底层权利说明；
3. 子集级来源字段、隐私过滤和近重复清单；
4. 在本机既有训练材料上的隔离结果。

因此 WanJuan 暂保持 `source_candidate_access_and_rights_unresolved`，不申请下载、不训练。后续只有在用户完成平台访问授权或获得可审计的子集文件后，才对单一子集做不超过小规模的训练侧抽样；优先排除书籍、专利、试题和来源不明的转载，先核查可保留来源字段的网页或百科子集。

# Integrated checkpoint with SPORA replacement layers

The prior integrated checkpoint persisted the individual and memory reader but did not include the grafted decoder layers. A new `spora-integrated-open-base-v3` format stores supported `SPORALayerReplacement` configurations and tensors together with the individual and reader. It records hashes over each layer's exact tensor values, a structural feature fingerprint, the base-weight and tokenizer/config fingerprints, and whole-checkpoint integrity. The existing v1/v2 formats remain readable and are still written when no replacements are supplied.

On load, replacement indices, dimensions, tensor sets, dtypes and hashes are validated before modifying the supplied base model. A name binding that declares a structural variant must match the stored layers; a base-only binding is rejected when replacements are supplied. Existing unversioned bindings remain usable with the original v1/v2 format. The runtime gathers supported replacement layers when saving a new memory state and rejects blended layers rather than silently dropping them. Direct callers of `save_integrated` must supply their replacements explicitly. The caller still must load the actual in-memory base from the verified files; file hashes cannot authenticate an arbitrary supplied model object.

The real-model probe saved the diverse-replay layer-6/12 candidates, a native reader and a separate synthetic state containing two writes. The 768-position candidates were embedded in a 244,114,744-byte local checkpoint. A fresh Python process reloaded the same DeepSeek base and this checkpoint; the state digest matched, both replacement lengths were restored, and generated token sequences matched before and after for two explicitly addressed questions. Both returned the expected short answers: current water and earlier coffee. Total save/reload probe time was approximately 296.3 seconds. The checkpoint remains local; `runs/deepseek-spora-structural-checkpoint-20261111/result.json` records its hash, metadata and outputs.

Seventy-four targeted tests passed, including structural and legacy round trips, replacement mismatch and corruption checks, preservation of an existing checkpoint on a failed save, and runtime writes retaining the graft. Independent process reload is not a simulated crash, power-loss or concurrent-write test. Two controlled facts and caller-supplied addresses do not establish autonomous recall or chat quality. The approximately 233 MiB structural checkpoint is rewritten on each runtime save; its actual write latency and incremental-persistence options require separate measurement. Frozen base weights and tokenizer remain separate files, so this is not a fully self-contained model package.

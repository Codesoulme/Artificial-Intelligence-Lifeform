# 记忆槽交叉注意力桥接试验

本轮在最佳绝对隐藏状态桥上增加一个零初始化的记忆槽交叉注意力模块，放在第 23 层注意力输出位置。模块用当前问题隐藏状态查询身份与事实槽，再和原有读取器、晚层残差一起训练。

入口：`scripts/deepseek_spora_cross_attention_hidden_bridge_distill.py`。

| 指标 | 绝对隐藏桥 | 交叉注意力桥 |
| --- | ---: | ---: |
| 留出人物记忆 | 100/108 | 100/108 |
| 留出人物换值 | 100/108 | 100/108 |
| 严格反事实配对 | 93/108 | 93/108 |

结果：`runs/deepseek-spora-cross-attention-hidden-bridge-20261115/result.json`。训练 320 步约 1049 秒，峰值 CUDA 分配为 4,670,359,040 字节。模块零初始化使训练前输出与基线一致，训练后没有带来额外事实切换收益。

## 判断

交叉注意力读取方式在本设置下没有超过现有晚层绝对残差桥，增加结构复杂度的收益不足，因此候选不接入。当前主要问题仍是跨身份、跨关系和开放事实值的桥接泛化，下一步应改善连续记忆表示与语言目标的对齐，而不是继续叠加读取位置。

评测使用受控地址、固定水果关系和有限问法，没有证明自然语言路由、自然写入或开放聊天。

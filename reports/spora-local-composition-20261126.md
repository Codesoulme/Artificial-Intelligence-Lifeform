# 本机版次记忆的中文成句

已知读出器可以组合两个正确地址，自动寻址仍会漏读、误读或读出明确排除的字段。本轮把已经验证的按字段成句模型接到 Windows 聊天入口，测量从生效版次、快权重持久写入、跨进程恢复到生成成品的链路。沿用 StaleBench 的旧值干扰对照和 StateMemBench 的当前值与历史值区分思路。 [分句寻址结果](spora-clause-read-20261126.md) · [成句训练](spora-typed-composition-20261125.md) · [StaleBench](https://arxiv.org/abs/2611.19752) · [StateMemBench](https://arxiv.org/abs/2608.19652)

Windows 入口用可选参数加载成句头，并校验成句权重、训练评估及底座和分词器的绑定。写入仍通过原快权重路径。命令指定同一人物的两项字段、各自版次、确认时间和写作要求。版次解析先完成，缺一项即澄清。测试问句没有档案事实值。解码时把两个从档案张量还原的候选和用户指定的时间交给训练过的读出头。结束时检查三个候选都执行了复制且自然结束。本轮由用户明确给出字段与时间，质量取决于写作要求及训练覆盖。 [本机使用](../docs/version-chat-local-use.md)

## 回放

新建隔离档案，为三个训练未见的人分别登记两项字段的两版，共 12 份张量。两个进程均用同一个 Windows 启动脚本。首次写入后生成两个句子，重新启动后在空对话中复现。另测只换时间、颠倒字段输入顺序、首次回忆时缺少人物、陌生人、无该版次、版次含糊、清除对话和普通首版查阅。

| 对照 | 查阅结果或实际成句 |
| --- | --- |
| 当前地点和当前用品 | 周五傍晚在杏叶廊见，请带上灰毛帽。 |
| 当前地点和上一版用品 | 周五傍晚在杏叶廊见，请带上青布袋。 |
| 两项当前版，但改时间 | 星期三中午在杏叶廊见，请带上灰毛帽。 |
| 首版书目与当前见面地点 | 今晚七点我们在南帆馆见，请带上《河口雨声》。 |
| 上一版饮品和当前书目 | 下午你要的《雨后山色》已经备好，我会带上蜜桃茶。 |

首次 14/14、重启 13/13，六项因果与持久化对照全部通过。只换一项版次或时间，其他文字与值保持原样。交换字段输入顺序不会改变句子。重启和清空对话后的答复逐字相同。版本档案为 69,632 字节，前后摘要一致且完整性检查通过。人工核对三种字段组合的书名、地点、时间和动作关系。运行耗时约 38 秒与 40 秒，含加载。默认入口另跑原回放，首次 27/27、重启 8/8。51 项版次单元测试通过。

这条入口提供受控的记忆成句，后续仍需要自然说法下的人物、字段、时间选择，以及开放对话的独立验证。下一轮可以用都绑定到同一人但记录类别不同的冷启动操作者测试，分开衡量中途修订、遗漏信息时澄清、泛聊时不误读和成品质量。

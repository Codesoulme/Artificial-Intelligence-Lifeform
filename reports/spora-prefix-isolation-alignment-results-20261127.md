# 完整前缀与孤立事实的状态对照

日期：2026-11-27。依据[预先计划](spora-prefix-isolation-alignment-plan-20261127.md)，比较完整聊天前缀与单独编码事实的各层键值；状态来自冻结底座，事实内容、地址和替换范围均由实验指定。共四条人工事实、五种条件、20 次生成。底座摘要前后一致，未加载或修改正式个体。耗时约 56 秒，CUDA 峰值分配约 3.33 GiB。

完整前缀中的事实部分与孤立输入逐词元一致；两种替换仅覆盖事实词元对应的键值，完整前缀中其余聊天模板状态保持原样。全部层替换、位置从 0 开始时，香蕉题改为“香蕉是小林最喜欢的水果。”；其余回答与基线文字一致。位置对齐后四条文字均与基线一致。完整目标出现是筛查，不等同语义与身份普遍可靠。

与第 5 层单头直接拼接的旧实验不同，本轮保留了原聊天模板前缀，替换了已有的事实位置，并使用所有层、全部头；因此不能仅凭两组结果判断哪一个改动是决定因素。位置从 0 开始也答对，表明这些样本没有证明位置偏移一定导致失败。

## 决策

这给出一个比单头拼接更有用的参照：在保留模板和人工提供事实位置的条件下，底座能够利用跨层孤立状态。下一步应查公开研究，设计受限存储与可学习的跨层状态，比较实际成本、值交换、错误关系、普通问题及未见材料；也应分别消融层数、头数与模板，以定位效果所需条件。当前事实缓存随词元增长，且由实验人工选择，不满足孢子自主持久记忆目标。

逐条输出、全部层的余弦和相对误差、摘要保存在本机 `runs/research/prefix-isolation-alignment-20261127-v1/result.json`。仅一位人物、两类关系、固定问法、四个训练前就已查看的值；没有验证纠错、跨会话、自然问法、错误状态或重启恢复。

# 语言适配器重置后的显式关系 Lane 试验

本轮从联合 codec continuation 候选出发，保留显式关系 lane，并重新初始化语言适配器，再训练 512 步。目的在于区分“关系结构不足”和“语言适配器保留水果域惯性”两种解释。

入口：`scripts/deepseek_spora_joint_relation_lane_reset_pilot.py`。

配置要点：

- 饮品、颜色、活动三个关系域；每域 4 个训练值、2 个留出值。
- 身份槽关闭，显式关系槽开启。
- 从 `deepseek-spora-joint-codec-bridge-continuation-20261115` 加载 codec 和 bridge。
- 语言适配器重新初始化，联合 codec 训练开启。
- 512 个语言训练步，独立留出值和 strict swap 评测保留。

## 结果

| 指标 | 训练前 | 训练后 |
| --- | ---: | ---: |
| 训练域 memory 包含目标值 | 1/42 | 3/42 |
| 留出实体 memory 包含目标值 | 0/28 | 1/28 |
| 训练域 exact | 0/42 | 0/42 |
| 留出实体 exact | 0/28 | 0/28 |
| 留出 swapped exact | 0/12 | 0/12 |

生成结果仍大量回到水果域先验、身份介绍、泛化回答或列举式回答。训练损失在 512 步后仍为 19.68，未形成可用的关系问法到记忆值的映射。

## 判断

重置语言适配器没有排除关系语义泛化失败。当前问题不是单纯的适配器权重惯性；显式关系 lane、联合 codec 和语言适配器重置组合仍无法让宿主语言层可靠读取新的关系域。

该候选不接入正式个体，也不覆盖现有最佳水果域候选。下一轮应优先验证关系查询的结构化读出与自然语言问法之间的单独训练目标，避免继续扩大有限关系值上的语言适配器训练。

本轮未修改正式底座、正式个体或正式检查点。候选文件保留在：

`runs/deepseek-spora-joint-relation-lane-reset-20261115/`

# 连续词元矩阵跨进程重载试验（2026-11-12）

在独立临时目录中，第一进程使用整合模型的两个孢子快速矩阵，写入 16 条受控短词元序列并覆盖其中一条；保存两处矩阵及码本、投影、底座和检查点摘要。第二个全新 Python 进程重新加载同一底座和检查点，以相同随机种子重建码本，再读取实验矩阵。

覆盖后，保存前及重载后 16/16 条在两处位置都完整恢复词元和结束标记，其中包括被纠正的记录及其余 15 条。两次结果逐项一致，矩阵摘要、临时文件哈希、重建码本和投影摘要均一致；实验前后底座、源检查点与真实个体的摘要未变。临时文件在测试结束后删除。

实验文件是专用研究格式，不是正式 SPORA 运行时检查点；值、地址及一至三个词元的测试数据由程序提供，码本来自同一底座和固定种子。未测试自然语言路由、来源控制、历史事件、错误拒答、跨机器兼容或写入中断恢复，不能据此称正式开放记忆已持久化。

此外，`ContinuousTextCodec.encode` 现在拒绝输入中已包含结束标记的情况，以及投影后为零的词元；构造时拒绝非有限码本，避免这些输入静默丢失或污染数据。六项组件单元测试通过。运行脚本 `scripts/deepseek_spora_continuous_codec_restart_probe.py`，完整结果位于本机 `runs/deepseek-spora-continuous-codec-restart-probe-20261112.json`。

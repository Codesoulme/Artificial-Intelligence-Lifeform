# P215 紧凑流对齐标签训练原语

针对 P214 的接口错位问题，新增 `PackedHybridTrainer`。它直接接收文档流产生的输入与已经对齐的下一单位标签，忽略 `-100`，按非忽略目标数累计训练量，不再额外右移；检查标签范围、填充与相邻对齐关系，并在更新时保留原个体冻结约束。训练原语要求调用者提供来源、词表、校验、审查和日程的谱系字段，但**不自行验证审查文件，也不是训练准入入口**。

检查点除模型、优化器及 PyTorch 随机状态外，保存 Python 文档抽样器状态。普通 `ByteTrainer` 拒绝恢复带该状态的检查点，防止改变抽样方式而静默续训。合成 CPU 测试通过磁盘保存和安全加载检查点，恢复后下一批抽样、损失和接口参数逐值相同；同时确认个体及状态摘要未变。测试覆盖错误对齐、空监督、文档边界和填充。这个结果不保证 CUDA、不同硬件或其他框架版本逐位一致。

当前仍未提供端到端训练入口：正式运行前需要把审查记录与数据、父检查点、预算绑定并实际验证，记录抽样窗口和不同目标位置，检查开发材料隔离，且处理异常和保存策略。`DocumentStream` 按目标位置抽取后监督窗口内多个目标，并不产生均匀的监督目标分布；该限制没有因为接口对齐而消失。

本轮只在人工合成数据上验证训练原语，没有读取 P210 候选正文或最终测试，也没有对孢子个体进行训练。P210 的故事质量和授权范围仍未完成准入，不能将本代码测试或输入摘要当作训练许可，更不能视为中文能力突破。

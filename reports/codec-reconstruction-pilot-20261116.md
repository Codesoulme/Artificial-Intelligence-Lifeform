# 压缩表示重建辅助目标试验

研究性实验在原语言损失外加入词向量重建：随机抽取冻结底座词向量，用可训练 codec 投影压缩，再用可训练桥接器还原，以余弦距离监督。128 步、辅助权重 5、每步 256 个词元；其余起点、随机种子、关系训练值和训练步数与 `joint-codec-gradient-repair` 一致，训练前生成结果 70/70 逐项一致。

| 训练后指标 | 原联合训练 | 加重建目标 |
| --- | ---: | ---: |
| 训练人物 memory 正确 | 0/36 | 0/36 |
| 留出人物 memory 正确 | 0/12 | 0/12 |
| 留出人物 swapped 正确 | 0/12 | 0/12 |
| 完整回答 exact | 0/70 | 0/70 |

正确采用实验的 `stored_fact_correct`。第一步重建损失约 0.484、投影梯度范数约 0.109；第 128 步重建损失约 0.507，数值对应不同随机批次，不可直接判定学习趋势。生成任务没有观察到改善。

另用固定随机种子的 1,024 个词元探针比较还原向量与底座词向量的平均余弦：起始候选约 0.5214，原联合训练约 0.5206，加重建目标约 0.5234。差异很小；探针没有证明与训练抽样或底座预训练不重合，不能称为独立泛化或据此断言可靠提升。

该目标监督单个词元的宿主词向量，并非将完整历史压缩为教师瓶颈的论文复现；随机训练抽样可能碰到语言留出词元，因此留出的含义仅为关系问答监督留出。没有验证自然写入、多事件、更正、长期保存或独立重载。候选仅用于研究，未接入正式个体；底座与源检查点由试验的摘要核对保护。

代码：`scripts/deepseek_spora_codec_reconstruction_pilot.py`、`scripts/deepseek_spora_codec_reconstruction_audit.py`；本地工件在 `runs/deepseek-spora-codec-reconstruction-20261115/` 与 `runs/deepseek-spora-codec-reconstruction-audit-20261116.json`。辅助目标和记忆梯度路径的 15 项测试通过。下一步应先明确分离教师瓶颈对事实和值的编码，以及学生读取机制对问题的选择，再用严格未见事实、换值和关闭记忆对照验证；不应将本次有限结果视作有效的开放记忆。

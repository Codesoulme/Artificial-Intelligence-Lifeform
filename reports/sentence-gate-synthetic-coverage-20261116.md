# 暂缓判断的人工问法覆盖

## 方法

沿用上一轮冻结前缀、自然对话训练材料、片段头和二分类方法。新增的人工问题从固定摘要的 CLUENER 训练分区选择 24 个姓名，排除其验证分区姓名、当前自然训练问题中出现的姓名，以及本轮评估姓名或其子串。按完整姓名分为 16 人拟合、8 人校准；每人构造两条单人问法，每两人构造两条多人问法。姓名来自已标注语料，但本轮问题由程序合成。

原有自然与人工材料分组方式不变；新增后共 144 条拟合、56 条校准。阈值仍取校准负例最高分并要求严格大于：40 条正例放行 38 条，16 条负例放行 0 条。校准样本少，且自然对话的知识三元组标签可能不完整；不能推断未知问题的误接受概率。

再次使用上一轮已查看的 46 条开发对话、36 条测试对话及 30 条人工姓名题。此实验是在观察过上一轮结果后调整的数据覆盖，不能当作独立验收；也没有修改或重新训练片段头。

## 结果

| 检查 | 原暂缓判断 | 加入人工问法 |
| --- | ---: | ---: |
| 开发对话：单人姓名完整识别 | 15/24 | 12/24 |
| 开发对话：多人句选出单一姓名 | 4/13 | 2/13 |
| 测试对话：单人姓名完整识别 | 3/11 | 3/11 |
| 测试对话：多人句选出单一姓名 | 3/14 | 1/14 |
| 人工登记姓名：正确匹配 | 0/8 | 1/8 |
| 测试无人句：判断器自身放行 | 7/11 | 10/11 |

无人句虽被判断器放行，后续片段头在该批 11 句上仍均未选人名；不能因此认为判断器正确识别了无人。人工登记姓名有三条通过判断器，但片段头仅对其中一条匹配成功，因此最终为 1/8。多人句选择单一姓名是风险代理，不等同于实际错读；本次没有执行个体记忆读取。

## 判断与限制

新增问法后，多人句单片段输出减少，登记姓名仍有七条无法正确匹配，且无人句放行增多。数据量、类别比例、标准化及由校准集得到的阈值同时变化，不能把表现归因于单一因素。单个种子、小样本和重复查看的评估材料都不足以证明泛化；完整姓名虽分组隔离，姓名组成字符、底座预训练和更早项目实验仍可能重合。

该方案仍依赖较早的 DeepSeek/SPORA 结构替换前缀，不是当前低秩更正候选。没有自动登记、同名与别名处理、真实读取、自然写入、持续学习或多轮对话验证，不部署该探针。原自然数据的上游文本及知识权利仍需核实。

加载时核对底座及数据来源摘要，运行前后核对来源检查点与对话归档；约 98 秒。代码 `scripts/deepseek_spora_sentence_gate_audit.py` 的 `--include-synthetic` 模式及 `tests/test_sentence_gate_audit.py`；逐项结果和隔离权重位于 `runs/deepseek-spora-sentence-gate-synthetic-audit-20261116/`。

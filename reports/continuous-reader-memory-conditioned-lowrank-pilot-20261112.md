# 由连续记忆调节语言层的实验

## 方法

在隔离实例中，读取两个当前记忆矩阵的指定地址，取两个读出向量的平均，经可训练变换和 `tanh` 调节后续注意力层的秩 8 更新。没有记忆或屏蔽读取时跳过更新；两个矩阵严格为零时，该低秩更新也为零。它只支持单行、明确地址及当前页，不能用于一般批处理、历史页或未经核验的地址。

测试 16 个训练水果、3 个人物和 3 种问法，共 144 组合，训练 768 步；冻结底座，联合训练读取器和低秩参数，使用完整回答、事实词监督和对称反事实损失。保留未训练人名、问法和两个水果；记忆和地址由程序在隔离矩阵直接写入。输出由语言模型生成，没有用码本直接输出答案。

## 结果

写入苹果或香蕉时，同一训练问题都回答“小林喜欢的水果名称是苹果、香蕉和橘子。”；由于同时列出两个互斥事实，不能算成功。未见人名仍列出多个水果，未见问法重复问题，未训练水果未正确给出。

相对于上轮“只按是否提供状态门控”的实验，严格空矩阵在本次两个受测问题上的输出与关闭读取一致；两条普通问题关闭读取的输出训练前后也一致。这是有限样例及理想零矩阵的结果，未写入真实地址可能有非零背景，因此不能据此识别未知事实或保证拒答。强制正确前缀下，香蕉相对苹果的分差为 -0.20，仍偏向苹果；条件分数不等于自由生成。

基础单元测试通过：无记忆、关闭掩码和零矩阵时低秩更新不改变结果；不同矩阵可以改变结果，并能向适配参数传播梯度。这只验证组件数学行为，不证明模型学会事实或身份。

候选保存在本机独立研究目录，标注依赖明确地址、关闭慢路径和零偏置，未用于正式个体。原底座、原检查点和旧候选摘要保持一致。完整原始数据在 `runs/continuous-reader-memory-conditioned-lowrank-pilot-20261112/result.json`；耗时约 507 秒，PyTorch 峰值分配约 4.27 GiB。

下一步需要更广的独立事实、改写问题与真实未知地址评测，并改进读取器和数据；不能以记忆向量改变输出、或者空矩阵静默，就声称实现了持久事实记忆。

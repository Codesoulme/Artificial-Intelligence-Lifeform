# 开源骨干与孢子记忆：首轮试验

用户选择独立分支 `research/open-base-memory` 测试开源语言底座接入孢子记忆；原随机初始化目标已暂停，旧谱系和个体保留。使用 [Qwen2.5-0.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct/tree/7ae557604adf67be50417f59c2c2f167def9a775)，修订 `7ae557604adf67be50417f59c2c2f167def9a775`，官方权重 LFS SHA-256 `fdf756fa7fcbe7404d5c60e26bff1a0c8b8aa1f72ced49e7dd0210fe288fb7fe`，模型卡标注 Apache-2.0。模型文件仅保存在 `runs/open-base-qwen2.5-0.5b-7ae5576/`，未提交 Git。下载在 63% 时连接重置，续传完成后文件长度与官方 LFS 摘要均一致；服务端 Xet ETag 不是文件 SHA-256。

环境为 Windows、GTX 1060 Max-Q、PyTorch 2.5.1+cu121、Transformers 4.57.6；模型以 FP16 载入。额外 Python 包隔离在 `runs/open-base-deps/`，原虚拟环境已有包未替换。`scripts/open_base_baseline.py` 生成三条中文回答：自我介绍、放松建议、社会主义核心价值观的个人层面。最后一题正确列出爱国、敬业、诚信、友善；自我介绍声称可生成图片、音乐等，不能据此认为本地具备这些功能。三条不是独立聊天评测，也尚未读取孢子记忆。基线峰值 PyTorch 分配约 1.01 GB、三次生成各约 4.0–4.7 秒；这是单次短问题测量，非整机显存或通用性能结论。详细输出和输入文件摘要在 `runs/open-base-baseline-20261109.json`。

## 层内结构

`spora/open_base_memory.py` 在底座解码器第 6、18 层输出处注入两组可训练读取：由隐藏状态生成查询，读取原个体的当前神经矩阵及历史页，按查询匹配加权后投影并以残差加入隐藏状态。读取的记忆是张量而非提示词；它是**新增在原有 Qwen 骨干中的结构**，并非已将全部骨干替换为孢子的最终设计。接口输出初始化为零，不自动更改底座或个体。单次读取固定状态快照，重叠挂接会拒绝；换状态必须结束旧挂接并重新建立生成上下文和 KV 缓存。

`scripts/open_base_memory_probe.py` 在真实底座和 `individual-prechinese-v3.pt` 上验证：零初始化接口时 logits 与原版逐项相等；移除接口后也逐项相等。对未训练投影人为加入随机扰动后，真实神经状态与全部清零状态的最大 logit 差为 0.796875、平均绝对差约 0.0370，说明状态进入了计算，并不代表答案理解了状态。个体文件及冻结状态核验通过，峰值 PyTorch 分配约 1.16 GB；结果在 `runs/open-base-memory-probe-20261109.json`。

`scripts/open_base_cache_probe.py` 使用一个提示和同一固定记忆快照，验证零接口下的贪心生成与基线一致；随机扰动接口下，有缓存和每步完整重算生成相同的 24 个新词元。这只是单提示、单状态验证，不证明任意状态切换可复用缓存。结果在 `runs/open-base-cache-probe-20261109.json`。

## 合成状态学习

`scripts/open_base_synthetic_alignment.py` 冻结底座权重和原个体，只训练两个读取接口：同一句问题配两个人造矩阵状态，目标分别为数字 1 和 2；训练与留出使用不同随机噪声及问法，但共享同一人为设定的矩阵规则。先做 40 步，再从同样初始设置独立重跑 400 步，旧输出保留。这里比较的是两个指定数字的下一词元得分，不是完整回答或真实记忆。

| 条件 | 40 步：单项正确 / 成对均正确 | 400 步：单项正确 / 成对均正确 |
| --- | ---: | ---: |
| 新状态与新问法 | 8/16 / 0/8 | 12/16 / 4/8 |
| 交换状态 | 8/16 / 0/8 | 12/16 / 4/8 |
| 清空状态 | 8/16 / 0/8 | 8/16 / 0/8 |
| 关闭接口 | 8/16 / 0/8 | 8/16 / 0/8 |

400 步在训练组合上为 64/64、32/32 对，说明有拟合；新组合仅部分成功。交换状态只是交换同一对矩阵的顺序，结果与正常顺序对称，不能当作额外独立样本。清空和关闭的单项 8/16 来自同一问题的两个相反标签，成对均正确为零，不能当作有效读取。单次 400 步及内置评估约 76.7 秒，峰值 PyTorch 分配约 1.14 GB。接口参数保存在 `runs/open-base-synthetic-alignment-400-20261109/adapter.pt`，只适用于这个合成测试，不是可发布的记忆模型。

进一步用 `scripts/open_base_synthetic_generate.py` 不限制输出词元，在两个留出矩阵种子、两种留出问法上测试：4 组成对问题中 2 组生成恰好 `1` 和 `2`，交换状态对应翻转；清空状态 0/4 组成对正确。另一种问法没有按要求只输出数字。只有四对且仍共享人造矩阵规律，不能视为普遍泛化；结果位于 `runs/open-base-synthetic-free-generation-20261109.json`。

综合来看，结构接线和受控信号传递有初步证据，真实个体中的对象、纠正与历史尚未对齐到中文回答；既不能宣称孢子已继承底座能力，也不能宣称已实现完整结构迁移。后续需要在隔离副本上训练真实记忆映射，以同问题切换记忆、未见实体与问法、清空和错误状态等对照，测量自由回答和旧个体记忆保持；不可把本合成适配器用于真实个体。`tests.test_open_base_memory` 和 `tests.test_open_base_synthetic_alignment` 共 9 项通过。

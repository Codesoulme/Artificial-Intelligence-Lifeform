# P113 训练侧 1 万篇规模试验

## 结论

在当前机器和保护阈值下，P113 对训练文件开头的 10,000 条记录完成了一次运行，耗时约 35 秒，峰值工作集约 410 MiB、峰值提交约 404 MiB。输出中 2,661 条保留为候选，7,339 条因包含被移除的高频特征而隔离，隔离占比 73.39%。这说明本次规模可以跑通，但较高的隔离比例是实际使用的重要限制；候选不代表已获准用于训练。

这是按原顺序截取的头部非随机样本，不能据此外推全部 20 万项的运行时间、内存或召回率。本次没有标注真值，也未测量召回率或精确率。

## 范围与方法

- 唯一数据来源：`runs/p28-stories-data/candidate-v3/pretrain-train.jsonl`。从二进制流按原顺序读取前 10,000 行，逐行原样写入新目录，未改写行内容或换行符。样本为 15,206,243 字节。
- 新目录：`runs/p113-real-scale-pilot-20261109/`；其中 `measure.py` 独立截取、启动和测量 P113，结果置于 `p113-output/`。输出数据文件包含原记录，本文不展示正文。
- 使用 P113 默认参数：相似度阈值 0.8；高频特征比例 0.1，最小频次上限 100，本次生效上限 1,000；桶上限 200；候选对预算 1,000,000；8 个 band，每个 4 行。
- 未读取开发或最终测试数据，未训练、修改 P113 或提交。P112 的两个 Python 进程在试验前后均存在；没有向它们发送终止信号或更改其文件。试验使用低于普通优先级的单个 P113 子进程，但共享机器资源，因此不能声称对其运行没有任何资源影响。

## 资源测量

| 指标 | 结果 |
|---|---:|
| P113 墙钟时间 | 34.966 秒 |
| P113 进程 CPU 时间 | 34.016 秒 |
| Windows 峰值工作集 | 430,354,432 字节，约 410.4 MiB |
| Windows 峰值提交 | 423,190,528 字节，约 403.6 MiB |
| 监督器墙钟时间 | 35.542 秒 |
| 启动前系统可用物理内存 | 2,335,825,920 字节，约 2.18 GiB |
| 运行期间采样到的最低可用物理内存 | 1,925,705,728 字节，约 1.79 GiB |
| 运行期间采样到的最低系统可用提交量 | 6,235,426,816 字节，约 5.81 GiB |

墙钟和 CPU 来自子进程内部计时；Windows 峰值来自 `GetProcessMemoryInfo` 的峰值工作集和峰值 pagefile usage（进程峰值提交）。监督器每 0.5 秒检查一次子进程与系统内存，系统最低值是采样值，不保证捕捉瞬时最低点。启动、抽样和结果核对不计入 P113 内部计时；其他进程的资源不计入子进程数字。

保护阈值为子进程当前提交量 768 MiB、系统可用物理内存低于 1,280 MiB、系统可用提交量低于 1,536 MiB，或运行超过 900 秒；触发时只终止本试验子进程。此次未触发，退出码为 0。检查有采样间隔，阈值不是绝对硬限制。

## 输出与核对

| 指标 | 数量 |
|---|---:|
| 输入及不同的精确文本 | 10,000 |
| 高频特征（文档频次严格大于 1,000） | 16 |
| 进入相似度核验的去重候选对 | 2 |
| 达到阈值的候选对 | 0 |
| 未检查的桶 | 0 |
| 输出组 | 10,000，全部为单条组 |
| 候选记录 | 2,661 |
| 隔离记录 | 7,339 |

所有隔离组的原因均为 `frequent_features_removed`；这意味着这些记录含有至少一个被排除的高频特征，并不表示它们被判定为重复。没有因过大桶或候选对预算而跳过的桶。候选对数量很少以及未发现达阈值的对，不能证明样本没有近重复：LSH 会漏检，字符五元组也不能覆盖语义改写。

抽取时计算的 SHA-256 与重新读取源文件前 10,000 行计算的值一致，也与 P113 报告的输入散列一致：`7a253eccdfd9c3c498b73c59fc9e0b4c7b6a30eca5fba46064db045f70759048`。源文件抽取前后大小及修改时间一致；此处核对的是所用前缀，未计算整个源文件的散列。P113 同时逐条核对了输入记录中相应的文本散列。

独立核对确认：每个输入行号恰好出现在一个组中，代表行是组内最小行号，组状态与复核原因一致；候选输出逐条等于各候选组代表记录，隔离输出逐条等于各隔离组全部记录，顺序也一致；四个输出文件散列均与 P113 摘要一致。`groups.json` 的 SHA-256 为 `aa7a3a76ebfba14e13c6785b9e66d7678973044199cc216e90a044493bdad2d1`。这些核对验证输出与分组的一致性，不验证分组的语义正确性。

机器可读的原始测量、子进程计时及工具摘要分别保存在新目录中的 `measurement.json`、`child-metrics.json`、`p113-output/summary.json`；运行标准错误为空。

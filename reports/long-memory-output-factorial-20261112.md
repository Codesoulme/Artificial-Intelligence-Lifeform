# 长输入记忆输出的四组消融（2026-11-12）

复用上一轮两个已知键、四个人工当前／历史查询和 174 词元输入，分别启用两处记忆读取和词表输出偏置、仅保留读取、仅保留偏置、两者均关闭。地址、事件时间及原生记忆证据均由测试程序明确提供；每种配置均通过真实 `generate` 和同一临时记忆快照。完整组合 4/4 逐词重现上一轮结果。

严格短答案匹配在完整组合为 2/4，其余三种设置均为 0/4；该指标只接受与预期词完全相同的回答，不能直接当作语义正确率。例如目标“水”时仅有偏置的回答为“水。”；目标“咖啡”时两者都关闭的回答中也包含“咖啡”。这两个例子说明不能由严格匹配为零断言相应设置完全没有正确语义。

针对键 22 的当前问题，直接数值证据为“豆浆”，但四种配置都没有给出精确目标；完整组合回答“水”，仅偏置或两者均关闭时回答“咖啡”，仅读取时则重复问题和无关解释。历史目标“果汁”的完整组合与仅读取均输出“橙汁”，仅偏置输出“水”，两者均关闭则回答“咖啡”。此实验表明开关不同路径会改变这些回答，但不能定位唯一根因，也不能证明关闭或保留偏置在其他场景总体更好。两处读取位置是一起关闭的，没有单独测每处作用。

结果位于本机 `runs/deepseek-spora-long-memory-output-factorial-20261112.json`，脚本 `scripts/deepseek_spora_long_memory_output_factorial.py`。本次约 87 秒，峰值分配显存约 3.70 GB；原检查点及真实个体未变。样本均为此前开发用人工事实、重复填充、有限输出，未检验自然语言写入、路由或通用聊天；下一步需增加成对事实反转和未参与调参的人物、问题及值，分别评估证据读取、输出偏置和生成行为。

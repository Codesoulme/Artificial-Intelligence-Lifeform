# 限制历史通路的单组事实生成诊断

用此前只按历史注意力向量训练的第 6 层 KV 头 0 的候选，对单组人工事实做反事实生成。事实分别为“小林最喜欢的饮品是豆浆”和“……咖啡”。先分别运行事实短句，提取该层 key/value，编码为两份临时特征统计矩阵及归一化向量；然后从头运行完全相同的问题，**问题输入不含事实原文，不传入事实前向的 KV 缓存**。在第 6 层输出投影前，将该记忆按 query 读取的向量直接以系数 1 加到对应的六个 query 头；其余原有通路保持。

| 条件 | 生成结果 |
| --- | --- |
| 写入豆浆 | “小林最喜欢的饮品是咖啡。” |
| 写入咖啡 | “小林最喜欢的饮品是咖啡。” |
| 不启用记忆 | 生成自我介绍开头，16 词元截断 |
| 原文上下文：豆浆 | 正确输出豆浆 |
| 原文上下文：咖啡 | 正确输出咖啡 |

两份矩阵状态摘要不同，问题词元及位置相同，各自生成时均有 8 次注入；生成词元序列却完全相同。与不启用记忆时的结果不同，只能说明干预改变了生成，不能说明模型正确读取状态。豆浆一侧明确错误；一侧偶然答对不能作为可靠事实区分。参考组直接把原文拼入提示，仅作为底座在该构造下的能力参照，不是内部记忆结果。

为对齐事实状态的位置，记忆和无记忆问题的起始位置均偏移 7；额外以位置 0 运行无记忆问题，前 16 个生成词元与偏移 7 一致。参考组使用通常的位置起点；关闭推理标记、人工编写的短句和 16 词元上限都可能影响行为。两次运行的记忆答案及上下文参考一致；第二次额外记录状态散列及位置对照。

这只是一人、一关系、一对事实、一个问题；自述无记忆答案也显示当前提示和底座输出不稳定。人工指定事实短句，尚无真实观察、身份寻址、未知拒答、并发状态、跨会话保存或普通问题无回归验证。单层单头的直接加法不是论文的训练门控结构，候选从未以事实问答训练；因此既不能证明其他记忆结构必然失败，也不能部署该候选。正式个体未参与，底座和候选文件散列核验一致。

脚本 `scripts/deepseek_learned_kernel_isolated_generation_20261117.py`，结果 `runs/deepseek-learned-kernel-isolated-generation-v2-20261117.json`；本轮约 94 秒、PyTorch GPU 峰值约 3.33 GiB。6 项已有基础检查通过，但没有覆盖实际 DeepSeek 注入钩子。下一步需要测量同一问题下两份状态对注意力残差与目标词概率的差异，训练可控门或跨头映射，并用多人物、未知和无关问题进行隔离反事实检查。

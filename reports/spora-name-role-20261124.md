# 孢子姓名边界与写入对象判断

上一轮的四层姓名标注器在近名上仍会误放行，强制句中只有一个人名又挡住全部联系人更正。本轮从冻结的 DeepSeek 孢子前 12 层提取字符表示，直接给已登记姓名指纹召回的片段打分。每个片段读入姓名平均表示、左邻和右侧两字。另一候选额外看整句平均表示和末尾表示。只有一个候选越过阈值才会选中对象。实验表征与原模型共享，推断过程只加载这一份语言骨干。[上一轮回放](spora-natural-field-write-20261124.md)

训练使用 24 个姓名、12 种句式，生成 1,440 条请求，涉及正确主体、其他已登记姓名充当联系人、左右延长的近名、并列主体和库外主体。共有 2,040 个被登记指纹召回的监督片段。随机初始化两个 64 隐维的打分头，在 CPU 上各训练 14 个轮次。局部版 393,345 个参数，整句版 589,953 个参数。用姓名和句式不同的 160 条校准请求冻结门槛，再评估新的 320 条请求以及上一轮的 340 条槽位回放。三组模板由研究代码编写。合成组的库外主体固定用同一个名字，槽位回放的库外姓名随组变化。

## 槽位回放

保留同一份字段地址权重和值编码。初始及更新值由题目给出。负例只测是否会进入写入槽位。

| 条件 | 写对 / 写错 / 跳过 | 更正值读对 | 未改值读对 | 近名误放行 |
|---|---:|---:|---:|---:|
| 上轮标注器，唯一匹配登记姓名 | 19 / 1 / 0 | 17/20 | 48/60 | 13/80 |
| 局部边界，固定阈值 | 6 / 0 / 14 | 1/20 | 8/60 | 1/80 |
| 局部边界，校准阈值 | 3 / 0 / 17 | 0/20 | 0/60 | 0/80 |
| 整句上下文，固定或校准阈值 | 9 / 0 / 11 | 7/20 | 21/60 | 1/80 |

每个条件均拒绝 80 条完全库外姓名和 80 条双人请求。整句候选漏掉全部五条联系人更正，也挡住了部分合法地点变更。整句候选唯一放行的近名是「林佳文越」，句子要求更新出门时间。这组低误判伴随明显的合法请求漏判，暂留研究用途。

## 新句式与后续方向

整句候选通过 11/32 条单人请求和 5/32 条联系人已登记的请求。后者的逐项打分中，正确主体在 27/32 条排在联系人之前，但多数正确主体的分数仍低于全局阈值。局部版也是 27/32 排序正确。作为事后诊断，在新题上把阈值抬到高于所有错误候选的分数后，两个候选分别只留下 9/64 与 11/64 个正例。校准难以同时弥补角色和句式变化。

下一次对照以同一句里的真实主体与联系人做相对排序，同时单独监督完整姓名边界和无可写对象。候选之间可以互相提供证据，再决定暂缓或选择。事件论元抽取中的 PAIE 以及较新的边界与论元依赖方法给出了可比较的训练思路。拒绝库外主体仍需留下独立负例。[PAIE](https://aclanthology.org/2022.acl-long.466/) · [片段边界与论元依赖](https://doi.org/10.1016/j.neucom.2025.132127) · [实体链接的空对象判定](https://aclanthology.org/2023.findings-acl.690/)

源检查点、字段地址权重和个体状态摘要一致。独立进程重载训练权重后逐项复现阈值、候选打分和槽位结果。12 项相关单元测试通过。训练权重和逐题结果位于 `runs/spora-name-role-v1/`。

```powershell
$sporaModel = 'runs/spora-composition-late-gates-20-23-24-v1/candidate.pt'
$sporaAddresses = 'runs/spora-entity-field-address-v1/addresses.pt'
.\.venv\Scripts\python.exe -m scripts.train_spora_name_role $sporaModel $sporaAddresses runs/spora-name-role-v2
.\.venv\Scripts\python.exe -m scripts.train_spora_name_role $sporaModel $sporaAddresses runs/spora-name-role-v2-reload --verify runs/spora-name-role-v2
```

# 随机特征记忆的分块合并与新文本检查

实现数值稳定的分块合并：各块用各自的最大对数特征缩放，合并时转到共同尺度后相加。合成测试覆盖不同尺度的块、全量和分块等价、内存序列化后读取，以及非法数值拒绝。调用方必须确保各块使用相同随机投影；当前状态未内置投影身份认证，不可直接用作正式个体的持久记忆。

沿用冻结 DeepSeek 第 6 层的历史注意力向量诊断，加入四段新的人工文本，并对全部八段各测两个 KV 头与三个预设随机种子。以下每列分母 8 是四篇文本乘两个头，它们不是独立人群样本：

| 随机种子 | 原四段：误差低于历史均值 | 新四段：误差低于历史均值 |
| ---: | ---: | ---: |
| 110617 | 7/8 | 7/8 |
| 110618 | 6/8 | 8/8 |
| 110619 | 7/8 | 6/8 |

新四段上，三个种子的 8 项平均均方误差分别约 0.0404、0.0478、0.0571；均值基线为 0.0758。此处比较向量，不代表准确回答；不同头的误差尺度可能不同，算术平均也不能视为统计显著性。新增文本是在观察原实验后编写，未经独立人员冻结或双重标注；训练底座可能见过相似内容。

四词元一块的状态与整段计算在 48 个文本、头、种子组合上的读取最大绝对差约 **3.22×10⁻⁶**。这些历史只有约十几到几十个词元，不能外推到长期持续更新，也没有在机器断电或真实个体恢复后测试。实测分块读取仍依赖对应的固定投影；没有自动确认不同进程加载的是同一投影，未验证错误投影时的拒绝。

每个例子原模型的早期层仍能看到完整历史；测试目标是历史注意力的向量近似，并非切断历史后的问答。实验还执行全量岭回归对照，整体约 93 秒、PyTorch GPU 峰值约 3.33 GiB，不能当成单个机制的速度或内存效率。正式个体未改，底座散列前后一致。

8 项相关单元测试通过，代码位于 `spora/research_random_feature_attention.py` 及 `scripts/deepseek_attention_kv_memory_probe_20261117.py`；逐项结果在 `runs/deepseek-attention-kv-chunked-feature-probe-20261117.json`。下一步需将状态与投影身份绑定，做更长序列的数值及恢复测试，并用遮断历史的隔离推理验证是否能正确回答；目前不部署。

# 完整回答教师监督的同条件对照

## 方法

沿用上轮的训练数据、初始化、随机种子、128 步、学习率、完整句子目标和事实词位置的反事实损失，移除逐词教师 KL，单独训练隔离读取器。随后在同一进程加载上轮带教师监督的候选，对原始读取器、无教师候选和教师候选，用同一组记忆与问题重新测量并生成。训练的数据顺序使用相同的独立随机数种子；教师模型的额外前向计算意味着这不是严格相同的计算量，而是相同训练步数和学生优化设置。

## 结果

两种候选对训练问题的苹果和香蕉，均生成“小林喜欢的水果名称是苹果、香蕉和草莓。”；换一个人名也同样列举这三种。它们都没有通过这些成对反事实测试。新问法和未训练词也未显示可靠的正确切换。答案包含目标词不够，因为同时包含互相冲突的词。

在提供正确句子前缀的条件下，测量应输出水果处的分数：

| 条件 | 苹果的首词元排名 / 相对香蕉的分数差 | 香蕉的首词元排名 / 相对苹果的分数差 |
| --- | --- | --- |
| 原始读取器 | 1 / +1.25 | 3 / -1.25 |
| 无教师 | 1 / +1.27 | 3 / -1.05 |
| 有教师 | 1 / +1.23 | 3 / -1.05 |

这表明这两个案例中，给出人工正确前缀后仍偏向苹果；训练损失下降并没有使它可靠区分不同记忆。此表是条件概率，不是自由生成，也不能推广到所有词。未训练词首词元排名，无教师为 18 和 7，有教师为 16 和 8，同样不足以说明有效泛化。

两组教师候选和对照在该少量样本上的输出和分数很接近，本实验没有证据说明教师项带来了有用的记忆读取收益；不能据此排除其他训练方法。两条关闭读取的普通问题前后输出相同，只覆盖极少样例。评估使用人工地址和短词码，不验证真实路由、持久性、身份或开放对话。未启用任何候选；原底座和检查点摘要保持一致。完整逐项数据在本机 `runs/continuous-reader-full-teacher-control-20261112/result.json`，耗时约 279 秒。

后续应检查训练信号在每个读取位置对事实词差值的实际影响，并比较可学习读取位置或容量；要求在同一问题替换事实时给出互斥正确答案，不能用“包含目标词”单独算成功。

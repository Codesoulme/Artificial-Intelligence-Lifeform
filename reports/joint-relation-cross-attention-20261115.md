# 多关系读取探索：交叉注意力与覆盖范围

在隔离候选上尝试让问题状态通过交叉注意力选择记忆槽。结果尚不足以接入正式个体。

| 实验 | 训练 memory 正确 | 留出人物 memory 正确 | 留出人物 swapped 正确 |
| --- | ---: | ---: | ---: |
| 显式关系槽、交叉注意力，320 步 | 3/36 | 0/12 | 0/12 |
| 身份槽、交叉注意力，320 步 | 3/36 | 0/12 | 0/12 |

上表使用结果中的 `stored_fact_correct`，它检查输出包含当前存储值且不包含同域其他值，并非完整自由对话质量。全部实验的完整回答 exact 均为零；个别包含目标的回答不一定满足严格判定。全覆盖试验的值均用于训练，因此它不测量未见值泛化。

## 配置勘误与限制

前两次新建入口时遗漏了显式关系槽开关，实际上启用了身份槽。早期口头称其为关系槽及将它们当成严格对照是不准确的。原始结果保留在 `runs/deepseek-spora-joint-relation-cross-attention-20261115/` 和 `runs/deepseek-spora-joint-relation-full-coverage-20261115/`，本报告按实际配置列出。

更正后重跑了显式关系槽的交叉注意力：`runs/deepseek-spora-joint-relation-lane-cross-attention-20261115/`。它从 `joint-relation-lane-reset` 候选继续，重置语言适配器，训练 320 步。来源、训练步数和初始化与更早的 reset 实验不同，不构成严格匹配的消融，不能据此判断单独增加交叉注意力的因果效果。

更正后的全覆盖实验在 `runs/deepseek-spora-joint-relation-lane-full-coverage-20261115/`，训练后留出人物 memory 从 1/36 到 3/36，swapped 从 1/36 到 3/36；训练人物从 0/54 到 3/54。即使所有值用于训练，这一配置仍不能可靠读取。两侧分别正确的数量也不能替代严格的配对成功率。

所有试验均使用人工短句、有限词表和显式数值地址；没有验证自然写入、开放关系、多轮对话或未知状态拒答。正式底座和个体未修改。结果文件原有配置没有记录 `store_relation`，本轮已增加该字段及训练值和重置标记，防止后续误判。下一步应设计同起点、同训练量的对照，分别检查存储值可恢复性、语言输出以及换值两侧是否均正确。

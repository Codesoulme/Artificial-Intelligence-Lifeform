# 语义槽证据勘误

`natural-sequence-slot-20261116.md` 的实验将已知答案的 token 向量依次注入语言输出头，并注入结束标记。精确输出证明这条受控复制通路能工作，不能证明语言模型自主理解、检索或自然组织了答案，也不能证明新的事实已经进入底座权重。槽是模型外单独持久化的状态文件，人物和关系由规则及字符串键决定。

此前将槽的保存和加载称为“独立重载”并不准确：`deepseek_spora_natural_sequence_slot_audit.py` 中两次加载都在同一进程内。此前适配器有独立进程加载实验，但不能代替个体槽状态的跨进程恢复证据。

受控结果仍可用于检查多 token 向量存储和读取，不能作为开放语言能力、自主学习或孢子结构改造成功的验收。可学习隐藏写入器在留出词元上失败，必须继续研究能泛化的写入和读取；正式底座和原个体不应被当前探针替换。

本次新增的子进程测试单独验证了槽文件可由新进程加载、向量内容一致及未知键不返回槽；它使用小型人工向量，没有重新加载 DeepSeek，也没有验证模型重启后的完整生成。另有测试验证摘要篡改、底座绑定不匹配被拒绝，以及保存失败时会话不发布候选。规则解析器新增部分否定、疑问和不确定表达的拒写检查，但这些枚举不能覆盖自然语言的所有形式。

# 等宽随机与训练投影的重建对照

与上一轮相同的 4,096 个训练词表行及 512 个留出行上，分别比较随机投影与仅使用训练向量拟合的近似主成分投影。两者均先用训练集均值中心化，编码归一化后，用含截距的岭回归解码并比较原向量。每条记录的编码宽度相同，但主成分矩阵和训练均值仍需单独存储；这不是整体参数量或计算量相同的比较。

| 宽度 | 随机：平均余弦 / 平均排名 | 主成分：平均余弦 / 平均排名 | 随机 / 主成分：无并列第 1 |
| ---: | ---: | ---: | ---: |
| 9 | 0.527 / 248.1 | 0.537 / 232.1 | 0 / 1 |
| 18 | 0.530 / 239.8 | 0.544 / 212.0 | 0 / 1 |
| 64 | 0.551 / 187.3 | 0.574 / 118.3 | 0 / 1 |

排名在 512 个已知留出向量中计算，数值越低越好；不同方法中有 3–6 条目标出现完全相同的浮点得分，因此无并列第 1 和宽松第 1 必须分开统计。排序相对于目标得分的精确浮点比较，不代表语义等价判定。平均方向本身可达到约 0.521 余弦，不能只根据余弦判断身份恢复。

主成分组在这份样本上平均排名更好，但每组只有 1/512 个严格排第一。它没有证明能够有效恢复词元，更没有证明可用于开放回答。样本为随机词表行，包含可能的特殊或未使用词元；只使用一个分区和随机种子，主成分方法也未针对语言输出优化。对照采用中心化和截距，不能与上轮无截距数字直接比较；对应数据均来自当前同条件实验。底座可能预训练见过这些词元。

这只是向量重建诊断，没有实际孢子矩阵写入、自然语言生成、身份路由和持久化；结果不支持部署。脚本 `scripts/audit_learned_projection_geometry_20261117.py`，结果 `runs/learned-projection-geometry-v2-20261117.json`；最初版本缺少并列标记，保留但不用于严格第一名统计。并列计数逻辑的合成测试通过；底座文件前后散列一致。下一步应对语言输出头、目标词元可区分性与实际矩阵写入进行隔离对照，不能把受限候选检索直接作为模型答案。

# 中文多人对话数据来源核查计划

日期：2026-11-27。配对一致性未改善缺席人物判断；先查对话关系的真实语料，不继续扩充同类自编模板。公开研究 [D-REX](https://aclanthology.org/2022.nlp4convai-1.4/) 把实体与关系相关的解释作为关系抽取中间步骤，提示需要同时验证主体、关系与支持证据；它没有证明本项目的神经结构可实现该能力。

候选 [CRECIL](https://github.com/bistu-nlp-lab/CRECIL/tree/68c922c003e19d68a36b63752cba4ef801b82933) 来自中文多人电视剧对话，包含话语、角色指代和人物关系三元组，仓库根目录有 Apache-2.0 许可，但剧本底层权利及转发条件不能仅凭仓库许可证认定。先仅本机研究使用，记录来源，不将语料或逐条内容推送。固定提交 `68c922c003e19d68a36b63752cba4ef801b82933`，只下载其训练集、开发集与说明，核验 Git blob 哈希并扫描结构、标签、重复与分布；不下载、不读测试划分。禁止不可信 pickle 反序列化。

查阅 [QAConv](https://github.com/salesforce/QAConv/tree/b1f140c39580dd4dadb4ecd35e9a247a90016407) 时，作者明确指出部分媒体数据限研究用途；此数据集为英语，本轮不下载。[LongMemEval 清洗版](https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned/tree/98d7416c24c778c2fee6e6f3006e7a073259d48f) 数据卡标记 MIT 和英文，涉及多会话、知识更新及拒答；其内容来源、评测方法与当前机器资源仍需单独核查。它适合作为后续长期记忆评测参考，不把整段上下文评测当成模型内记忆。

先调查 CRECIL 标注是否是当前片段内的可证明事实。全局人物关系不等于片段有明确证据；未标注也不必然是负例。只有确认标注和划分语义后才能规划训练与评测；本轮不训练、不使用测试集。

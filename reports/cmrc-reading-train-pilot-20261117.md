# 中文自然阅读定位的隔离训练试点

使用 CMRC 2018 官方 [固定版本](https://github.com/ymcui/cmrc2018/tree/c0eb1b6ba219847457e6af3180da722bbeb656af)训练分区（仓库标示 [CC BY-SA 4.0](https://github.com/ymcui/cmrc2018/blob/c0eb1b6ba219847457e6af3180da722bbeb656af/LICENCE)，论文 [Cui 等，2019](https://aclanthology.org/D19-1600/)）。按固定规则选 64 篇不同文章的“谁”等问题；排除所有开发文章的完全相同标题、32 条开发题答案的完全相同字符串，以及训练内重复答案。不能排除别名、其他未选开发答案、语义重复和底座预训练重叠。

冻结 DeepSeek 与孢子运行时，从[多问法查询候选](fact-paraphrase-train-20261117.md)继续训练定位头 400 步：自然阅读批次和 32 条人工有答案／无答案重放批次交替。64 条自然训练例中有 63 条可按当前词元边界表示，1 条被排除；不使用答案所在句裁剪，训练和测试都输入全文与问题。自然素材只有正例，人工无答案重放不能代替自然无答案测试。

| 检查 | 训练前 | 训练后 |
| --- | ---: | ---: |
| 32 条已查看自然开发题：精确位置 | 0 | 5 |
| 同组：错选片段 | 10 | 26 |
| 同组：暂缓 | 22 | 1 |
| 人工同类干扰：已知精确 | 16/16 | 16/16 |
| 人工同类干扰：无证据误选 | 0/8 | 0/8 |
| 人工同名：误选 | 0/8 | 0/8 |

63 条可表示训练例中，训练后精确 14 条、错选 47 条、暂缓 2 条；因此这不是“已学会阅读”。自然开发集从全无精确匹配增加到 5 条，同时错误选择显著增加。与上一次按答案文本比较不同，本次按**精确词元位置**比较；当前开发集答案在原文只出现一次，仍不能代替语义人工评审。小规模人工回归通过不能推断真实未知问题安全。

答案可能是人物、机构或其他实体；数据集标注是阅读答案，而非真实身份、个人经历或写入授权。训练和评估使用完整上下文，不使用孢子持久记忆，没有自然对话、多主体事实写入、崩溃恢复或生成测试。已看过的开发材料非密封测试。不能据此把候选用于正式个体。

下一步应检查训练不足、长文本位置与问题信息如何进入候选分数，并以相同数据和算力比较更合适的交互结构；同时引入许可明确且经过复核的自然无答案负例，按文章和实体隔离评估。不能仅靠更多正例放大错归属。

训练数据固定 Git blob 后下载并仅留本机，来源、摘要和不含原文的选择清单保存在 `runs/cmrc-train-pilot-manifest-20261117.json`。脚本 `scripts/prepare_cmrc_train_pilot_20261117.py` 和 `scripts/deepseek_cmrc_reading_train_pilot_20261117.py`；候选与详细计数在 `runs/deepseek-cmrc-reading-train-pilot-20261117/`。底座、数据及候选源摘要前后校验，正式个体未参与。约 279 秒，GPU 峰值约 3.57 GiB；5 项数据与重放构造检查通过。实验仍依赖部分本机未跟踪研究文件，仓库单独检出尚不能完整复现。

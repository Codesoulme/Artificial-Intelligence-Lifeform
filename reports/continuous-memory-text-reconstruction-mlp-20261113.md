# 非线性语义桥文本重建试验

## 方法

在线性语义桥文本重建基础上，将连续槽到词向量的桥替换为两层 GELU MLP，并将桥预训练步数从 400 增加到 800。文本回答头和训练数据保持一致：训练人物为小林、小周、小王，留出人物为小赵。

## 结果

- 训练人物完整句：54/54 exact。
- 留出人物事实内容：18/18 包含正确水果。
- 留出人物完整句：0/18 exact。
- 留出人物输出姓名统一偏向训练人物“小王”，水果事实仍全部正确。
- 语义桥余弦重建损失降至约 0.455，较线性桥没有带来身份输出改善。

## 判定

增加桥接器容量不能解决身份泛化。连续记忆中的事实槽能够支持留出事实内容重建，但文本头对身份槽没有形成可泛化绑定。下一步应为身份 token 建立独立监督目标，分别评估身份恢复、事实恢复和最终句子组合；继续扩大桥接器没有依据。

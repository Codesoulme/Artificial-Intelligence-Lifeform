# 多词元记忆答案训练试验（2026-11-12）

训练脚本不再假定事实只有一个词元：先在完整目标答案中查找唯一连续的事实词元序列，直接答案分支对整个序列及结束标记计算损失。找不到、为空或出现多次均拒绝训练；针对单词元、多词元、重叠重复和缺失情况的两个单元测试通过。当前对比分数仍只比较事实的首个词元，不表示完整序列概率或全词表排名。

在隔离副本中，使用四个人物、两种问法和八种饮品（64 条条件），训练 128 步；每步完整句与直接答案各占一半，主体冻结。保留两个人物、一种新问法和五种已训练饮品，共十条。可乐由两个词元组成，此次在两个人物的状态中均作为当前事实，内部数值首选查询均正确；旧值、地址与事实仍由程序指定。

两道保留可乐题在训练前后都没有回答可乐：一道持续给出健康饮食建议并被截断，另一道从建议联网查询变成无意义片段。标准完整答案前缀下的损失分别从约 2.965 降至 2.857、2.725 降至 2.532；这不等于自由生成学会了答案。十道保留题严格短答案由 4/10 变成 5/10，新增的是果汁而非可乐；四条训练样例抽查由 1/4 降至 0/4。两条完全不接记忆的普通请求输出逐词不变。

这证明训练流程能处理并监督一个两词元饮品，但没有证明读取器能可靠表达它。样例、实体和类别有限，保留名字及相关问法在前期开发中出现过，不能视为真正独立验收。下一步应加入更多多词元、共享词首和非饮品事实，并固定从未参与调参的测试，检查前缀与完整序列的条件概率、实际生成及无关记忆。

脚本 `scripts/deepseek_spora_reader_full_answer_pilot.py`，测试 `tests/test_reader_answer_token_span.py`；隔离候选及完整记录位于本机 `runs/deepseek-spora-reader-multitoken-mixed-20261112`。峰值分配显存约 3.51 GiB；底座、原检查点与真实个体经摘要核验未变，候选未采用。

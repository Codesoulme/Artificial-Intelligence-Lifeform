## 结论

**最值得开展小规模质量试验的是 Frontiers for Young Minds 中文科普**：三个具体中文全文页面可读，均在文章处链接 CC BY 4.0；其中一篇是站点标示的中文撰写与审阅文章，另两篇有明显译文或英文来源线索。文章面向青少年，适合检验通俗、连续的解释性文字，但目前只确认至少 13 个不同的文章链接，无法证明可用正文总规模、总体质量或各篇权利链，也不能代表广泛日常会话。

**国立台湾史前文化博物馆学习单**的三个新资源目录及小型 JSON 实际可访问，目录声称使用政府资料开放授权条款第 1 版，但返回的主要是题目和附件地址；样本网页没有连续正文，附件是否属于相同授权范围未核。它适合作为逐项追查线索，暂不适合文字试验。WHO 出版物有逐项标示许可的候选，但本次所试中文附件被拒绝；WHO 普通网页与 UNICEF 页面也不能因为公开可读而视为开放训练文本。

许可链接和声明对应各自文章页面，而非仅凭期刊首页推测。CC BY 4.0 规定署名、链接许可并标明修改等条件；还须按实际训练、文本处理及成果发布方式评估适用义务。文章中的图片、引用、外部内容、翻译及署名可能有独立权利；公开许可不是对本项目拟定用途的专门确认。应保存每篇的文章地址、DOI、作者、译者（如有）、取得时间、原页面和许可链接，且去除联系方式与少年个人资料。

### 小样本与提取方法

本次以 `curl.exe --ssl-no-revoke -L` 实际读取三个页面，HTTP 返回 200；HTML 字节数分别为 82,899、84,896、86,798。使用 BeautifulSoup 选 `.fulltext-content`，依次得到 6,869、5,360、4,862 个字符，其中 U+4E00–U+9FFF 汉字分别 4,262、2,998、2,287 个。**这些数字包含摘要、标题、图注、词汇表等，既非清洗后正文，也非词元或质量合格量。** 已观察到页面将作者及少年简介放在正文容器之外，但单靠此选择器仍会混入其他内容；还需要逐段对照原页，清理图注、参考文献和依赖图片的段落，避免损伤句义。未保存文章正文文件。

最低可复现的单篇读取方式（网络请求一次；仅打印概况，不写正文）：

```python
import subprocess
from bs4 import BeautifulSoup

url = 'https://kids.frontiersin.org/zh/articles/10.3389/frym.2025.1479697-zh'
html = subprocess.run(
    ['curl.exe', '--ssl-no-revoke', '-fsSL', '--max-time', '20', url],
    capture_output=True, check=True,
).stdout
page = BeautifulSoup(html, 'html.parser')
body = page.select_one('.fulltext-content')
assert body is not None
print('HTML bytes:', len(html), 'container chars:', len(body.get_text(' ', strip=True)))
print('license links:', [a.get('href') for a in page.select('a[href*="creativecommons.org/licenses/"]')])
```

可从[中文目录](https://kids.frontiersin.org/zh/articles)读取文章链接，或先查看 [robots.txt](https://kids.frontiersin.org/robots.txt) 和[站点地图](https://kids.frontiersin.org/sitemap.xml)；页面提供各篇 PDF 下载入口，本次以 HTML 为准。目录首页返回 12 个链接，但分页、完整清单及重复译本未验证，**不能以 12 或 13 推算总量**。后续先冻结少量按主题和原文/译文分层的样本，人工核查抽取忠实度、完整句段、通俗程度与许可；按 DOI、翻译关系和相似内容分组，避开既有训练与评测材料。医疗内容应单列时效与专业审核。

## 3. 机构正文：许可和可访问性须分别判断

**WHO。** [《烟草与不孕不育症》出版物页面](https://www.who.int/zh/publications/i/item/B09819)提供中文概述、出版单位和页数；页面版权图标链接至 [CC BY-NC-SA 3.0 IGO](https://creativecommons.org/licenses/by-nc-sa/3.0/igo/deed.zh)。其 [9 页中文 PDF 链接](https://iris.who.int/server/api/core/bitstreams/dd0f4c52-26d8-40c8-98ac-468d28aa356b/content)本次返回 403，因此无法确认文件内许可文字、实际中文正文、引用或提取质量。非商业与相同方式共享条件及 IGO 特定条款须评估，不能当作 CC BY 4.0 或默认适合商业用途。[WHO 版权政策](https://www.who.int/about/policies/publishing/copyright)讨论明确采用该许可的材料；[网站条款](https://www.who.int/about/policies/terms-of-use)另有版权及使用限制。例如[气候变化与健康](https://www.who.int/zh/news-room/fact-sheets/detail/climate-change-and-health)网页本次可读，但未找到该篇明确的 CC 版本，不能把上述出版物许可套用上去。出版物站可按单项网页发现标题、页数、版权链接和下载地址，附件能否取得须单独测试。

**UNICEF。** 中文首页可读，并链接[儿童版《儿童权利公约》](https://www.unicef.org/zh/%E5%84%BF%E7%AB%A5%E6%9D%83%E5%88%A9%E5%85%AC%E7%BA%A6/%E8%81%94%E5%90%88%E5%9B%BD%E3%80%8A%E5%84%BF%E7%AB%A5%E6%9D%83%E5%88%A9%E5%85%AC%E7%BA%A6%E3%80%8B%EF%BC%88%E5%84%BF%E7%AB%A5%E7%89%88%EF%BC%89)等面向普通读者的内容；本次只读了首页入口，没有核验该儿童版全文的独立授权。[法律页面](https://www.unicef.org/legal)称使用其网络材料需事先书面许可，同时指出有些出版物权利另行许可。未经具体作品相反证据，不能把页面可读视为可训练。其 HTML 链接可用于发现作品，但应先找到对应文件的条款再考虑取样。

**StoryWeaver。** [首页](https://storyweaver.org.in/)返回 200，[robots.txt](https://storyweaver.org.in/robots.txt)列出[站点地图索引](https://storyweaver.org.in/sitemap.xml)。站点是潜在儿童读物发现入口，但本次未验证任何具体中文故事、译者、正文或逐篇许可，也未确定中文总数、下载接口或是否与 P84 已收故事重合。故不把网站上的泛化开放宣称当作本文证据；后续须以具体中文作品页和来源为单位检查。

## 4. 使用边界及下一步

1. 先对 Frontiers 另选少量文章，逐篇记录 CC 版本、作者及译者，核实原文与引用关系；固定样本后对照网页完整阅读并评估连续性、自然度、医学与科学表述，分别汇报候选数、可获取数和通过审查数。样本应避开少年资料和联系方式。
2. 对博物馆先确认目录的授权是否覆盖具体附件文字，再对少量文件检查文字层、条目类型和篇幅。对于 WHO，先解决合法访问，并评估具体非商业许可；不得以站点可读或目录标签替代逐篇确认。
3. 目前没有证据表明任何一个来源能独自提供足够规模的高质量通用中文。不要将网页字节、条目数量或机构名等同于可训练汉字量；与既有来源、翻译和评测材料的重叠仍需审查。

访问说明：本机通过 Python `requests` 做部分发现与检查时因证书链错误使用了 `verify=False`，这些请求没有完成 TLS 证书验证，故相应状态与内容证据有链路限制；三个 Frontiers 样本另用系统 `curl.exe --ssl-no-revoke` 成功复核，证书链校验通过但吊销检查未完成。各 URL 的可用性会随网络和时间变化；403、超时、未读取正文或未核实权利均不等于资源不存在。

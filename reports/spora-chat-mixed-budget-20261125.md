# 本机聊天入口的生成预算、记忆查阅与续聊

此前的跨进程记忆实验使用独立入口和 24 词元上限。本轮直接调用 `spora_chat.cmd` 的连续记忆实现，在新建的隔离文件中写入、更正和查阅，再用新进程继续使用同一份记忆。普通对话题覆盖保留限制、更新约定、明确转题及带引号的文本请求。Hy-MultiTurn 将限制保持和精确执行分别评分，本文也分别记录路由、是否传入历史、可逐字核验的要求和实际答复。 [此前的研究入口实验](spora-version-restart-20261125.md) · [Hy-MultiTurn](https://arxiv.org/abs/2607.29196) · [MultiChallenge](https://aclanthology.org/2025.findings-acl.958/)

## 生成预算对照

两个档位都运行相同的 22 个用户轮次，其中 15 轮在写入进程内，7 轮在重启后。按当轮自己的模型回复继续问话。每个档位使用独立的持久记忆与清醒状态文件。两次写入、两次查更正前的值、三次查现值均成功。原用户文件的摘要在执行前后相同。

| 项目 | 64 词元 | 128 词元 |
| --- | ---: | ---: |
| 普通对话进入普通生成 | 6/14 | 6/14 |
| 普通对话通过可逐字核验的要求 | 2/14 | 2/14 |
| 应承接上一轮且实际传入历史 | 2/7 | 2/7 |
| 普通生成自然结束 | 6/6 | 6/6 |
| 两进程共正确查阅 | 5/5 | 5/5 |
| 只改写或评价问题，却读出了记录 | 2/2 | 2/2 |

普通生成最长 45 词元。两档的全部可见答复相同。未进入普通生成的轮次主要返回澄清提示，有时还会针对普通文本提问读出事实。应保留「椅子」和避免「会议室」时，模型已经收到上一轮却只说「好的，我明白了」。跨记忆查阅后要求继续修改提醒时，普通历史被清空，模型也未完成改写。这两类失分需要不同处理。

## 混合会话的修复

带引号且外层明确要求评价、改写或翻译时，先按文字处理，避免引号中的待处理句子进入记忆查询路径。受支持的明确查阅及历史模式仍走原流程。普通历史只写入普通问答。读写记忆时保留这条已有的对话历史，用户明确切换话题时清空。此改动没有增加跨重启的可见对话存档。

修复后的实际入口把两条引号请求都转给文字生成，两次都没有说出已保存的饮品。三次明确查阅仍读对。记忆查阅后的「把椅子换成桌子」收到两轮普通历史，模型却继续写「椅子」和「会议室」。两个引号请求的答复也未完成所需的改写或语言判断。此处用程序断言验证了读取范围和历史传递，并逐题检查生成内容。

同一组 12 轮再启用现有的可选普通请求分类器。进入文字生成的轮次从 5/9 增至 9/9，通过可逐字核验要求的轮次从 3/9 增至 5/9，四条续问全都得到普通历史。三次记忆查阅仍读对，两条引号请求均未输出记录值。该分类器在整个对照中使用原权重，需要单独指定路径启用。

## 原版 DeepSeek 对照

原版模型复读 64 词元档已进入常规解码的六条问句。给它相同的当前问句、实际已经产生的聊天历史和同一个长度上限，逐条核对重组后的提示长度。两版都通过 2/6 条可逐字核验的要求，六条可见答复各不相同。原版在两次改写中复述了明确删掉的词，也没将「椅子」替换成「桌子」。测量针对进入常规解码的六条，剩余问题需要独立的路由对照。

下一轮把同一组用户要求一次性给全和按轮给出，分别观察学生用自己的回答继续时会不会丢掉有效约束。参考 2026 年的规范上下文蒸馏研究，先用无干扰的完整要求建立对照，再对确实受前序回答干扰的轮次补监督。已有读写与引号请求继续作为回归项。 [Canonical-Context On-Policy Distillation](https://arxiv.org/abs/2605.30251) · [SAGE-OPD](https://arxiv.org/abs/2606.19659)

本次针对启动入口、范围和对话状态的 32 项相关单元测试通过。另一路径的 `test_runtime_memory_read_selection` 有四个子例报错，测试替身缺少 `key_count`。128 档首次运行的输出轮次不完整，在新建的独立目录重跑后完成两阶段。逐题日志保存在两个预算目录的 `first.json` 和 `restart.json`，后续复查及原版对照位于 `tokens-64`。

## 复现

预算对照的原始记录来自范围修复前的本机入口。下面的命令在修复后的入口上创建两个独立档案，再执行范围复查和原版对照。新结果应按当前规则解读，修复前的逐题记录保留在本次运行目录。

```powershell
$env:OMP_NUM_THREADS = '2'
$env:MKL_NUM_THREADS = '2'
.\.venv\Scripts\python.exe -u -m scripts.audit_spora_chat_mixed_budget runs/spora-chat-mixed-budget-v1 --budget 64
.\.venv\Scripts\python.exe -u -m scripts.audit_spora_chat_mixed_budget runs/spora-chat-mixed-budget-v2 --budget 128
.\.venv\Scripts\python.exe -u -m scripts.audit_spora_chat_mixed_budget runs/spora-chat-mixed-budget-v1 --recheck-scope
.\.venv\Scripts\python.exe -u -m scripts.audit_spora_chat_mixed_budget runs/spora-chat-mixed-budget-v1 --base-replay 64
```

现有聊天入口支持为普通回复调整上限，名字和历史记忆的读取预算由各自路径决定。

```powershell
.\spora_chat.cmd --ordinary-new-tokens 128
.\spora_chat.cmd --ordinary-intent-head runs/deepseek-awake-ordinary-intent.pt
```

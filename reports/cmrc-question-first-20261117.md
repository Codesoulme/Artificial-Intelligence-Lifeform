# 问题前置的自然阅读对照

底座按因果顺序产生特征：问题在段落之后时，前面的候选词元不能直接读取后面的问题；已有[因果特征诊断](causal-subject-diagnostic-20261117.md)验证过相近限制。将输入改为“问题、资料”，候选词元能够访问前置问题，但这也改变了位置、格式和训练分布，不能单独证明因果方向是主要瓶颈。

首先只调整输入、不改[现有自然阅读头](cmrc-reading-train-pilot-20261117.md)：32 条已查看开发题均可表示，问题前置后精确 4/32，原顺序精确 5/32。该头未使用前置格式训练，属于分布外检查。

随后从同一旧候选重新训练，使用同样 63 条可表示自然训练样本、32 条人工正负重放、400 步和优化设置；自然问题放在前面，人工重放保留原格式。与原顺序训练对照：

| 训练后 | 问题在后 | 问题在前 |
| --- | ---: | ---: |
| 自然训练题精确 | 14/63 | 13/63 |
| 自然开发题精确 | 5/32 | 5/32 |
| 自然开发题错选 | 26/32 | 27/32 |
| 自然开发题暂缓 | 1/32 | 0/32 |
| 人工同类无证据误选 | 0/8 | 0/8 |

本批固定开发题上没有观察到精确数提升，仍有大量错选。单次、小样本结果不能排除其他结构或更充分训练下的收益。自然数据没有无答案标签；人工负例与自然题格式不同，不能证明无证据拒答。输入是全文，未测身份、记忆、真实写入或生成，也不能把数据集答案当个人经历。训练／开发文章和精确答案隔离及其他限制见[原试点](cmrc-reading-train-pilot-20261117.md)。

下一步应扩大独立自然样本、检查候选位置与问题信息的真实交互，同时使用经复核的自然无答案题及未见表达。不能将这批已反复查看的开发题当成最终验收。

只读顺序检查脚本 `scripts/deepseek_cmrc_question_first_probe_20261117.py`；同预算训练入口 `scripts/deepseek_cmrc_question_first_training_20261117.py`。结果与候选留在本机 `runs/`，底座、数据与来源权重前后核验，正式个体未参与；训练约 308 秒、GPU 峰值约 3.58 GiB。5 项输入转换及训练数据检查通过。脚本仍依赖部分本机未跟踪研究文件，单独检出仓库尚不能完整复现。

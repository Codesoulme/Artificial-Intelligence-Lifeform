# 联合 codec 梯度链路修复

审计发现记忆快照的复制处于 `torch.no_grad()`：即使请求保留梯度，投影与语言损失之间仍断开。检查五个候选的 projection，全部逐位相同。原联合 codec 报告中关于投影已参与优化的结论撤回；语言适配器的生成结果属于原配置的实测，不因此自动作废，也不能证明 codec 更新有效。

修复将保留梯度的快照复制移到无梯度作用域外；默认快照仍 detach。训练结束后刷新码本并重建评测记忆，使写入使用更新后的投影。当前研究入口对多事件与纠正序列主动拒绝，因为其评测状态刷新尚未实现，不改变正式个体。

在相关 24 个词元上，旧候选保存的码本与其投影计算结果最大坐标差约 2.53e-7，旧码本 top-1 为 24/24；这说明此次发现的旧码本不一致并非已观察到的大幅漂移。投影始终未更新才是旧实验的关键问题。

128 步隔离试验 `runs/deepseek-spora-joint-codec-gradient-repair-20261115/` 中，第一步梯度为零（语言适配器零初始化）；第 50、100、128 步约为 0.03、0.01、0.02。相对起始候选，投影最大绝对变化约 0.001829，变化范数约 0.1534。训练后留出人物 memory 与 swapped 均为 0/12，训练人物 memory 为 0/36；这是短程诊断而非充分训练，也不能视为能力突破。

相关写入、快照、集成推理和语言桥测试 31 项通过；另有针对刷新码本与可微编码一致性的测试。尚未对新候选做独立进程重载、真实多轮、旧能力保持或开放关系评测，因此不接入正式个体。下一步需运行同起点、同种子、同训练步数的投影冻结/解冻对照，并在独立重载中逐项比较反事实与普通对话。

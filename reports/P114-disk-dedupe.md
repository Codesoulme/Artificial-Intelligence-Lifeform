# P114 磁盘支撑的候选故事分组

状态：实现、小规模合成测试和万条合成基准完成，不能据此认定 20 万条真实数据可在本机完成。本工具不训练，也不读取其他数据集；执行者必须确认输入确属获准处理的候选文件。

## 算法与范围

逐行读取 JSONL，原始记录、前缀、签名桶、候选对、并查关系和组成员均放在 SQLite；不把全体故事、特征集、候选对或分组放入 Python 容器。每次只在内存中持有受单行长度限制的一条记录及其特征，核验时持有两条。精确原文相同或 NFKC、casefold、去空白之后的前 96 字符相同，直接合并。短文本取全部前缀。仅原文完全相同的记录不重复参与索引；同前缀但原文不同的记录仍各自参与，以保留桥接关系。摘要相同还会比较原文，避免单凭摘要认定完全相同。

近重复索引使用全部 NFKC 后汉字序列的字符五元组，包含代码中列出的扩展区，先删除其他字符。固定哈希的 32 项 MinHash，按 8 组、每组 4 项生成确定性候选。所有高频特征均保留，不沿用 P113 的高频剔除；这并不能保证真实数据的隔离率低。每个候选对以两个完整集合计算真实 Jaccard，达到阈值（默认 0.8，含等号）才连边；最后取连通分量，最早输入行是代表。输入顺序是结果定义的一部分。

桶按签名排序；超过 `--max-bucket` 的整桶不比较。按桶中全部可能对数保守预留 `--max-pairs` 预算，超预算的整桶不比较，即使某些对已经在其他桶被处理。每个被跳过的桶列在 `unchecked_buckets.jsonl`，签名与桶成员可在 `index.sqlite3` 的 `buckets` 表关联；所有相关成员所属连通组进入隔离。少于五个汉字的记录也隔离。精确重复行通过连通关系继承风险。由于未检桶可能连接多个组，隔离的组不能当成已完成去重的结果。

LSH 本身可能漏掉阈值以上的对，未触发隔离也不代表完整覆盖；字面特征无法保证识别语义改写。传递合并可能使组内两端相似度低于阈值。此工具只处理指定文件内部，不证明与任何其他数据之间的隔离，也不能据此宣称语义全面隔离。

## 输入和输出

输入行要求 `text`、`group`、`sha256` 字符串。普通格式的 `sha256` 是原文 UTF-8 摘要；P112 格式还带 `source_original_sha256`，其值必须匹配原文，而 `sha256` 必须匹配文本经 NFKC、去除正则空白、`lower()` 后的 UTF-8 摘要。两种规范化用途不同：摘要使用 `lower()`，组前缀使用 `casefold()`。空行、无效 JSON、摘要不符或超长行会失败。

```powershell
python -B scripts/p114_disk_story_dedupe.py --input D:/path/candidate.jsonl --output D:/SPORA/runs/p114-example --max-memory-mib 256 --min-available-mib 1536 --max-disk-mib 2048 --max-pairs 1000000
```

输出目录须为 `runs` 下不存在的新目录，父目录须存在；不会覆盖或删除已有文件。`candidates.jsonl` 是无已知风险组的代表原始记录，`quarantine.jsonl` 是隔离组的所有原始记录。`groups.jsonl` 每个输入行一条，包含代表行、状态、原因；`unchecked_buckets.jsonl` 记录未检桶；`summary.json` 包含计数、参数、输入及输出摘要、采样资源与局限。`index.sqlite3` 含原文和中间索引，输出目录因此必须按原始数据处理，不得提交。`failure.json` 标记失败阶段及异常，失败目录内所有部分输出不可使用；极端磁盘耗尽或进程被外部终止时该文件可能无法写出，必须以存在成功摘要为完成条件。

默认 SQLite 缓存 16 MiB，默认单行上限 128 KiB，可用 `--cache-mib`、`--max-line-bytes` 调节。`--max-disk-mib` 同时设置数据库页数上限和目录大小采样阈值；`--max-memory-mib` 检查本进程提交量，`--min-available-mib` 检查系统可用物理内存。程序在读取、桶、核验、输出阶段周期检查，达到限制时停止并尝试写故障记录。SQLite 临时文件、回滚日志、输出缓冲及单次数据库操作可能在检查之间增长；这些是采样保护而非操作系统硬配额，目录大小阈值不包括系统临时目录。磁盘需预留额外空间，且 Windows 为当前唯一支持资源检测的平台。实际速度与磁盘开销取决于故事长度和重复分布，不可将小样本线性外推。

# P65 OpenAssistant 2 中文候选审查

从 [OpenAssistant/oasst2](https://huggingface.co/datasets/OpenAssistant/oasst2) 的固定版本 `179dd21fc55192153d94adb0e0ce8f69e222bf75` 获取 ready 消息文件；54,301,900 字节，SHA-256 `a9f240c4c77aa1378364f70d37e753c07ba284e247b019d700e1947a0e5da751`，与远端元数据一致。数据卡声明 Apache-2.0；该声明不等于每条内容事实可靠。

源文件有 8,615 条语言标注为中文的消息，其中 3,448 条消息 ID 也出现在本地 OASST1 ready 文件。复用审查标签阈值和机械风险筛查后，可重建 262 条完整角色交替路径，其中 77 条至少含两轮用户交互；这是路径数，不是独立对话树数。按旧消息 ID 排除、每棵树只保留一条、限制长度和排除现有开发题精确全文后，生成 63 条训练候选、7 条开发候选；训练候选仅 16 条多轮。开发集按树分组，但其他数据的近重复尚未排查。

用种子 651109 从训练候选抽取 20 条，检查每轮开头至多 240 字，并非全文审核。样本中出现商业宣传及未经证实的商品属性、可能过时的产品事实、第一人称亲历、错误或可疑的自然科学解释、可能混淆历史人物与演义的引语，及答非所问或术语错误。来源标签和自动过滤不足以保证语义、隐私或事实质量；样本小且仅看前缀，不能据此估计总体错误率。

结论：整个候选集**不批准训练**。若要进一步使用，需逐条完整复核、核对事实及身份表述、检查旧数据与评测集近重复，再生成新的、绑定摘要的子集。候选和源文件位于本地 `runs/`，未上传或用于训练。`scripts/prepare_oasst2_candidate.py` 保存了可复现的来源、角色和树分组处理规则；未完成的语义隔离仍是明确限制。

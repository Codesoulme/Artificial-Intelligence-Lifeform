# 六人交错写入与记忆回答复核

使用第 9 层记忆残差候选，登记六个姓名并在三个进程间交错写入。第一次保存后，每人有两个版本。第一次重载后逐题复核，再为每人写入第三个版本。第二次重载只读。六次登记和十八次事实写入共产生 24 次提交。

每次读取共 21 题。六个人各查当前、旧值和新版本，另有三道未登记姓名题。题目中的姓名由调用方确认。三道拒读始终通过。两个重载阶段的逐题记录与各自的重载前结果一致。

| 条件 | 由模型选择时间 | 提供正确时间 |
|---|---:|---:|
| 每人两个版本 | 11/21 | 13/21 |
| 每人三个版本，原输出层 | 12/21 | 14/21 |
| 每人三个版本，训练完整词序列输出层 | 18/21 | 21/21 |
| 将新输出层封装进检查点并重新读取 | 18/21 | 21/21 |
| 对拒读追加一次新版本判断 | 21/21 | 21/21 |

原输出层在时间正确时，内部事实读取已通过 18/18 道正例，最终回答只正确 11/18。典型错误是内部读到「豆浆」，回答生成「水」。新输出层用已读出的神经证据生成完整词序列。它分别在已经写好的实验库，以及封装后重新写入的库中运行，逐题输出一致。三个普通语言短题的生成词元在封装前后完全相同。封装比较确认，除输出适配器以外的检查点元数据与张量一致。

错误还集中在「刚换上的单子」这种问法。模型在六道题里拒读三道。给定时间后回答全部正确，说明这三个样本的故障位于时间选择。

把已确认姓名替换为统一称呼后，这组六道题的正确数从 3 降为 0。单独补充更正问法和拒读对照后，新分类器答对了六道，但在旧版时间留出中丢掉了部分当前和历史题。因此仅当原分类器拒读且新分类器强判「更正后」时启用补充判断。该规则在已测对照中恢复了三道正例。新的独立问法仍暴露原分类器会误读个别无读取意图的句子，因此这个结果限定在已确认姓名的受控实验中。

结果位于 `runs/named-memory-interleaved-v1/`。输出层训练记录位于 `runs/named-memory-layer9-counterfactual-reply-v1/`。独立生成和重载记录位于 `runs/named-memory-layer9-packed-reply-v1/`。

## 本地入口

在 `D:\SPORA` 下运行以下命令。入口串接已经验证的检查点、两个时间判断模块和个体数据库。第一次运行会创建个体，下一次运行会重新打开同一个数据库。

```powershell
Set-Location D:\SPORA
.\.venv\Scripts\python.exe -m scripts.spora_named_memory_chat
```

可以直接输入中文，或使用 `/登记 小芮`、`/记 小芮 豆浆`、`/查 小芮 小芮现在登记的饮品是什么？`。把饮品改为可乐后重开程序，当前查询返回可乐，更正前的查询返回豆浆。对未登记的「小芮璇」返回未登记。以上操作已在独立实验库用两个进程复测。当前记忆入口覆盖八种饮品，普通对话仍需通过独立中文多轮验收。

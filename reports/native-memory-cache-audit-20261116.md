# 原生记忆读取与生成历史对照

## 方法

使用 DeepSeek 底座和两层孢子替换候选，以隔离状态给一个已知人物分别设置咖啡和水。程序直接指定同一个数字地址，使用当前记忆读取器，不传入词表输出适配器的证据。对同一问题分别在生成时开启和关闭历史缓存，贪心生成最多 24 个词元。另对一道算术题强制注入无关的咖啡记忆。每次生成使用独立快照和新历史。

## 结果

两条记忆题分别回答“咖啡”和“水”，均正常结束；启用与关闭缓存的输出词元完全一致。算术题两种方式也完全一致，均回答五本，正确答案应为四本。

该算术题在本轮只有强制读取条件，没有单独测量关闭读取的结果；因此不能单凭本轮断言错误由注入造成。更早的配对实验观察到注入前后答案变化，但两项实验均使用已反复研究的题目。

运行约 104 秒，CUDA 峰值分配约 3.45 GiB；底座、来源检查点和临时记忆摘要前后相同。第一次运行因重复传递 `use_cache` 在生成前报错，修正实验脚本后重新运行；结果记录于本机 `runs/deepseek-spora-native-memory-cache-audit-20261116.json`。

## 边界

这是一个人物、两个有限值和一道普通问题的开发检查，问题、人物和值均曾用于研究。地址由程序指定，使用关闭思考前缀，未验证自然写入、自动识别人物、开放式回答、跨轮缓存复用或长期记忆恢复。逐词元一致只适用于本次测试，不保证不同精度或采样条件下的生成一致。

# 联合姓名片段实验：未通过

## 方法

在冻结的 DeepSeek/SPORA 前 21 层特征上，训练一个同时给开始和结束位置打分的小型片段头，并设置一个无答案选项。它与现有逐词定位器比较；这只是独立研究组件，没有接入聊天运行时或操作真实个体。训练使用 CLUENER 训练数据提取的 64 个姓名及人工姓名变体、无人和多人问题，共 216 条，随机抽样训练 1200 步。评测使用校验集选出的另 20 个姓名及其人工前后缀变体，外加 8 条无人及 8 条多人问题；两个姓名集合的完整字符串不重合。所有训练和评测姓名边界可用当前词元切分准确表示。

## 结果

| 指标 | 原定位器 | 联合片段候选 |
| --- | ---: | ---: |
| 已登记姓名完整定位 | 3/20 | 17/20 |
| 后缀新姓名被截成登记姓名 | 3/20 | 15/20 |
| 前缀新姓名被截成登记姓名 | 0/20 | 0/20 |
| 无人问题错误选中姓名 | 3/8 | 0/8 |
| 多人问题选中单一片段 | 0/8 | 8/8 |

新候选虽然更常找对已登记姓名，但也明显增加了后缀误配，并在全部八个人工多人问题上选择了单一片段。后缀被截短后若用于已登记姓名匹配，可能指向错误的人；这是片段和字符串层面的代理指标，本次没有实际执行记忆读取，不能将其称为实际误读次数。多人问题在此实验中一律视作应拒绝，实际系统还需结合提问意图判断。

## 解释与局限

训练时三种姓名变体分别固定搭配不同问法，模型可能学到措辞与边界的关联；这只是待验证假设。后缀训练始终使用“子”，评测使用“月”，因此不能区分新后缀、新问法及其组合的影响。姓名子串重合、底座预训练重合未知，CLUENER 校验集和其中姓名已用于先前开发，数据属于人工短句，不能作为独立泛化评测。前 21 层特征与完整模型只在另外十例上做过一致性验证。训练过程中单样本损失下降不代表模型泛化。

**判定：不部署，不替换现有定位器。** 下一轮应先打破问法、姓名形态与标签的固定对应：每个姓名以多种问法和前后缀交叉组合，并将姓名家族、问法及后缀分别隔离；单独评估不同变化来源、多人拒绝与已登记召回。最终还需使用未经调参的自然对话和真实路由进行端到端验证。

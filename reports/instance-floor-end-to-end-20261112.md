# 实例级读取下限端到端验证（2026-11-12）

使用 v7 读取意图候选、v5 时间候选和临时四人物状态；每个人物写入旧值“咖啡”和当前值“水”。通过 `SporaChat.read_intent_recovery_floor = -1.0` 设置低门槛，未修改模块全局常量。对当前、过去、后续三种问题各运行三个人物，并记录实际时间类别、地址和最终答案。

三类问题均为 3/3 正确路由和 3/3 严格答案正确；读取过程中临时状态摘要保持不变，候选权重和源检查点摘要也未变化。这确认低门槛可通过实例属性进入真实 `answer()` 路径，且不需要 monkey-patch 全局变量。

这是受控开发样例：事实和地址由程序写入，问法数量少，v7 和 v5 候选仍未在独立开放问法上证明泛化。低门槛实例选项不会自动解决未知姓名、时间歧义、事件缺失或错误输出，默认实例仍使用 `2.0`。

脚本 `scripts/deepseek_spora_instance_floor_runtime.py`，结果位于本机 `runs/deepseek-spora-instance-floor-runtime-20261112.json`。该验证没有修改真实个体或默认检查点。

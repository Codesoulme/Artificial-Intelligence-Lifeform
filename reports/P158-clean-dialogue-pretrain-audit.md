# P158 大规模中文连续语料训练侧审计

本轮只读取 `runs/clean-dialogue-v2/pretrain-train.jsonl`，没有打开开发或封存测试正文，也没有启动训练。该文件是当前本地候选中规模最大的连续文本材料之一，来源仍是混合的本机非商业研究语料，manifest 版本摘要固定为 `f7c17dec3f6508a44ceab4187583db50ddfa08fd4d687642b997e7e765f79ec1`。

流式审计结果：

- 1,085,328 条记录；
- 1,083,315 个唯一 group；
- 381,308,737 个字符，约 380,223,409 个下一字符目标；
- 训练分区文件摘要为 `4ec0b001db65b7ccabfaa064e56ce6dff3bbf0bb0a3890c116f4b99999bae9a1`；
- 封存测试分区未读取，训练未启动。

机械风险计数如下：

| 信号 | 数量 | 占记录 |
|---|---:|---:|
| 低汉字比例 | 99,297 | 9.149% |
| PII 模式 | 890 | 0.082% |
| 身份/经历暗示 | 4,288 | 0.395% |
| 明显重复片段 | 3,370 | 0.311% |
| URL | 2,459 | 0.227% |
| 问答或角色标记形态 | 1,535 | 0.141% |
| 重复 group 行 | 2,013 | 0.186% |

这些规则只提供阻断线索，不是语义、事实、权利、隐私或人工质量认证。尤其是低汉字比例和身份词命中都可能误报，未命中也不能说明记录安全。来源混合、事实正确性、语义近重复、上游权利和训练/评测隔离仍未完成审查。

当前决定：候选保持 `candidate_not_approved_for_training`，不进入语言训练。它的规模足以成为后续分域、分来源、分长度盲审的对象，但不能用 3.8 亿字符的总量覆盖上述质量和权利缺口。下一步应先对固定分层样本做正文审查和来源隔离，再决定是否构造一个规模较小、可追溯的训练子集。

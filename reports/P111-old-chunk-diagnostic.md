# P111：旧流分块采样诊断

将 P110 旧训练流的单文档窗口换成不重叠目标分块，以固定种子等概率抽块；短文整篇为一块，长文按最多 512 个目标分块，每块保留目标前一个词作为起始上下文。其余采用 P110 的共同父检查点、50:50 来源预算、均匀短故事采样和价值观重点回放。这个方案使每个旧流目标的理论抽中概率相同，但每批目标数及损失归一化仍影响梯度权重；长文分块起始可见历史也比旧方法短。两组随机轨迹及实际目标数不同，不能单独归因于某一机制。

新增 `scripts/train_p111_chunk_coverage.py`，分别记录旧流及故事流的本次监督位置；替换为重点文本的行从原来源覆盖中扣除。采样器、边界、覆盖及恢复使用合成测试验证，历史入口和检查点保留。实际实验以新目录分段运行：50 步时总目标 432,663，其中旧流原始目标 216,168，记录为 1,020 篇、216,168 个本次不同位置；故事原始目标 216,405，其中 215,738 个本次不同位置。第 50 步个体张量精确保持、合成探针 `[7,5,9,3]`，之后从检查点恢复至 200 步。

旧流并非新收集或完全通过质量审核的语料，模型初筛发现大量规则候选仍有指令、列表或其他缺陷，见 P111 抽样报告。此实验是采样诊断，并非证明这些材料质量达标或模型已具备聊天能力。

## 200 步结果

| 指标 | P110 单文档窗口 | P111 非重叠分块 |
| --- | ---: | ---: |
| 全部目标呈现 | 1,740,459 | 1,717,966 |
| 旧流目标呈现 / 本次不同位置 | 870,264 / 未记录 | 858,524 / 857,184 |
| 故事目标呈现 / 本次不同位置 | 869,886 / 850,090 | 859,133 / 841,182 |
| 旧文本：固定文档内目标 NLL | 3.5207 | 3.5085 |
| 旧文本：固定拼接窗口 NLL | 3.4340 | 3.4340 |
| 对话开发 NLL | 3.3279 | 3.3212 |
| 故事开发窗口 NLL | 2.6767 | 2.6776 |
| 24 轮开发结束 / 明显循环 | 9 / 8 | 14 / 8 |

固定文档内比较使用相同 32 个窗口和 16,307 个目标，父模型 NLL 为 3.5120；旧拼接窗口和故事窗口使用不同目标，不能直接相互比较。分块组在该文档内指标上略低，但只有一个种子，训练中实际目标数、上下文和抽样顺序不同；不能将差异单独归因于采样，也不能由 NLL 推断聊天能力。覆盖仅限本次运行；相同位置可能已被祖先见过，P110 没有旧流位置追踪，无法直接比较不同位置数。

将两个分支共 48 轮开发回答打乱并隐藏分支身份，由两个模型实例逐轮盲评：P110 组 0 轮有用、24 轮无用，P111 组 1 轮有用、23 轮无用。每项的匿名标识、场景和轮次已核对；其中两个场景的分支由不同实例评分，后续轮次也依赖各自先前回答。这是模型评审，不是人审或最终验收，结果不支持聊天突破。

P111 的训练与监测记录约 256 秒；重点文本 309 个目标，原个体张量精确保持，合成探针 `[7,5,9,3]`。真实运行从第 50 步检查点恢复，但尚未在真实模型上与连续 200 步逐张量比较；合成恢复测试的通过不应冒充该验证。数据和模型输出留在 runs，未访问最终测试。
